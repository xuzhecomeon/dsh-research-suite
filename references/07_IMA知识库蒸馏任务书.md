## 〇、为什么需要"结构化蒸馏"而不是"让 ima 总结一下"

我要的是能**直接变成技能条目**的内容——方法决策规则、R 代码、参数、踩坑点。
如果 ima 输出的是"本文介绍了 X 方法，具有重要意义……"这类综述腔，我无法使用。

**三条硬要求**：
1. **卡片化**：每个主题一张卡（不是一篇连贯文章）；
2. **可执行**：必须带 R 代码 + 函数名 + 关键参数；
3. **可溯源**：每张卡标注它来自库里的哪几个文件标题（我会用已爬取的标题清单交叉核验，防止 ima 编造）。

## 一、通用输出规范（先看这条，每个库都要遵守）

### 1.1 文件格式
- **Markdown（`.md`），UTF-8 编码**。若 ima 只能导出 docx/txt，也可（我能读），但优先 md。
- 每个文件**开头必须有这段头部**（便于我程序化归类）：

```markdown
---
kb_name: R语言包            # 知识库名称
kb_id: 9kwPEw2idx_...        # 可选
batch: 1/4                   # 第几批 / 共几批
topic_scope: 回归与生存分析   # 本批覆盖的主题范围
source_files_read:           # ★ 本批实际读到的库内文件标题（用于交叉核验）
  - survival.pdf
  - rms.pdf
generated_at: 2026-09-29
---
```

- 文件命名：`IMA-<库名简称>-<批次号>-<主题>.md`
  例：`IMA-R语言包-01-回归与生存.md`、`IMA-一起学统计-03-缺失数据.md`

### 1.2 卡片模板（★ 核心，每个主题一张）

```markdown
### 【卡片 07】Logistic 回归的事件数要求（EPV）

- **适用场景**：二分类结局、拟纳入多个预测因子时，估算最小样本量或判断现有数据能否建模
- **前提/假设**：EPV = 事件数 ÷ 参数个数；分类变量按哑变量个数计参数
- **R 实现**：
  ```r
  # EPV 计算与预警
  n_event <- sum(d$outcome == 1)
  n_par   <- length(coef(model))
  cat("EPV =", round(n_event / n_par, 1))
  # 参考：pmsampsize 计算最小样本量
  pmsampsize::pmsampsize(type = "b", csrsquared = 0.1,
                         parameters = 8, prevalence = 0.2)
  ```
- **关键输出怎么读**：EPV < 10 提示过拟合风险；pmsampsize 取四准则最大值
- **常见错误/坑**：① 把样本量当分母（分母必须是事件数）；② 分类变量只算 1 个参数
- **报告写法**：
  - 中文：本研究事件数为 {n}，纳入参数 {p} 个，EPV = {值}，满足建模要求
  - 英文：With {n} events and {p} parameters, the events-per-variable ratio was {value}
- **库内依据**：《XXX.pdf》《YYY》（写清标题，勿写页码）
- **补充/存疑**：库内未涉及的，单列并标注"库外补充"
```

**没有 R 代码的主题**（如概念辨析）省略代码块，但必须保留"适用场景 / 坑 / 报告写法"三栏。

### 1.3 反面清单（ima 的常见输出，视为不合格）
| 不合格写法 | 为什么不行 |
|---|---|
| "X 方法是一种重要的统计方法，广泛应用于……" | 无操作信息 |
| 只给公式不给 R 函数 | 我用不了 |
| 编造库内不存在的文件标题 | 我会核验，编造会破坏整批可信度 |
| 大段摘抄书原文（超 200 字连续引用） | 版权风险 + 我无法内化；要"要点 + 自己的话" |
| 把 6 个库混在一个文件里 | 无法定位来源、无法分批 |

1. **核验**：用我已爬取的标题清单（6 个库共约 3 万条标题）检查每张卡的"库内依据"是否真实存在 → 剔除编造内容；
