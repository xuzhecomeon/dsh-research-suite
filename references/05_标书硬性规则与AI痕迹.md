# 标书硬性规则与 AI 痕迹清单

> 来源：ima 永久记忆导出（条目日期见下，源自评审专家反复反馈后沉淀）
> 适用范围：科研标书 / 国自然申请书 / 学术论文正文的硬性规范。

---

## 一、格式硬性规则

- **中文字体**：标题黑体，正文宋体
- **英文字体**：标题与正文统一 Times New Roman（英文 / 数字）
- **页面**：A4；页边距**上 2.5 / 下 2.5 / 左 3 / 右 2 cm**；正文 1.5 倍行距或 20 磅行距
- 正文段落**首行缩进 2 字符**；参考文献段落**悬挂缩进 2 字符**
- 不同层级标题（1 级 / 2 级 / 3 级 / 4 级）必须**统一格式**
- **用户偏好**：每次输出 Word 文档时，必须按本节的【格式硬性规则】执行

## 二、参考文献硬性规则

- 正文参考文献编号**一律上标格式（superscript）**
- **GB/T 7714-2015** 格式：作者、题名、刊名/出版者、年、卷(期)、页码、DOI/URL
- **每次生成 / 修改新文档后必须核查全文上标 run 数 > 0**
- 参考文献列表本身的 `[n]` **保持普通字体**（非上标）
- **严禁占位写法**：不得使用"转引自卫勤精兵网""原始数据被 XX 媒体引用"等无标准要素的表述。凡数据来自中文网站 / 公众号 / 二次编译，**必须追溯到原始期刊论文或官方原始来源**（外文期刊用 `[J]`、官网/报告用 `[R]` 或 `[EB/OL]` 带具体 URL）；无法追溯时至少给出可访问的二级来源标准著录，并明确标注"原始量化来源待考"。
  > ⚠️ 用户曾因此严厉批评，**属不可再犯类错误**。

## 三、严禁出现的 AI 感痕迹

**格式类**

- 正文段落严禁出现 `**xxx**` 加粗、`*xxx*` 斜体、`#` 标题等 **Markdown 残留**；文档渲染前必须 100% 清除所有 Markdown 语法标记（`#`、`*`、`>`、`[text](url)` 等）。任何强调一律通过字体（黑体/宋体）、字号、上下文语气实现，**不依赖 Markdown 语法**。
- 严禁连续破折号（——或—）做停顿或列举，改用顿号 / 逗号 / 分号连接短句
- 严禁过多括号补充说明（如 A(近似)、B(捕捉)），强调内容融入正文

**词汇类（半 AI 化造词黑名单）**

"病理驱动""关键 XX 触发器""力学触发""根本性""决定性""颠覆性""革命性""重塑""重构""赋能""抓手""痛点""闭环""底层逻辑""顶层设计""全链路""全方位""全栈式""一站式""颗粒度""高维""降维"

**结构类**

- "即时终点—出血确证—全身病理—中枢机制"这类**四字短语串联的标签式表达**

**元话语类（暴露 AI 与课题内幕）**

- "本团队""本课题组推断""导师重点关注""详见 X.X"
- "本课题组前期文献梳理""基于本课题组""如本团队"等自我标注
- "知识库""AI 辅助""AI 工具""统计学知识库"等**暴露 AI 过程**的元话语
- **国自然标书 / 科研论文正文严禁暴露 AI 辅助过程**：正文不得出现"知识库""AI 辅助""LLM"等元话语标注（如"所有统计参考'统计学'与'一起学统计工具'知识库规范执行"），必须删除；**仅保留标书模板强制要求的生成式人工智能使用声明**（如段 161）

## 四、证据-结论匹配硬性规则

- 每一条结论**必须有对应的文献证据支撑**
- 文献是回顾性研究 → 只能得出**相关性**结论，不能得出"机制不清""缺乏特异性干预"等**本体论**结论
- 文献数据是单因素 OR 值 → 只能得出"该因素是独立危险因素"，不能跳跃到"协同放大""关键病理环节"
- 区分**文献结论 vs 课题组猜想 vs 工作假说**；明确标注"文献报道""课题组推测""本课题组提出"等来源
- "是模型需复现的关键病理环节"这类**自我设定式表述只在研究内容部分出现**，立项依据 / 机制总结部分不应出现

## 五、语言规范

- "解析"在"探究机制"语境中应改为**"探究"**
- "血压震荡"应改为**"血压波动"**
- 英文缩写首次出现须按**"中文（英文全称, 英文缩写）"**格式展开
- 避免口语化连接词（如"这一结果直接连接 X 与 Y"）
- 避免 AI 式流畅表达（"课题组由此推断""上述证据表明"等过场话）
- **措辞严谨性（优先级最高）**：严禁"根本性""决定性"等过于绝对的措辞，应替换为"显著""重要""深刻""实质性"等更客观的表述
- **基础研究正文禁用"队列"一词**

## 六、评审反馈后必须执行的复核清单（每次新生成 / 修改文档后必查）

1. **全文上标核查**：遍历所有段落，统计参考文献上标编号数 ＝ 正文引用出现总数（**0 遗漏**）
2. **AI 痕迹扫描**（必须全面清除）：见第三节全部条目
3. **证据-结论匹配扫描**：每条结论是否由前文证据合理推出
4. **参考文献格式**：GB/T 7714-2015 ＋ 英文 Times New Roman
5. **格式统一**：首行缩进 2 字符、行间距、中文字体黑体/宋体、英文 Times New Roman

## 七、执行原则

- 评审专家意见**逐条响应，不遗漏**
- 大型修改任务**分批执行**（每批 5-10 个段落修改），避免单次操作过大导致文件损坏
- 每次修改后**立即保存并验证**，避免累积操作导致 python-docx zip 内部索引损坏
- 重大决策点（修改研究框架、删除整段、重写工作假说）**应主动询问用户**而非自作主张
