# 论文类型风格档案（中华医学会系列）

> 来源：ima 永久记忆导出（条目日期 2026-07-08 / 2026-08-02）
> 目标：作今后中文医学论文生成 / 润色的权威标杆，**无需每次附范文模板**。

---

## 一、通用框架（所有类型共性）

① **双语要素齐备**（中英文标题 / 作者单位 / 摘要 / 关键词 / 通信作者含 Email）

② **摘要形态**：论著 / 病例 / Meta 用【目的】【方法】【结果】【结论】四段式；综述为单段指示性；指南 / 系统评价用结构式（目的 / 方法 / 结果 / 结论，中英双语）

③ **主体 IMRaD**：引言多为无编号首段直接切入 → 资料与方法 → 结果 → 讨论

④ **收尾**：利益冲突 / 作者贡献 / 参考文献（必备），常附基金 / 志谢

⑤ **章节层级**：一级多无编号或 1/2/3；二级用中文数字"一、二、三"或 1.1

---

## 二、各类型风格要点

### 1. 原创论著 · 基础 / 动物机制

- 方法细分"动物 / 试剂 / 具体方法 / 统计学"
- 结果按指标分节
- 讨论首段先述背景流行病学再回归本研究，以"……可能通过……发挥……作用"因果推测收束，客观、少用第一人称

### 2. 原创论著 · 临床观察 / 队列 / 数据库建模

- **必列**纳入排除标准、一般资料、分组（观察组与对照组 / 早期与晚期 / 训练集与验证集）、伦理审批号与知情同意
- 数据库建模按"研究对象、变量筛选、模型构建、验证(ROC/DCA)"对应
- 摘要方法**明示设计**（前瞻性 / 回顾性 / 横断面加队列）

### 3. 综述

- "综述"栏目标识；**单段非结构摘要**；1/1.1 两级编号
- 骨架"机制、检测、防治、总结展望"，末章必落治疗或转化；**无引言标题**
- 参考文献 60–90 条（近 5 年为主）
- 自称"作者 / 本文"，回避"我们"；述评结合（引证、结果、评议三段式）

### 4. 病例报告加文献复习

- 标题含"1 例报告并文献复习"
- 正文"病例资料"加"讨论及文献复习"
- 文献复习嵌入讨论分段（机制 / 鉴别 / 治疗 / 小结）
- 结论含审慎临床启示

### 5. 系统评价 / 系统综述（基于 3 篇实证）

三种形态：① 系统评价＋Meta 分析（定量合成）；② 系统评价仅定性合成（异质性大不做 meta，如预测模型专项）；③ 概览性综述 / 证据综述（overview of reviews，二次综合已发表 SR/MA，用 AMSTAR-2 ＋ GRADE）

**通用结构（PRISMA 式）**：

结构式摘要(目的/方法/结果/结论，中英双语) → 未编号引言(含 PROSPERO 注册号) → 资料与方法〔1. 问题确立 PICOTS/PICOS；2. 检索策略[中英文库并列＋时限"建库至 XXXX 年 X 月"]；3. 纳排标准；4. 筛选与提取[双人独立＋第三方裁决＋EndNote 去重]；5. 偏倚/适用性/方法学质量评价[ROBINS-I / PROBAST / AMSTAR-2 / QUADAS-2]；6. 数据合成[定性或 Meta]〕→ 结果〔筛选流程 PRISMA 图＋数量、纳入特征、质量评价、Meta 结果[异质性 I²/Q、效应量 RR/OR/MD/SMD(95%CI)、森林图、敏感性、发表偏倚 Egger/Begg＋漏斗图]或定性合成〕→ 讨论(含局限与建议) → 利益冲突/作者贡献/参考文献

**方法学透明性必备**：PROSPERO 注册号、PRISMA 声明、检索库＋明确时限、双人独立、偏倚工具、GRADE（含 Meta 或概览时）

**统计表述**：效应量 RR/OR/MD/SMD＋95%CI；异质性 I²(≤50% 固定，>50% 随机) 与 Q 检验 P；敏感性(leave-one-out)；发表偏倚 Egger/Begg＋漏斗图；软件 RevMan / Stata / R('meta' 包)；预测模型用 AUC / C-index / R / MSE / R² / 校准(H-L / Bootstrap / Brier)

**语言特征**：客观、透明、结论克制（标注证据级别 / 确定性，不作过度推论）；善用"异质性大故仅定性描述""多存在较高方法学偏倚"等审慎表述

**避坑**：须报告检索时限（实证 TBI 营养文缺失为警示）；复杂结果建议补森林图；AMSTAR-2 非强制但概览综述宜用

> 注：妊高症篇为"外刊精选"译述稿（仅 1 条文献、无分级标题、非结构式摘要），**不作完整中文 SR 正文模板**，仅取 PROSPERO / ROBINS-I / GRADE / 随机效应(DerSimonian–Laird) / RR(95%CI) / I² / Begg-Egger 等方法学要素参考。

### 6. Meta 分析 / meta 回归

- 结构为资料与方法(检索/纳排/质量)、结果(流程/特征/质量/Meta/亚组/敏感性/偏倚)、讨论
- 效应量 RR / SMD / MD(95%CI) 附 P
- 异质性 I² 与卡方(P) 决策固定或随机效应
- PRISMA 流程、PROSPERO 号、Egger 检验；结论含局限

### 7. 方法学 / 动物模型

- 强调可重复：动物来源加许可证号、随机数字表法、具体造模步骤（麻醉浓度 / 结扎比例 / 针规格 / 容积剂量）、试剂货号
- 独立统计学节；均数 ± 标准差与 P<0.05
- 常用"本研究建立 / 采用"第一人称主体

## 三、临床实践指南（clinical practice guideline）风格要点

> 基于 CRRT 处方液体应用、新一代四环素儿科应用 2 篇 2026 版实证，均载《中华医学杂志》

**框架**：中英文双语题名＋作者单位＋通信作者 → 中英文摘要(【摘要】/【Abstract】、【关键词】/[Key words]) → 未编号引言/背景段 → 第一部分:指南制订方法(成员与利益冲突管理、适用范围与人群、制订方法含 GRADE 分级定义表、证据检索与评价、推荐意见形成、外审批准) → 第二部分:临床问题＋推荐意见(问题驱动，"问题 X："＋"推荐意见 Y："穿插) → 第三部分:结语 → 专家委员会名单 → 利益冲突声明("所有作者声明不存在利益冲突") → 参考文献(134~161 条)

**推荐意见四 / 五段式模板**："推荐意见 Y："陈述句＋句末括号(推荐强度, 证据级别)；强推荐用"推荐"、弱推荐用"建议"、专家共识强推荐标 GPS；独立"推荐依据 / 证据总结 / 实施建议 / 其他考虑 / 推荐理由"段（四环素指南为五段式；CRRT 指南为"推荐意见 ＋ (Ⅱa, B 级证据) ＋ 推荐依据"）

**推荐强度与证据分级(GRADE)**：CRRT 用罗马数字 Ia/IIa/III ＋ A/B/C/D 证据级；四环素用"强推荐(推荐) / 弱推荐(建议，含条件性/酌情/限定性推荐) / GPS" ＋ 高/中/低/极低把握度证据

**方法学声明**：须声明遵循《WHO 指南制订手册》《中国制订/修订临床诊疗指南的指导原则(2022 版)》、AGREE II、RIGHT、PRISMA；GRADEpro 辅助；Delphi 法＋投票通过率(≥70% 或 >80%)；注册号(CRRT: PREPARE-2023CN809；四环素: GIN)

**统计表述**：仅引他人 Meta/队列结果（如"3 项队列研究的荟萃分析…RD=0, 95%CI: -0.04~0.04"），区间用波浪号

**参考文献**：同通用 GB/T 7714 医学变体；外文刊名缩写＋卷(期):页＋DOI；含 [J]/[M]/[EB/OL]；团体作者写机构名

## 四、综述细分补充（研究进展 / 机制综述）

> 基于急性呼吸道感染多源数据、ARDS 神经并发症、肺纤维化血液生物标志物 3 篇实证

**通用**：栏目标识"·综述·"；无独立引言标题，以未编号导引段承担（背景＋述评动机＋检索策略/分类框架）；一级"一、二、三、四"、二级"1.2."或"（一）（二）"、三级"(1)(2)"或"1.2.3."；收尾"总结与展望"（机制综述常含"小结与展望"）

**研究进展 / 机制综述**：按主题 / 机制分类平行分述，每子类"名称(英文全称, 缩写)＋机制＋证据＋局限"，常配 1 张分类汇总表；机制综述骨架"概述 → 临床类型表现 → 病理生理机制分述 → 临床管理策略 → 小结与展望"；统计仅转述他人流行病学区间值＋文献号

**综述引述语体**："近年来 / 目前 / 当前 / 综上所述 / 本文系统梳理 / 研究显示 / 研究表明 / 既往研究表明"引出；定性转述统计（敏感度 / 特异度 %、增幅、相关/负相关），**不列原始 p 值**

---

## 五、类型覆盖状态（闭环确认）

**已完整覆盖（实证 ≥1 篇）**：原创论著（基础机制 / 临床对照 / 队列 / 数据库列线图 / 横断面＋纵向）、综述（含研究进展 / 机制综述细分）、病例报告＋文献复习、Meta 分析（含 meta 回归）、动物模型方法学、临床实践指南、系统评价 / 系统综述（含定性合成 / 含 Meta / 概览性综述）

**用户明确"暂时不涉及"**：① 纯方法学论文（非动物模型类）；④ Letter / 短篇 / 快报

结论：除用户主动排除的 2 类外，其余预期文献类型标杆均已建立。
