# 科研技能索引（Research Skill Index）

> **用途**：本文件是 v2 期（2026-10-28）对本机技能库的人工通读索引，覆盖当时 **719** 个 skill 中的约 370 个科研相关项（A–S 类 229 条 + 附录 B 145 条）。
> **v3 起（2026-11-06）以能力卡为准**：源全集改为用户打包的 **592 条源记录（586 个技能目录）**，逐条判定见 `data/ledger/<域>.json`，全量编目见 `knowledge/INDEX.md`；选路一律走 `research_playbook`，本文件降为历史参考与线索来源（同名技能到底哪个更全时仍可查）。
> **强制规则**：凡接到科研相关任务（文献检索/精读/撰写/润色/综述/统计/绘图/PPT/标书/审稿/参考文献/投稿/临床辅助），
> **v3 起第一步是 `research_playbook(task=<用户原话>)`**（选能力卡，不选技能）；本文件仅作目录层线索，需要原文时用 `research_kb_read` 读；
> 严禁在未读本索引的情况下凭印象作答。任务推进中若发现方向变化，须重新扫读本索引相关类别。

**优先级说明**：`★` = 类别首选（用户本机环境已验证可用）｜`C` = 核心，多数科研任务会用到｜`R` = 推荐，按任务性质启用｜`O` = 按需（专业领域，非相关方向可忽略）
