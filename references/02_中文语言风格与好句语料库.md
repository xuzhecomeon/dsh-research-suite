# 中文医学写作语言风格与好句语料库

> 来源：ima 永久记忆导出（条目日期 2026-08-02，基于 8 篇中华系列文献重学语言风格）
> **最高优先级声明**：中华医学会系列期刊论文的语言风格 ＝ 标准医学学术语言风格，是中文医学写作的权威标杆与**最高优先级语言参照**；永远优先于任何 AI 默认文风 / 通用中式或机器翻译腔。今后所有中文生成与润色，语言层一律对标此风格，不以原稿 AI 腔 / 长难句 / 翻译腔为参照。

---

## 一、客观化手段（实证规律）

1. **自称规范**：指南用"本指南 / 专家组 / 指南工作组"；综述 / 论著 / 系统评价用"本文 / 本研究"。
   **一律禁用**"我们 / 笔者 / 本文作者认为"。
2. **无主语句与被动**："由…"被动、无施事主语陈述（如"经筛选后，共有 11 项研究纳入""文献筛选由 2 名研究者独立完成"）；现状 / 方法 / 推荐多省略主语。
3. **句子骨架** ＝ 实体主语 ＋ 具体动词 ＋ 量化 / 引证（如"本研究遵循 PRISMA 声明进行报告"），杜绝第一人称与比喻式评价。
4. **定义与分类**："X 定义为…"（机制综述）、"X: X 是一种…"（冒号式）、"即"（缩写界定）、"可分为 N 大类"；术语首现附英文全称 ＋ 缩写。

## 二、连接词与过渡词（实际高频，短实）

| 关系 | 用词 |
|---|---|
| 因果 | 因此 / 综上 / 从而 / 进而 / 在此基础上 / 导致 / 引起 |
| 转折 | 但 / 然而 / 尽管…但 / 与…相比 / 而不是 |
| 补充 | 此外 / 同时 / 且 / 另一方面 |
| 条件 | 基于 / 鉴于 / 如果 / 应 |
| 举例 | 例如 / 目前 / 近年来 / 总体而言 |
| 局限段 | 首先…其次…此外…最后 |

**禁用**：值得注意的是 / 综上所述（空泛）/ 近年来随着…的不断发展 / 在当今…背景下 / 扮演着…的重要角色 / 为…提供了新思路 / 毋庸置疑 / 不言而喻 / 不难看出 / 众所周知

## 三、与 AI 腔的反面对照（写作红线）

1. **开场直入事实**（"50 多年的基础实验与临床研究已经证实…"），不铺陈"近年来随着…发展""在当今…背景下"。
2. **强调确需时直陈**（"需要警惕…"），不滥用"值得注意的是"填充。
3. **收束小结必有实质结论与量化支撑**，非空泛的"综上所述本文综述了…"。
4. **结论克制**（"临床推广应用受限""尚需更多高质量研究验证""证据级别均为极低"），不夸大（"具有重要临床推广价值与广阔前景"）。
5. **句式**：短句 ＋ 分号/句号切分、一句一意、数据内嵌；拒绝一逗到底的超长复合句与抽象名词堆砌。
6. **结果必带统计量**（RR / OR / MD ＋ 95%CI ＋ P），不写"效果显著"这类空泛句。

## 四、语言铁律（高优先级 · 通用）

- **总纲**：语言严格以中华医学会系列期刊论文为标杆，杜绝 AI 化 / 机器翻译腔，杜绝过多长难句。
- **禁用套话**：值得注意的是 / 综上所述 / 近年来随着…的不断发展 / 在当今…背景下 / 扮演着…的重要角色 / 为…提供了新思路 / 不难看出 / 众所周知 / 具有重要理论意义和临床价值 / 亟待进一步…研究与探索 / 总体而言 / 从某种意义上说 / 基于此 / 换言之
- **长难句限制**：单句 **≤ 40 字**、一句一意、主谓宾清晰、嵌套长句必拆分。
- **正确写法**：直接陈述事实 / 数据 / 结论；衔接用"因此、此外、然而、但、目前、综上、鉴于"；客观被动与无主语句适度使用；推测限用"可能 / 提示 / 或有助于"，**禁绝对化**；缩写首现展开。

## 五、统计表述惯例（通用）

- 计量资料：**均数 ± 标准差**
- 相对数：附绝对数，如"100.0%(22/22)"
- 组间比较："与 X 组相比，Y 组…升高 / 降低(P<0.05)"
- 标准句："差异有 / 无统计学意义(P<0.05)"，并**明示检验水准**
- 回归：给 OR / HR(95%CI) 及 P
- 相关：给 Pearson r 与 P
- Meta：给 I²、卡方(P)、SMD / MD / RR(95%CI)

## 六、好句语料库（可直接模仿，逐字摘自 8 篇中华系列文献）

### 背景 / 现状直陈

① "耐碳青霉烯类革兰阴性杆菌是近 20 年来我国临床面临的棘手问题[63-64]。"

② "急性呼吸道感染具有高发病率、强传播性及症状非特异性等特点，传统单一数据源监测体系难以满足早期预警需求。"

③ "IPF 是预后最差的一种类型。患者确诊后平均生存期仅 3 年，5 年生存率仅为 25%，低于多数恶性肿瘤。"

### 机制描述（实体 ＋ 介质 ＋ 通路 ＋ 结局）

④ "ARDS 患者肺损伤后释放大量 TNF-α、IL-1a、IL-1b 和 IL-6 等炎症介质，经循环破坏血脑屏障，激活小胶质细胞与星形胶质细胞，诱导神经元凋亡。"

⑤ "从分子机制上看，KL-6 能够作为配体与成纤维细胞表面受体结合，激活下游细胞内信号通路，从而增强成纤维细胞的增殖、迁移能力，并促进胶原蛋白的合成与沉积，直接参与纤维化形成。"

### 因果 / 推测

⑥ "有研究提示，发生低镁血症的危重患者与其他患者相比病死率增至 1.5~2.0 倍[42-44]。"

⑦ "气体交换障碍所致的长时间低氧血症破坏了脑组织的能量底物供应，引起线粒体功能障碍与能量衰竭，最终导致神经元凋亡、坏死及细胞毒性水肿。"

### 对比 / 转折

⑧ "与乳酸盐相比，应用碳酸氢盐置换液/透析液行 CRRT 的患者尽管在病死率、血清乳酸、血清肌酐方面没有显著差异，但心血管事件及低血压事件发生率更低，更适合重症患者进行 CRRT。"

⑨ "目前 PF 诊断主要依赖高分辨率 CT(HRCT)和外科肺活检[4]，但侵入性检查对高龄及呼吸功能不全的患者风险较高。"

### 引用证据（[n] ＋ 量化）

⑩ "例如，贾萌萌等[32]在基于 BERT 的 ARIs 识别研究中，对比人工判定的参考标准，灵敏度和特异度分别达到了 92.67% 和 96.45%。"

⑪ "研究显示，在亚洲人群中以 500 U/ml 作为诊断阈值时，KL-6 鉴别 PF 的敏感度和特异度分别可达 77.75% 与 94.51%，显示出良好的诊断价值[8]。"

### 数据量化

⑫ "CRRT 导致的氨基酸丢失可达 15~25 g/d 或 0.22~0.49 g/(kg·d)。"

### 推荐 / 结论克制（附证据级）

⑬ "推荐意见 1：对于需要 CRRT 的重症患者，建议使用碳酸氢盐而不是乳酸盐置换液/透析液。(Ⅱa, B 级证据)"

⑭ "推荐意见 1：专家组建议……在其他备选药物因各种原因不能使用时可以用于 8 岁以下儿童。（低把握度证据，条件性推荐）"

### 方法透明

⑮ "本研究遵循系统评价与 Meta 分析首选报告项目声明进行报告。"

⑯ "文献筛选与资料提取由 2 名研究者独立完成并进行交叉核对，出现分歧由第三方裁决。"

### 效应量结果（必带统计量）

⑰ "与延迟营养相比，早期营养可显著降低 TBI 患者死亡率(RR=0.35, 95%CI: 0.24~0.50, P<0.001)"

### 证据限定 / 结论克制

⑱ "总体存在较大异质性；未发现发表偏倚；证据级别均为极低。"

⑲ "结论 现阶段鼻咽癌放疗后口干预测模型多存在较高方法学偏倚，临床推广应用受限。"

⑳ "生酮饮食和 ω-3 脂肪酸的临床疗效尚需更多高质量人体研究验证。"

### 小结与展望克制

㉑ "现代 ARDS 的临床管理理念已从以肺为中心的保护性策略，发展为早期识别高危人群、多模态动态监测和评估神经系统功能的'肺脑并重'的整体性治疗策略。"
