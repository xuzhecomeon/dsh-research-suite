# 12 - 中华医学会首页脚注与伦理号规范

**来源**：基于中华医学会系列期刊 30+ 篇论文的实证归纳

**适用范围**：所有中华医学会系列期刊投稿，首页脚注必备项。

---

## 一、首页脚注完整模板

```
DOI: 10.3760/cma.j.cn.....(12位)

基金项目: [国家自然科学基金(编号); XX 重点研发项目(编号)]
（无基金时写"无"）

通信作者: [姓名], Email: [xxx@xxx.com]
（可多位，但分别给 Email）

作者单位: [XX 医院 XX 科, 北京 100000]

伦理: 本研究经 [XX 医院伦理委员会] 批准
（批准号: KYLL-XXXXKS-XXX）；
所有患者签署知情同意书 / 知情同意豁免（回顾性研究）。

动物伦理: 本研究经 [XX 大学实验动物伦理委员会] 批准
（批号: DW-P-XXXX-XXX）。

利益冲突: 所有作者声明不存在利益冲突
（必须声明）

作者贡献: [姓名]: [贡献描述]; [姓名]: [贡献描述]
```

## 二、各项目详细规范

### 1. DOI

| 项目 | 规范 |
|------|------|
| 格式 | `DOI: 10.xxxx/xxxxx.` |
| 大小写 | DOI 大写 + 冒号 + 空格 + 全小写（除前缀 `10.`）|
| 位置 | 论文首页脚注首项 |
| 示例 | `DOI: 10.3760/cma.j.cn121094-20240813-00377` |

### 2. 基金项目

| 项目 | 规范 |
|------|------|
| 格式 | `基金项目：基金名称(编号); 基金名称(编号)` |
| 多个基金 | 用分号分隔 |
| 无基金时 | 写"无" |
| 示例 | `基金项目：国家自然科学基金(82371710); 天津市医学重点学科(专科)建设项目(TJYXZDXK-043A)` |

**实证样本**：
> "基金项目：国家临床重点专科建设项目（2022）专项资金（301-2305）"

> "基金项目：深圳市宝安区人民医院重点专科院内立项（2022-3）；急救与创伤研究教育部重点实验室开放基金（KLET-202220）"

> "基金项目：天津市医学重点学科（专科）建设项目（TJYXZDXK-043A）"

### 3. 通信作者

| 项目 | 规范 |
|------|------|
| 格式 | `通信作者：姓名, Email: xxx@xxx.com` |
| 多位通信作者 | 分别列，标注各 Email |
| 顺序 | 第一位为第一通信作者 |
| 示例 | `通信作者：马青变, Email: maqingbian@126.com; 郭治国, Email: applevict@163.com` |

**实证样本**：
> "通信作者：卢中秋、徐军、田英平、朱华栋、赵晓东、于学忠（5 位联合通信作者，标注各 Email）"

### 4. 作者单位

| 项目 | 规范 |
|------|------|
| 格式 | `1.XX 医院 XX 科, 北京 100000` |
| 多单位 | 用上标 1, 2, 3... 标注 |
| 邮编 | 必须附 |
| 示例 | `1. 北京大学第三医院急诊科, 北京 100191; 2. 分子心血管学教育部重点实验室, 北京 100191; 3. 北医三院临床流行病学研究中心, 北京 100191` |

### 5. 伦理审批

#### 5.1 涉人研究

| 项目 | 规范 |
|------|------|
| 格式 | `本研究经 XX 医院伦理委员会批准（批准号: KYLL-XXXXKS-XXX）` |
| 知情同意 | `所有患者签署知情同意书` / `知情同意豁免（回顾性研究）` |
| 示例 | `本研究经山东大学齐鲁医院伦理委员会批准（批准号: KYLL-202107-090）` |

**实证样本**：
> "本研究经山东大学齐鲁医院伦理委员会批准（批准号: KYLL-202107-090），知情同意豁免（回顾性研究）。"

> "本研究经 XX 医院伦理委员会批准（伦理号 2024ky073），患者签署知情同意书。"

#### 5.2 涉动物研究

| 项目 | 规范 |
|------|------|
| 格式 | `本研究经 XX 大学实验动物伦理委员会批准（批号: DW-P-XXXX-XXX）` |
| 动物许可证 | 必须附动物生产许可证号（SCXK）和使用许可证号（SYX）|
| 示例 | `本研究经 XX 大学实验动物伦理委员会批准（批号: DW-P-2024-021-01），动物生产许可证号 SCXK(京)20XX-XXXX，使用许可证号 SYX(京)20XX-XXXX` |

### 6. 利益冲突

| 项目 | 规范 |
|------|------|
| 必备项 | **必须声明** |
| 标准句 | `所有作者声明不存在利益冲突` |
| 有冲突时 | 详细描述：`XX 作者声明接受 XX 公司资助` |

**实证样本**：
> "利益冲突 所有作者均声明不存在利益冲突"

### 7. 作者贡献

| 项目 | 规范 |
|------|------|
| 必备项 | **必须声明** |
| 格式 | `姓名: 贡献描述; 姓名: 贡献描述` |
| 多个作者 | 用分号分隔 |
| 贡献类型 | 研究设计、数据收集、统计分析、论文撰写、稿件修订等 |

**实证样本**：
> "作者贡献 王兵侠: 论文撰写；谈定玉: 数据整理；蒋大明: 研究指导"

> "作者贡献声明 段泽君：实验设计、文章撰写；齐雪岭：研究指导、论文审校"

## 三、首页脚注顺序

按以下顺序排列：

1. **DOI**（首位）
2. **基金项目**
3. **通信作者 + Email**
4. **作者单位**
5. **伦理审批**
6. **知情同意**
7. **动物伦理**（如适用）
8. **收稿日期 / 修回日期**（如适用）
9. **本文编辑**（如适用）

**实证样本**（来自样本 5）：
```
DOI: 10.3760/cma.j.cn121094-20250521-00197
通信作者：XX, Email: xxx@xxx.com
基金项目：……
收稿日期：2025-05-21
本文编辑：霍飞
```

## 四、参考文献中的特殊标注

### 期刊增刊

- `S-equol, a selective estrogen receptor β agonist, does not affect safety endpoints[J]. J Nutr, 2010, 140(7 Suppl): 1325-1332.`
- 标注"suppl"或"Suppl"

### 会议论文

- 加"会议名称 + 地点 + 日期"
- `2010: 45-50.`

### 网络引用

- `[EB/OL]. [YYYY-MM-DD]. URL.`

## 五、特殊场景

### 5.1 多中心研究

- 作者单位按中心编号 1, 2, 3... 标注
- 通信作者可多位（来自各中心）

### 5.2 动物实验

- 必须附动物伦理审批
- 必须附动物生产许可证号（SCXK）和使用许可证号（SYX）

### 5.3 基因组研究

- 须声明遵循人类基因组伦理宣言
- 须声明数据可访问性（数据可用性声明）

### 5.4 AI 工具使用（如 ChatGPT）

- 部分期刊要求声明 AI 工具使用情况
- 实证样本：`本研究在文献检索与语法修订过程中使用了 AI 辅助工具（具体工具），但所有学术观点与结论均由作者独立完成。`
