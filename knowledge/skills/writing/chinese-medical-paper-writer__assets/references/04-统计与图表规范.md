# 04 - 统计与图表规范

## 一、统计描述用语（通用）

| 类别 | 推荐表述 |
|------|---------|
| 计量资料集中趋势 | 均数 ± 标准差（`x̄ ± s`） |
| 计量资料离散 | 中位数（四分位数间距）`M(P25, P75)` |
| 计数资料 | 例数（百分比）`n(%)` |
| 相对数 | 必须附绝对数 `100.0%(22/22)` |
| 检验水准 | α=0.05 |
| 差异判断 | "差异有/无统计学意义(P<0.05)" 明示检验水准 |
| 组间比较 | "与 X 组相比，Y 组…升高/降低(P<0.05)" |
| 置信区间 | 95%CI 必带 |
| 范围号 | 波浪号 `~`（不用一字线或半字线，避免与减号混淆） |

## 二、回归分析表述

| 类型 | 标准写法 |
|------|---------|
| 单因素 Logistic 回归 | "单因素分析显示，年龄、APACHE II 评分与预后不良相关（P<0.05）" |
| 多因素 Logistic 回归 | "多因素 Logistic 回归分析显示，年龄（OR=1.05, 95%CI: 1.02~1.08, P=0.001）是预后不良的独立危险因素" |
| Cox 回归 | "Cox 比例风险模型分析显示，X 组的死亡风险显著高于 Y 组（HR=2.13, 95%CI: 1.45~3.12, P<0.001）" |
| 线性回归 | "线性回归分析显示，X 与 Y 呈正相关（β=0.45, 95%CI: 0.32~0.58, P<0.001）" |

## 三、相关性分析表述

| 类型 | 标准写法 |
|------|---------|
| Pearson 相关 | "Pearson 相关分析显示，X 与 Y 呈正相关（r=0.65, P<0.001）" |
| Spearman 相关 | "Spearman 秩相关分析显示，X 与 Y 呈正相关（rs=0.58, P=0.002）" |

## 四、Meta 分析统计表述

| 项目 | 标准表述 |
|------|---------|
| 效应量 | RR / OR / MD / SMD（连续变量优先 MD 或 SMD） |
| 置信区间 | 必带 95%CI |
| P 值 | 附 P 值 |
| 异质性 | I² + Q 检验 P：`I²=45%, P=0.08`（同质，固定效应） |
| 效应模型选择 | I² ≤50% 且 Q 检验 P>0.1：固定效应模型；否则随机效应模型 |
| 敏感性分析 | leave-one-out 法："剔除 X 研究后，合并效应量变化不大，结论稳健" |
| 发表偏倚 | Egger 检验 P 值 + Begg 检验 P 值 + 漏斗图 |
| 软件 | RevMan 5.x / Stata 14+ / R（'meta'/'metafor' 包） |
| 亚组分析 | "按年龄分层后，<60 岁组（RR=0.65, 95%CI: 0.45~0.94, P=0.02）与 ≥60 岁组（RR=0.82, 95%CI: 0.65~1.03, P=0.09）效应量存在差异" |

## 五、预测模型统计表述

| 指标 | 标准写法 |
|------|---------|
| 区分度 | AUC / C-index：AUC=0.85 (95%CI: 0.78~0.92) |
| 校准 | H-L 检验 P>0.05 校准良好；Bootstrap 1000 次校准曲线 |
| 总体性能 | Brier 分数 / R² |
| 临床效用 | DCA 决策曲线分析 |
| 内部验证 | Bootstrap / K-fold 交叉验证 |
| 外部验证 | 时间外部验证 / 地理外部验证 |

## 八、图表格式规范

### 表格

- **三线表**（顶线、表头分隔线、底线）—— 无竖线、无斜线
- **表序/表题位于表上方**（如"表 1 两组患者基线特征比较"）
- **表注位于表下方**（如缩写解释、统计方法说明）
- 中文 6 号宋体加粗 / 英文 6 号 Times New Roman 加粗
- **表格内数值小数点对齐**
- **P 值列在该分组有 P 值时填入，无则留空**
- 表格位置：正文**第一次提及的段落之后**

### 表头规范

| 指标 | A 组（n=50） | B 组（n=50） | 统计量 | P 值 |
|------|-------------|-------------|--------|------|
| 年龄（岁，x̄ ± s） | 42.5 ± 15.3 | 45.1 ± 13.8 | t=0.89 | 0.376 |
| 男性 [例(%)] | 30 (60.0) | 32 (64.0) | χ²=0.17 | 0.683 |
| APACHE II（分，x̄ ± s） | 18.2 ± 5.4 | 17.8 ± 5.1 | t=0.39 | 0.697 |

### 表格自检要点

- [ ] 三线表（仅顶线、表头分隔线、底线）
- [ ] 无竖线/斜线
- [ ] 表序/表题在表上方
- [ ] 表注在表下方
- [ ] 数值小数点对齐
- [ ] P 值列在该分组有 P 值时填入，无则留空
- [ ] 统计量与 P 值在最后一列
- [ ] 计量单位在列标题中标注

### 图

- **图序/图题位于图下方**（如"图 1 两组患者 28 天生存曲线"）
- **图注**（Figure legend）位于图题下方
- 中文 6 号宋体加粗 / 英文 6 号 Times New Roman 加粗
- **图片分辨率 ≥300 dpi**
- 图片格式：TIFF / EPS / PNG
- 图位置：正文**第一次提及的段落之后**

### 图种类推荐

| 目的 | 推荐图表 |
|------|---------|
| 分类资料对比 | 柱状图（带误差棒） |
| 时间趋势 | 折线图 |
| 生存分析 | Kaplan-Meier 曲线 |
| 诊断准确性 | ROC 曲线 |
| 相关性 | 散点图（含回归线） |
| 模型校准 | 校准曲线 |
| 临床效用 | DCA 决策曲线 |
| 亚组分析 | 森林图（Forest plot） |
| 异质性/偏倚 | 漏斗图（Funnel plot） |
| 筛选流程 | PRISMA 流程图 |
| 多组比较 | 箱线图 / 小提琴图 |

## 九、数据呈现的"四要四不要"

### 四要

- 要附统计量（均数±标准差、OR/HR(95%CI)）
- 要附 P 值
- 要附置信区间
- 要附样本量（n）

### 四不要

- 不要只写"差异显著"而无统计量
- 不要"有效率 90%"而无绝对数
- 不要罗列所有 P 值而无主次
- 不要省略"差异无统计学意义"项
