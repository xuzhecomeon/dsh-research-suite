# 16 - 免责声明与共识指南模板

**来源**：基于 22 篇中华医学会期刊共识/指南论文实证归纳

**关键发现**：免责声明（Disclaimer）是 CMA 期刊共识/指南类论文的**必备标准开头/封笔**，几乎所有 CMA 期刊都强调"非强制性"。

---

## 一、首页免责声明（开头必备）

### 实证样本（来自多个 CMA 期刊）

**样本 1**：
> "本指南不是强制性标准，不可能包括或解决[主题]的所有问题。临床医生在面对具体患者时，应遵循本指南的原则，充分了解患者的病情，认真考虑患者的观点和意愿，并结合当地的医疗资源和实践经验，制订全面合理的个体化治疗方案。"

**样本 2**：
> "本指南专家委员会成员均声明不存在与本指南相关的利益冲突。所有参与文献检索、证据评价和推荐意见形成的专家均签署利益冲突声明表。本指南涉及的药品和器械均按国家药品监督管理局批准的应用指征推荐使用。"

**样本 3**：
> "本指南的制订旨在推动我国[主题]的规范化诊治，最终惠及广大患者。随着[主题]领域新证据的出现，本指南计划每 3~5 年更新一次。"

### 撰写模板

```
本指南[共识]由中华医学会[XXX]学分会[XXX]学组牵头，组织相关领域专家
依据最新循证医学证据，参考国际权威指南并结合我国国情与临床实践制订。

本指南不是强制性标准，不可能包括或解决[主题]的所有问题。临床医生
在面对具体患者时，应遵循本指南的原则，充分了解患者的病情，认真考虑
患者的观点和意愿，并结合当地的医疗资源和实践经验，制订全面合理的
个体化治疗方案。

本指南专家委员会成员均声明不存在与本指南相关的利益冲突。所有参与
文献检索、证据评价和推荐意见形成的专家均签署利益冲突声明表。

本指南涉及的药品和器械均按国家药品监督管理局批准的应用指征推荐
使用。

随着[主题]领域新证据的出现，本指南计划每 3~5 年更新一次。
```

## 二、共识开篇模板（10 句）

1. "为[XXX]提供循证依据，规范我国[XXX]的诊治，由中华医学会[XXX]学组牵头，组织相关领域专家，成立指南制订工作组。"

2. "本指南基于国内外最新研究成果，参考国际权威指南并结合我国国情与临床实践。"

3. "工作组采用 GRADE/牛津/Delphi 等方法学评估证据质量与推荐强度。"

4. "本指南采用改良 Delphi 法形成共识，意见分歧由第三方仲裁解决。"

5. "指南已在国际实践指南注册与透明化平台（PREPARE）或 GIN 注册。"

6. "本指南聚焦临床关键问题，针对 20XX 年发表的系统评价进行证据合成。"

7. "本指南形成 N 个临床问题，提出 M 条推荐意见。"

8. "本指南对[循证综述方法]的可靠证据进行了系统检索与评价。"

9. "本指南使用 GRADE 方法评估证据质量，分为高、中、低、极低 4 个等级。"

10. "推荐等级分为强推荐、弱推荐和有条件推荐，分别对应临床实践中的'必须做'、'建议做'与'视情况做'。"

## 三、共识封笔模板（5 句）

1. "本指南不是强制性标准，不可能包括或解决[XXX]的所有问题。临床医生在面对具体患者时，应遵循本指南的原则，充分了解患者的病情，认真考虑患者的观点和意愿，并结合当地的医疗资源和实践经验，制订全面合理的个体化治疗方案。"

2. "随着[XXX]领域新证据的出现，本指南将定期更新。"

3. "本指南的局限性在于[XXX]，未来需开展[XXX]进一步验证。"

4. "建议后续开展多中心 RCT 验证本指南中[XXX]推荐。"

5. "本指南的制订旨在推动我国[XXX]的规范化诊治，最终惠及广大患者。"

## 四、共识封笔"局限性"模板

### 4.1 证据局限性

```
本指南的局限性之一是部分推荐意见的证据级别较低，主要基于观察性研究
和小样本 RCT。未来需开展更多大样本、高质量的随机对照试验以提供
更强证据。
```

### 4.2 适用局限性

```
本指南的推荐意见主要基于中国成人患者的循证证据，对儿童、孕妇、老年人
等特殊人群的适用性需结合具体临床情况判断。建议进一步研究上述特殊
人群的循证证据。
```

### 4.3 地域局限性

```
本指南的制订主要参考中国及国际权威指南，对我国不同地区、不同医疗资源
条件的适用性存在一定差异。建议在经济欠发达地区结合本地医疗资源
灵活应用。
```

## 六、共识/指南 vs 论著的差异

| 项目 | 共识/指南 | 论著 |
|------|---------|------|
| **摘要** | 单段指示性（约 200-400 字）| 结构式【目的/方法/结果/结论】（约 350-500 字）|
| **关键词** | 5-10 个（分号分隔）| 3-8 个（分号分隔）|
| **首页脚注** | 9 项必备（DOI、基金、伦理、通讯作者、单位、利益冲突、作者贡献、声明、致谢）| 6 项必备（DOI、基金、伦理、通讯作者、单位、利益冲突、作者贡献）|
| **章节结构** | 引言 + 方法学声明 + 推荐意见 + 参考文献 + 附录 | IMRaD（引言 + 方法 + 结果 + 讨论 + 参考文献）|
| **推荐意见** | N 条，每条带证据级别 | 无 |
| **证据级别** | 必有 | 必有（统计） |
| **方法学声明** | 7 要素必备 | 仅说明研究方法 |
| **免责声明** | **必有**（开篇与封笔）| 无 |
| **更新周期** | 必有声明 | 无 |
| **利益冲突** | 专家个人 + 资助方 双重声明 | 仅作者 |

## 七、撰写实战 Checklist

撰写共识/指南类论文时：

- [ ] 标题格式：[主题]中国专家共识 / [主题]指南（XXXX 年版）
- [ ] 首页脚注 9 项要素齐全
- [ ] 引言声明制订方、注册平台、证据系统、共识法
- [ ] 推荐意见**句末**必有双层括号标注
- [ ] 每条推荐意见**附证据来源/文献引用**
- [ ] 论文封笔**有免责声明**
- [ ] 论文封笔**有局限性声明**
- [ ] 论文封笔**有更新周期声明**
- [ ] 致谢**有资助方信息**
