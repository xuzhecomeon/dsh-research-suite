# 17 - 预测模型 / 机器学习类研究写作规范

**来源**：基于中华医学会期刊 31 篇预测模型/机器学习类论文实证归纳（2026-08-10 第二轮精读）

**适用范围**：所有基于公开数据库（SEER、NIS、MIMIC、NHANES、TCGA）或医院数据构建预测模型的研究，包括：
- 列线图（Nomogram）
- 机器学习分类/回归模型（XGBoost、随机森林、SVM、LASSO-Cox）
- SHAP 可解释性 AI 分析
- 决策曲线分析（DCA）
- 内部验证（Bootstrap、K-fold）
- 外部验证（时间外部验证、地理外部验证）

---

## 一、论文结构（标准骨架）

```
1. 摘要（结构式【目的/方法/结果/结论】）
2. 引言（疾病背景 + 现有模型局限 + 本文目的）
3. 资料与方法
   3.1 数据来源与样本筛选
   3.2 变量筛选与定义
   3.3 缺失值处理
   3.4 样本分组（训练集/验证集，按 7:3 随机分组）
   3.5 模型构建
       (1) LASSO-Cox 筛选
       (2) Cox 多因素回归
       (3) 列线图（Nomogram）生成
       (4) SHAP 分析（机器学习）
   3.6 模型验证
       (1) ROC 曲线 + AUC
       (2) 校准曲线（Calibration Curve）
       (3) Hosmer-Lemeshow 检验
       (4) Bootstrap 内部验证（1000 次）
       (5) 决策曲线分析（DCA）
       (6) 外部验证（如适用）
   3.7 统计学软件与显著性水平
4. 结果
   4.1 基线特征
   4.2 变量筛选结果
   4.3 列线图
   4.4 模型性能（ROC、校准、DCA）
   4.5 SHAP 分析（如适用）
5. 讨论
   5.1 主要发现
   5.2 与既往模型比较
   5.3 临床应用价值
   5.4 局限性与展望
6. 利益冲突、作者贡献
7. 参考文献
```

## 二、关键句式（按 写作顺序）

### A. 摘要

```
目的 构建并验证[疾病]患者的[结局]预测模型。
方法 检索 SEER 数据库 [时间范围]，[纳入标准]，
最终纳入 N 例患者。按 7:3 比例随机分为训练集（n=?）
和验证集（n=?）。采用 LASSO-Cox 回归筛选预测变量，
多因素 Cox 回归构建预测模型，以列线图可视化。
通过 ROC 曲线下面积（AUC）、校准曲线、决策曲线
分析（DCA）评估模型性能。Bootstrap 内部验证
（1000 次重采样）评估模型稳健性。
结果 共筛选出 N 个独立预测因素，构建的列线图
训练集 AUC 为 0.847（95%CI: 0.821-0.873），
验证集 AUC 为 0.821（95%CI: 0.792-0.850）。
校准曲线显示模型预测概率与实际观察概率吻合良好
（Hosmer-Lemeshow P=0.412）。DCA 显示阈值概率
10%~60% 时模型具有较高临床净获益。
结论 本研究构建的列线图能有效预测[疾病]患者[结局]，
为临床决策提供个体化评估工具。
```

### B. 数据来源

```
SEER 数据库（Surveillance, Epidemiology, and End Results）
筛选 2010-2020 年[疾病]患者 N 例。纳入标准：(1)...；
(2)...；(3)...。排除标准：(1)...；(2)...。
最终纳入 N 例患者，按 7:3 比例随机分为训练集（n=?）
和验证集（n=?）。

或：

基于[XX 医院] 2018 年 1 月至 2023 年 12 月收治的
[疾病]患者的电子病历数据，共纳入 N 例。按 7:3 比例
随机分为训练集（n=?）和验证集（n=?）。
```

### C. 变量筛选

```
使用最小绝对值收敛和选择算子-Cox 比例风险回归模型
（LASSO-Cox）筛选出最佳预测变量。LASSO 通过 L1 正则化
实现变量选择与复杂度调整的平衡，通过 10 折交叉验证
确定最优 lambda 值。
```

### D. 模型构建

```
采用 R 软件（version 4.2.0）进行统计分析，使用 glmnet
包拟合 LASSO 模型，使用 survival 包构建 Cox 比例风险
回归模型，使用 rms 包绘制列线图（nomogram）。
```

### E. 模型验证

```
通过 ROC 曲线下面积（AUC）评估模型区分度，
通过校准曲线（calibration curve）评估模型校准度，
通过 Hosmer-Lemeshow 拟合优度检验评估预测值与
观察值的一致性（P>0.05 认为校准良好）。
Bootstrap 自举重采样（n=1000）进行内部验证。
```

### F. 决策曲线

```
决策曲线分析（Decision Curve Analysis, DCA）
用于评估模型的临床实用性。当阈值概率为 10%-60% 时，
模型的净获益率显著高于"全部治疗"或"全部不治疗"
策略，提示其具有较高的临床应用价值。
```

### G. SHAP 分析（机器学习）

```
采用 SHAP（SHapley Additive exPlanations）值评估
每个特征对模型预测的贡献。SHAP 值基于博弈论
中的 Shapley 值，正值表示特征促进预测为正向结局，
负值表示特征抑制预测。SHAP summary plot 用于展示
所有样本的特征贡献分布，SHAP dependence plot 用于
展示单个特征与预测概率的关系。
```

### H. 内部/外部验证

```
Bootstrap 自举重采样（n=1000）进行内部验证，
通过[XX 医院/数据库] 286 例[疾病]患者作为
外部验证集进行外部验证。
```

## 三、统计指标标准写法

| 指标 | 标准写法 |
|------|---------|
| **AUC** | AUC=0.847 (95%CI: 0.821-0.873) |
| **敏感度/特异度** | 敏感度 0.651、特异度 0.784 |
| **校准** | Hosmer-Lemeshow P=0.412（>0.05 校准良好）|
| **Bootstrap 验证** | 自举重采样 1000 次 |
| **C-index** | C-index=0.832 (95%CI: 0.805-0.859) |
| **OR/HR + 95%CI** | OR=1.43, 95%CI: 1.12-1.84, P=0.005 |
| **NRI** | NRI=0.123 (95%CI: 0.085-0.161) |
| **IDI** | IDI=0.045 (95%CI: 0.028-0.062) |

## 四、AUC 判读阈值

| AUC 范围 | 判读 |
|---------|------|
| **<0.5** | 无价值 |
| **0.5-0.7** | 较差 |
| **0.7-0.8** | 一般 |
| **0.8-0.9** | 良好 |
| **>0.9** | 优秀 |

## 五、ROC 曲线下面积比较的标准写法

```
与 ILD-GAP 模型相比，本研究构建的 3ARIDH 模型
在训练集 AUC 显著提高（0.847 vs 0.762, P=0.012），
在验证集 AUC 也有显著差异（0.821 vs 0.751, P=0.018）。
```

## 六、列线图（Nomogram）写作标准

### 6.1 列线图构造

```
本研究构建的列线图整合了年龄、性别、T 分期、N 分期、
M 分期、肿瘤分化程度、化疗状态 7 个独立预测因素。
每个因素对应一个评分轴（Points），所有因素评分相加
得到总分（Total Points），对应预测概率轴。
```

### 6.2 列线图使用说明

```
使用方法：临床医师根据患者各因素状态在列线图上
找到对应评分，将各评分相加得到总分，根据总分
在预测概率轴上读取对应的[结局]发生概率。
```

## 七、SHAP 分析写作标准

```
SHAP 分析显示，T 分期（平均 SHAP 值 0.32）和
N 分期（平均 SHAP 值 0.28）对模型预测贡献最大。
年龄、肿瘤分化程度次之。SHAP dependence plot 显示，
T 分期每升高一级，模型预测[结局]的风险随之升高。
```

## 十、常见错误清单

- ❌ 缺少内部验证（Bootstrap 或 K-fold）
- ❌ 缺少外部验证（即使是 single-center 也建议做时间外部验证）
- ❌ AUC 未报告 95%CI
- ❌ 校准曲线未绘制或未报告 Hosmer-Lemeshow P 值
- ❌ 决策曲线未绘制或阈值范围不明确
- ❌ 样本量不足（事件数 <10 × 候选变量数）
- ❌ 缺失值处理方法不报告
- ❌ 未遵循 TRIPOD 声明
- ❌ 训练集/验证集随机分组方法不说明
- ❌ 列线图无使用说明
- ❌ SHAP 分析仅给出结论而无图示
