## 二、客观化手段

### 1. 自称
| 类型 | 推荐自称 | 禁用自称 |
|------|---------|---------|
| 指南 | 本指南 / 专家组 / 指南工作组 | 我们 / 笔者 / 本文作者认为 |
| 综述 | 本文 / 作者 | 我们 / 笔者 / 本文作者认为 |
| 论著 | 本文 / 本研究 | 我们 / 笔者 / 本文作者认为 |
| Meta | 本研究 | 我们 / 笔者 / 本文作者认为 |
| 病例 | 本例 / 本研究 | 我们 / 笔者 / 本文作者认为 |

### 2. 客观化手段
- 无主语句/被动
- 骨架 = 实体主语 + 具体动词 + 量化/引证
- 定义/分类："X 定义为…""X: X 是一种…""即"
- 术语首现附英文全称 + 缩写

## 三、连接词与过渡词（短实）

| 关系 | 推荐词 | 禁用词 |
|------|--------|--------|
| 因果 | 因此 / 综上 / 从而 / 进而 / 在此基础上 | 值得注意的是 / 基于此 / 换言之 |
| 转折 | 但 / 然而 / 尽管…但 / 与…相比 | 不难看出 / 众所周知 |
| 补充 | 此外 / 同时 / 且 / 另一方面 | 总体而言 |
| 条件 | 基于 / 鉴于 / 如果 / 应 | 在当今…背景下 |
| 举例 | 例如 / 目前 / 近年来 | 近年来随着…的不断发展 |

## 六、润色实操

### 例 1：背景段

**修改前**（AI 腔）：
> 近年来，随着医学技术的不断发展和进步，热射病作为一类严重的临床急症，已经得到了广泛的关注和研究。但是，目前对于热射病致横纹肌溶解症的具体机制，仍然不是非常清楚，需要进一步深入探讨。

**修改后**（中华系列标杆）：
> 热射病（heat stroke, HS）是暴露于高温环境或剧烈运动所致的严重热相关疾病，以核心体温迅速升高（通常 >40℃）和中枢神经系统功能障碍为特征，病死率较高。横纹肌溶解症是 HS 常见且严重的并发症，但其病理生理机制尚未完全阐明。

### 例 2：方法段

**修改前**：
> 我们回顾性地收集了 2018 年到 2023 年在我们医院接受治疗的 100 个热射病患者的临床资料，对他们的数据进行了统计分析。

**修改后**：
> 回顾性选取 2018 年 1 月至 2023 年 12 月某三级甲等医院收治的 100 例热射病患者的临床资料。其中男性 78 例、女性 22 例，年龄（42.5±15.3）岁。

### 例 3：结果段

**修改前**：
> 经过治疗以后，大部分患者的症状都得到了明显的改善，肌酸激酶水平也显著下降。

**修改后**：
> 经综合治疗后，70 例（70.0%）患者存活出院。治疗后血清肌酸激酶、CK-MB、肌红蛋白及血肌酐水平均较治疗前显著下降（P 均<0.001）。

### 例 4：讨论段

**修改前**：
> 综上所述，本研究具有重要的临床价值，能够为热射病的诊治提供全新的思路，具有广阔的推广前景。

**修改后**：
> 本研究结果显示，早期积极的降温联合血液净化治疗可显著改善 HS 致横纹肌溶解症患者的预后，与既往研究结论一致。但本研究为单中心回顾性分析，样本量有限，结论的外部效度尚需多中心前瞻性研究验证。
