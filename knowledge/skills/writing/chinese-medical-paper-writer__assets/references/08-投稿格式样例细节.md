# 08 - 投稿格式样例细节（来自中华医学会《投稿格式样例稿件》）

**来源**：用户上传的《投稿格式样例稿件.pdf》实证解析 + 《中华医学会系列杂志编排规范（2016）》+ 各刊稿约

**适用范围**：所有中华医学会系列期刊投稿；本规范为最高优先级版式参考。

---

## 一、完整结构（按出现顺序）

```
1. 标题（中文，黑体三号居中，≤20 字）
   └ 副标题（如有）
2. 作者（仿宋四号居中，作者间逗号分隔）
   └ 上标 1,2,3...（单位序号）
3. 单位（按序号列出：1. XX 医院 XX 科，北京 100000；2. XX 医院 XX 科，北京 100000）
4. 通信作者 + Email（首页脚注）
5. 基金项目（首页脚注："基金项目：国家自然科学基金（No. 82271710）"）
6. 【摘要】（结构式，论著用【目的/方法/结果/结论】）
7. 关键词（分号"；"分隔，3-8 个，末尾不标点）
8. 中图分类号 / 文献标志码 / 文章编号（小四号黑体）
9. 英文题名（黑体三号居中）
10. Authors（英文作者名）
11. Affiliations（英文单位）
12. Corresponding author Email
13. 【Abstract】（Objective/Methods/Results/Conclusions 四段式）
14. Key words
15. References（仅在英文摘要后有 References 标题，正文无此节）
16. 正文（按论文类型）
17. 致谢（可选）
18. 利益冲突
19. 作者贡献声明
20. 参考文献（按 GB/T 7714-2015 顺序编码制）
```

## 四、标题层级编号体系（投稿样例实测）

### 严格按以下编号体系

| 层级 | 编号格式 | 示例 |
|------|---------|------|
| 大标题 | 独立，无序号 | H3K27 变异型弥漫性中线胶质瘤临床病理分析及 NTRK 作为治疗靶点的初步探讨 |
| 一级章节 | 不加序号，居中黑体 | 资料与方法 / 结果 / 讨论 / 参考文献 |
| 二级条目 | 阿拉伯数字 + 圆点 | 1. 资料收集：/ 2. 方法：/ 3. FISH：/ 4. 统计学分析： |
| 三级条目 | 括号数字 | (1) 临床特征：(2) 成人组和儿童组 DMG 临床特征： |
| 四级条目 | 阿拉伯数字 | 一般不出现；如需用 1.2.1 |

### 与 SKILL.md 主体编号的差异

**SKILL.md 主体规范是**：
- 一级章节：`一、`（顿号）
- 二级：`（一）`（无标点）
- 三级：`1.` `2.`（圆点）
- 四级：`(1)` `(2)`（圆括号）

**实际投稿样例是**：
- 一级章节：不加序号（"资料与方法"）
- 二级：`1.`（圆点）
- 三级：`(1)`（圆括号）

**两者差异原因**——投稿样例采用"一级标题不加序号"的做法（来自中华医学会系列杂志的实际操作），而 SKILL.md 主体规范参考了部分教材。

**修订方案**：
- 实际撰写论文时，**采用投稿样例的编号体系**（一级不加序号 + 1./(1)）
- 这与中华医学会《投稿格式样例稿件.pdf》一致
- SKILL.md 主体规范可保留作为"通用医学论文编号体系"参考

## 五、摘要规范（最严格）

### 中文摘要（论著）

**字数**：350-500 字
**结构**：【目的】【方法】【结果】【结论】四要素（必须用方括号标签）

### 【目的】
- 1-2 句
- 不重复题名
- 阐明研究目的

### 【方法】
- 对象 + 分组 + 检测指标 + 统计学方法 + 样本量
- 必含设计类型（前瞻性/回顾性/RCT/横断面等）

### 【结果】
- 必须给出关键数据
- 含百分比与统计量
- 不解释、不推断

### 【结论】
- 与研究目的呼应
- 避免夸大结论
- 不使用"具有重要价值"等空泛句

### 关键词
- 数量：3-8 个
- 分隔符：中文分号 `；`
- 末尾不标点
- 首选 MeSH 词
- 关键词应紧接摘要

### 中图分类号 / 文献标志码 / 文章编号
- 置于摘要与关键词之后
- 字体：小四号黑体
- 中图分类号：按《中国图书馆分类法》（第 5 版）
- 文献标志码：A（理论与应用研究学术论文）/ B（实用性技术成果报告）/ C（业务指导与技术管理性文章）
- 文章编号：本刊 ISSN + 年代 + 流水号

## 七、章节详细规范

### 资料与方法（章级居中黑体）

下设：
```
1. 资料收集：筛选 XXX 医院病理科 2016 年 7 月至 2021 年 3 月间的病理数据库…
2. 方法：…
3. FISH：…
4. 统计学分析：…
```

### 结果（章级居中黑体）

下设：
```
1. 临床资料：(1) 临床特征：224 例病例中女性为 106 例,男性为 118 例…
                 (2) 成人组和儿童组 DMG 临床特征：
2. 病理学特征：
3. 影像资料：
4. Pan-TRK 蛋白免疫组织化学染色：
5. NTRK FISH 检测结果：
6. 随访和预后：
```

### 讨论（章级居中黑体）

- 不设二级标题（按段叙述）
- 首段：重述主要发现
- 中段：与文献对比、机制推测
- 末段：局限性、未来方向

## 八、图表规范

### 表格

- **三线表**（顶线、表头分隔线、底线；合计/统计处理行加分界横线）
- **表序/表题位于表上方**（如"表 1 不同年龄组 H3K27 变异型弥漫性中线胶质瘤 224 例临床病理特征[例(%)]")
- **表注位于表下方**（注释符号用 ①②③④）
- 数据有效位数一致（按 SD 的 1/3 确定）
- 数值小数点对齐
- P 值列在该分组有 P 值时填入，无则留空

### 图

- **图序/图题位于图下方**
- **图注**（Figure legend）位于图题下方
- 含子图标签（A~I、A~L 等）
- 图注说明染色方法与放大倍数（如"HE 中倍放大""Benchmark Ultra 自动染色 中倍放大""FISH 法 高倍放大"）
- 图片分辨率 ≥300 dpi
- 图表随文出现（如"见表 1""如图 2""图 3 显示"）

## 九、参考文献格式（GB/T 7714-2015 顺序编码制）

### 期刊文献[J]

```
[3] Wu G, et al. The genomic landscape of diffuse intrinsic pontine glioma and pediatric non-brainstem high-grade glioma[J]. Nat Genet, 2012, 44(3): 251-253. DOI: 10.1038/ng.1102.
```

注意：
- 年、卷、期、页之间用逗号分隔（**不是中文逗号**）
- DOI 完整
- 末尾英文点

### 图书[M]

```
[1] Louis DN, Ohgaki H, Wiestler OD, et al. WHO classification of tumours of the central nervous system[M]. 4th ed. Lyon: IARC Press, 2016.
[2] WHO Classification of Tumours Editorial Board. WHO classification of tumours of the central nervous system[M]. 5th ed. Lyon: IARC Press, 2021.
```

### 网络资源[EB/OL]

```
[11] Wells GA, et al. The Newcastle Ottawa Scale (NOS) for assessing the quality of nonrandomised studies in meta-analyses[EB/OL]. [2025-04-04] http://www.ohri.ca/programs/clinical_epidemiology/oxford.asp.
```

## 十、利益冲突 / 作者贡献声明

### 利益冲突

- 必须有独立段落
- 标准句："所有作者声明不存在利益冲突"或"XX 作者声明接受 XX 公司资助"

### 作者贡献声明

- 必须有独立段落
- 列各作者具体贡献（如"XX 负责研究设计、统计分析、论文撰写；YY 负责数据收集、结果解释；ZZ 负责研究指导、论文审校"）
- 多作者按贡献排序

---

## 十二、致谢

- 致谢在利益冲突与作者贡献之后，参考文献之前
- 标准句："感谢 XX 单位/XX 基金/XX 个人对本研究的支持"
- 可列出基金号、技术协助等

## 十三、统计学表达规范（投稿样例实测）

| 场景 | 标准写法 |
|------|---------|
| 样本量描述 | 精确分数如 `59/98, 60.2%`，括号内写例(%) |
| P 值写法 | `P<0.05` 为差异有统计学意义 |
| 检验水准 | 三档：`P>0.05`、`P<0.05`、`P<0.01` |
| 免疫组化判读 | 阳性 ≥1% 判读，强度分负/1+/2+/3+ |
| 缩写首次出现 | 注全称（如 DMG、MGMT、NTRK、FISH、IHC） |
| 总体参数 | OR/HR + 95%CI + P |
| 百分比范围 | 用连字符 `31%-33%`，不用 `~` |

## 十四、各期刊的细分差异

| 期刊 | 特征差异 |
|------|---------|
| **中华医学杂志**（总刊）| 摘要 ≤300 字；栏目最全 |
| **中华外科杂志** | 摘要 300-500 字；统计学要求最严 |
| **中华心血管病杂志** | **I/IIa/IIb/III + A/B/C** 推荐类别固定模板 |
| **中华血液学杂志** | "1 例报告并文献复习"是典型体例；摘要 200-300 字 |
| **中华皮肤科杂志** | 摘要 300-500 字；明确禁用一稿两投 |
| **中华新生儿科杂志** | 多用预测模型 + 列线图；脚注列国家自然科学基金号 |
| **中华预防医学杂志** | 流行病学调查为特色栏目 |
| **中华流行病学杂志** | P=0.000 写为 P<0.001；统计学符号用斜体（GB/T 3358.1-2009）|
| **中华肿瘤杂志** | t、χ²、F 精确到小数点后 2 位；P 值精确到小数点后 3 位 |
| **中华显微外科杂志** | 主打显微外科领域；编辑部极为重视规范性 |

## 十五、撰写实战 Checklist

撰写完成前对照本规范逐项核查：

```
□ 1. 标题是否 ≤20 字、是否用黑体三号居中？
□ 2. 作者是否标上标 + 单位是否对应？
□ 3. 首页脚注是否包含 DOI、基金项目、通信作者、单位？
□ 4. 中英文摘要是否结构式【目的/方法/结果/结论】？
□ 5. 摘要结果段是否给出具体百分比与统计量？
□ 6. 关键词是否分号分隔 + 末尾无标点？
□ 7. 中图分类号是否正确？
□ 8. 正文是否按"资料与方法→结果→讨论"结构？
□ 9. 一级章节是否不加序号居中黑体？
□ 10. 二级是否用 "1." 圆点？
□ 11. 三级是否用 "(1)" 圆括号？
□ 12. 表格是否为三线表？
□ 13. 图题是否在图下方、表题是否在表上方？
□ 14. 缩写首次出现是否注全称？
□ 15. 利益冲突是否声明？
□ 16. 作者贡献是否声明？
□ 17. 参考文献是否按 GB/T 7714-2015 规范？
□ 18. DOI 是否完整？
□ 19. 是否避免使用"具有显著性差异"等禁用表述？
□ 20. 参考文献是否全部真实可查？
```

任何一项回答"否" → 立即修正。
