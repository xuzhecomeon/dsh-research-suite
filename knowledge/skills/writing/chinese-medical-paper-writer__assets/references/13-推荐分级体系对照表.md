# 13 - 中华医学会期刊推荐分级体系对照表

**来源**：基于 22 篇中华医学会期刊共识/指南论文实证归纳（2026-08-10 深度精读）

**关键发现**：中华医学会期刊使用**至少 6 套不同的推荐分级体系**，没有任何一个"统一标准"。

---

## 一、6 套主要分级体系对照

### 体系 A：GRADE 强/弱推荐 + 高/中/低/极低证据级别（国际通用）

**代表期刊**：中华肝脏病杂志、中华骨质疏松和骨矿盐疾病杂志、中华结核和呼吸杂志

| 推荐强度 | 含义 | 临床实践指导 |
|---------|------|------------|
| **强推荐（推荐）** | 获益显著超过风险 | 必须执行 |
| **弱推荐（建议 / 条件性推荐 / 酌情推荐）** | 获益与风险接近 | 视情况而定 |
| **GPS**（Good Practice Statement） | 专家共识强推荐 | 应当执行 |

| 证据级别 | 含义 |
|---------|------|
| **高（A）** | 进一步研究很难改变估计 |
| **中（B）** | 进一步研究可能影响估计 |
| **低（C）** | 进一步研究很可能影响估计 |
| **极低（D）** | 任何估计都非常不确定 |

**实证样本**：
> "推荐意见 1：对于 NSTE-ACS 患者，应在入院后尽快完善 12 导联心电图。（强推荐，中等质量证据）"

### 体系 B：I/IIa/IIb/III + A/B/C（国际心血管病学会标准）

**代表期刊**：中华心血管病杂志（固定模板）、部分心原性休克共识

| 推荐类别 | 含义 |
|---------|------|
| **Ⅰ类** | 获益>>风险，应实施 |
| **Ⅱa类** | 获益>>风险，大多数情况下应实施 |
| **Ⅱb类** | 获益≥风险，可考虑实施 |
| **Ⅲ类** | 无获益甚至有害，不应实施 |

| 证据级别 | 含义 |
|---------|------|
| **A** | 来自多项 RCT |
| **B** | 来自单项 RCT 或大型非随机研究 |
| **C** | 来自专家共识、小样本研究、回顾性研究 |

**实证样本**：
> "**推荐**：对于 NSTE-ACS 患者，应在入院后尽快完善 12 导联心电图（Ⅰ, C）。"

### 体系 C：陈述（Statement）体（无明确分级）

**代表期刊**：中华消化杂志（部分共识）、中华肝脏病杂志（部分共识）

| 编号 | 形式 |
|------|------|
| **陈述 1** | [主题] + [简短陈述] |
| **陈述 2** | [主题] + [简短陈述] |
| ... | 不附证据级别与推荐强度 |

**实证样本**：
> "陈述 1：肝硬化是一种全球性疾病，与显著增加的发病率与病死率相关。"

### 体系 D：建议（Recommendation）体

**代表期刊**：中华外科杂志（部分指南）

| 编号 | 形式 |
|------|------|
| **建议 1** | [主题] + [建议] |
| **建议 2** | [主题] + [建议] |

**实证样本**：
> "建议 1：急性胆道系统感染患者应在确诊后尽早开始经验性抗菌药物治疗（强推荐，中等质量证据）。"

### 体系 E：推荐意见（Recommendation）体（带证据级别）

**代表期刊**：中华消化杂志（部分共识）、中华肾脏病杂志、中华儿科杂志

| 编号 | 形式 |
|------|------|
| **推荐意见 1** | [陈述] + [证据级别, 推荐强度] |
| **推荐意见 2** | [陈述] + [证据级别, 推荐强度] |

**实证样本**：
> "推荐意见 1：对于 CD 高危患者，应在 CDI 一线抗菌药物治疗后给予贝曲唑巴或菲达霉素以降低复发风险。（强推荐，高质量证据）"

### 体系 F：临床问题 + 推荐意见（Q&A 体）

**代表期刊**：中华儿科杂志（儿童重症早期康复指南）、中华急诊医学杂志

| 编号 | 形式 |
|------|------|
| **问题 1**：[临床问题] | |
| **推荐意见 1**：[陈述] + [证据级别, 推荐强度] | |

**实证样本**：
> "问题 5：早期康复介入是否可改善重症患儿的远期生活质量？
> 推荐意见 5：早期康复介入可改善重症患儿的远期生活质量（弱推荐，低质量证据）。"

### 体系 G（特例）：中华医学会肺癌临床诊疗指南 1/2A/2B/3 四级

| 推荐类别 | 含义 |
|---------|------|
| **1 类** | 强推荐 |
| **2A 类** | 中等推荐 |
| **2B 类** | 弱推荐 |
| **3 类** | 不推荐 |

## 三、强制规范：双层标注必须位于句末

**所有推荐意见后**都必须用括号标注：

```
推荐意见 1：[陈述]。  （[推荐类别], [证据级别]）
```

或

```
推荐意见 1：[陈述]。  （[推荐强度], [证据质量]）
```

**实证样本**：
> "推荐意见 2：对于 STEMI 患者合并心原性休克，应在确诊后 2  小时内实施直接 PCI。（Ⅰ, B）"

**常见错误**：
- ❌ 推荐意见后无标注
- ❌ 推荐意见中标注（如 "(强推荐)" 内嵌句中）
- ❌ 标注位置在句首

---

## 四、统计同意率标注

部分共识类论文会在每条推荐意见后注明**德尔菲法的同意率**，例如：

```
推荐意见 5：...（强推荐，中等质量证据；统计同意率 92.5%）
```

---

## 五、撰写实战 Checklist

撰写共识/指南类论文时：

- [ ] 已确认目标期刊及其采用的分级体系（参考本表）
- [ ] 推荐意见编号格式与该刊一致（如"推荐意见 N"）
- [ ] 每条推荐意见后**必有**双层括号标注
- [ ] 推荐意见的实质内容（陈述 + 证据级别）
- [ ] 推荐意见的实施建议（若适用）
- [ ] 推荐意见的理由（若适用）
- [ ] 首页免责声明完备

---

## 六、撰写建议

撰写共识/指南时，**绝对不要**：

1. 使用与目标期刊不一致的分级体系（如投《中华心血管病杂志》却用 GRADE）
2. 推荐意见缺少证据级别标注
3. 推荐意见表述空泛（无具体证据支撑）
4. 推荐意见数量过多（无重点）
5. 缺少方法学声明（注册平台、证据系统、共识法）
