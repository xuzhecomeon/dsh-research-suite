# 10 - 典型章节开头句模板（来自中华医学会期刊实证）

**来源**：基于 34 篇中华医学会期刊论文的实证归纳（2026-08-10 深度检索）

**用途**：撰写论文时直接套用对应模板，避免"小学生作文"风格。

---

## 一、综述类论文

### 1.1 综述开篇（4 种典型范式）

#### 范式 1：领域意义 + 综述目的

```
[领域/疾病] 是 [重要性描述] 的 [分类]。本文系统综述
[主题] 的 [研究进展/作用机制/临床应用/安全性评价]，
以期为 [临床实践/转化研究] 提供科学依据。
```

**实证样本**：
> "镇静镇痛策略是危重症患者治疗的重要组成部分……本文系统综述 [主题] 的 [演变历程]，以期为临床实践中镇静策略的个体化应用提供科学依据。"

#### 范式 2：历史事实驱动

```
[历史人物/事件] + [时间] + [首次事件] + [领域意义]。
本文系统综述 [主题] 的 [研究进展]，
旨在为 [读者对象] 提供 [参考价值]。
```

**实证样本**：
> "瑞典 Wrelind 教授利用大豆油和蛋黄卵磷脂首次成功研制了可静脉输注的长链脂肪乳剂（Intralipid），开创了肠外营养（PN）治疗方法[1]。本文系统综述 [主题]。"

#### 范式 3：流行病学切入

```
[疾病/主题] 已经成为全球性的公共卫生问题[1]。
[权威流行病学数据] 显示 [关键数据点] [1-2]。
本文综述 [主题] 的研究进展。
```

**实证样本**：
> "心血管药物中毒已经成为全球性的公共卫生问题[1]。美国中毒控制中心 2021 年数据显示 CCB 中毒致死占心血管药物中毒死亡的 54%[1]。国内单中心 2014—2021 年数据显示 CCBs 中毒病死率达 28.8%[2]。本文综述 [主题]。"

#### 范式 4：研究空白引入

```
目前国内外对于 [主题] 的文献报道 [现状描述]，
以 [个案报道/小样本研究] 为主，
[深入探讨/系统研究/高质量证据] 罕见。
本文综述 [主题] 的研究进展。
```

**实证样本**：
> "目前国内外对于氨氯地平中毒文献报道散见，以个案报道为主，深入探讨其临床及血流动力学特点的研究罕见。本文系统综述 [主题]。"

### 1.2 综述章节开头句

#### 机制章节

```
[X] 是 [分类] 中的 [重要性描述]，
其 [生物学特性/作用机制] 主要涉及 [通路/受体/细胞]，
[参与/调节] [生理/病理过程]。
```

**实证样本**：
> "乙腈进入人体后氧化生成羟基乙腈，进而生成氰化氢和甲醛[5]并释放氰根离子（CN⁻），后者与细胞色素氧化酶中 Fe³⁺ 结合，阻止其还原成 Fe²⁺，阻断线粒体氧化过程，导致细胞内窒息[6]。"

#### 流行病学章节

```
[主题] 的 [发病率/病死率/流行特征] 因 [地区/人群/时间] 而异。
[权威流行病学数据] 显示 [关键数据点] [1-3]。
```

#### 临床证据章节

```
近年来，多项 [RCT/队列研究/Meta 分析] 探讨了 [主题] 在
[疾病] 中的 [作用/效果]。
本文检索 [数据库]，[检索时限]，
共纳入 [N 项研究/N 例患者] 的 [研究结果]。
```

#### 安全性章节

```
[主题] 的 [不良反应/安全性] 已受到广泛关注。
现有证据显示 [关键发现]，
但长期 [安全性/罕见不良反应] 数据仍有限。
```

#### 展望章节

```
未来研究应在以下方向深化：
第一，[方向 1]；
第二，[方向 2]；
第三，[方向 3]；
第四，[方向 4]。
```

## 二、原创论著（临床观察/队列/数据库建模）

### 2.1 引言段（无独立标题）

```
[疾病/主题] 是 [重要性描述]，
[流行病学数据/关键数据] [1-2]。
然而，[研究空白/未解决问题]，
[本研究目的] 旨在 [研究目的]，
以期为 [临床意义] 提供 [证据/参考]。
```

**实证样本**：
> "急性化学中毒因其高发病率与高致死率，已成为全球范围内威胁公众健康的重大公共卫生问题。然而 [研究空白]。本研究 [目的]，旨在 [为临床实践/治疗决策] 提供 [循证依据]。"

### 2.2 资料与方法

#### 资料与方法开头句

```
回顾性选取 [单位] 收治的 [疾病] 患者 [N 例]，
其中 [分组描述]。
比较两组的 [指标 1]、[指标 2]、[指标 3] 等。
采用 [SPSS 26.0 等] 软件进行统计学分析。
计量资料以 (x̄ ± s) 表示，
组间比较采用 t 检验或 Mann-Whitney U 检验；
计数资料以 [例(%)] 表示，
组间比较采用 χ² 检验或 Fisher 确切概率法。
采用多因素 Logistic 回归分析 [独立影响因素]。
检验水准 α=0.05。
```

**实证样本（来自样本 3）**：
> "回顾性选取因氨氯地平中毒并发休克在北京大学第三医院急诊科救治的成年患者，同时也检索了已发表的氨氯地平中毒个案、系列报道和临床研究中的成年患者。"

### 2.3 结果

#### 基线特征

```
研究共纳入 [N 例] 患者，
其中男 [N 例]（[%]）、女 [N 例]（[%]），
平均年龄（[X]±[X]）岁。
两组基线特征比较，
[指标] 差异无统计学意义（P>0.05），
具有可比性。
```

#### 主要结果

```
与 [A 组] 相比，[B 组] [指标] 显著 [升高/降低]
（[X±X] vs [X±X]，t=[X]，P<0.05）。
多因素 Logistic 回归分析显示，
[因素] 是 [结局] 的独立危险因素
（OR=[X]，95%CI: [X]-[X]，P<0.05）。
```

#### ROC 分析

```
ROC 曲线下面积 AUC=[X]（95%CI: [X]-[X]），
最佳界值 [X]（敏感度 [X]、特异度 [X]）。
```

### 2.4 讨论

#### 讨论开头句

```
本研究结果显示 [主要发现]，
这一发现与文献报道[X]一致，
提示 [机制/临床价值]。
其可能的机制包括：（1）[机制 1]；（2）[机制 2]；（3）[机制 3]。
同时，本研究亦与 [Y 研究] 的报道存在差异[X]，
分析原因可能与 [差异来源] 有关。
```

#### 局限性

```
本研究存在以下局限性：
（1）样本量较小，系单中心回顾性研究；
（2）随访时间较短；
（3）部分指标存在测量偏倚。
未来需开展多中心、前瞻性研究加以验证。
```

```

```

## 四、病例报告

### 4.1 病例资料（开头句）

```
患者 [性别]，[年龄] 岁，
[日期] 因 "[主诉 + 时间 + 伴随症状]" 入院。
既往 "[疾病 1][疾病 2]" 病史。
入院查体：[关键阳性/阴性体征]。
辅助检查：[关键检查结果]。
```

**实证样本**：
> "患者女，72岁，2024 年 11 月 13 日因'误服不明液体 15 ml 后 1 d 伴咽痛、上腹痛'入院。既往'高血压'病史 10 年。"

### 4.2 讨论开头句（病例报告）

```
[毒物/疾病] 属于 [分类] 中的一种。
本文报告 1 例 [主诊断] 患者，
并结合相关文献复习，
对 [机制/鉴别诊断/治疗/预后] 进行探讨。
```

**实证样本**：
> "急性虫螨腈中毒属于新新型毒型农药中毒。本文报告 1 例急性虫螨腈中毒并发横纹肌溶解症患者，并结合相关文献复习，对其毒理机制、临床特征及治疗进行探讨。"

### 4.3 病例报告+文献复习（机制讨论段）

```
[毒物/药物] 属于 [分类]，
[作用机制] 主要涉及 [通路/受体/细胞] [机制描述]。
人类 [中毒/疾病] 症状主要包括 [症状 1]、[症状 2]、[症状 3] [1-3]。
[本例患者] 的 [特殊表现] 与 [文献报道] [一致/存在差异]，
推测 [机制] 与 [本例] 的 [特殊情况] 有关。
目前 [本病] 无特效解药，
治疗以 [减吸/促排/对症支持] 为主[4-6]。
```

**实证样本**：
> "新烟碱类杀虫剂主要通过激动烟碱型乙酰胆碱受体 α4β2 亚型发挥作用，对哺乳动物毒性相对较低，但其分解产物可经血脑屏障引起神经系统症状[1]。人类新烟碱类中毒症状主要包括头晕、乏力、恶心、呕吐等主观症状和流涎、瞳孔缩小、肺水肿等客观体征[2-3]。本例患者以横纹肌溶解为主要表现，与既往报道的噻虫嗪中毒典型表现存在差异，推测可能与中毒后抽搐、躁动导致肌肉损伤有关[4]。目前噻虫嗪中毒无特效解毒剂，治疗以洗消、血液净化及对症支持为主[5-6]。"

## 六、Meta 分析 / 系统评价

### 6.1 资料与方法

#### 检索策略

```
系统检索 [PubMed、Embase、Cochrane Library、CNKI、万方、CBM] 数据库，
检索时限为 [建库至 XXXX 年 X 月]。
英文检索词：[XXX]；
中文检索词：[XXX]。
采用主题词与自由词相结合的方式，
并辅以手工检索相关期刊。
```

#### 纳排标准

```
纳入标准：
（1）[研究类型]（RCT/队列研究/病例对照研究）；
（2）[研究对象]；
（3）[干预措施]；
（4）[结局指标]；
（5）[语种]（不限/中英文）。

排除标准：
（1）[排除研究类型]；
（2）[数据不完整]；
（3）[重复发表]；
（4）[无法获取全文]。
```

#### 文献筛选与数据提取

```
由 [N 名] 研究者独立筛选文献、提取数据并交叉核对，
分歧由第三方裁决。
采用 EndNote X9 软件去重。
```

#### 偏倚风险评价

```
采用 Cochrane 偏倚风险评价工具（RoB 2.0）评估 RCT 的偏倚风险；
采用 ROBINS-I 评估非随机研究的偏倚风险。
```

#### 统计学分析

```
采用 RevMan 5.4 软件进行 Meta 分析。
计数资料采用相对危险度（RR）为效应量，
计量资料采用均数差（MD）为效应量，
各效应量均给出 95%CI。
异质性检验采用 Q 检验和 I² 统计量。
若 I²≤50% 且 P>0.1，采用固定效应模型；
否则采用随机效应模型，并分析异质性来源。
采用漏斗图和 Egger 检验评估发表偏倚。
检验水准 α=0.05。
```

### 6.2 结果

#### 文献筛选流程

```
初检获得相关文献 [N 篇]，
经 EndNote 去重后剩余 [N 篇]，
经阅读文题和摘要后排除 [N 篇]，
阅读全文后排除 [N 篇]，
最终纳入 [N 篇] 文献进入 Meta 分析。
```

#### Meta 分析结果

```
[N 项研究] 共纳入 [患者数] 例。
Meta 分析结果显示，
与 [对照组] 相比，[实验组] [结局] 显著 [改善/增加]
（RR=[X]，95%CI: [X]-[X]，P<0.05）。
异质性 I²=[X]%，Q 检验 P=[X]，
采用 [固定效应/随机效应] 模型。
```

#### 亚组分析

```
按 [X 因素] 进行亚组分析显示，
<[X] 岁组（RR=[X]，95%CI: [X]-[X]，P<0.05）与
≥[X] 岁组（RR=[X]，95%CI: [X]-[X]，P>0.05）效应量存在差异。
```

### 6.3 讨论

```
本研究 Meta 分析结果显示 [主要发现]。
[与某研究] 报道一致[X]，
但与 [另研究] 存在差异[Y]，
分析原因可能与 [差异来源] 有关。
本研究存在以下局限性：
（1）纳入研究质量参差不齐；
（2）部分研究样本量较小；
（3）存在一定异质性。
未来需开展更多大样本、高质量的 RCT 加以验证。
```

## 七、专家共识 / 临床实践指南

### 7.1 共识/指南开头

```
[疾病/主题] 是 [重要性描述]。
然而目前对于 [主题] 的诊治 [现状描述]，
存在 [不规范/争议/缺乏标准] 等问题。
为规范 [主题] 的 [诊断/治疗/管理]，
由 [制定组织] 组织相关领域专家，
基于 [最新循证医学证据]，
制定本 [共识/指南]。
本 [共识/指南] 已在 [国际实践指南注册平台] 注册
（注册号：[XXXX]）。
```

### 7.2 推荐意见格式

```
[推荐意见 X]：对于 [人群]，
[推荐措施]（[证据等级：I/II/III/IV]，
[推荐强度：A/B/C/强推荐/弱推荐/GPS]）。

推荐依据：[依据描述]。

证据总结：[证据描述]。

实施建议：[实施建议]。

其他考虑：[其他考虑]。

推荐理由：[理由描述]。
```

**实证样本**：
> "[推荐意见 7] 急性高危 PTE（（血流动力学不稳定）患者，在绝对禁忌或溶栓失败时可考虑使用静脉-动脉体外膜肺氧合（VA-ECMO）桥接治疗（证据级别：C；有条件推荐）。"

### 7.3 共识/指南收尾

```
本 [共识/指南] 旨在为 [目标用户] 提供 [决策依据]。
随着 [研究进展]，
本 [共识/指南] 将定期更新。
```

## 八、模板速查表

| 论文类型 | 开头范式 | 关键句 | 必备模块 |
|---------|---------|--------|---------|
| 综述 | 4 种（领域意义/历史/流行病/空白）| "本文系统综述…以期为…提供依据" | 单段摘要+无引言+机制→检测→防治→展望 |
| 论著（临床）| 流行病学切入 | "回顾性选取…收治的…患者" | 结构式摘要+引言段+1./2./3.+讨论 |
| 论著（基础）| "本研究利用…模型揭示了…" | 方法细分动物/试剂/方法/统计 | 结构式摘要+结果按指标分节+因果推测 |
| 病例报告 | "患者XX，XX岁，…入院" | "本文报告1例…并结合文献复习" | 病例资料+讨论+可附图 |
| Meta 分析 | "系统检索…数据库" | PRISMA 流程图 | 结构式摘要+方法透明+异质性+敏感性 |
| 专家共识 | "为规范…由…组织专家…制定" | 推荐意见+证据等级 | 推荐意见四/五段式+方法学声明 |

## 九、使用指南

1. **撰写时**：先选定论文类型 → 套用对应章节模板 → 替换占位符
2. **润色时**：检查是否仍残留"模板痕迹"（如"XX"未替换）
3. **禁忌**：直接复制模板而不替换，会被视为"AI 痕迹"
