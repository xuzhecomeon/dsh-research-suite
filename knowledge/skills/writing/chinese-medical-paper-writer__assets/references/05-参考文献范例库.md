# 05 - 参考文献范例库（v2.0 扩充版）

## ⚠️ 撰写类任务必读（最高优先级）

撰写论文时，所有引用的参考文献**必须真实可查**，含完整作者、期刊、年卷期页码、DOI。

- **严禁虚构**作者、期刊、年卷期页码、DOI
- **严禁占位写法**（如"王某某""张某某"等）
- **无法核实时**标注"原始来源待考"，不得用占位写法
- **二次引用**严禁"转引自卫勤精兵网""原始数据被XX媒体引用"

## ⚠️ 投稿样例实测细节

期刊文献格式：**年、卷、期、页之间用英文逗号 `,`**（不是中文逗号）

图书格式：**第 X 版 + 出版地 + 出版社 + 出版年 + 页码**

DOI：紧跟页码后，**英文大写 + 冒号 + 空格 + 全小写**

## 一、GB/T 7714-2015 顺序编码制基本规则

1. **编号格式**：`[1][2][3]...` 或 `[1-3]`、`[1, 3]`、`[1, 3-5]`
2. **正文引用位置**：作**句末上标**
3. **条目格式**：`作者. 题名[文献类型标识]. 刊名, 年, 卷(期): 起-止页. DOI: 10.xxxx/xxxxx.`
4. **作者数量**：
   - > 3 人：英文前 3 + `et al.`；中文前 3 + `等`
   - = 2 人：全列
   - = 1 人：全列
5. **西文作者连接符**：`", et al."`（逗号 + 空格 + et al.）
6. **DOI**：末尾英文点；DOI 大写 + 冒号 + 空格 + 全小写
7. **类型标识**：`[J]`/`[M]`/`[D]`/`[J/OL]`/`[EB/OL]`/`[C]`/`[N]`/`[S]`/`[P]`/`[DB]`
8. **英文刊名**：NLM 缩写
9. **中文刊名**：全称
10. **页码**：`年,卷(期):起-止页.`

## 五、DOI 标准格式

### DOI 大小写

DOI **大写 + 冒号 + 空格 + 全小写**（除前缀 `10.`）：

- ✓ `DOI: 10.1038/s41572-021-00264-3`
- ✓ `DOI: 10.3760/cma.j.cn101441-20241120-00431`
- ✓ `DOI: 10.3760/cma.j.cn121094-20240406-00145`
- ✗ `DOI:10.1038/s41572-021-00264-3`（冒号后缺空格）
- ✗ `DOI: 10.1038/S41572-021-00264-3`（末尾 S 大写）

### 末尾标点

末尾为**英文点** `.`，紧随 DOI 之后：

- ✓ `...2021-00264-3.`
- ✗ `...2021-00264-3，`

## 六、特殊场景处理

### 同一作者多篇文献

按出版年递增排列，年份相同时按题名字母顺序，用 `a`、`b`、`c` 区分：

```
[5] Smith J, et al. Title A[J]. Lancet, 2020a, 395(10220): 100-105.
[6] Smith J, et al. Title B[J]. Lancet, 2020b, 395(10221): 200-205.
```

### 中英文混排

```
[1] Moore EE, et al. Trauma-induced coagulopathy[J]. Nat Rev Dis Primers, 2021, 7(1): 30. DOI: 10.1038/s41572-021-00264-3.
[2] 贾佳, 等. 卵巢微环境与多囊卵巢综合征关系的研究进展[J]. 中华生殖与避孕杂志, 2025, 45(4): 409-413. DOI: 10.3760/cma.j.cn101441-20241120-00431.
```

## 七、自查清单（42 条样本基础上）

- [ ] 全部文献含 DOI 或可访问 URL
- [ ] 英文作者 >3 时用 "et al."，=2 时全列
- [ ] 中文作者 >3 时用 "等"，=2 时全列
- [ ] 西文作者用 ", et al."（逗号+空格+et al.）
- [ ] DOI 末尾为英文点，大写+冒号+空格+全小写
- [ ] 英文刊名用 NLM 缩写
- [ ] 中文刊名用全称
- [ ] 类型标识正确（[J]/[M]/[D]/[J/OL]/[EB/OL]/[C]/[N]/[S]/[P]）
- [ ] 页码格式为 "年,卷(期):起-止页."
- [ ] 无"转引自""原始数据被XX引用"等无标准要素占位写法
- [ ] 电子文章引用日期 `[YYYY-MM-DD]`
- [ ] 末尾英文点
- [ ] **作者真实可查**（不能出现"王某某""张某某"等占位）
- [ ] **期刊真实可查**（不能出现无法核实的期刊名）
- [ ] **年卷期页码真实可查**
- [ ] **DOI 真实可查**（可到 doi.org 验证）

## 八、生成 Word 时上标实现

使用 `python-docx`：

```python
from docx import Document
from docx.shared import Pt

doc = Document()

# 段落
para = doc.add_paragraph()

# 普通文字
run1 = para.add_run("…的研究已经证实")
run1.font.size = Pt(12)

# 参考文献上标
run2 = para.add_run("[1-3]")
run2.font.superscript = True
run2.font.size = Pt(12)

# 普通文字
run3 = para.add_run("。")
run3.font.size = Pt(12)
```

**交付前必查**：

```python
# 统计上标数与引用总数是否一致
import re
text = doc.element.xml
superscripts = re.findall(r'<w:vertAlign w:val="superscript"/>.*?\[(\d+(?:-\d+)?(?:,\s*\d+(?:-\d+)?)*)\]', text, re.DOTALL)
total_references_in_body = sum(len(s.split(',')) for s in superscripts)
print(f"正文引用总数：{total_references_in_body}")
```
