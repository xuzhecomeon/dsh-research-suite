## 一、原创论著 - 基础/动物机制

### 框架

```
大标题
摘要【目的】【方法】【结果】【结论】
关键词
Abstract (Objective/Methods/Results/Conclusions)
Key words
资料与方法
  一、动物
  二、试剂
  三、具体方法
    （一）模型制备
    （二）干预措施
    （三）检测指标
  四、统计学方法
结果
  一、一般情况
  二、指标 1（X 表达）
  三、指标 2（Y 通路）
  四、指标 3（Z 结局）
讨论
  （首段：背景流行病学 → 回归本研究）
  （中段：与文献对比、机制推测）
  （尾段：局限与展望）
参考文献
```

### 风格要点

- **方法细分**："动物/试剂/具体方法/统计学"四节
- **结果按指标分节**，每节先描述主结果，再用统计量佐证
- **讨论首段先述背景流行病学再回归本研究**——"…是临床面临的棘手问题。本研究…"
- 收束以 **"……可能通过……发挥……作用"** 因果推测句式
- 客观、**少用第一人称**——"本研究建立/采用"为主体

### 方法学可重复细节

- 动物来源 + 许可证号
- 随机数字表法分组
- 具体造模步骤（麻醉浓度、结扎比例、针规格、容积剂量）
- 试剂货号
- 独立统计学节
- 计量资料 `均数±标准差` 与 `P<0.05` 标注

## 二、原创论著 - 临床观察/队列/数据库建模

### 框架

```
大标题
摘要【目的】【方法】【结果】【结论】（方法段明示设计：前瞻性/回顾性/横断面+队列）
关键词
资料与方法
  一、研究对象
    （一）纳入标准
    （二）排除标准
    （三）分组（观察组与对照组 / 早期与晚期 / 训练集与验证集）
  二、研究方法
    （一）资料收集
    （二）变量定义
    （三）统计学方法
  三、伦理审批与知情同意
结果
  一、一般资料
  二、基线特征比较
  三、主要结局
  四、亚组分析
  五、敏感性分析
讨论
参考文献
```

### 风格要点

- **必列**：纳入排除标准、一般资料、分组、伦理审批号、知情同意
- **数据库建模** 按"研究对象、变量筛选、模型构建、验证(ROC/DCA)"对应
- **摘要方法段**必须明示设计类型：前瞻性 / 回顾性 / 横断面 / 队列 / 病例对照
- 队列研究需报告**失访率**与**删失处理**
- 预测模型报告：**AUC/C-index/R²/Brier/H-L 校准/Bootstrap**

## 三、综述（细分：研究进展 / 机制综述）

### 框架

```
大标题（栏目标识"·综述·"）
单段指示性摘要（无结构式标签）
关键词
正文（无独立引言标题）
  一、（机制/检测/防治/总结展望 第一类）
    （一）…
      1. …
        (1) …
  二、…
  三、…
  四、总结与展望
参考文献（60-90条，近5年为主）
```

### 风格要点

- **栏目标识**："·综述·"置于标题前
- **单段非结构摘要**（无【目的】【方法】标签）
- **1/1.1 两级编号**为主
- 骨架："机制、检测、防治、总结展望"——**末章必落治疗或转化**
- 无引言标题，以未编号导引段承担
- **参考文献 60-90 条**（近 5 年为主）
- 自称："作者/本文"回避"我们"
- **述评结合**（引证、结果、评议三段式）

### 综述引述语体

| 场景 | 推荐句式 |
|------|---------|
| 背景 | "近年来/目前/当前/…已经证实…" |
| 综合 | "综上所述/本文系统梳理…" |
| 证据 | "研究显示/研究表明/既往研究表明…" |
| 数据转述 | 定性转述（敏感度/特异度%、增幅、相关/负相关）——**不列原始 p 值** |

### 机制综述骨架

```
概述 → 临床类型表现 → 病理生理机制分述 → 临床管理策略 → 小结与展望
```

## 四、病例报告 + 文献复习

### 框架

```
大标题（必须含"1例报告并文献复习"）
摘要【目的】【方法】【结果】【结论】（100-200字叙述性或简要结构式）
关键词
正文
  病例资料（章级）
    一、一般资料
    二、现病史
    三、查体
    四、辅助检查
    五、诊断与治疗
    六、随访
  讨论及文献复习（章级）
    一、机制
    二、鉴别诊断
    三、治疗
    四、小结（审慎临床启示）
参考文献
```

### 风格要点

- 标题必含"**1例报告并文献复习**"
- 正文只两个一级标题："**病例资料**" + "**讨论及文献复习**"
- 文献复习嵌入讨论分段（机制/鉴别/治疗/小结）
- 结论含**审慎临床启示**，不夸大（"提示""或可为""尚需更多研究"）

### 标题例

- 正确：`劳力型热射病并发急性肾损伤1例报告并文献复习`
- 错误：`劳力型热射病并发急性肾损伤的病例分析`（缺少"1例报告并文献复习"标识）

## 五、系统评价 / 系统综述（PRISMA 式）

### 框架

```
大标题
结构式摘要【目的】【方法】【结果】【结论】（中英双语）
关键词
未编号引言（含 PROSPERO 注册号）
资料与方法
  一、问题确立（PICOTS / PICOS）
  二、检索策略（中英文库并列 + 时限"建库至XXXX年X月"）
  三、纳排标准
  四、文献筛选与资料提取（双人独立 + 第三方裁决 + EndNote 去重）
  五、偏倚/适用性/方法学质量评价（ROBINS-I / PROBAST / AMSTAR-2 / QUADAS-2）
  六、数据合成（定性或 Meta）
结果
  一、文献筛选（PRISMA 流程图 + 数量）
  二、纳入研究特征
  三、质量评价结果
  四、Meta 分析结果（异质性 I²/Q、效应量 RR/OR/MD/SMD(95%CI)、森林图、敏感性、发表偏倚 Egger/Begg + 漏斗图）
  五、定性合成（如异质性大仅定性）
讨论
  （含局限与建议）
利益冲突 / 作者贡献声明
参考文献
```

### 风格要点

- **三种细分**：
  1. 系统评价 + Meta 分析（定量合成）
  2. 系统评价仅定性合成（异质性大不做 meta，如预测模型专项）
  3. 概览性综述 / 证据综述（overview of reviews，二次综合已发表 SR/MA，用 AMSTAR-2 + GRADE）
- **方法学透明性必备**：PROSPERO 注册号、PRISMA 声明、检索库 + 明确时限、双人独立、偏倚工具、GRADE（含 Meta 或概览时）
- **统计表述**：效应量 RR/OR/MD/SMD+95%CI；异质性 I²（≤50% 固定，>50% 随机）与 Q 检验 P；敏感性（leave-one-out）；发表偏倚 Egger/Begg+漏斗图；软件 RevMan/Stata/R('meta'包）
- **预测模型**用 AUC/C-index/R/MSE/R²/校准(H-L/Bootstrap/Brier)
- **语言特征**：客观、透明、结论克制（标注证据级别/确定性，不作过度推论）
- 善用"异质性大故仅定性描述""多存在较高方法学偏倚"等审慎表述

### 避坑

- **须报告检索时限**（实证 TBI 营养文缺失为警示）
- 复杂结果建议补森林图
- AMSTAR-2 非强制但概览综述宜用

## 六、Meta 分析 / Meta 回归

### 框架

```
大标题
结构式摘要
关键词
资料与方法
  一、检索策略
  二、纳排标准
  三、质量评价
结果
  一、文献筛选流程（PRISMA 流程图）
  二、纳入研究特征
  三、质量评价
  四、Meta 分析结果
  五、亚组分析
  六、敏感性分析
  七、发表偏倚（Egger/Begg + 漏斗图）
讨论（含局限）
参考文献
```

### 风格要点

- 效应量：RR/SMD/MD(95%CI) 附 P
- 异质性：I² + 卡方(P) 决策固定或随机效应
- PRISMA 流程、PROSPERO 号、Egger 检验
- 结论含局限

## 七、临床实践指南（clinical practice guideline）

### 框架

```
大标题
中英文摘要【目的】【方法】【结果】【结论】
关键词
未编号引言/背景段
第一部分：指南制订方法
  一、成员与利益冲突管理
  二、适用范围与人群
  三、制订方法
    （一）证据检索与评价
    （二）推荐意见形成（GRADE 分级定义表）
    （三）外审批准
第二部分：临床问题与推荐意见
  问题 X：…
    推荐意见 Y：陈述句（推荐强度, 证据级别）
    推荐依据 / 证据总结 / 实施建议 / 其他考虑 / 推荐理由（四/五段式）
第三部分：结语
专家委员会名单
利益冲突声明（"所有作者声明不存在利益冲突"）
参考文献（134-161条）
```

### 风格要点

- **问题驱动**："问题 X：" + "推荐意见 Y：" 穿插
- **推荐意见句末括号**：`(推荐强度, 证据级别)`，如 `(Ⅱa, B级证据)`
- **强推荐用"推荐"**、弱推荐用"建议"、专家共识强推荐标 **GPS**
- **四/五段式模板**："推荐意见 + 推荐依据 + 证据总结 + 实施建议 + 其他考虑 + 推荐理由"（部分指南为四段式）
- **方法学声明**：须声明遵循《WHO 指南制订手册》《中国制订/修订临床诊疗指南的指导原则(2022版)》、AGREE II、RIGHT、PRISMA；GRADEpro 辅助；Delphi 法 + 投票通过率（≥70% 或 >80%）；注册号（如 CRRT：PREPARE-2023CN809；四环素：GIN）
- **GRADE 分级**：
  - CRRT 用罗马数字 Ia/IIa/III + A/B/C/D 证据级
  - 四环素用"强推荐(推荐)/弱推荐(建议, 含条件性/酌情/限定性推荐)/GPS" + 高/中/低/极低把握度证据
- 参考文献 134-161 条；含 [J]/[M]/[EB/OL]；团体作者写机构名
- 统计仅引他人 Meta/队列结果，区间用 **波浪号** `~`

### 推荐意见四/五段式模板

```
推荐意见 Y：对于需要 CRRT 的重症患者，建议使用碳酸氢盐而不是乳酸盐置换液/透析液。
  （Ⅱa, B级证据）

推荐依据：…

证据总结：…

实施建议：…

其他考虑：…

推荐理由：…
```

## 八、述评（Editorial）

### 框架

```
大标题
无摘要 / 极简摘要
正文
  （述评结合：引证、结果、评议三段式）
参考文献（5-20条）
```

### 风格要点

- 围绕一篇或一类文章展开评议
- 引证 → 结果解读 → 评议（优势、局限、临床意义）
- 短小精悍，1500-3000 字
- 立场鲜明但不情绪化

## 九、各类型骨架速查表

| 类型 | 一级章节 | 摘要 | 参考文献数 | 特殊要求 |
|------|---------|------|-----------|---------|
| 论著-基础/动物 | 资料与方法/结果/讨论 | 结构式 250字 | 15-30 | 动物许可证、试剂货号 |
| 论著-临床/队列 | 资料与方法/结果/讨论 | 结构式 250字 | 15-30 | 伦理审批、纳入排除 |
| 综述 | 一/二/三/四（无引言） | 单段指示性 | 60-90 | 近5年为主 |
| 病例报告+文献复习 | 病例资料/讨论及文献复习 | 100-200字 | 5-15 | 标题必含"1例" |
| 系统评价 | 资料与方法/结果/讨论 | 结构式 | 30-100 | PROSPERO + PRISMA |
| Meta分析 | 资料与方法/结果/讨论 | 结构式 | 30-100 | 流程图 + 森林图 + 漏斗图 |
| 临床实践指南 | 制订方法/问题与推荐/结语 | 结构式 | 134-161 | GRADE + 利益冲突 |
| 述评 | 单段展开 | 无 | 5-20 | 引证-结果-评议 |
