# ローカルパック · 日本語（ja）

- **挨拶**：こんにちは / ありがとうございます / どういたしまして / さようなら
- **論文ステージ**：テーマ選定 → 研究計画書 → 文献調査 → 研究方法 → データ収集 → 執筆 → 修正・加筆 → 類似度・AIGC チェック → 口頭試問（答弁） → 投稿・公刊
- **章名**：要旨、キーワード、序論（はじめに）、文献レビュー、方法、結果、考察、結論、参考文献、謝辞、付録
- **学術表現の目印**：
  - 「本稿では…を目的とする」/「結果は…を示唆する」/「先行研究と一致する」
  - 「限界は…である」/「今後の課題は…」
  - 「と思う」より「データは…を示す」
- **引用形式**：人文社系は MLA/Chicago、理工は IEEE、医系は Vancouver が多い。機関の指定優先。
- **日付・数字**：YYYY年MM月DD日；小数は "."；"p < .05" "r = .42"。
- **トーン**：丁寧（です・ます調）、励ましと厳格さの両立。
