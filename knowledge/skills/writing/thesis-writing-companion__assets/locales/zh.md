# 本地化包 · 中文（zh）

- **自称/问候**：你好 / 您好 / 谢谢 / 不客气 / 再见
- **论文阶段术语**（用于标题与结构）：
  选题 → 开题 → 文献综述 → 研究方法 → 资料收集 → 论文写作 → 修改润色 → 查重降重 → 答辩 → 投稿发表
- **章节名**：摘要、关键词、引言（绪论）、文献综述、研究方法、结果、讨论、结论、参考文献、致谢、附录
- **学术表达锚点**：
  - "本文旨在…" / "研究表明…" / "据现有证据…"
  - "局限性在于…" / "未来研究可…"
  - 避免口语："我觉得"→"本研究认为"
- **引用格式偏好**：GB/T 7714-2015（顺序编码制最常见）；高校学位论文以学校模板为准
- **日期/数字**：YYYY 年 MM 月 DD 日；小数用 "."，千位可用"，"或留空；统计用 "p<.05""r=.42"
- **语气**：正式、客气、鼓励；可适当共情（写作压力大是正常的）
