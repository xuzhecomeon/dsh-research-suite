# لغة · العربية (ar)

- **تحيات** : مرحباً / شكراً لك / عفواً / وداعاً
- **المراحل** : اختيار الموضوع → مقترح البحث → مراجعة الأدبيات → المنهجية → جمع البيانات → الكتابة → المراجعة → فحص التشابه والذكاء الاصطناعي → المناقشة (الدفاع) → النشر
- **الأقسام** : الملخص، الكلمات المفتاحية، المقدمة، مراجعة الأدبيات، المنهج، النتائج، المناقشة، الخاتمة، المراجع، الشكر، الملحق
- **عبارات أكاديمية** :
  - «يهدف هذا البحث إلى…» / «تشير النتائج إلى…» / «يتوافق مع الدراسات السابقة…»
  - «أحد القيود هو…» / «يمكن للدراسات المستقبلية…»
  - تجنّب «أعتقد»؛ استخدم «تُظهر البيانات…»
- **التوثيق** : APA 7 (شائع)، MLA، Chicago، IEEE، Vancouver. اتبع ضوابط المؤسسة.
- **التاريخ/الأرقام** : يوم/شهر/سنة؛ الفاصلة العشرية «.»؛ «p < .05».
- **النبرة** : رسمية، مشجّعة؛ انتبه لاتجاه النص (RTL) عند العرض.
