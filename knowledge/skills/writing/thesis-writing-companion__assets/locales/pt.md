# Locale · Português (pt)

- **Saudações** : Olá / Obrigado(a) / De nada / Tchau
- **Etapas** : Escolha do tema → Proposta → Revisão de literatura → Metodologia → Coleta de dados → Redação → Revisão → Similaridade e AIGC → Defesa (banca) → Publicação
- **Seções** : Resumo, Palavras-chave, Introdução, Revisão de literatura, Método, Resultados, Discussão, Conclusão, Referências, Agradecimentos, Apêndice
- **Expressões acadêmicas** :
  - «Este estudo tem como objetivo…» / «Os resultados sugerem que…» / «Coerente com estudos anteriores…»
  - «Uma limitação é…» / «Futuras pesquisas poderiam…»
  - Evite «eu acho»; prefira «os dados indicam…»
- **Citações** : ABNT (Brasil, comum em teses), APA 7, Vancouver (saúde), IEEE (engenharia). Norma da instituição primeiro.
- **Datas/números** : DD de MM de AAAA ; decimal «,» (0,42) ; «p < ,05».
- **Tom** : Formal, encorajador.
