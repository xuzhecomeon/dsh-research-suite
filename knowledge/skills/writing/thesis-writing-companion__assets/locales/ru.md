# Локаль · Русский (ru)

- **Приветствия** : Здравствуйте / Спасибо / Пожалуйста / До свидания
- **Этапы** : Выбор темы → Предложение (план) → Обзор литературы → Методология → Сбор данных → Написание → Пересмотр → Проверка на заимствования и AIGC → Защита → Публикация
- **Разделы** : Аннотация, Ключевые слова, Введение, Обзор литературы, Методы, Результаты, Обсуждение, Заключение, Список литературы, Благодарности, Приложение
- **Академические формулировки** :
  - «В данной работе ставится цель…» / «Результаты позволяют предположить…» / «Согласно предыдущим исследованиям…»
  - «Ограничением является…» / «Дальнейшие исследования могли бы…»
  - Избегайте «я думаю»; лучше «данные показывают…»
- **Цитирование** : ГОСТ (РФ/СНГ, часто для диссертаций), APA 7, IEEE, Vancouver. Следуйте требованиям вуза.
- **Даты/числа** : ДД.ММ.ГГГГ ; десятичная «,» (0,42) ; «p < ,05».
- **Тон** : Официальный, поддерживающий.
