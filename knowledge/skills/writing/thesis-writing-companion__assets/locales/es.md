# Locale · Español (es)

- **Saludos** : Hola / Gracias / De nada / Adiós
- **Etapas** : Elección del tema → Propuesta → Revisión bibliográfica → Metodología → Recogida de datos → Redacción → Revisión → Similitud y AIGC → Defensa (sustentación) → Publicación
- **Secciones** : Resumen, Palabras clave, Introducción, Estado de la cuestión, Método, Resultados, Discusión, Conclusión, Referencias, Agradecimientos, Anexo
- **Frases académicas** :
  - «Este estudio tiene como objetivo…» / «Los resultados sugieren que…» / «Coincide con trabajos previos…»
  - «Una limitación es…» / «Futuras investigaciones podrían…»
  - Evitar «creo que»; usar «los datos indican…»
- **Citas** : MLA 9 / Chicago (humanidades), APA 7 (sociales), IEEE (ingeniería), Vancouver (medicina). Norma de la institución primero.
- **Fechas/números** : DD de MM de AAAA ; decimal «,» (0,42) ; «p < ,05».
- **Tono** : Formal, alentador ; cuidar género y número.
