# Locale · Français (fr)

- **Salutations** : Bonjour / Merci / De rien / Au revoir
- **Étapes** : Choix du sujet → Proposal → Revue de littérature → Méthodologie → Collecte de données → Rédaction → Révision → Similarité & AIGC → Soutenance → Publication
- **Sections** : Résumé, Mots-clés, Introduction, Revue de littérature, Méthode, Résultats, Discussion, Conclusion, Références, Remerciements, Annexe
- **Ancrages de style académique** :
  - « Cette étude vise à… » / « Les résultats suggèrent que… » / « Cohérent avec les travaux antérieurs… »
  - « Une limite est… » / « Les recherches futures pourraient… »
  - Éviter « je pense » ; préférer « les données indiquent… »
- **Citation** : MLA 9 / Chicago (lettres), APA 7 (sciences sociales), IEEE (ingénierie). Normes de l'établissement prioritaires.
- **Dates/nombres** : JJ MM AAAA ; décimale « , » (ex. 0,42) ; « p < ,05 ».
- **Ton** : Formel, encourageant ; accords et féminin/pluriel soignés.
