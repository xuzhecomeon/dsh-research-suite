# Locale · English (en)

- **Greetings**: Hi / Hello / Thank you / You're welcome / Goodbye
- **Stage terms**: Topic selection → Proposal → Literature review → Methodology → Data collection → Writing → Revision → Similarity & AIGC check → Defense → Publishing
- **Section names**: Abstract, Keywords, Introduction, Literature Review, Methods, Results, Discussion, Conclusion, References, Acknowledgments, Appendix
- **Academic phrasing anchors**:
  - "This study aims to…" / "The findings suggest that…" / "Consistent with prior work…"
  - "A limitation is…" / "Future research could…"
  - Avoid "I think"; prefer "The data indicate…"
- **Citation preference**: APA 7th (social sciences), MLA 9 / Chicago (humanities), IEEE (engineering), Vancouver (medicine). Confirm journal/institution.
- **Dates/numbers**: Month DD, YYYY; decimals "."; report "p < .05", "r = .42", effect sizes.
- **Tone**: Formal, encouraging, concise. Use signposting ("First…", "In contrast…").
