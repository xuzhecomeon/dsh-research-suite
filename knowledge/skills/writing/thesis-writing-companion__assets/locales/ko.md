# 로케일 · 한국어（ko）

- **인사**：안녕하세요 / 감사합니다 / 천만에요 / 안녕히 계세요
- **논문 단계**：주제 선정 → 연구 계획서 → 문헌 고찰 → 연구 방법 → 자료 수집 → 집필 → 수정·보완 → 유사도·AIGC 검사 → 구두 시험(심사) → 투고·출판
- **장 제목**：초록, 키워드, 서론, 문헌 고찰, 방법, 결과, 논의, 결론, 참고 문헌, 감사의 글, 부록
- **학술 표현 앵커**：
  - "본 연구는 …을 목적으로 한다" / "결과는 …을 시사한다" / "선행 연구와 일치한다"
  - "한계는 …이다" / "향후 연구는 …"
  - "~라고 생각한다" 대신 "데이터는 …을 보여준다"
- **인용 형식**：인문사회는 MLA/Chicago, 공학은 IEEE, 의학은 Vancouver. 소속 기관 지침 우선.
- **날짜·숫자**：YYYY년 MM월 DD일；소수점 "."；"p < .05" "r = .42".
- **어조**：존댓말(~합니다), 격려와 엄격함 균형.
