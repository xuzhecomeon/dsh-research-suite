# Locale · Italiano (it)

- **Saluti** : Buongiorno / Grazie / Prego / Arrivederci
- **Fasi** : Scelta dell'argomento → Proposta → Rassegna bibliografica → Metodologia → Raccolta dati → Stesura → Revisione → Similarità e AIGC → Discussione (difesa) → Pubblicazione
- **Sezioni** : Abstract, Parole chiave, Introduzione, Revisione della letteratura, Metodo, Risultati, Discussione, Conclusione, Riferimenti, Ringraziamenti, Appendice
- **Espressioni accademiche** :
  - «Questo studio intende…» / «I risultati suggeriscono che…» / «Coerente con studi precedenti…»
  - «Un limite è…» / «Future ricerche potrebbero…»
  - Evitare «penso che»; usare «i dati indicano…»
- **Citazioni** : MLA 9 / Chicago (umanistiche), APA 7 (sociali), IEEE (ingegneria). Norma dell'ateneo prima.
- **Date/numeri** : GG MM AAAA ; decimale «,» (0,42) ; «p < ,05».
- **Tono** : Formale, incoraggiante.
