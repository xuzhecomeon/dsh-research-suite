# 数据管理与共享指南（Data Management）

> 本文件为 `thesis-writing-companion` 的深度专题。无论文理，规范的数据管理都是可重复研究（reproducible research）的基石，也是越来越多资助机构与期刊的硬性要求。

## 一、FAIR 原则（可发现·可获取·可互操作·可重用）

- **Findable 可发现**：持久标识符（DOI/Handle）、详细元数据、注册到可检索存储库、含关键词与分类标签。工具：DataCite、Zenodo、Figshare。
- **Accessible 可获取**：选择开放程度（完全开放/条件开放/受控访问/封闭）；明确获取协议与 embargo（延迟开放，通常 6–24 个月，注意部分期刊要求即时开放）。
- **Interoperable 可互操作**：优先开放格式（CSV/TSV/JSON/TIFF/PNG），避免 .xlsx、PDF 表格、PSD/AI；用领域本体（GO、DDI、ISO 19115）；提供数据字典与跨数据集映射。
- **Reusable 可重用**：README、数据字典、代码本、方法文档齐全；许可用 CC0/CC-BY 等；提供推荐引用格式（含 DOI）。

## 二、数据清洗规范

### 1. 原始数据保护
永远保留 `raw/` 只读原始数据；清洗用脚本（可审计、可重复），不用手工改。推荐目录：
```
data/
├── raw/          # 只读，永不修改
├── processed/    # 清洗后，版本控制
├── derived/      # 分析用数据
└── scripts/      # 清洗脚本（clean_survey.R / .py）
```

### 2. 清洗步骤
1. 导入检查：编码（UTF-8）、行列数、数据类型、缺失值表示（空/NA/-999/"无"）。
2. 缺失值：计算各变量缺失比例、记录原因、按策略处理（删除/插补/多重插补 MICE/标记），并做敏感性分析。
3. 异常值：箱线图（IQR×1.5）、Z-score（|z|>3）、马氏距离；结合领域知识（年龄>120、收入<0、未来日期）；核实/修正/保留/删除。
4. 一致性：逻辑检查（出生<入学）、范围检查（性别编码统一、Likert 1–5）、重复检查（同受访者多次提交）。
5. 转换：反向计分、虚拟编码、生成新变量（BMI=体重/身高²）、日期统一 YYYY-MM-DD。
6. 验证：与原始抽样对比、统计摘要、交叉验证、可视化。

### 3. 清洗记录
记录每步操作（代码+注释）、修改了哪些行/值、删除原因与数量、生成变量公式、处理时间与处理人。

## 三、数据可视化规范（Tufte：数据-墨水比最大化）
- **原则**：一图一信息；避免 3D 与装饰；坐标轴从 0 开始（对数尺度除外）；误差线用 SD/SE/CI；标注 n 与显著性（*p<.05, **p<.01, ***p<.001）。
- **类型**：比较（柱/箱线/小提琴）、关系（散点/气泡/热力/网络）、趋势（折线/面积）、构成（饼≤5 类/堆叠柱/树状）、地理（choropleth/点/热力）。
- **配色**：色盲友好（避免红绿）、黑白打印友好（图案+颜色）、≤7 类；推荐 ColorBrewer；避免彩虹色与高饱和。
- **分辨率/格式**：打印/发表 300–600 dpi；矢量优先（PDF/EPS/SVG），位图用 PNG/TIFF；导出嵌入字体、裁剪白边、按期刊尺寸（单栏 8cm、双栏 17cm）。

## 四、存储、备份与版本控制
- **3-2-1 原则**：3 份副本、2 种介质、1 份异地。
- **版本命名**：`data_2023-06-15.csv`、`data_v1.2.csv`，杜绝 `final_final.csv` 这类命名。
- **工具**：Git/GitHub（代码+小数据）、Git LFS/DVC（大数据）；长期保存优先开放格式（CSV/TXT/PDF-A/TIFF），每 5–10 年检查格式可用性。

## 五、数据伦理与隐私
- **PII 识别**：直接标识（姓名/身份证/手机/地址）、准标识（邮编/生日/性别组合）、敏感属性（健康/财务/性取向/政治观点）。
- **匿名化 vs 假名化**：k-匿名（每准标识组合至少出现 k 次，工具 ARX）；假名化保留可逆密钥表。
- **知情同意**：明确用途、未来研究（broad consent）、是否共享/商业使用、撤回权。
- **安全**：传输加密（HTTPS/SFTP/VPN）；存储加密（BitLocker/FileVault）；云数据确认彻底删除。

## 六、数据管理计划（DMP）
研究开始前制定，说明：数据描述（类型/量/格式/来源）、文档与元数据标准、存储与备份、法律与伦理（IP/隐私）、共享计划（embargo/访问限制）、责任与资源。工具：DMPonline、DMPTool；模板参考中科院、国家自然科学基金、Horizon Europe。

## 七、数据引用与论文关联
- **引用格式**：作者. (年). 数据集标题 [数据类型]. 存储库. 标识符（DOI/URL）。
- **Data Availability Statement**：在方法末尾或参考文献前独立段落说明数据获取方式（开放 DOI / 合理请求 / 受限原因）。
- **数据论文 Data Paper**：在 Scientific Data、Data in Brief、China Scientific Data 等只描述数据集、不分析，以获得正式引用。

## 八、推荐资源
- FAIR：FORCE11、GO FAIR、FAIRsharing。
- 存储库：re3data.org、Zenodo、Figshare、Dryad、学科库（GenBank/PDB/ICPSR）。
- 清洗工具：OpenRefine、Python（pandas/numpy）、R（tidyverse）。
- 学习：DataONE、中科院科学数据管理课程、Coursera "Research Data Management and Sharing"。
