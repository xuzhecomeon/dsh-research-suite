# 开题报告指南（Proposal）

开题的本质是**一次微型答辩**：向评审证明"问题值得做、你能做出来"。

## 标准结构（可裁剪）
1. **选题背景与意义**：现实/理论背景 → 为什么重要 → 理论意义与实践意义（各 2–3 句，别空喊）。
2. **文献述评（简版）**：已有研究脉络 → 你的缺口（见 `literature_review.md`）。
3. **研究问题 / 假设**：1–3 个清晰的 RQ 或 H；可操作、可检验。
4. **研究内容**：把 RQ 拆成 2–4 个子问题/章节。
5. **研究方法与技术路线**：范式、策略、数据、分析；附**技术路线图**。
6. **创新点**：1–3 点，务实质疑"新在哪"（新对象/新数据/新方法/新视角）。
7. **进度安排**：倒排时间表（用甘特图最佳）。
8. **参考文献**：精选 15–30 篇，中英均衡、含近 5 年文献。

## 技术路线图（必画）
在 `workflow.md` 给出四类模板，这里给画法原则：
- **流程式**（实验/工程）：问题→文献→假设→设计→收集→分析→结论。
- **时间轴式**（纵向）：Phase1/2/3 各列任务。
- **循环式**（行动研究）：Plan→Do→Check→Act。
- **树状式**（多案例/多方法）：核心问题分叉到多条子路径。
画图工具：draw.io / ProcessOn / PPT SmartArt / Mermaid。

## 常见被毙原因（重点规避）
- 问题不清晰，或与背景/意义无关。
- 方法空洞："用深度学习"却不说明为什么、数据从哪来、基线是什么。
- 创新点写"首次研究""填补空白"却无文献支撑。
- 技术路线逻辑断裂（A→B 跳步）。
- 工作量评估失真（硕士做成了博士量级，或反之）。

## 开题陈述 / 问答准备
- 准备 3 分钟版自述（背景→gap→RQ→方法→创新）。
- 预演高频追问："你的 gap 真成立吗？""样本量怎么定的？""方法为什么选这个不选那个？"
- 态度：评审质疑是帮你，不是刁难；答不上就坦诚"这是后续要澄清的"。

## 模板句
- "既有研究多聚焦于 X，对 Y 关注不足，而 Y 在……情境下日益关键。"
- "因此本研究提出 RQ：……；并采用……方法，以……数据加以检验。"
- "预期贡献在于：在理论上……；在实践上……。"
