# 工具链推荐（Toolchain）

按论文流程分类推荐。**优先开源/免费或学校已购**；不绑定任何厂商。以最新版本为准。

## 写作与排版
- **Word**：主流；用"样式+题注+交叉引用+域"做自动目录/图表编号。
- **LaTeX / Overleaf**：公式、定理、大文档首选；用 BibTeX 管理文献。
- **Markdown + Pandoc**：轻量草稿，再转 Word/LaTeX。
- **语雀 / 飞书文档 / Notion / Obsidian**：构思、提纲、笔记（双向链接利于知识管理）。

## 文献管理（必用）
- **Zotero**（开源、强）：抓取、标注、生成各格式引用。
- **EndNote / NoteExpress / Mendeley / Citavi**：各校常用；NoteExpress 在中文高校普及。
- 插件：Zotero Connector、浏览器抓取；CNKI 用插件或导出 RIS。

## 检索与发现
- 中文：CNKI、万方、维普、CSSCI。
- 英文：Web of Science、Scopus、Google Scholar、PubMed、IEEE Xplore、arXiv、JSTOR。
- 追踪：Google Scholar 提醒、Connected Papers、ResearchRabbit。

## 数据与分析
- 量化：**SPSS**（入门）、**R**（tidyverse/lme4/ggplot2，开源）、**Python**（pandas/statsmodels/scipy）、**Stata**、**SAS**、**MATLAB**、**JASP**（界面友好）。
- 质性：**NVivo**、**Atlas.ti**、**MAXQDA**、**Taguette**（开源轻量）。
- 统计功效：**G*Power**。

## 绘图与可视化
- 流程图/架构：**draw.io**、**ProcessOn**、**Visio**、**亿图**、**Mermaid**（文本即图）。
- 数据图：**Matplotlib/ggplot2/Origin/Tableau**。
- 思维导图：**XMind**、**MindManager**、**幕布**。

## 语言与润色
- 英文：**Grammarly**、**QuillBot**（释义）、**Writefull**、**LanguageTool**（开源）。
- 翻译辅助：**DeepL**、**Google 翻译**、**有道**（仅辅助，需人工校）。
- 公式：**MathType**、**LaTeX/MathJax**。

## 查重与 AI
- 学校指定系统为准（知网/维普/万方/Turnitin）。不要用来路不明的"降重神器"。

## 协作、备份与版本
- 协作：腾讯文档、石墨、Overleaf（多人）。
- 备份：**OneDrive / 坚果云 / Google Drive**，多副本 + 版本历史。
- 版本控制：Git/GitHub（代码型论文、LaTeX 友好）；至少手动保留 v1/v2/...

## 时间管理
- 番茄钟（Forest/Focus）、看板（Trello/Notion）、甘特（Excel/Project）。

## 按学科推荐组合
"不知道用什么"时，按学科直接套默认组合：
- **文科定性**：Word + Zotero + NVivo（质性）/ SPSS·R（如需统计）+ draw.io / ProcessOn
- **理工定量**：LaTeX·Overleaf + Zotero + Python / R / MATLAB + Python·R·Origin（绘图）+ Git·GitHub
- **商科**：Word + Zotero·EndNote + Stata / R / Python + Excel·R·Tableau
- **法学**：Word + Zotero（法条/案例类型）+ NVivo（案例研究）+ ProcessOn·Visio
- **医学/生物**：Word / LaTeX + Zotero + SPSS / R / GraphPad Prism + Origin + EndNote
- **快速草稿（通用）**：Obsidian + Pandoc + Zotero

## 学习资源
- 统计：Coursera（Johns Hopkins Data Science）、DataCamp（R/Python）、B 站统计课程；教材《统计学习方法》（李航）、《R 语言实战》。
- LaTeX：lshort-zh-cn、Overleaf 模板、B 站入门。
- 学术写作：Coursera Academic English、*They Say / I Say*、*Writing Science*。

## 避坑指南
1. **不要用盗版软件**：学校通常提供正版授权。
2. **不要过度依赖翻译**：学术写作需自己组织语言，翻译仅作辅助并人工校。
3. **不要忽视备份**：云同步 + 本地备份（3-2-1 原则），详见 `data_management.md`。
4. **不要临时学工具**：提前熟悉，避免 deadline 前手忙脚乱。
5. **不要忽视格式**：排版也是学术规范的一部分，早用样式/模板。
6. **慎用"降重神器"**：只用学校指定查重系统，来历不明的工具可能泄露文稿或诱导作弊。
