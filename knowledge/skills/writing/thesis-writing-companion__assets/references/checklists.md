# 各阶段自检清单（Checklists）

提交/答辩前逐项打勾。**以学校/期刊官方要求为最终标准**。

## A. 开题前自检
- [ ] 研究问题清晰、可检验、范围适中
- [ ] 已做初步文献检索，能指出 gap
- [ ] 方法与问题匹配，数据可得
- [ ] 创新点务实且有依据
- [ ] 技术路线图逻辑连贯
- [ ] 进度安排含缓冲期
- [ ] 参考文献含近 5 年文献

## B. 初稿完成自检（宏观→中观→微观）
**宏观（结构）**
- [ ] IMRaD/学科结构完整，章节比例合理
- [ ] 每章服务总 RQ，无离题
- [ ] 摘要独立自明、含关键结果
**中观（段落/论证）**
- [ ] 每段有中心句，论证有证据
- [ ] 结果不含讨论、讨论回应 RQ
- [ ] 图表自明、编号连续、与正文呼应
**微观（语言/规范）**
- [ ] 术语一致、无口语化
- [ ] 引用格式统一（见 `citation_formats.md`）
- [ ] 参考文献与正文一一对应
- [ ] 无错别字、标点、单位、符号错误

## C. 查重/AIGC 前自检
- [ ] 全部来源已标注（含数据）
- [ ] 释义段落已重构并引用（`plagiarism_ai.md`）
- [ ] 无整段 AI 直出未改写
- [ ] 用学校指定系统自测达标

## D. 格式排版自检
- [ ] 封面/页边距/页眉页脚/页码符合模板
- [ ] 标题层级、字体字号、行距、段距合规
- [ ] 三线表、图题、公式编号规范
- [ ] 中英文摘要、关键词齐全
- [ ] 目录/图表目录自动生成且准确
- [ ] 参考文献格式统一、无遗漏

## E. 答辩前自检
- [ ] PPT 按 `defense_guide.md` 结构，文字精简
- [ ] 自述稿演练掐表（5–10 分钟）
- [ ] 高频问题每类备好答案
- [ ] 局限与展望主动准备
- [ ] 打印/备份最终稿、U 盘/笔记本备用
- [ ] 线上答辩测过网络与共享

## F. 提交/归档前
- [ ] 按导师意见逐条修改并留痕
- [ ] 盲审/外审材料齐全（隐去身份信息如要求）
- [ ] 电子版 + 打印版一致
- [ ] 数据/代码按学校政策归档备份
- [ ] 确认提交截止时间与方式
