# 学术英语写作指南（Academic English）

> 本文件为 `thesis-writing-companion` 的专项指南，适用于英文论文撰写、国际期刊投稿，以及中文作者提升英文学术表达。配合 `bilingual_core.md` 使用。

## 一、中式英语常见问题与纠正

| 中式英语 | 学术英语 | 说明 |
|---------|---------|------|
| in the year of 2023 | in 2023 | 年份前无需 the year of |
| due to the fact that | because / since | the fact that 多余 |
| in order to | to | in order 多余 |
| it is important to note that | note that / importantly | 避免填充短语 |
| very important / very big | critical / substantial / considerable | 用强形容词替代 very+形 |
| etc. / and so on | 列举完整或用 including X, Y, Z | 避免不严谨 |
| some / a lot of / many | several / numerous / a total of X | 量化 |
| things / stuff | factors / variables / aspects | 具体化 |
| people | participants / respondents / subjects | 具体化 |

**例句**："Due to the fact that the sample size was small..." → "Because the sample size was small..."

## 二、逻辑连接与语法要点
- **避免双连接**：Because... so... / Although... but... → 只用一种连接方式。
- **序列词**：First / Second / Third（而非 Firstly... finally...）；避免 "Last but not least" 这类陈词。
- **主谓一致**："The number of participants is 100"（number 单数）；"A total of 50 participants were recruited"（participants 主语）。
- **冠词**：泛指不用 the（Society is changing）；抽象概念不用 the（research on online learning）；元音前用 an（an important finding）。
- **时态**：文献综述（现在/过去）、方法（过去）、结果（过去）、讨论/结论（现在解释意义/过去讲局限）、图表描述（现在）。

## 三、Hedging 模糊限制语（体现学术严谨）
- **情态**：may / might / could / seem / appear to。
- **副词**：possibly / probably / generally / relatively / approximately。
- **形容词/名词**：tentative / preliminary / potential；possibility / suggestion / assumption。
- **短语**：to some extent / based on the available evidence / it is possible that。
- **必须 hedging**：相关≠因果（X is associated with Y）、样本局限、初步结果、推测、未来研究。避免过度叠加（一次表达一个程度）。

## 四、Academic Phrasebank（按论文部分）

**引言·建立领域**：In recent years, there has been growing interest in... / X has become a central issue in...
**引言·指出空白**：However, little research has been conducted on... / To date, no study has investigated...
**方法·描述设计**：A qualitative design was employed to explore... / Data were collected using...
**方法·样本**：The sample comprised 100 participants recruited from... / The inclusion criteria were as follows:...
**结果·呈现**：The results revealed that... / As shown in Figure 1,...
**讨论·解释**：These findings suggest that... / This finding is consistent with Smith's (2020) theory that...
**讨论·局限**：Several limitations should be acknowledged... / The cross-sectional design precludes causal inferences...
**结论·贡献**：This study extends previous work by... / These results have implications for practice...

## 五、常见错误速查

| 避免 | 使用 | 原因 |
|------|------|------|
| get | obtain / acquire | 正式 |
| prove | suggest / indicate / demonstrate | 科学不"证明" |
| show | demonstrate / reveal / illustrate | 多样 |
| always / never | generally / typically / rarely | 避免绝对化 |
| I think / I believe | The evidence suggests / It is argued that | 客观 |
