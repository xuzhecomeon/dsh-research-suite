# 研究方法与设计（Methodology）

本文件帮用户**选对方法、写清方法、避开方法谬误**。先辨范式，再选策略，最后落地。

## 一、研究范式（Paradigm）
| 范式 | 本体论/认识论立场 | 适合问题 |
|------|----------------|----------|
| 实证主义（Positivism） | 客观、可测量 | "X 是否导致 Y" |
| 后实证主义（Post-positivism） | 近似真理、可证伪 | 多数定量社科 |
| 解释主义/建构主义（Interpretivism） | 意义是社会建构 | "人们如何理解 X" |
| 批判理论（Critical） | 权力、解放 | 不平等、structural 问题 |
| 实用主义（Pragmatism） | 看是否管用 | 混合方法 |

## 二、三大策略族
**定量（Quantitative）**：实验、准实验、调查、二手数据挖掘。强调抽样、信效度、统计推断。
- 常用：t 检验、ANOVA、相关、回归（含中介/调节）、因子分析、结构方程（SEM）、多层模型。
- 样本量：用 G*Power / 功效分析（power analysis）反推；报告效应量与置信区间，不只报 p 值。
- 信效度：Cronbach's α（信度）、内容/结构/效标效度；量表要说明来源与适配。

**定性（Qualitative）**：访谈、焦点小组、案例研究、民族志、扎根理论、话语/文本分析、现象学。
- 抽样：目的性抽样、理论抽样；样本"饱和"为准而非数量。
- 分析：主题分析（Thematic）、扎根编码（开放–轴心–选择）、话语分析、叙事分析。
- 质量准则：可信性、可迁移性、可靠性、可确认性（对应定量的信效度）。

**混合方法（Mixed Methods）**：QUAN→qual、QUAL→quan、或并行。用三角验证增强说服力；需说明"为什么混、怎么混、优先级"。

## 三、研究设计图（给用户画）
帮用户用 ASCII/Mermaid 画出：RQ → 范式 → 策略 → 数据来源 → 分析 → 回答 RQ。例：
```
RQ: X 对 Y 的影响？
  └─ 范式：后实证
      └─ 策略：问卷调查(定量)
          ├─ 样本：N=320，分层随机抽样
          ├─ 工具：XX 量表(α=.87)
          └─ 分析：层级回归 + 调节效应
```

## 四、变量与测量
- 操作性定义：把抽象构念变成可测指标（如"学习投入"→ 每周时长+自评量表）。
- 概念化→操作化→测量工具三段写清。

## 五、效度威胁（要主动讨论）
- 内部效度：混淆变量、选择偏差、成熟/历史效应。
- 外部效度：样本代表性、生态效度。
- 构念效度：测量是否真测到构念。
- 统计结论效度：检验力不足、 violations of assumptions。

## 六、伦理（Ethics）
- 知情同意、匿名化/去标识化、数据安全与留存期限。
- 涉及人/动物/敏感数据须过 IRB/伦理委员会；在方法章节声明审批号。
- 数据可复现与共享政策（很多期刊要求预注册/开放数据）。

## 七、常见方法谬误（教练要指出）
- "问卷随便发 100 份"——无抽样框架、无功效分析。
- "用了访谈就是质性"——却无编码过程、无可追溯引文。
- 定量定性硬拼，无整合逻辑。
- 用相关宣称因果。
- 只报显著结果，隐瞒不显著（选择性报告）。

## 八、方法章节写作模板
1. 研究设计概述（范式+策略+为何适配 RQ）
2. 参与者/数据来源（抽样、样本量依据）
3. 工具/材料（含信效度、来源）
4. 程序/流程（时间线）
5. 数据分析方案（事先确定，避免 p-hacking）
6. 伦理考量
7. 局限性预告（可选）

> 学科特异性方法见 `disciplines/` 各文件。
