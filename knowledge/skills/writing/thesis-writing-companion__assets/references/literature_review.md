# 文献综述方法（Literature Review）

综述的核心是**围绕你的研究问题，系统性地呈现、批判、并指向空白（gap）**。不是读书报告。

## 一、综述的四种形态
1. **叙述性综述（Narrative）**：按主题梳理，适合开题。
2. **系统性综述（Systematic Review）**：预设 PRISMA 流程、可复现检索。
3. **元分析（Meta-analysis）**：定量合并效应量。
4. **文献计量（Bibliometric）**：用 CiteSpace/VOSviewer 看结构与演化。

## 二、文献类型与重要性
- **按内容**：理论文献、实证文献、方法文献、综述文献、政策文献。
- **按重要性**：奠基性（必引）、里程碑、最新进展（近 3–5 年，展示前沿）、直接相关、方法论。

## 三、检索策略（Search）
**数据库**：
- 中文：CNKI 知网、万方、维普、读秀、CSSCI。
- 英文综合：Web of Science、Scopus、Google Scholar。
- 分学科：社科 SSCI/PsycINFO/ERIC；医学 PubMed/Cochrane；工程 IEEE Xplore/ACM；经济 EconLit/NBER；法律 HeinOnline/Westlaw。

**检索技巧**：
- 布尔逻辑：AND（交集）、OR（并集）、NOT（排除）。
- 截词：`*`（通配）、`?`（单字符）；短语用 `"exact phrase"`；字段限定 `title:`/`author:`/`journal:`。
- 引文追踪：前向（谁引了它）、后向（它引了谁）。
- **检索式构建**：先用 PICO（Population/Intervention/Comparison/Outcome）或类似框架分解问题 → 提取同义/近义/上下位词 → 组装 `(A OR B OR C) AND (D OR E) AND F` → 按结果迭代优化。
- **检索记录**：保存检索式、日期、数据库、命中数——审稿人常要求透明（建议写进方法或附录）。

## 四、筛选（Screening）
用 PRISMA 思路：初检 → 去重 → 读题摘筛 → 读全文筛 → 纳入。记录排除理由。**纳入/排除标准**事先定（年份、语言、研究类型、样本）。

## 五、管理与阅读
- 用 Zotero/EndNote 建库；标签化（方法/结论/gap）。
- **分层阅读**：标题+摘要（2 分钟判相关性）→ 引言+结论（5 分钟核心贡献）→ 全文精读（30–60 分钟）→ 批判性阅读（质疑评估｜联系）。
- **阅读笔记模板**：
  ```
  - 基本信息：作者、年份、期刊、题目
  - 研究问题：核心问题是什么？
  - 理论框架：用了什么理论？
  - 研究方法：怎么做的？
  - 主要发现：结论是什么？
  - 评价：优点、缺点、局限
  - 关联：与我的研究的关系
  - 引用价值：是否值得引用？
  ```

## 六、组织与写作
**组织逻辑（选一）**：按主题、按时间演变、按方法论、按理论流派、按争议、按"问题—原因—方案"。
**述评而非堆砌**：每段末尾给"本研究由此缺口……"的桥梁句。
**段落结构（推荐）**：
```
主题句：这一节讨论…
文献呈现：A(2010)发现…；B(2012)指出…
对比分析：然而，C(2015)质疑…
评价总结：这些研究表明…
过渡：但仍有以下不足…
```
**批判性写作**：不是"A 说…B 说…C 说…"，而是"A 和 B 都支持 X，但 C 基于 Y 理由质疑，本文认同 C，因为…"。
**引用方式**：信息突出（研究发现…(Smith, 2010)）/ 作者突出（Smith（2010）发现…）/ 多文献（Several studies (Smith, 2010; Jones, 2012; Lee, 2015)）。
**gap 的三种写法**：
- 矛盾型："A 发现 X，B 却发现非 X，原因未明"
- 空白型："现有研究集中于城市，农村样本缺失"
- 方法型："多采用横截面，缺纵向追踪"

## 七、避免抄袭（与 `plagiarism_ai.md` 呼应）
- 直接引用：加引号+页码+出处。
- 改写 Paraphrase：换结构+同义+自己解释，**仍须标注**。
- 总结/综合：概括或整合多篇，标注多处出处。
- 错误示例：只换几个词、改语序保留原结构、遗漏引用——仍算抄袭。

## 八、常见错误
- 只述不评；漏掉奠基/对立文献；过度依赖二手综述；引用失当（把书评当原作）；
- 把"最新=最好"；忽略方法局限；综述与后文 RQ 断裂。

## 九、常见问题（QA）
- **读多少篇？** 本科 15–30、硕士 30–50、博士 100–200，重质不重量。
- **写多长？** 本科 3000–5000 字、硕士 5000–10000、博士 10000–20000，占全文 10–20%。
- **引多少篇？** 本科 15–30、硕士 30–60、博士 60–120，看学科惯例。
- **怎么找 gap？** 方法局限、样本局限、情境空白、矛盾发现、未探索变量。
- **综述与绪论区别？** 绪论含背景/问题/意义；综述是其中专门梳理文献的部分。

## 十、综述章节自检
- [ ] 是否明确回答"已有研究到哪了"
- [ ] 是否指出至少 1 个清晰 gap
- [ ] 是否覆盖主要流派与对立观点
- [ ] 引用是否以一手文献为主
- [ ] 是否自然过渡到"因此本研究…"
