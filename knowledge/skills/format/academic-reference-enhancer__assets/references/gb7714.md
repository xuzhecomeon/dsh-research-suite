# GB/T 7714 Formatting

Use this file before formatting Chinese academic reference lists. Keep punctuation consistent across the final list.

## Common Templates

Journal article:

```text
[1] AUTHOR A, AUTHOR B, AUTHOR C, et al. Title[J]. Journal Name, Year, Volume(Issue): Pages. DOI: xxx.
```

Conference paper:

```text
[2] AUTHOR A, AUTHOR B. Title[C]//Proceedings of Conference Name. Place: Publisher, Year: Pages. DOI: xxx.
```

Standard:

```text
[3] 发布机构. 标准名称: 标准号[S]. 出版地: 出版者, 年份.
```

Online regulation or government document:

```text
[4] 发布机构. 文件名称: 文件编号[A/OL]. (发布日期)[访问日期].
```

Electronic resource:

```text
[5] 责任者. 题名[EB/OL]. (发布日期)[访问日期]. URL.
```

Book:

```text
[6] AUTHOR A. Title[M]. Place: Publisher, Year.
```

Report:

```text
[7] AUTHOR A. Title[R]. Place: Publisher, Year.
```

## Formatting Rules

- Use `[J]` only for formally published journal articles.
- Use `[C]` for conference papers or proceedings papers.
- Use `[S]` for standards.
- Use `[A/OL]` for online official documents, regulations, notices, and similar issued documents.
- Use `[EB/OL]` for ordinary electronic resources.
- Preserve verified DOI values. Do not invent DOI values.
- If pages, issue, volume, or article number cannot be verified, omit or mark the uncertainty in the verification report instead of fabricating it.
- Use one global numbered list unless the user requests chapter-level lists.
- Order references by first appearance in the body unless a different order is required.

## Quality Checks

Before finalizing:

- Every in-text citation number exists in the reference list.
- Every final reference is cited in the body.
- Numbers are continuous and not duplicated.
- Same work appears only once.
- Document type labels match verified publication types.
