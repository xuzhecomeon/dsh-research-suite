# Output Templates

Use these templates for plans and reports. Keep tables concise for long documents; split by chapter when needed.

## First-Stage Plan

End the first-stage plan with: `以上为执行前方案。请确认是否开始修改目标文档。`

### A. Overall Assessment

```text
Main document read:
Reference suggestion files read:
Citation style:
Numbering mode:
Chapter requirements:
High-risk references:
Modification recommended:
```

### B. Reference Verification Table

```text
| Chapter | Original No. | Title | Grade | Journal Article | Verification Source | DOI/Official URL | Keep? | Problem | Recommendation |
|---|---|---|---|---|---|---|---|---|---|
```

### C. Chapter Journal Ratio Table

```text
| Chapter | Total References | Journal References | Journal Ratio | Requirement Satisfied | Notes |
|---|---:|---:|---:|---|---|
```

### D. Final Proposed Reference List

Include global number, GB/T 7714 formatted reference, chapter usage, document type, and verification grade.

### E. Citation Insertion Plan

```text
| Chapter | Section | Original Sentence Keyword | Proposed Citation | Supported Claim | Corresponding Reference |
|---|---|---|---|---|---|
```

### F. User Confirmations Needed

List decisions such as replacement acceptance, moved insertion positions, standards or online regulations, relaxed reference counts, citation style, and numbering mode.

## Final Report After Modification

```text
A. Modification summary
B. Number of citations inserted per chapter
C. Final number of references
D. Number and ratio of journal references
E. Replaced or removed references
F. Numbering consistency check result
G. Remaining issues requiring manual review
H. Document modification status
```
