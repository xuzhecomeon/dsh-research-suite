## 一、GB/T 7714-2015 参考文献著录规则

### 期刊文章格式
```
[序号] 作者.题名[J].刊名,出版年,卷(期):起止页码.
```
示例：
```
[1] 沈宇红.在高中开展气排球运动的实践研究[J].体育教学,2014(5):45-47.
[2] 邢中有.新课程理念下高中气排球课程教学改革研究[J].体育师友,2013(6):12-14.
```

### 专著格式
```
[序号] 作者.书名[M].出版地:出版社,出版年:页码.
```

### 学位论文格式
```
[序号] 作者.题名[D].保存地:保存单位,年份.
```

### 常见错误
- ❌ 缺少文献类型标识 [J]/[M]/[D]
- ❌ 作者与题名之间缺少点号
- ❌ 缺少年份或页码
- ❌ 英文文献大小写混乱

## 三、AI生成文本的典型特征（供人工复核参考）

### 结构特征
1. 所有段落长度几乎相同（变异系数 < 0.3）
2. 标题结构高度模板化（一、二、三...每个标题格式完全一致）
3. 枚举必定用"首先...其次...最后..."或"第一...第二...第三..."

### 语言特征
1. 高频废话词："值得注意的是""毋庸置疑""综上所述"
2. 形容词堆砌："具有重要的""深刻的""广泛的""全面的"
3. 过渡句公式化："基于上述分析""由此可见""总而言之"

### 内容特征
1. 缺乏具体人名、地名、机构名、日期
2. 数据精确到不合理的小数位（如23.47%）
3. 结论全是正确的废话（"具有重要意义""值得进一步研究"）
4. 引用的文献无法在知网检索到

## 四、学术不端行为识别要点

### 抄袭迹象
- 大段文字无引用标记
- 风格在某处突然变化
- 引用分布极不均匀（全堆在一段）

### 数据造假迹象
- 同一数据在不同位置数值不同
- 统计数据超出合理范围（如相关系数 > 1）
- 百分比数据过于精确但原始样本量很小

### 引用造假迹象
- 作者名为纯拼音且非常见学者
- 刊名与真实期刊相似但不相同
- 年份/期数组合不合理
- DOI格式错误或无法解析
