## 四、问题代码说明

| 代码 | 含义 |
|------|------|
| `E-FAKE` | 完全虚构，全平台无记录 |
| `E-TITLE` | 题名与实际不符（实质性差异）|
| `E-AUTHOR` | 作者姓名/顺序与实际不符 |
| `E-JOURNAL` | 期刊名/会议名/卷期页码有误 |
| `E-YEAR` | 发表年份错误 |
| `E-DOI` | DOI无效或指向不同文献 |
| `E-RETRACT` | 文献已被期刊正式撤稿 |
| `E-PREDATORY` | 来源为掠夺性期刊/会议 |
| `W-UNVERIFIED` | 无法通过现有渠道核实 |
| `W-FORMAT` | 引用格式问题（不影响真实性）|
