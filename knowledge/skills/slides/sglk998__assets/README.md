# 论文汇报PPT制作

> 为学术论文（中文/英文、量化/质性）自动生成组会文献汇报 PPT，一键产出专业级幻灯片。

## ✨ 功能亮点

- 📄 **自动解析论文 PDF** — 提取标题、作者、摘要、方法、发现等关键信息
- 🎨 **学术风视觉设计** — 专业蓝色系配色，卡片式布局，信息密度高
- 📐 **16:9 标准比例** — 默认 Widescreen 尺寸，适配现代投影设备
- 📋 **完整汇报结构** — 17-20 页标准组会流程：背景→理论→方法→发现→讨论→反思
- 🔖 **支持母版保留** — 提供母版 PPTX 时，自动保留原始封面和结尾页
- 🌏 **中国语境连接** — 自动加入中国平台生态（抖音、快手等）的本土化讨论

## 🚀 使用方法

在 WorkBuddy 对话中直接说：

```
帮我做这篇论文的组会PPT
（然后上传 PDF 文件）
```

或者更简洁的触发词：
- `文献汇报`
- `组会PPT`
- `学术PPT`
- `论文汇报`
- `生成PPT`

## 📦 安装方法

1. 下载 `论文汇报PPT制作.skill` 安装包
2. 在 WorkBuddy 中选择「导入技能」
3. 选择该 `.skill` 文件完成安装

## 📖 产出 PPT 结构

| 页码 | 内容 |
|------|------|
| 1 | 封面（来自母版或自动生成） |
| 2 | 论文信息（期刊、IF、作者、方法概览） |
| 3 | 汇报大纲（圆形导航） |
| 4 | 研究背景（4 卡片布局） |
| 5 | 理论框架 |
| 6 | 研究问题 / 假设 |
| 7-8 | 研究方法 |
| 9 | 变量说明（量化论文） |
| 10-12 | 研究发现 |
| 13 | 讨论 |
| 14 | 批判性反思 |
| 15 | 研究启示 |
| 16 | 局限与展望 |
| 17 | 个人反思（含中国语境） |
| 18 | 结尾页（来自母版或自动生成） |

## ⚙️ 技术说明

- 依赖 Python `python-pptx` 和 `pymupdf` 库
- 中文字体：微软雅黑；英文字体：Arial
- 标题 28pt / 正文 16pt
- 不生成动画效果
