# 学术论文汇报PPT — 内容结构模板

以下为通用学术论文文献汇报PPT的推荐结构。根据论文类型（量化/质性/综述）可灵活增删。

---

## 必选页面（每份PPT都必须有）

### 1. 封面页
- **必须保留原始封面**：使用用户提供的母版PPT的封面页（含校徽、论文标题、作者等）。切勿重新设计。如果母版封面缺少汇报人和日期，提醒用户在PPT中手动补充。
- 如果用户没有提供母版PPT，则从论文信息中提取并构建封面页，**必须包含以下信息**：
  - 论文标题（中英双语）
  - 作者、期刊
  - **汇报人**（必填，18pt 黑色居中）
  - **日期**（必填，16pt 灰色居中，格式如"2026年6月20日"）
- 使用 `COVER()` 辅助函数自动生成具备完整信息的封面页。

### 2. 发表信息页（可选但推荐）
- 期刊名称、SSCI/CSSCI 分区、影响因子、DOI
- 作者及所属机构
- 发表时间（Online/正式见刊）
- 基金项目（如适用）
- 研究对象/方法/样本量（一行总结）

### 3. 目录/汇报提纲
- 5-11个章节，用蓝色圆形编号标记（01, 02, ...）
- 列出全部页面的标题

### 4. 研究背景/为什么关注这个问题
- **中英文论文通用格式**：3-4个卡片分别呈现：
  - 现象/趋势（平台/市场数据）
  - 研究缺口（既有研究覆盖了什么、忽略了什么）
  - 政策/社会语境（为什么此时此问题重要）
  - 本研究的独特贡献
- 如为量化研究：加入代表性案例（1个）增加生动性
- 如为质性研究：可加入"理论视角"卡片（如第三空间、社会资本等）

### 5. 理论框架/核心概念
- 理论模型可视化：用左右对比卡片或三栏对比展示核心概念
- 如有论文原图：嵌入原图
- 如有交互效应/调节/中介：分别标注

### 6. 研究问题/假设
- **质性研究**：研究问题写在中性色调卡片中，附中文翻译
- **量化研究**：列出所有假设 H1-H5 及子假设，附论文理论模型图
- 注意标注"本研究剔除的假设"及理由

### 7. 研究方法
- 方法总览页（必选）：
  - 核心方法、分析框架、分析工具、数据形式（四行可视化）
  - 关键数字用圆形徽标突出（样本量/年数/社区数/研究者数）
- 数据收集页（可选）：
  - 收集流程 + 分析步骤（左右分栏）
  - 伦理审查/编码信度/数据筛选条件（底部信息框）
- 时间轴/筛选流程图（可选）：
  - 研究阶段时间轴 或 样本筛选漏斗
  - 关键政策/事件时间节点

### 8. 变量测量/操作化定义（量化论文）
- **位置**：放在方法论部分（假设之后、结果之前），不要放到附录
- 包括：因变量计算公式、自变量操作化方式、控制变量清单（7项左右）、编码信度
- 信息感知价值/叙事策略等编码表如太详细可省略

### 9. 核心发现
- **质性论文3页**：①构建关系 ②纳入排斥 ③社会权力 — 每页用3个子卡片展开
- **量化论文2-3页**：①描述性统计+主效应表 ②交互效应对比（叠加vs衰减）③与已有研究的对话
- 数据表可视化：Beta系数 + 显著性标注（***/**/*)，避免原始回归表信息过密
- 交互效应：用双栏对比（叠加效应/衰减效应）

### 10. 典型案例/民族志片段（质性论文）
- 至少1个带名字的案例（如"Emma"），放在卡片底部
- 案例要体现"过程性"（不只是结果，还有转折）

### 11. 平台挑战/附加发现（如适用）
- 独立成页，不要压缩在核心发现里
- 3个子卡片：FOMO / 算法隔离 / 性别差异
- 每个卡片 = 现象 + 机制解释

### 12. 结论与讨论
- **与已有研究的对话**（推荐独立成页）：
  - 找2-3篇论文中被引用的文献逐一对话
  - "本研究印证/拓展/挑战了什么"
- 反直觉发现重点突出

### 13. 批判性反思（推荐）
- 理论层面：概念操作化是否充分？剔除的变量是否合理？
- 方法论层面：样本局限、测量精度、因果推断限制
- 编码者反思（如适用）：作为同领域研究生的编码偏误

### 14. 实践启示/建议
- 3-4个分角色建议卡片（如：家长/政策/平台）
- 或4个策略卡片（如：强化视听/调适叙事/精准定位/内容为王）
- 每个建议关联到具体研究发现

### 15. 研究局限与未来方向
- 局限用2-3个小卡片 + 未来方向4点列表

### 16. 个人反思/本土对话（推荐）
- 将论文发现与个人观察/中国语境关联
- 提出可研究的新问题
- 与导师研究方向的关联（如有）

### 17. 结尾页
- **必须保留原始结尾页**：使用用户母版PPT的结尾页（含校徽+"谢谢观看"）。切勿重新设计。
- 如果没有母版PPT，则用校徽背景+"谢谢观看！请各位老师批评指正"

---

## 页面设计原则

1. **高信息密度**：一页放多个相关内容（卡片布局），不追求"一页一观点"
2. **逻辑链明确**：每页之间有明显的逻辑递进
3. **标题即论点**：每页大标题不是"研究背景"而是"为什么我们需要研究这个问题"
4. **文字多不怕**：正文14-16pt，用卡片区分信息层级
5. **数据可视化**：关键数字放大、Beta系数标星号、对比用双栏卡片
6. **不堆砌动画**：静态展示，所有内容同时可见
