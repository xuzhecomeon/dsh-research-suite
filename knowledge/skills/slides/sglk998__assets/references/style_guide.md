# 学术论文汇报PPT — 视觉风格规范

## 配色方案
- **主色（蓝）**: #5A97D0 — 标题、强调、图标、分隔线
- **深蓝**: #2E5A8B — 卡片标题、重点标注
- **浅蓝背景**: #EBF3FA — 卡片底色、信息框
- **正文黑**: #333333 — 正文文字
- **辅助灰**: #666666 — 次要信息、脚注
- **浅灰**: #999999 — 装饰线、非重点
- **白色**: #FFFFFF — 深色背景上的文字
- **橙色**: #E87A00 — 对比色、案例、研究问题框
- **绿色**: #4A904A — 正面发现、建设性建议
- **红色**: #E53935 — 负面发现、衰减效应、警示
- **紫色**: #9C27B0 — 第三维度、补充信息

## 背景
- 浅色背景（白色为主），不使用深色背景
- 分隔页使用全屏蓝色背景 + 白色大字

## 字体
- **中文**: 微软雅黑
- **英文/数字**: Arial

## 字号规范
- **大标题**: 28pt, 蓝色, 加粗 — 每页顶部，带蓝色下划线(宽2.5英寸)
- **正文**: 16pt（默认）, 黑色 — 正文内容
- **卡片内标题**: 13-16pt, 对应主题色, 加粗
- **卡片内正文**: 10-13pt — 支持高信息密度
- **注释/脚注**: 9-10pt, 灰色 — 底部补充说明
- **分隔页数字**: 72pt, 白色 — 章节编号
- **分隔页标题**: 32pt, 白色, 加粗

## 布局规范
- 幻灯片尺寸: 13.333x7.5 英寸 (标准16:9)
- 内容边距: 左右0.5英寸, 顶部从1.5英寸开始(标题下方)
- 卡片间距: 0.2英寸
- 卡片圆角矩形: 圆角矩形(Rounded Rectangle)
- 圆形图标: 用于数据突出(84/3/4个)或章节标记

## 卡片颜色映射
| 用途 | 底色 | 边框色 |
|------|------|--------|
| 主信息卡 | #EBF3FA (浅蓝) | #5A97D0 (蓝) |
| 对比/案例 | #FEF3E8 (浅橙) | #E87A00 (橙) |
| 正面/建设 | #E8F5E9 (浅绿) | #4A904A (绿) |
| 负面/警示 | #FFEBEE (浅红) | #E53935 (红) |
| 补充/第三维 | #F3E5F5 (浅紫) | #9C27B0 (紫) |
| 高亮/金框 | #FFF8E1 (浅黄) | #E87A00 (橙) |

## 不使用
- 动画效果（用户明确不要）
- emoji 图标（在正式汇报PPT中不使用）
- 深色背景（除分隔页外）
- 多余装饰元素
