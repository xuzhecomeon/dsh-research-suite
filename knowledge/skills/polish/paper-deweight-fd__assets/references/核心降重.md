## 一、核心原则

### 1.1 降重三板斧

#### 第一板斧：同义词替换

**替换对象**：句子中非专属名词的一切——动词、形容词、副词、连接词。

| 该替换的 | 不该动的 |
|----------|----------|
| 选择、作为、进行、开展、围绕、结合、考虑、发现、找出、重要、突出、影响、关系、作用…… | 存货周转率、中国农业银行、GDP、ROE、作者名、年份…… |

#### 第二板斧：更换句式

句意不变的前提下，结构随意换。最忌讳一字不差从百度百科复制粘贴。

```
原文：A 对 B 进行研究，发现……
改写：A 选择 B 作为研究对象，得出结论为……

原文：随着 A 的发展，B 越来越 C
改写：在 A 发展的过程中，B 受其影响不断 C
```

#### 第三板斧：扩句与缩句

| 查重系统 | 推荐策略 | 原因 |
|----------|----------|------|
| 知网、万方、大雅、笔杆网 | **扩句** | 对新增文字友好 |
| 格子达、维普 | **缩句** | 扩句会被反向感染 |

扩句示例：`A 是一种 B，用于 C、D 等领域 → A 作为 B，在以 C、D 为代表的领域中较为常见`

缩句示例：`A公司是某行业某类型企业，业务包括B、C、D，总部位于E → A公司是一家拥有X位员工的某类企业。`

### 1.2 黄金法则：80/20 原理

一段话中 **80% 被改写后，剩余 20% 即使原文保留，系统也判定为原创**。不必与零星几句较真。

### 1.3 改写底线

- 保持原文逻辑完整
- 专业术语、专有名词、数据、引用标注不动
- 替换后读一遍确认可读

### 1.4 无效降重三大症状

| 症状 | 为什么无效 |
|------|-----------|
| 只倒装不换词 | 关键词原地不动 |
| 简写名称凑字数 | 删除专属信息，句子变空洞 |
| 删长句留短句 | 剩的句子核心词全在 |

> 正确思路：换骨架，不是换皮。「打乱顺序重新编论文。」

## 二、常用替换词表（140+组，9大类）

> **降档甄别（配套铁律一"不改语言档次"）**：替换后若读起来比原文更口语或带文言腔，即为降档，必须改用其他选项或保留原文。下表已对高危替换对逐条标注"慎用"；未经标注的替换对在正式学术语境中一般安全。

### 2.1 逻辑连接词

| 原文 | 替换选项 |
|------|----------|
| 目前 | 现阶段、就当前而言 |
| 最初 | 最早、率先、首次 |
| 从而 | 进而、由此、最终 |
| 因此 | 所以 |
| 随着…发展 | 伴随…演进、在…的同时 |
| 如果 | 假设、要是、一旦、倘若、若 |
| 除此之外 | 不仅如此、再者、然而 |
| 一方面…另一方面 | 不仅…还… |
| 无论 | 不管、不论、即便 |
| 出于对X的考虑 | 考虑到X、因为X |
| 仅仅 | 只有、单单 |
| 和 | 与、同、以及 |

### 2.2 顺序/时间词

| 原文 | 替换选项 |
|------|----------|
| 过去 | 传统、常规、以往、曾经 |

## 三、句式改写策略（8种）

### 3.1 主动 ↔ 被动转换
```
原文：管理者过度自信导致收购失败
改写：收购活动的失败受到管理者过度自信的影响
```

### 3.2 长句拆分为因果链
```
原文：A 通过 B 得出 C
改写：A 借助 B 完成了相关分析。其研究发现，C。
```

### 3.3 重新组织信息顺序
```
原文：某人提出了 X 假说，假定 Y 有效、Z 无效，以此解释 W
改写：在某人建立的 X 假说中，Y 被设定为有效而 Z 无效，基于此对 W 展开分析
```

### 3.4 衔接词加成
```
原文：该模型分为两类，分别对比了 A 和 B，得出结论 C
改写：这一模型包含两类情形。对 A 与 B 进行对照研究后发现，C
```

### 3.5 概率/倾向表达
```
更可能执行某活动 → 执行某活动的概率更高
更容易实施 → 实施意愿更加强烈
```

### 3.6 冗余词精简

| 冗余表达 | 精简方案 |
|----------|----------|
| 来源于英文单词「X」 | → 即「X」 |
| 不同A对于B都会C | → 由于A有区别，B在C时同样存在D |
| 一般指 | → 由…构成 / 可理解为 |
| 不能忽视、偏废一方 | → 一视同仁，平等对待 |
| A是B，它包括B | → A反映出B，可理解为二者的综合 |

### 3.7 句式结构映射法

先抽象原句骨架，再设计全新骨架，最后填回术语。

```
原骨架：不同A对于B都会C。无论12还是3，都是4为了5而6。
新骨架：由于A有区别，B在C时同样会存在D。例如123，都可作为4在达成5时所生成的6，只不过7有别。

原骨架：A是B，它包括B，是X的综合，不能忽视Y。
新骨架：A能够反映出B，可将其理解为X的综合，且需要一视同仁，平等对待。
```

### 3.8 一义多形：核心动词平行替换链

以「A反映了B」为例，5种有效改写：

| # | 改写 | 技法 |
|---|------|------|
| 1 | A 是对 B 最直观的**表示** | 替换+语序 |
| 2 | A **体现**的正是 B | 替换+语序 |
| 3 | A 这一指标**对应**着 B | 替换+语序+补主语 |
| 4 | A 可对 B 进行**描述** | 替换 |
| 5 | A 能充分**反映出**当前 B | 扩句 |

学科弹性：经管 4-5种+ / 文学社科 2-3种 / 思政法学 1-2种

## 四、操作流程 SOP

1. **逐段读取**：一次一个自然段
2. **识别类型**：文献综述 / 理论阐述 / 数据分析 / 结论
3. **提取核心**：保留名词术语、数据、引用标注
4. **三板斧改写**：替换词表 → 句式结构 → 扩缩句
5. **文献综述**：优先套用模板（详见模块二）
6. **自校验**：对照原文确认逻辑一致、语义完整
7. **输出**：改写后段落 + 改动原因

## 五、百科概念/定义降重专项

核心策略：百科原文只取四要素（是什么/特性/作用/公式），删除废话铺垫。

**处理流程**：自问自答 → 提取四要素 → 逐句改写 → 合并精简

**案例速览**：

- **转让定价**：「一般指大企业集团尤其是跨国公司」→ 删废话，合并为「企业集团」
  - 「利用…差异」→「根据…不同」，「实现…最小化」→「确保…降至最低」

- **金融市场**：「金融市场是指由…所形成的市场」→ 合并多句，删重复抬头
  - 「运用」→「凭借」，「实现」→「完成」

- **营运资本**：公式 `营运资本 = 流动资产 - 流动负债` **一字不动**
  - 「是指」→「即」，「具体包括」→「例如…都属于」

- **交易成本**（ABC 抽象法）：术语用字母代称→专注改结构→填回
  - 「包括 1、2 以及 3」→「主要有三种，即 1、2 和 3」

**百科速查替换对**：是指→即 / 包括→主要有/例如…都属于 / 利用差异→根据不同 / 我们称之为→即 / 运用→凭借 / 实现→完成 / 可分为→有…之分

## 六、经管类降重实例

### 实例1：金融计量模型

| # | 原文关键词 | 改写关键词 |
|---|-----------|-----------|
| 1 | 将其扩展到 GARCH 模型 | 把它延伸至 GARCH 模型 |
| 2 | 将当前一切可利用信息作为条件 | 把现阶段所有可利用信息当做条件 |
| 3 | 很难以进行检验 | 检验难度较大 |
| 4 | 从而求得…Var值 | 能够确定…Var值 |
| 5 | 三个参数的系数都大于0 | 三个参数系数均高于0 |
| 6 | 条件方差存在均值反转特性 | 条件方差具备均值翻转特性 |
| 7 | 通过格兰杰因果检验 | 依靠格兰杰因果检验 |
| 8 | 将网络中所有连边的权重进行统计 | 把网络中每一个连边的权重统计整理 |

**要点**：公式和模型名原封不动，只改周围描述性文字。

### 实例2：绩效定义（管理类）

```
原文：绩效，来源于英文单词"performance"，一般指工作的效果和效率。
改写：绩效，即"performance"，由工作效果与效率两部分综合构成。
```

### 实例3：无效 vs 有效降重对比

| 无效症状 | 为什么无效 |
|----------|-----------|
| 只做前后倒装 | 关键词原地不动 |
| 简写会议名称为「两个学术会议」 | 丢专属信息 |
| 删长句留短句，保留的核心词全在 | 挤痘痘留半张脸 |

**核心教训**：「不断发展」「形成」「包括」「其中」这些连接词全部剔除后，重复率可归零。无效和有效之间往往就差几个关键词。
