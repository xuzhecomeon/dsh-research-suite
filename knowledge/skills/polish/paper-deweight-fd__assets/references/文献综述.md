> **用途**：加载本模块专门处理论文文献综述章节的降重。包含15个模板和文献综述特有的替换策略。

## 一、文献综述降重核心

文献综述是查重重灾区。核心方法：**降重三板斧**（替换同义词 + 更换句式 + 扩句缩句）。其中文献综述段优先使用下面的模板库。

### 黄金法则

一篇文献综述的标准格式 = **作者名 + 年份 + 研究内容 + 研究结论**。只要这四个要素到位，怎么排列组合都行。

### 文献综述专属替换词

| 原文 | 替换选项 |
|------|----------|
| 目前 | 现阶段、就当前而言、从现有研究来看 |
| 最初 | 最早、率先、首次 |
| 该学者认为 | 在他看来、其观点是、他指出、他表示 |
| 提出了（理论/假说） | 建立、构建、创立、形成、发展出 |
| 进行了研究 | 展开探讨、实施分析、完成考察 |
| 通过…分析 | 借助…方法、利用…工具、运用…手段 |
| 对比了 | 比较了、对照…与…、将…与…对照分析 |
| 得出结论 | 研究结果表明、研究发现、分析显示 |
| 基本是…的微调 | 主要基于…的延伸/拓展 |
| 将…引入（某领域） | 率先对…二者结合的内容进行梳理总结 |
| 现实（中） | 实际发生的、已有的、过往的 |

## 二、文献综述模板库（15个）

> **使用规则**：「作者名（2024）」替换为【作者名（年份）】；`____` 填入内容；`（）` 内为可选措辞。
> **关键**：模板之间灵活切换，同一段内不要复用同一模板。

---

### 【基础模板】适用于单一文献引用

#### 模板1：始祖模板（最简）
```
作者名（2024）对____进行研究，研究结果表明________。
```

#### 模板2：研究对象 + 方法 + 结论
```
作者名（2024）选择____作为研究对象，通过____进行分析，其结果表明_____。
```

#### 模板3：实证研究 + 结论
```
作者名（2024）的实证研究主要围绕____，其研究结论为_______。
```

---

### 【进阶模板】信息补全型

#### 模板4：全要素五段式
```
作者名（2024）在研究___的过程中，其选用的研究对象为___，
使用的研究方法是___，实验数据来自于____，
通过___分析得出结论，即_______。
```

#### 模板5：相关性/影响性研究
```
作者名（2024）的研究内容为___和___的相关性关系（或___对___造成的影响性研究），
利用（通过/根据/结合/围绕）____方法来完成关于____的分析，
分析结果显示（表明/得出/为）_______。
```

---

### 【发展脉络模板】理论演进型

#### 模板6：理论发展始末
```
__理论最早由作者名（2024）提出，他将其定义为___。
学者B和学者C（2024）在作者名的基础上进行延伸，
并发展出更加完整的理论体系，其简称为____。
随着____的发展，_____不断兴起，
尤其是以____为标志的___假说更是重新定义了____，
这同样代表着_____的雏形基本形成。
```
> 适用：国内外研究综述开头，介绍某理论从提出→发展→成熟的过程。

---

### 【著作前置模板】

#### 模板7：著作在前，观点在后
```
在《著作名》中，作者名将____划分为___、____、_____三种，
且从_____等方面概括其含义。
所有满足_____条件的，必须由_____依照____进行……
```

#### 模板8：作者+著作+定义+观点
```
作者名发表的《著作名》，对______的定义是____，
在他看来，无论是_____，还是_____，从____角度出发，都同样属于_____，
想要实现___的有效性并不取决于____，
而是要明确_____，这才是做好_____的关键。
```

---

### 【转折/分歧模板】

#### 模板9：观点转折/不同意见
```
作者名的《著作名》对______提出了不同的观点，
他认为（表示/指出）在____方面可能依旧存在____等问题，
但是首要问题（最大问题/关键问题）始终都是____，
想要解决好（处理好/应对好/预防好/妥善安置），
必须要懂得平衡____和____之间的关系，
在此基础上找到符合实际需求的解决办法。
```
> 适用：不同学者观点存在矛盾/分歧时使用。

---

### 【通用补充模板】

#### 模板10：因果关系型
```
作者名（2024）通过____证实了____和____之间的关系，
结果表明____很大程度上可以消除因___而产生的____，
其原因主要是____，以此来应对受____影响而发生的___现象，
至于___，则是可以同样帮助缓解来自于____的风险。
```

#### 模板11：动因关系型
```
作者名（2024）认为___自身所具有的__和___能够使其获得更多____，
并最终成长为____，这意味着____本身就可以对____加以____。
```

#### 模板12：样本研究型
```
作者名（2024）选择____作为研究样本，
特别是涉及____方面的____展开深入研究，
研究结果表明若发生____则______，反而无法____，
一般会以_____的形式来实现____。
```
> 结论若过长，拆分为多个句子。

#### 模板13：理论模型型
```
作者名（2024）基于____完成了理论模型的构建，
该模型的对比主要是根据____和____，
二者的区别在于____，对比结果表明，若____则_____，
在他看来____________。
```

#### 模板14：研究方向型
```
作者名（2024）通过（根据/凭借/依靠/以）对_____的研究，
明确关于____的研究方向，他认为（的看法是/提出/表示）______，
若____则______，反之____则_______，
从而可知，只要能够符合___条件即可算作是____，这同样说明了____。
```

#### 模板15：理论假说验证型
```
作者名（2024）在____的基础上完成了对___理论假说的构建，
她的研究样本主要来自于____，在经过_____等筛选后，
结合____进行分析，最终明确其结论为_____，
该理论假说被证实成立标志着______。
```

## 三、文献综述降重实例

### 实例1：理论提出与演进

**原文：**
> 最初将管理者过度自信或乐观主义假设引入公司金融的是 Roll，他提出了"狂妄自大(HubrisHypothesis)"假说，假定市场是有效的，而经理层是无效的，以此来解释现实中大量失败的并购。他认为，许多公司收购活动的失败，原因在于管理者的过度自信，高估目标公司，对收购后的收益过度乐观，从而发起了一系列有损企业价值的收购。

**改写：**
> Roll率先对管理者过度自信或乐观主义和公司金融行为的相关研究进行梳理总结，且在此基础上建立"狂妄自大(HubrisHypothesis)"假说，在该假说中，市场是有效的，经理层则无效，从而对已经发生过的失败并购进行分析。在他看来，大部分公司收购行为之所以没有成功，主要是受到管理者过度自信、对目标公司的价值高估、对收购后收益的过度乐观等多方面因素的影响，最终导致会对企业价值造成损失的收购活动被实施。

**改动映射：**

| 原文 | 改写 |
|------|------|
| 最初将X引入Y | 率先对X和Y的相关研究进行梳理总结 |
| 他提出了 | 在此基础上建立 |
| 假定…有效/无效 | 在该假说中…有效/无效 |
| 以此解释 | 从而对…进行分析 |
| 现实 | 已经发生的 |
| 他认为 | 在他看来 |
| 许多…的失败 | 大部分…之所以没有成功 |
| 原因在于A、B、C | 主要是受到A、B、C多方面因素的影响 |

### 实例2：理论模型综述

**原文：**
> 目前，经理人过度自信的公司并购理论模型基本都是 Ulrike Malmendier 和 GeoffreyTate 理论模型上的微调。该模型分为没有竞争者存在的并购活动和存在竞争者的并购活动两类，分别对比了理性公司高管和过度自信公司高管的并购决策，得出结论：过度自信的经理人更可能执行负期望收益的并购活动……

**改写：**
> 就现阶段而言，经理人过度自信的公司并购理论模型主要基于 Ulrike Malmendier 或 GeoffreyTate 理论模型的延伸。这一模型包括不存在竞争者的并购活动与存在竞争者的并购活动，对理性公司高管与过度自信公司高管的并购决策进行研究后发现，过度自信的经理人实施负期望收益并购活动的概率更高……

**改动映射：**

| 原文 | 改写 |
|------|------|
| 目前 | 就现阶段而言 |
| 基本是X的微调 | 主要基于X的延伸 |
| 该模型分为两类，分别对比 | 这一模型包括…与…，对…研究后 |
| 得出结论 | 发现 |
| 更可能执行 | 实施…的概率更高 |
| 在有丰富资源的经理人中 | 若经理人掌握着大量内部可动用资源 |
| 更易实施 | 实施意愿相较于…更加强烈 |

### 实例3：无效 vs 有效降重

**无效降重症状**：
- 只做前后倒装（某人在某会议提出 → 某理论是某人在某会议提出的）
- 简写会议全称为「两个学术会议」
- 关键词（于/提出/论述/阐述）原封不动

**正确做法**：全新编排信息顺序。
```
原骨架：某人在某时某会议上明确了某方法论
新骨架：某年，某理论在某会议上被确立，其提出者是某人。
         在会上所讨论的内容包括某某，紧接着在某会议上该理论得到补充。
```
