# 学术润色官 · 扩展 FAQ（references）

**Q1 学科术语怎么处理？**
→ 专业术语保留原词并校准（CRISPR / transformer），不强行中英互换；冷僻不确定术语标「待作者确认」。

**Q2 参考文献格式选哪个？**
→ 中文常用 GBT7714，英文 APA / MLA / IEEE 按学科；未指定默认 GBT7714 并标注，以目标期刊为准。

**Q3 AIGC 降重阈值 <15% 有依据吗？**
→ 多数期刊安全区间参考值，非绝对；只做表达优化，以目标期刊检测工具为准，不承诺通过。

**Q4 英文 Chingish 怎么改？**
→ 按 Native 语感重写（时态 / 语态 / 术语），附 Chingish 错误对照表，不做逐字翻译。

**Q5 期刊 IF 时效？**
→ 示例 IF 为公开历史值可能过时；投稿前以期刊最新 JCR 数据为准。

## 学科术语处理细则
- 缩写首次出现写全称，后续用缩写
- 物种拉丁名斜体，基因符号正体大写
- 单位用国际单位制，数字与单位间留空格
- 上述为通用规范，特定期刊以作者指南为准
