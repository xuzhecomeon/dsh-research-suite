# 论文降重 Skill

## 重要声明

本 Skill **仅提供论文降重改写功能**，不具备查重检测能力。无法告诉你论文当前重复率是多少，只能帮你对已有文本进行改写以降低被查重系统判定为抄袭或 AI 生成的概率。

## 三条硬性铁律（最高优先级，所有改写必须同时满足）

1. **保持学术风格**：原文作者偏口语化时，改写仍须回到学术书面语，不迁就、不模仿口语腔；允许短句留白，但不允许口语、网络用语、感叹腔。**严禁文言文、半文半白、仿古句式**（如"盖""然""亦""所谓"），出现即视为失败输出。
2. **字数变动 ±5% 以内**：降重/降 AI 是重组不是删减，前后字数差异控制在 ±5% 以内；数据、年份、事件、引用一字不动。
3. **不生硬表达**：改写后自然流畅、可读，避免翻译腔、欧化句式与为降重而降重的机械拼凑。

## 使用流程

### 0. 加载引导（每次会话加载本 Skill 时执行，整个会话仅执行一次）

无论本 Skill 是在全新会话中首次加载，还是在已有上下文（可能残留其他对话的改写约定、风格印象）的会话中加载，都必须先完成以下两条引导，**各只引导一次，不得默默跳过，也不得重复追问**：

**引导一：文风初始化（一次）**

1. **查找文风文件**（按优先级顺序）：
   - 当前工作区及其上级目录中的 `文风与写作偏好设定.md`（含 `Claw/` 子目录）
   - 本 Skill 自带默认模板 `references/文风与偏好设定.md`
2. **找到即加载**，并向用户确认一句：已加载文风与写作偏好设定，其约束优先级高于本 Skill 的一般风格建议；references 与文风文件冲突之处，以文风文件为准。
3. **找不到则询问用户是否初始化**，提供三个选项：
   - 使用本 Skill 默认模板 `references/文风与偏好设定.md`
   - 根据用户口述偏好现场生成一份，保存到工作区供后续会话复用
   - 本次跳过，仅按 Skill 通用规则处理
4. **上下文污染场景**：若会话中残留此前对话的改写结果或风格约定，加载时照样执行本引导，并显式声明"以本次加载的文风文件为准，先前的风格处理方式作废"；改写过程中若发现文言腔、AI 套话回潮等污染症状，不必重新引导，直接重新加载文风文件并对照其硬性禁令清单逐段复查返工。

**引导二：任务类型选择（降重 or 降AI，一次）**

加载本 Skill 后，向用户确认本次要处理的目标，**同一会话只问一次**：

| 用户选择 | 目标 | 对应参考文件 |
|----------|------|-------------|
| 降重 | 降低查重系统判定的重复率 | `references/核心降重.md` |
| 降AI | 降低 AIGC（AI 生成）检测率 | `references/AIGC降低.md` |
| 文献综述专项 | 文献综述章节降重 | `references/文献综述.md`（通常与另两者搭配） |
| 两者都要 / 全文处理 | 重复率与 AI 率同时压降 | 三个文件均需参考 |

两条引导可以合并为一次双问题提问（文风初始化 + 任务类型），减少打断；但每一项都必须得到用户明确答复或默认确认后才进入正文处理。

**引导豁免**：同一会话内用户追加新段落继续改写时，不再重复引导；仅当用户明确切换任务类型（如从降重转降AI）或反馈文风异常时，按需重载对应参考文件或文风文件。

### 1. 获取待修改文本

要求用户提供需要降重的文本内容。**建议逐句或逐段提供**，不要一次性扔整篇论文。逐段处理效果最好。

### 2. 评估方案先行（确认闸门，强制）

对整段及以上的改写任务，先输出**评估方案**（每条含：位置、原文摘录、问题类型、拟用策略），**不动原文**，经用户确认后再进入改写。这是文风文件第五节的硬性流程，不得跳过。用户在对话中逐句给出原文要求直接改的小改动，视为已确认，可免此闸门。

### 3. 逐段处理

对用户提供的每段文本：

1. 先识别段落类型（文献综述 / 理论阐述 / 定义 / 数据分析）
2. 加载对应的 references 文件中的替换词表和策略
3. 进行改写，输出改写后的版本
4. **必须给出修改前后的对比**，并标注关键改动和使用的策略
5. **事实要素核对**：改写前先列出本段事实要素清单（年份、数据、条款/模型名、事件、引用标注），改写后逐项核对，一字不差
6. **字数精确统计**：字数变化以脚本去除空白字符后统计为准（禁止估算）；超出 ±5% 必须压缩或扩写返工后再输出

### 4. 输出格式

每次修改后按以下格式输出，**一处修改一个完整格式块；连续多处修改时格式块逐条重复输出，不得合并或省略**：

```
【位置】
（章节/段落定位）

【原文】
（用户提供的原文）

【改写】
（降重后的版本）

【改动说明】
- 策略1：具体改动
- 策略2：具体改动

【字数变化】
原文 N 字 → 改后 M 字（偏差 ±x%，须在 ±5% 以内）
```

版本记录四要素（位置/原文/改后/字数变化）为强制项，与文风文件第五节保持一致。

## 核心改写策略速览

### 策略一：同义词替换
- 替换非专属名词的一切（动词、形容词、副词、连接词）
- 专业术语、专有名词、数据、引用标注不动
- 详细替换词表见 `references/核心降重.md` 第二章

### 策略二：句式变换
- 主动 ↔ 被动转换
- 长句拆分、短句合并
- 语序重组
- 8 种句式策略详见 `references/核心降重.md` 第三章

### 策略三：扩句与缩句
- 知网/万方/大雅/笔杆网 → 优先扩句
- 格子达/维普 → 优先缩句
- **边界约束**：扩句/缩句仅限句式层面的长短调整，字数仍受铁律二（±5%）约束，不得借机扩写注水或删减事实

### 策略四：文献综述模板（15个）
- 直接套用 `references/文献综述.md` 中的 15 个模板
- 模板之间灵活切换，同段不重复使用

### 策略五：降低 AIGC 痕迹（词汇/句式层 + 篇章结构层）
- 详细见 `references/AIGC降低.md`
- **三条硬性铁律（最高优先级）**：① 保持学术风格，原文口语化也须回到书面语；② 改写前后字数变动控制在 ±5% 以内；③ 不生硬表达，避免翻译腔与机械拼凑
- **核心：结构重组优先于词汇替换，同义词替换无效**
- 词汇/句式层：去「了」、去「的」堆叠、去排比、句式翻面
- 结构层七类高频痕迹模式：序数机械并列、对仗结构、总结性连接词、套话动词、英文被动+抽象名词、总分总闭环、句长节奏均匀化
- 六类补充扫描：递进连词过密、礼貌表达、术语缺乏变体、引用语境缺失、结论过于乐观、数据描述模板化
- 关键抓手：打散序数并列、打破对称、打破总分总、句长比≥4:1、段落长度变异
- **序数结构裁量规则**：跨段的研究缺口编号（"第一…第二…第三…"分若干自然段）可能是论文体例要求，不问就拆会破坏章节结构；遇到此类场景先与用户确认体例是否强制编号，或同时提供"拆序数"与"保留序数、仅打散段内平行结构"两个版本

## 用户文风约束（文风文件加载后为最高优先级）

以下为文风文件的硬性要点速览，完整版见 `references/文风与偏好设定.md`（或工作区 `文风与写作偏好设定.md`）。文风文件与本 Skill 任何建议冲突时，**一律以文风文件为准**。

- 文体：规范的现代学术书面语，第三人称，以"本文/本研究"为主语；严禁文言文、半文半白、仿古句式（"盖""然""亦""所谓"等），产出即视为失败。
- 硬禁令八条：编号列表/要点式行文、破折号解释（——）、引号强调、模糊对比术语（"背离/收敛/共振/倒挂"非标准术语时禁用）、AI 高频套话（"值得注意的是""综上所述"等）、空洞总结句、口语网络语、感叹号。
- 过渡靠语义自然衔接，不靠"首先/其次/此外"模板连接词；长短句交错，段内最长句与最短句相差 4~5 倍，同段话题唯一，一段通常 4~8 句。
- 数据口径精确（区分"货币资金/现金余额"等相近概念，不得混用），来源可溯；财务表述用段落式三段式结构（总述趋势 → 拆解驱动因素 → 落到含义）。
- 改写工作流：先出评估方案（不动原文），经确认后执行；每条修订含"位置/原文/改后/字数变化"四要素；完成后对照硬禁令清单统一复查一遍。

## 黄金法则

- **80/20 原理**：一段话 80% 被改写后，剩余 20% 即使原文保留也判为原创
- **无效降重避坑**：只倒装不换词 = 无效；只删长句留短句 = 无效；简写专属名称 = 无效
- **百科概念处理**：只取四要素（是什么/特性/作用/公式），删废话铺垫
