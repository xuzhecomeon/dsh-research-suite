# 学术文本润色工具

对输入段落进行学术化改写，去除口语表达，优化语句逻辑，保持专业术语不变；支持中文论文精炼、中英学术段落互译，输出修改前后对照表。

## 适用场景

1. **中文论文润色** — 去口语、去冗余、理顺逻辑
2. **中译英学术翻译** — 中文→英文学术写作规范
3. **英译中学术语体** — 英文→中文论文语言习惯
4. **修改对照输出** — 原文 ↔ 润色后 ↔ 修改说明 对照表

## 核心规则（优先级从高到低）

1. **术语不可篡改** — 专业名词、算法名、模型名、公式符号、固定译名保持原样
2. **语义保真** — 不改变核心信息、逻辑关系、数值、结论倾向
3. **学术化但不冗长** — 去口语（然后/就是说/反正/挺…的），替换为书面表达；避免从句堆叠
4. **句式逻辑优化** — 理顺因果/转折/递进/并列；中文主谓宾清晰，英文避免 dangling modifier
5. **标点规范化** — 中文全角，英文半角；混排时随主语言
6. **保留可读性** — 保留必要承接连词与过渡语句

## 工作流程

### 第一步：分析原文
- 识别段落主旨与核心结论
- 圈定术语清单（不变词/短语）
- 标记口语化、歧义、逻辑跳跃、冗余

### 第二步：逐句/逐段润色
- 中文润色：口语→书面、精简冗余、理顺语序
- 中译英：语法正确、时态一致、主谓一致、冠词/介词准确
- 英译中：避免翻译腔

### 第三步：输出对照表

| # | 原文 | 润色后 | 修改说明 |
|---|------|--------|---------|
| 1 | ... | ... | 口语「然后」→「进而」 |
| 2 | ... | ... | 语序调整，原因前置 |
| 3 | ... | ... | 术语「反向传播」保持不变 |

## 注意事项

1. 不确定的术语译法，搜索核实或标注供用户确认。
2. 不改动公式、引文、引用标注（如 `[1]`、`(Smith et al., 2020)`）。
3. 可指定目标期刊/会议风格（IEEE、ACM、中文计算机学报）。
4. 不添加原文不包含的新结论。
5. 原文逻辑不通/信息残缺导致无法润色，如实告知不强行编造。
