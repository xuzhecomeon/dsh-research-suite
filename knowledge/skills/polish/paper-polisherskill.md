# Paper Polisher 学术论文精修

一站式论文精修流水线：降重 → 去AI味 → Word文档输出。

## 触发条件

当用户提出以下意图时触发：

- "帮我给这篇论文降重并去AI味"
- "这篇论文查重率太高，而且读起来像AI写的"
- "把我的论文精修一下，既要降重也要让语言更自然"
- "论文润色：降重 + 去AI感 + 输出Word"
- 任何同时涉及「降重/去AI味/论文润色 + 文档输出」的请求

## 核心工作流

按以下三阶段流水线执行，前阶段输出作为后阶段输入。

### 阶段一：论文降重（Plagiarism Reduction）

**目标**：通过合法的语言改写手段降低查重系统检测到的重复率，同时保持学术含义完整。

**改写策略（按优先级排序）**：

1. **同义词/近义表达替换**：替换非专业术语的常用词，保持学术语域
   - 例："方法" → "技术"、"做出预测" → "进行推断"
2. **句式重组**：长句拆短、短句合并、从句结构调整
   - 例：定语从句 → 前置定语、"随着X的发展，Y..." → "X的发展推动了Y..."
3. **主被动语态转换**：主动改被动、被动改主动交替使用
4. **语序调整**：改变信息呈现顺序，不改变逻辑关系
5. **表述角度转换**："X表明..." → "研究发现..." / "根据X的分析..."

**不可修改项**：
- 学科专有名词和术语
- 直接引用的原文（保留引用标记）
- 公式、数据、图表编号
- 引用来源和参考文献

**输出要求**：
- 逐句改写，标注每处修改使用的策略
- 生成策略对照表（原文片段 → 改写片段 → 策略）
- 标注保留未改的部分及原因

### 阶段二：AI痕迹去除（Humanization）

**目标**：消除文本中的AI生成特征，使语言更自然、更有「人味」。

**检查并移除以下AI写作模式（基于 Wikipedia: Signs of AI writing）**：

**内容模式**：
- 夸大重要性的表述：`stands as a testament to`, `marks a pivotal moment`, `crucial role`, `underscores its significance`
- 空洞的知名度声明：`has been cited in`, `maintains an active presence`, `widely recognized`
- 表层分析句式：`-ing` 分词尾巴（`highlighting...`, `reflecting...`, `symbolizing...`）
- 广告型语言：`boasts a`, `vibrant`, `renowned`, `stunning`, `groundbreaking`

**语言模式**：
- AI高频词汇：`additionally`, `crucial`, `delve`, `underscore`, `tapestry`, `landscape`, `pivotal`, `interplay`, `intricate`
- 系词规避：`serves as` / `stands as` / `represents` 代替简单的 `is`
- 否定排比：`It's not just X, it's Y` / `Not only...but...`
- 三段式：强行将观点组织为三个一组
- 同义词堆砌：连续重复概念用不同词语表达

**风格模式**：
- 破折号过度使用（—）
- AI协作残迹：`I hope this helps!`, `Let me know if...`, `Certainly!`
- 知识截止日期声明：`As of [date]...`, `based on available information...`
- 过度修饰：`In order to achieve` → `To achieve`
- 正面积极结论模板：`The future looks bright`, `Exciting times lie ahead`

**语言灵魂注入**：
- 确保句子长度和结构有变化（不要每句都一样长）
- 允许表达不确定性或复杂感受
- 使用具体细节替代模糊断言
- 用简单的 `is` / `has` 替代虚饰动词

**输出要求**：
- 提供改写后文本
- 列出改动摘要（移除了哪些AI模式，替换了什么）

### 阶段三：Word文档输出

使用 python-docx 生成结构化精修报告文档。

**文档结构**：

```
1. 封面
   - 论文标题
   - 「精修报告」副标题
   - 生成日期

2. 降重报告
   - 原文全文
   - 降重后全文
   - 策略对照表（表格形式）
   - 保留项清单

3. 去AI味报告
   - 降重后全文（即去AI味的输入）
   - 去AI味后全文
   - 改动摘要（逐条列出移除的AI模式）

4. 终稿
   - 精修后的最终文本
   - 可直接使用
```

**格式规范**：
- 页面：A4，边距 2.54cm
- 标题：黑体，一级 18pt，二级 15pt，三级 13pt
- 正文：宋体 12pt，1.5 倍行距
- 表格：Light Grid Accent 1 风格，表头加粗居中
- 页脚：页码居中
- 原文/改写前后用不同颜色标记（降重红色=原文，绿色=改写；去AI味橙色=问题句，蓝色=修正后）

## 重要约束

- **保持原意是底线**：任何改写不可曲解原文含义
- **专业术语不可替换**：学科专有名词必须保留
- **不代写论文**：仅做语言层面的降重和去AI味，不编造学术内容
- **不删除引用标记**：引用他人观点必须保留出处标注
- **不保证特定重复率**：降重效果取决于原文重复类型和查重系统差异

## 使用示例

**示例 1：论文段落精修**
```
用户：这段文献综述查重率50%，导师也说AI痕迹太重，帮我全面精修一下
[提供段落]
→ 阶段一降重：逐句改写，生成策略对照表
→ 阶段二去AI味：移除 inflated language、AI vocab、填充词
→ 输出含降重报告 + 去AI味报告 + 终稿的 Word 文档
```

**示例 2：全文精修**
```
用户：我的毕业论文写完了但查重35%，而且读起来很生硬，帮我从降重到去AI味全流程处理
[上传或粘贴论文全文]
→ 分章节处理（建议分段提交，每段 300-500 字最佳）
→ 先降重再去AI味，两步串联
→ 生成完整精修报告 Word 文档
```

## 分段处理建议

- 文献综述和理论基础部分重复率通常最高，优先处理
- 建议每段 300-500 字，小段落改写质量更高
- 先提交一小段测试效果，确认风格后再全量处理
- 精修后自己通读，确认每句话都认同且理解

## 相关技能增强

若已安装以下技能，组合使用可提升各阶段质量：

- `paper-plagiarism-reducer` → 增强降重策略多样性和策略标注精度
- `humanizer` → 增强AI痕迹检测覆盖面和修正准确度
- `word-docx` → 增强Word输出格式控制的精细度

若未安装，本技能使用内置能力独立完成全流程。

## 注意事项

- 生成本 Word 前先安装 python-docx：`pip install python-docx`
- 报告保存到当前工作目录的 outputs 文件夹
- 用户论文内容仅用于当次处理，不存储不传播
- 涉及学术创新的核心内容注意保密
