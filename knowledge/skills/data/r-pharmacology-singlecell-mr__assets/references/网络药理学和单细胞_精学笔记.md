## 1. ★★★ 单细胞 eQTL 的 MR（`T.R`）—— 本域最前沿的方法

**核心思路**：用**细胞类型特异性的 eQTL**（如仅 T 细胞中显著的基因表达遗传变异）作为工具变量做 MR，
从而回答"**某细胞类型中某基因的表达 → 疾病**"这一比 bulk eQTL 更精细的因果问题。

**完整技术链**
```
1. 上游：tensorQTL / cellregmap 输出 tensor_out/（每个细胞的 eQTL 结果）
2. 读取：批量读 tensor_out/ 下的文件，加 Cell 列标记细胞来源
3. ★ 变异标识转换：variant_id（chr_pos_ref_alt）→ chr:pos 区间
   CHR = str_extract(variant_id, "^[^_]+")
   POS = str_extract(variant_id, "(?<=_)[0-9]+(?=_")
   ranges = "CHR:POS-POS"
4. ★★ 用 GRCh37 的 dbSNP 包把 chr:pos 映射为 rsID
   snps <- SNPlocs.Hsapiens.dbSNP155.GRCh37
   snp.res <- snpsByOverlaps(snps, GRanges(ranges))
   inner_join(data, by="ranges")
5. ★★ 计算 EAF（关键且容易错）
   eaf = ifelse(A2 == maf, maf, 1 - maf)      # A2 = effect allele
6. format_data → exposure_dat（effect_allele_col="A2", other_allele_col="A1"）
7. ★ 工具变量强度：F = beta^2 / se^2
8. 阈值放宽：pval.exposure < 1e-05（eQTL 样本量小于 GWAS，必须放宽）
9. extract_outcome_data(outcomes="ieu-b-40") → harmonise_data(action=2)
10. ★★ 手写 Steiger 方向性检验
    rsq.exposure <- get_r_from_pn(p=, n=)^2
    rsq.outcome  <- get_r_from_lor(lor=, af=, ncase=, ncontrol=, prevalence=)^2
    st <- psych::r.test(n=, n2=, r12=sqrt(rsq_exp), r34=sqrt(rsq_out))
    steiger_dir  <- rsq.exposure > rsq.outcome
    steiger_pval <- pnorm(-abs(st$z)) * 2
```

**★★★ 本脚本的最大价值：它给出了第三域缺失的 Steiger 方向性检验的完整手写实现**
- 用 `get_r_from_pn()`（由 p 值与样本量反推 r）算暴露的 R²
- 用 `get_r_from_lor()`（由 OR、等位基因频率、病例/对照数、患病率反推）算结局的 R²
- 用 `psych::r.test()` 检验两个相关系数差异
★ **这三步可直接移植到任何 MR 分析**，补上 STROBE-MR 的推荐必备项。

**脚本的问题**
| # | 问题 | 说明 |
|---|---|---|
| S1 | **p 值口径**：`pnorm(-abs(st$z)) * 2` 是**双侧** | Steiger 检验通常应报**单侧**（`pnorm(-abs(z))`），因为方向性有明确的先验方向。需核实口径并在 Methods 中声明 |
| S2 | `harmdat <- cbind(harmdat, rsq.exposure=1, rsq.outcome=1)` 后立即覆盖 | 冗余死代码 |
| S3 | `write.csv(exposure_dat, "T细胞暴露.csv", quote=F)` 在 Steiger 之后写，但写的是 `exposure_dat` 而非 `harmdat` | **可能写错对象**（丢掉了 steiger 列） |
| S4 | 结果未落盘为可复用的分析数据 | 应 `write.csv(harmdat, "harmdat.csv")` |

## 2. 基因富集分析（`基因富集.R`）—— 本域代码质量最高

**流程**
```r
genes <- read.delim('gene.txt', header=F)[[1]]                       # 靶点基因列表
gene2kegg <- bitr(genes, fromType="SYMBOL", toType="ENTREZID", OrgDb=org.Hs.eg.db)
kegg_df <- enrichKEGG(gene=gene2kegg$ENTREZID, organism="hsa",
                      pAdjustMethod="BH", pvalueCutoff=1, qvalueCutoff=1)
ego_bp <- enrichGO(..., ont="BP", pvalueCutoff=0.01, qvalueCutoff=0.05)  # CC / MF 同
```

**★★ 三个值得学的技术点**

1. **正确地把 `enrichResult`（S4）转成 data.frame 再筛选**
   ```r
   kegg_sig <- as.data.frame(kegg_df) %>% dplyr::filter(pvalue < 0.01)
   ```
   直接用 `kegg_df %>% filter()` 会因 S4 对象而失败 —— 这是初学者最常踩的坑。

2. **EntrezID → Symbol 反向映射，生成"基因-通路"一对一表**
   ```r
   id2sym <- setNames(gene2kegg$SYMBOL, gene2kegg$ENTREZID)
   pairs_list <- lapply(seq_len(nrow(kegg_sig)), function(i) {
     entrez_vec <- strsplit(kegg_sig$geneID[i], "/")[[1]]
     data.frame(Gene=id2sym[entrez_vec], Pathway=kegg_sig$Description[i])
   })
   gene_pathway_df <- bind_rows(pairs_list) %>% filter(!is.na(Gene)) %>% distinct()
   ```
   ★ `enrichKEGG` 的 `geneID` 是**斜杠分隔的 EntrezID 字符串**，必须拆开才能做后续的通路-基因网络。这是**网络药理学的核心数据整理步骤**。

3. **气泡图按 KEGG 一级分类循环出图**
   ```r
   lvl1_order <- c("Environmental Information Processing","Human Diseases","Organismal Systems",
                   "Cellular Processes","Metabolism","Others")
   for (cat in lvl1_order) { ... ggsave(sprintf("KEGG_bubble_%s.png", ...), width=max(10, nrow*0.4)) }
   ```
   ★ 比一张混在一起的大图清晰得多，且 `width` 随条目数自适应。

4. **GO 三栏 Facet 条形图**（`facet_grid(ONTOLOGY ~ ., scales="free_y", space="free_y")`）+ `slice_min(pvalue, n=5)` 取每栏 Top5 —— 规范的 GO 呈现方式。

## 5. 单细胞流程（`单细胞.R`）—— Seurat 标准范式

```r
# ① 批量读入 → ② 逐个 CreateSeuratObject → ③ merge
for (i in 1:10) { tmp <- read.csv(paste0('GSE165816/', file_list2[i]))
                  tmp <- CreateSeuratObject(counts=tmp)
                  tmp$sample <- paste0('sample', i); tmp$disease <- disease1[i]
                  assign(paste0('sample', i), tmp) }
obj3 <- merge(sample1, sample2); for (j in 3:10) obj3 <- merge(obj3, get(paste0('sample', j)))

# ④ 标准降维聚类
obj3 <- SCTransform(obj3); obj3 <- RunPCA(obj3); obj3 <- RunUMAP(obj3, dims=1:15)
obj3 <- FindNeighbors(obj3, dims=1:10); obj3 <- FindClusters(obj3, resolution=0.1)
DimPlot(obj3); FeaturePlot(obj3, features=c('CD3D','CD3E'))     # 辨识 T 细胞

# ⑤ ★★ 提取 T 细胞亚群 → 重新降维聚类 → 差异基因
T_obj <- subset(obj3, seurat_clusters %in% c(0,2,4))
T_obj <- RunPCA(T_obj); T_obj <- RunUMAP(T_obj, dims=1:15)
T_obj <- FindNeighbors(T_obj, dims=1:15); T_obj <- FindClusters(T_obj, resolution=0.1)
FeaturePlot(T_obj, features=c('CD4','CD8A','CD44'))
T_obj <- PrepSCTFindMarkers(T_obj)                       # ★ SCTransform 后必须做
marker1 <- FindMarkers(T_obj, ident.1=0, min.pct=0, logfc.threshold=0)
```

**★★ 本域的核心设计：单细胞 → 细胞类型特异 eQTL → MR**
`subset(T_obj, seurat_clusters %in% c(0,2,4))` 提取 T 细胞，正是为了后续在 **T 细胞上做 eQTL**（`T.R`），
再与 GWAS 做 MR —— 即"**单细胞 MR / 细胞类型特异 MR**"。

**问题**
| # | 问题 | 严重度 | 说明 |
|---|---|---|---|
| C1 | **`disease1[i]` 变量从未定义** | 🔴 | `tmp1$disease <- disease1[i]` → **报错**，脚本中断 |
