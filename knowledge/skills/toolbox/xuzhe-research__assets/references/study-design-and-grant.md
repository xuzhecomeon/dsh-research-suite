# 科研思路与基金标书

> 定位：处理**尚未发生**的研究（将来时，无结果数据）。已经做完的分析要写成论文 → `writing-and-citation.md`；已有数据要跑统计 → `statistics.md`。

## 何时进 / 何时出

| 进入 | 转出 |
|---|---|
| 选题、假设、新颖性、研究设计、样本量与功效、可行性、预分析计划、标书框架与预审 | 已有结果数据撰写 → 撰写模块；需要重算或建模 → 统计模块；需要文献证据 → 检索模块 |

## 假设与设计卡（最小可判定单元）

假设必须写成**一句可被证伪的话**：明确人群、暴露/干预、对照、结局、时间窗、预期方向。写不出"什么结果会推翻它"，就是没写假设。反例：「探讨 A 与 B 的关系」——不可证伪；正例：「在 X 人群中，A 暴露者的 90 天 Y 结局发生率高于非暴露者」。

设计卡固定四栏，六类设计各填一遍，不写满四栏即视为设计未定：

| 设计类型 | 人群与入排 | 暴露/干预与对照 | 结局与测量时点 | 混杂与偏倚控制 |
|---|---|---|---|---|
| 随机对照（含实用型、适应性） | 入排须能外推到目标人群；排除标准不得删掉主要受益人群 | 干预方案可执行到剂型/频次/疗程；对照选常规治疗或安慰剂并说明理由 | 主要终点唯一，时点事前固定；次要终点标"探索性" | 随机化与分配隐藏、盲法层级（受试者/实施者/评估者/统计者）、方案偏离与退出处理 |
| 队列（前瞻/回顾） | 明确起点（入组日/诊断日/手术日）与随访至何时 | 暴露测量工具与时点；回顾性研究须说明暴露是何时记录的 | 结局判定标准与判定者盲法 | 关键混杂清单（不是"多因素调整"四个字）、时间相关混杂、失访与竞争风险 |
| 病例对照 | 病例来源与诊断依据；对照来源（同院/社区）与匹配变量 | 暴露回溯方式（病历/问卷/生物样本）与回忆偏倚 | 病例组与对照组结局定义对称性 | 选择偏倚（入院率）、匹配过度（匹配了中介变量）、暴露测量一致性 |
| 横断面 | 抽样框与抽样方法；应答率 | 暴露与结局同时测量 | 单时点，不得推因果 | 无应答偏倚、现患-病程偏倚（只捕获存活者） |
| 诊断准确性 | 连续或按临床路径入组，避免只纳入确诊者 | 待评价试验的操作与判读（是否盲法） | 参照标准定义与判读独立性 | 谱偏倚、验证偏倚（部分人未做参照标准）、不确定结果处理 |
| 自身对照（前后/交叉） | 同一受试者的两个时段 | 洗脱期与顺序效应 | 时段效应与携带效应 | 顺序随机化、季节/学习效应 |

可行性三维必须量化，写成"能/不能/需要什么"而不是"较好/一般"：**病例量**（近 3 年符合入排的实际例数，与所需样本量比较）、**随访**（随访手段、失访估计、最长随访窗）、**多中心**（是否必需、参研单位是否落实、伦理与数据共享安排）。

## 样本量与功效要点

| 项 | 必须写清 |
|---|---|
| 依据来源 | 主要终点的预期效应量取自哪项既往研究或预试验；无来源则写"缺乏可靠依据，按最小临床意义差值假设" |
| 参数 | 显著性水平、把握度、预期效应量、变异度、脱落率、单/双侧 |
| 计算对象 | 主要终点算样本量；次要终点不参与（否则多重比较失控） |
| 设计校正 | 配对/交叉用配对公式；整群用设计效应；重复测量考虑相关性；生存资料按事件数而非人数 |
| 事件数 | 生存与 logistic 类研究必须同时报**事件数**与每个参数的事件数（EPV），EPV 不足即判设计缺陷 |

## 新颖性三档（判定语必须落到证据）

| 档 | 判定语 | 判定依据 |
|---|---|---|
| 新颖 | 「未见同类研究回答该问题」 | 检索式、库、日期、命中数可复现；同概念不同人群/不同结局不算新颖 |
| 部分重叠 | 「已有 X 研究，本研究在人群/暴露窗/结局/设计上不同」 | 明确指出重叠点与差异点各一条 |
| 已发表 | 「已有研究回答了同一问题」 | 给出可核验标识（DOI/PMID）；此时建议改问题或改为验证性研究 |

未做检索验证的选题，一律写「未检索验证」，不得宣称新颖（见 SKILL.md R1）。

## 选题评估与预分析计划

| 产出 | 必含列 |
|---|---|
| 选题评估表 | 候选问题、新颖性档位、可行性三维（病例量/随访/多中心）、资源缺口、预期产出、结论（推荐/备选/淘汰） |
| 淘汰留档 | **被淘汰的候选必须留档并写明淘汰理由**，否则用户无法复核为何不选 |
| 阶段证据门 | 每个阶段先有证据再下结论：先检索→再判新颖→再定设计→再算样本量；任一环缺证据，后续结论标"待验证" |
| 预分析计划 | 主要/次要终点、统计方法与前提处理、亚组与交互（事前声明）、缺失数据处理、敏感性分析、多重比较校正方案、分析人群定义 |

## 标书框架（缺指南时按通用框架并显式声明）

| 章节 | 必含内容 |
|---|---|
| 立项依据 | 领域现状（带证据锚点）→ 关键缺口 → 前期基础 → 本研究的科学问题与假设 |
| 研究内容 | 拆成 2–4 个研究内容，每条对应一个可交付结果，不写"深入研究"类动词 |
| 技术路线 | 步骤化流程图 + 每步的方法与判定标准；关键节点写"失败则如何" |
| 可行性 | 三维量化（见上）+ 团队分工 + 平台条件 |
| 统计方案 | 设计类型→方法→样本量→敏感性分析（与统计模块同一套判据） |
| 预算 | 分科目列单价×数量；**脚本只负责算术正确与格式**（出表、合计、占比），**金额假设与资助方合规性由正文说明**；假设变更须同步改正文 |
| 预审意见 | 四视角各出一份：新颖性、可行性、预算合理性、逻辑与表述 |

红线：资助方指南、申报条件、字数与格式要求**一律以用户提供或实时获取的文件为准**；未获取时必须写「未获取指南，按通用框架撰写」，**禁止凭记忆写条款号、禁止编造限项与截止日期、禁止编造评审标准权重**。

## 输出与反例

示例仅演示格式，规则本身领域无关。

| 反例（算什么错） | 正确做法 |
|---|---|
| 「本研究首次发现 A 可改善 Y」（未检索就说首次） | 「未检索验证；据现有检索未见同类研究」 |
| 样本量写「参考同类研究约 200 例」 | 写清终点、效应量来源、α、把握度、脱落率与算式结果 |
| 标书技术路线写「采用先进统计方法分析」 | 写具体方法名、前提处理与替代方案 |
| 把已完成的预实验数据写成「将开展」 | 时态与结果状态必须一致，预实验标"前期基础" |
