# 文献检索与证据集

> 定位：把一句提问变成**可追溯的证据集**。只负责"找到、筛清、留痕"，不负责下结论。要"这个领域还有什么没做"→ 转 `study-design-and-grant.md`。

## 何时进 / 何时出

| 进入 | 转出 |
|---|---|
| 用户要查文献、要检索式、要近五年证据、要纳入排除后的清单、要系统评价筛文 | 要结论/空白/方向 → 科研思路；要把 N 篇整合成综述 → 撰写与引文；要对单篇做拆解 → 审阅与解读 |

## 检索式构建（字段语法与组合）

| 语法 | 含义 | 何时用 |
|---|---|---|
| `[MeSH]` | 主题词（默认爆炸检索含下位词） | 概念有规范主题词时，先抓召回 |
| `[Majr]` | 主要主题词 | 需要高精度时收紧 |
| `[tiab]` | 标题与摘要 | 新词、商品名、尚无主题词的概念 |
| `[pt]` | 出版类型 | 限定随机对照试验、系统评价、指南 |
| `[dp]` | 出版日期 | 实现"近五年"等时间窗 |
| `[ta]` | 期刊名 | 限定目标刊群 |
| `[au]` / `[ad]` | 作者 / 机构 | 追踪团队或系列研究 |
| `*` | 截词 | 词根扩展（需注意过宽） |
| `"..."` | 短语检索 | 固定搭配 |

组合规则：①先分概念块（人群、暴露/干预、结局、设计），每块内部 OR、块间 AND；②每块先 MeSH 后 tiab，两者 OR 合并，保证召回；③限定词一律放最后，逐条加、逐条看数量变化；④`NOT` 只在能明确说清排除了什么时用，否则会静默丢真阳性；⑤检索式必须能被人原样复现——存下完整字符串、库名、检索日期、命中数。

调优方向：召回不足就去限定词、加同义词/缩写/旧称、加 tiab、换更上位主题词；噪音过多就加出版类型、加主要主题词、用短语而非单词、加结局词。不做"只查近三年""只查英文"的默认；预印本是否纳入必须显式声明。

示例仅演示格式，规则本身领域无关。

```text
("Concept A"[MeSH] OR "Concept A"[tiab] OR "synonym A"[tiab])
AND ("Concept B"[MeSH] OR "Concept B"[tiab])
AND ("randomized controlled trial"[pt] OR "cohort"[tiab]) AND ("2019"[dp] : "3000"[dp])
```

## 多源、去重与取数

| 源 | 主要覆盖 | 标识体系 | 取数注意 |
|---|---|---|---|
| PubMed / MEDLINE | 生物医学主库 | PMID、DOI | 接口有速率限制，批量必须分页并留间隔 |
| Europe PMC | 含部分中文与非英文刊、预印本 | PMID、DOI、PMCID | 适合补非英文语种覆盖 |
| OpenAlex | 跨学科全景、引文网络 | OpenAlex ID、DOI | 适合滚雪球与作者/机构追踪 |
| Semantic Scholar | 语义相似与引用上下文 | DOI、paperId | 有明确限流与引用声明义务，需遵守 |
| 中文库（知网/万方/中华医学期刊全文库） | 中文核心与指南共识 | 无统一 DOI | 需人工导出，导出格式与时间须留档 |

去重主键优先级：DOI → PMID → 规范化标题＋年份＋首作者。滚雪球三路并行：正向引文（谁引用了它）、反向引文（它引用了谁）、语义相似推荐；每路都要记录来源与轮次。**禁止为凑覆盖率而扩检**：命中数远超预期时先查检索式是否过宽，而不是继续堆源。

## 筛选留痕（可复现的最低要求）

| 环节 | 留什么 |
|---|---|
| 题录筛 | 双人独立判读；每人判定（纳入/排除/待定）与排除理由代码 |
| 全文筛 | 同上，加"排除理由"必须落到具体条目（人群不符/设计不符/结局不符/数据不可用） |
| 分歧 | 每处分歧记录双方理由与仲裁结论，仲裁人可为第三人 |
| 计数 | 识别数→去重后→题录筛后→全文筛后→最终纳入，五个数字必须自洽 |

系统评价子流程（在检索式确定之后执行，与统计分析分属两个模块）：①注册或声明方案（若用户要做正式 SR，先确认是否有方案与注册号，没有则明确告知"未注册"）；②检索式定稿并冻结；③双人题录筛；④双人全文筛；⑤偏倚风险评估（按设计类型选工具）；⑥数据提取表冻结后再提取；⑦异质性与发表偏倚交统计分析模块处理。**筛文阶段只交清单与理由，不出效应量。**

## 输出契约

| 列 | 必填 | 说明 |
|---|---|---|
| 序号 | 是 | 与文内引用序号一致 |
| 标题 | 是 | 原始语种标题，不改写 |
| DOI | 是 | 无 DOI 写"无"，不得编造；可给 PMID 替代标识 |
| 年份 | 是 | 与出版年一致 |
| 期刊 | 是 | 英文用标准缩写 |
| 来源库 | 是 | 记录实际取到该条目的库 |
| 研究类型 | 是 | 随机对照/队列/病例对照/横断面/诊断准确性/系统评价/指南/基础研究 |
| 相关性判定 | 是 | 纳入/排除/待定，附一句理由 |
| 证据级别 | 是 | 按用户指定体系（GRADE 或分级体系），未指定则写"未分级" |

交付为 xlsx；同时在 `evidence/` 存检索式留档（库名、完整字符串、日期、命中数）与筛选计数表。缺项一律留空或写"待核验"，**不得补全为看似合法的值**（见 SKILL.md R1、§7 第 4 行）。

## 全文获取：合规边界与失败分类

只做三件事：给出可公开访问的链接或 DOI、告知是否为开放获取、告知机构订阅通常能拿到什么。**不做**绕过付费墙、不下载未授权资源、不使用他人凭据。

| 失败类别 | 判定信号 | 处置 |
|---|---|---|
| 无权限/无馆藏 | 返回登录页或订阅提示 | 记录"需机构订阅"，给 DOI 与题录，不代取 |
| 链接失效 | 404 或跳转至无关页 | 记录"链接失效"，回查 DOI 重取一次 |
| 需人工验证 | 出现验证码或人机校验 | 记录"需人工完成"，不尝试自动绕过 |
| 格式不可解析 | 拿到文件但无文本层 | 记录"无文本层"，要求用户粘贴正文或改用外部 PDF 工具 |

## 未联网与接口失败（诚实降级）

未联网或接口失败时，**只能给检索式**：库名、完整字符串、字段说明、预期纳入排除标准、筛选流程。禁止给条目清单、禁止给"约有多少篇"的估计、禁止用记忆补文献。运行记录写 `network: unavailable`，并在交付说明里写明"本次未执行在线检索"。

| 反例（算什么错） | 正确做法 |
|---|---|
| 凭记忆列出 10 篇"相关文献"并附看似合理的 DOI | 只给检索式，明确"未联网，未检索" |
| 用户给了 5 篇，输出里多出 3 篇没见过的 | 只用用户给的与真实检索到的 |
| 把"检索到 120 篇"写成结论，实际是模型估计 | 写实际命中数；无法获取则写"未获取" |
