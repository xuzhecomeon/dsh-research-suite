# 科研绘图与科研 PPT

> 定位：只做视觉产物。讲什么内容由解读卡提供（`manuscript-reading-review.md`）；数值只能来自统计结果 JSON 或用户数据，**不得手抄、不得由模型估数**（SKILL.md R2）。

## 数据图 vs 示意图（先判这一步）

| 判据 | 数据图 | 示意图 |
|---|---|---|
| 有没有数据文件 | 有（csv/xlsx/结果 JSON） | 无，靠语义关系 |
| 由谁产出 | 脚本按坐标确定性生成，可校验 | 模型生成 SVG，元素语义命名 |
| 能不能改数 | 改数据重跑即变 | 图元位置可手调，无数据可改 |
| 必须标注 | 图注写 n、统计方法、误差棒定义 | 角标「示意图，非数据图」 |
| 允许 AI 生图 | **绝对禁止** | 仅概念草图，且必须角标说明，不得作为正式插图 |

## 图型选择

| 想表达 | 图型 | 硬要求 |
|---|---|---|
| 组间分布 | 箱线图或散点叠加 | 显示个体点与样本量 |
| 两变量关系 | 散点图加拟合 | 说明拟合方式与区间含义 |
| 率或计数比较 | 柱状图加点 | 误差棒定义写清（标准差/标准误/置信区间） |
| 时间趋势 | 折线图 | 同一图内不混用不同量纲 |
| 生存 | 阶梯曲线＋风险人数表 | 风险表与曲线同一横轴刻度 |
| 效应汇总 | 森林图 | 给权重、异质性、总体效应菱形 |
| 诊断准确性 | ROC | 标出阈值点与 AUC 区间 |
| 多因素结果 | 森林图或热图 | 给参照组与调整变量 |
| 机制/流程 | 示意图 | 箭头语义一致（激活实线、抑制平头） |

## 两条通路与降级

| 通路 | 做法 | 代价 | 何时用 |
|---|---|---|---|
| 主通路：手算坐标直写 SVG | 零第三方依赖，坐标完全可控，文字为活字，可逐字节比对 | 复杂图层（平滑置信带、抖动、多面板自动排版）需自己算 | 默认 |
| 增强通路：绘图库或 R | 图层丰富、排版省力 | 依赖缺失即不可用；产物与主通路同名不同后缀便于对比 | 探测到依赖才用 |
| PDF/PNG | 依赖二级渲染后端；无任何后端时 PNG 不可达（无字体栅格化） | 缺失即降级 | 有则给，无则显式声明 |

**v1 未实现（明示）**：matplotlib 的 rich 出图通路（探测到也只登记、不切换，产物始终是手写 SVG）；PDF 的 CJK 字体嵌入（中文图请交 SVG，交付里不得出现「中文变方框却算成功」）。

降级必须写三样：未生成什么、为什么、怎么补。交付判定以 SVG 是否生成并通过合规校验为准，PDF/PNG 缺失不判能力不达标，但**运行记录里必须有"未生成＋原因"条目**。

## SVG 硬规范（字必须能改）

| 规范 | 要求 |
|---|---|
| 文字载体 | 所有文字必须是 `<text>` 元素；轮廓化成路径即视为不达标 |
| 禁止元素 | 不写脚本、不写外部样式表、不写动画、不写位图嵌入（数据图内） |
| 命名空间与转义 | 文本与属性中的 `&`、`<`、`>` 必须转义，否则整页空白 |
| 坐标方向 | 纵轴向上设计时整组翻转，`<text>` 需局部再反向，否则文字倒置 |
| z 序 | 背景最先画，标题最后画；组名用序号前缀控制叠放 |
| 字号 | 终稿图内字号落在 7–9 磅区间；缩放后不得低于 6 磅 |
| 字体 | 英文 Arial 或 Helvetica；中文用系统可用的黑体类，且必须在图注声明所用字体 |
| 特殊符号 | 对勾、叉号、上下标数字依赖字体字形易缺字，改用路径绘制或普通字符 |
| 单位与刻度 | 刻度不得少于 3 个；轴标题带单位；不用三维效果与阴影 |
| 可达性 | 每图给替代文本（一句话说明看图能看到什么结论） |

## 期刊预设（未指定目标刊时用默认列）

| 参数 | 单栏 | 双栏 | 说明 |
|---|---|---|---|
| 图宽 | 89 毫米 | 183 毫米 | 按目标刊要求可微调，但同稿内统一 |
| 字号 | 7–8 磅 | 8–9 磅 | 终稿不缩放到 6 磅以下 |
| 字体 | Arial / Helvetica | 同 | 中文刊可换宋体类，图注声明字体 |
| 线宽 | 0.5–1 磅 | 同 | 曲线比坐标轴线粗一档 |
| 分辨率替代 | 矢量优先 | 同 | 位图仅作预览 |

## HR/P 标签避让曲线的规则（生存图必查）

| # | 规则 |
|---|---|
| 1 | 默认位置：右上角**图外或图内空白区外置**，不与曲线同层；不得压在曲线上 |
| 2 | 先算包围盒：每条曲线取所有台阶点与标签文本框的外接矩形，标签框与任一曲线包围盒相交即判冲突 |
| 3 | 冲突处置顺序：右移出绘图区 → 上移出绘图区 → 整体下移到图下方单独成行（横排、按组顺序） |
| 4 | 风险人数表在图下方时，标签行放在风险表之上，且不得与风险表行重叠 |
| 5 | 多条曲线标签沿纵向等距排列，行距 ≥ 1.6 倍字高；不得为省空间缩小字号 |
| 6 | 交付前必须跑一次重叠校验；有冲突就改坐标重出，不得靠"看起来没压上"交付 |

## 图内文字语言（唯一裁决）

按目标刊语种：英文刊图内全英文（基因名、器械型号、量表专名保留原文，首次出现给全称）；中文刊图内可中文；**同一图内不得中英混排**（专名除外）。目标刊未定时默认英文，并只问一次。坐标轴标题、图例、面板字母、注释数字符号全图统一一种语言。中文图若需 PDF 而字体嵌入未实现，优先交 SVG 并说明原因，**不得交付中文变方框的 PDF**。

## 图注与出图前门禁

图注四件套：① 一句话结论（这张图证明什么）；② 每组样本量；③ 统计方法与误差棒定义；④ 缩写说明。手填统计量出图时，图注必须写「数据来源：文献报告值（hand-plotted）」。

出图前门禁：数据是否有缺失或负值（对数轴尤其）、组别是否都有 n、量纲是否统一、轴范围是否截断（截断必须标断轴）、配色是否色盲可辨（不用红绿对立，改用蓝橙并加成形状或线型差异）、图内是否残留内部代号。

## PPT：两版式与叙事

| 版式 | 布局 | 约束 |
|---|---|---|
| A 标题＋要点 | 标题一行 ＋ 要点不超过 5 条，层级不超过 2 级 | 一页一个论点；正文不小于 18 磅；不写整段话 |
| B 图＋说明 | 上图下文或左图右文 | 图必须带图注；说明不超过 3 行；图不拉伸变形 |

叙事骨架：讲型 → 页数 → 逐页主题 → 每页时间预算 → 预设问答。页数基准：组会 10–15 页、科室汇报 15–20 页、答辩 20–25 页、会议发言按每分钟一页估算。页数超出时先删背景页，不删结果页。

| 段落 | 占比（分钟制） | 内容 |
|---|---|---|
| 背景与问题 | 两成 | 只讲缺口，不讲教科书 |
| 方法 | 两成 | 设计与统计，一页讲清 |
| 结果 | 四成 | 每页一张图，结论句作标题 |
| 结论与展望 | 两成 | 三条以内，含局限 |

讲稿与时间预算：每页给一句讲稿要点与分配秒数，总时长控制在给定时间的九成，留一成应变。预设问答准备 5–8 条，每条给一句答复要点。

PPT 质检（不合格即返工）：一页多论点、字小于 18 磅、图无标注、正文整段搬运、动画与花哨转场、母版主题乱改、讲稿与页面内容不一致、总数超出时间预算。兜底：无演示软件环境时同出可翻页的单文件预览并明确"仅供预览"，正式交付仍是可编辑演示文件。

## 反例（什么样算不合格）

示例仅演示格式，规则本身领域无关。

| 反例 | 正确做法 |
|---|---|
| 图内文字被转成路径，双击改不了字 | 保留 `<text>`，字号与字体写进图注 |
| 生存图 HR 与 P 文本压在曲线上 | 按避让规则外置或下移到图外单独成行 |
| 组会 PPT 30 页讲 10 分钟、正文 14 磅 | 按时间预算裁页，正文不小于 18 磅 |
