# 语言润色（保真优先）

> 定位：只改表达，不改结构、不加事实、不改结论强度。需要重排段落、补论证、改章节 → 转 `writing-and-citation.md`。唯一总则：**忠于作者原意**，其余全部规则服从它。

## 两档强度（默认保真）

| 档 | 做什么 | 不做什么 | 何时启用 |
|---|---|---|---|
| 保真档（默认） | 单遍润色：语法、搭配、冗余、歧义、术语统一、句长拆分 | 不改结构、不加事实、不换论证顺序、不改结论强度 | 用户未指定档位时一律用此档 |
| 深度档 | 四层推进：术语层 → 句法层 → 逻辑衔接层 → 文风层 | 仍不得新增数据、不得改变结论强度、不得删独立信息 | 用户明确说"深度润色""四层""大改语言" |

优先级（冲突时自上而下）：用户给定的文风样本或风格要求 > 目标刊体例 > 本档规则 > 默认文风。中文正文不改标点体系（沿用中文标点），英文正文不改术语既定译法。

## AI 痕迹黑名单（中英各 12 条以上，命中先看上下文再改）

| 中文侧 | 英文侧 |
|---|---|
| 铺垫代替陈述（"这不仅是一次更新，更是…"） | Filler openers (It is worth noting that / It should be noted that) |
| 公式化三段式（强行凑三条并列，重复同义） | Rule-of-three padding with synonymous items |
| 拔高与借权威（"彰显了…的重要意义""专家认为"） | Vague authority (experts believe / studies have shown, no citation) |
| 伪深刻格言（"协作是效率的语言"） | Aphorism or pseudo-profound closing line |
| 起跑式铺垫（"接下来让我们深入看看"） | Runway phrasing (Let us dive into / In this section, we will) |
| 套话收尾（"总而言之，让我们拭目以待"） | Generic wrap-up (In conclusion, X plays a crucial role) |
| 层叠的"的"与超长定语 | Stacked noun modifiers and prepositional chains |
| "进行＋动词"冗余（"进行全面的测试"） | Nominalization (conduct an analysis of / perform a comparison of) |
| 被字句堆叠且施事不明 | Agentless passive chains |
| 四字词排比空转（"稳定可靠、快速响应、易于维护"） | Adjective triplets without measurement |
| "随着…的不断发展"式背景开头 | In recent years, with the rapid development of |
| 聊天与草稿残留（"好问题！""希望这对您有帮助"） | Chat residue (Great question! / Hope this helps!) |
| 元话语标注（"详见某节""本团队认为"） | Meta-commentary (As mentioned above / In this paper, we will) |
| 知识边界免责重复（"信息确实有限"） | Hedging pile-up (may possibly / might potentially) |
| 破折号当万能连接 | Em-dash used as a universal connector |

改法纪律：黑名单是**检查线索**，不是词表。单个词、单个三项并列、单个四字词都不是修改理由；先判断该处是否空泛、重复、歧义或与文体不符，再动手。没有问题的地方不改。

## "原意未变"核对清单（交付前逐条过）

| # | 检查 |
|---|---|
| 1 | 新增的每个具体信息都能在原文或用户材料里找到；找不到就撤回 |
| 2 | 独立信息未丢；否定、限定、时间、范围、条件、归因都在 |
| 3 | 「可能」没被写成「确定」；「计划」没被写成「已完成」；相关没被写成因果 |
| 4 | 比较对象、参照组、统计口径未变（数值可核） |
| 5 | 调整句式后没有添出新并列项、没有改变列表项含义 |
| 6 | 连接词仍表达原来的顺序、因果、同时发生或转折 |
| 7 | 受保护内容原样：代码、命令、路径、标识符、表格数据、引用编号、标题层级 |

## 降重与降 AIGC 的边界

只允许改表达层：换词、换句法、拆合句、调整语序。**禁止**为降重删信息、弱化结论、模糊化数值、删掉限定条件；**禁止**声称"已通过某检测"——本技能不提供 AI 率或查重率判定，也不保证任何检测器结果。需要量化自评时，只用可解释的"空话分"（0 无空话，5 通篇空话）并附命中条目，不作为通过与否的依据。

## 输入矩阵与长文规则

| 输入 | 处理 |
|---|---|
| 纯文本/粘贴 | 直接改，交付改后全文 + 逐句对照 |
| md | 保留标题层级与锚点，只改正文段落 |
| docx 文本 | 按节切分处理，回读校验段落数未减少 |
| 需要格式适配的稿 | 只改文字；版式与字体由交付模块处理 |

长文规则：按节切分（每批 5–10 段），逐节处理并记录段落数；全部完成后回读核对"总段落数未减少、引用编号未断"。发现段落缺失即停并报告，不得静默补写。

## 输出契约

必给三件：① 改后全文；② 逐句对照表（原句 / 改句 / 改动理由，一行一处）；③ 原意未变核对清单（上表逐项打勾 + 备注）。返修改稿支线（用户带审稿意见来）：先解析意见 → 分档（必须改 / 可辩 / 不改并说明）→ 逐档执行 → 终审自检，交付时把每条意见与改动处一一对应，便于填回复信。

## 反例（什么样算不合格）

示例仅演示格式，规则本身领域无关。

| 反例 | 正确做法 |
|---|---|
| 为更"学术"把"可能相关"改成"显著相关" | 保留不确定性，只改搭配与句法 |
| 为降重把"随访 12 个月"删成"长期随访" | 数值与时间窗是信息，不能删；换表达不换数据 |
| 交付只给改后稿，无对照无核对 | 三件齐全：全文 + 逐句对照 + 核对清单 |
