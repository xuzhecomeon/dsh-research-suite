# 论文审阅 · 论文解读 · 科研诚信异常信号

> 定位：用户给一篇稿子，读出东西来。三个产出版块按序推进：**解读卡（中性拆解）→ 分级意见（带判决）→ 异常信号清单（不下结论）**。审阅**只出意见不改稿**（SKILL.md §7 第 9 行）。

## 输入契约

| 项 | 要求 | 缺失时 |
|---|---|---|
| 稿件 | 有文本层的 PDF、docx、md 或粘贴正文 | 无文本层/扫描件/加密 PDF → 报「未提取到文本层」，要求粘贴正文或改用外部 PDF 工具，**禁止猜测补全** |
| 目标刊 | 刊名或刊型（中文核心/SCI/综述刊） | 按通用规范并声明"未指定目标刊" |
| 审阅目的 | 投稿前自查 / 真实审稿 / 返修复审 | 默认投稿前自查 |
| 关注点（可选） | 统计、方法、伦理、写作 | 默认全维度 |

只有摘要时，全部产出必须首行标注「**仅基于摘要**」，且不得对方法细节下判决。

## 三产出版块各自契约

| 块 | 回答什么 | 不回答什么 | 必备结构 |
|---|---|---|---|
| ⑫ 解读卡 | 这篇做了什么、怎么做的、结果是什么、能复用哪一点 | 不评价好坏，不给改进建议 | 九栏表 + 图表拆解 + 数值核对结果 |
| ③ 分级意见 | 哪里不合格、多严重、定位在哪 | 不代写改写稿 | 致命/重要/次要三档 + 章节定位 + 报告规范打勾表 |
| ⑩ 异常信号 | 哪些地方**看起来**不像真实数据/不像独立完成 | 不下"造假"结论、不指认作者动机 | 分级清单 + 证据坐标 + 已执行/未执行项 + 免责声明 |

## ⑫ 解读卡九栏（中性、可核对）

| 栏 | 填写要求 |
|---|---|
| 问题 | 用一句话写研究问题，含人群与结局 |
| 设计 | 设计类型（六类之一）＋ 单/多中心 ＋ 时间窗 |
| 人群 | 入排标准、样本量、来源（单中心/数据库/注册研究） |
| 暴露/干预 | 定义、剂量或分层、对照是什么 |
| 结局 | 主要终点（唯一）与次要终点；定义与测量时点 |
| 结果 | 主要终点效应量与区间，不抄 P 值代替效应量 |
| 局限 | 作者自陈的局限 + 你补的（分开列，不混写） |
| 可复用点 | 可直接借用的方法、量表、图型、分析策略 |
| 版本差异 | 若有前版：本轮改了什么（只在返修场景填） |

图表拆解逐图逐表列出"这张图想证明什么、能不能证明、坐标与标注是否自洽"。数值核对结果只写三态：一致 / 不一致（给两处数值与位置）/ 无法核对（说明原因）。

## 报告规范对照（三态可勾选：有／无／无法判断）

| 稿件类型 | 规范 | 判定要点 |
|---|---|---|
| 观察性（队列/病例对照/横断面） | STROBE | 混杂控制是否成立、暴露与结局测量一致性、缺失处理、亚组是否事前声明 |
| 随机对照 | CONSORT | 随机化与分配隐藏、盲法、样本量依据、是否按意向性分析、退出与方案偏离 |
| 系统评价/Meta | PRISMA | 检索可复现、双人筛选、偏倚风险评估、异质性与发表偏倚处理 |
| 预测模型/临床 AI | TRIPOD+AI ＋ PROBAST | 事件数与 EPV、内部验证方式、**校准而非只报 AUC**、数据泄漏、是否注册 |
| 诊断准确性 | STARD | 参照标准、判读盲法、谱偏倚、不确定结果处理、四格表完整性 |
| 病例报告 | CARE | 时间线、诊断依据、干预与结局、随访、知情同意 |
| 动物实验 | ARRIVE | 随机分组、盲法评估、样本量、福利与伦理批件 |

规范版本与条目号一律"用户提供或实时获取"，**不得凭记忆写条款号**。「无法判断」是合法结论，不得为凑满打勾表编造判断。

## 临床＋预测模型双范式表（混合稿必查）

左列问"写了没有"，右列问"能不能信"。任一行出现「未报告 ＋ 高风险」，即判致命；末列任一命中为一票否决。

| 报告要点（TRIPOD+AI 侧） | 偏倚风险域（PROBAST 侧） | 一票否决信号 |
|---|---|---|
| 数据来源、纳排、研究设计 | 参与者 | 只分析完整病例却不交代缺失；纳排逐次排除主要人群 |
| 预测因子定义与测量时点 | 预测因子 | 预测因子含结局发生后才能获得的信息（数据泄漏） |
| 结局定义与判定方式 | 结局 | 结局由知晓预测因子者判定，无盲法 |
| 样本量与事件数 | 分析 | 事件数不足；参数个数远超事件数 |
| 缺失数据处理 | 分析 | 先插补后拆分数据集 |
| 建模与变量选择 | 分析 | 用全量数据筛变量后再拆分验证 |
| 区分度 | 分析 | 只报训练集区分度，无任何验证 |
| 校准 | 分析 | 全文无校准（校准曲线、截距与斜率、Brier 或拟合优度） |
| 临床效用 | 分析 | 只在事后挑出的阈值处宣称净获益 |
| 内部验证方式 | 分析 | 重抽样后仍称"外部验证" |
| 外部验证 | 分析 | 同中心时间切分却写成外部验证且未说明 |
| 模型呈现 | 分析 | 据文中公式/列线图无法复算预测值 |

## 12 条致命项（判定信号 · 反例 · 证据位置）

证据位置统一格式：**章节 ＋ 表或图 ＋ 序号 ＋ 局部**（例：「方法段第 2 段」→ 写作 `方法-2`；`表1-第3行`；`图2C-左上`；`第7页右栏`）。**每条意见必须带位置，无法定位即不得列为致命。**

| # | 致命项 | 判定信号 | 反例（什么样算不合格） | 证据位置写法 |
|---|---|---|---|---|
| 1 | 混杂控制不成立 | 关键混杂未测量或未调整；只写「多因素调整」但无协变量清单 | 写「调整了混杂因素」却未列变量名与选择依据 | `方法-3` |
| 2 | 事件数不足 | 报告的事件数 < 10×模型参数个数 | 样本量写 800 例，结局事件仅 40 例却拟合 8 个变量 | `结果-1`＋`表2` |
| 3 | 多重比较与亚组未事前声明 | 事后亚组多、无校正、无交互检验、无"探索性"标注 | 5 个亚组里挑一个阳性结论当作主结论 | `结果-4`＋`表3` |
| 4 | 缺失数据不交代 | 无缺失比例、无处理方式、完整病例分析未说明 | 全文不出现"缺失"二字，但表中 n 在各处不同 | `方法-2`＋`表1` |
| 5 | 结局定义/测量不一致 | 方法段与结果段的结局口径不同（含时间窗、判定标准） | 方法写 28 天死亡，结果写院内死亡 | `方法-4` vs `结果-2` |
| 6 | 随访完整性与删失 | 无随访中位数、无删失比例；有竞争事件却用 1−KM | 中位随访只说"随访至某年"，删失率未报 | `结果-1`＋`图1` |
| 7 | 只报 P 不报效应量与区间 | 表内仅 P 值；正文写"差异有统计学意义"无数值 | 表 1 各变量只有 P 列，无均值差/OR/HR 与 95%CI | `表1` 全表 |
| 8 | 表 1 组间可比性 | 未做基线比较；或做了却把 P<0.05 当作纳入协变量的筛选标准 | 用单因素 P 值筛变量进多因素模型且未说明 | `表1`＋`方法-3` |
| 9 | 相关被写成因果 | 观察性数据出现"导致""降低风险 N%" | 横断面研究写"A 是 B 的保护因素" | `讨论-2`＋`摘要-结论` |
| 10 | 样本量依据缺失 | 无功效计算、无事件数说明 | 只写"根据既往研究估算"，无参数无算式 | `方法-1` |
| 11 | 统计方法与设计不匹配 | 配对设计用独立检验；重复测量用单次 t 检验；整群数据不分层 | 前后对照用两组独立样本检验，且未做基线差异校正 | `方法-4`＋`表2` |
| 12 | 图/表数字与正文不一致 | 脚本一致性核对命中：同一统计量在不同位置数值不同 | 摘要 OR=1.8，结果段 OR=1.82，表中 1.79 | `摘要-结果` vs `表2` |

工序建议：先按"最强化攻击"写一遍（假设这篇稿子必须被拒，理由是什么），再逐条裁定是否成立——比逐条打勾更容易逼出真问题。审阅视角分工可选：方法学、统计、临床、写作、伦理各出一轮，再合并去重。

## ⑩ 异常信号：九维检测矩阵

只报"信号"，每条给：维度、信号描述、位置、强度（高/中/低）、可能解释（至少一条非造假解释）。

| 维度 | 看什么 | 强信号（需给位置） |
|---|---|---|
| 图像复用 | 同一图/子图跨条件或跨论文重复 | 背景噪点模式一致；内参加载条完全相同；边缘有裁切痕 |
| 图像拼接 | 泳道/区域间不自然分界 | 垂直分界线、背景灰度在一条线处突变 |
| 数值分布 | 末位分布、SD 规律性、"太整齐" | 多列差值恒定；SD 全部相同；统计量小数位数异常 |
| 统计不可能值 | 与样本量/取值范围冲突 | 百分比与 n 反算不出整数；GRIM 不一致；n 在各处不同 |
| 内部一致性 | 摘要/结果/表/图四处数字 | 同一指标四位数不同；图表号跳号或引用缺失 |
| 方法可复现 | 描述是否足以复现 | 关键步骤缺失；软件与版本未写；随机化方法未写 |
| 引文 | 序号连续性、引文与论断是否对得上 | 引文序号跳号；引文标题与所述内容无关；同一文献多处自引堆叠 |
| 产出异常 | 同一批数据在多篇论文复用、投稿节奏异常 | 同一对照组在多篇出现且数值一致 |
| 代码与附件 | 有附件时数字能否复现 | 附件跑不出正文数字；无附件则标"未执行" |

论断级核验（逐条 claim → 证据 → 判定）：三态 **PASS / WARN / FAIL**。PASS＝正文 claim 与表/图/统计量一致；WARN＝可解释但不精确（如四舍五入差异、口径未说明）；FAIL＝数值或方向相反。核验表必须列 total 与各态计数。

## 分级评定与免责（不可省略）

| 等级 | 判据 |
|---|---|
| 高 | 存在**无法用常规误差解释**的强信号，且直接影响主要结论 |
| 中 | 存在强信号但只影响次要结果；或存在多个弱信号指向同一问题 |
| 低 | 单个弱信号，存在明确的非造假解释（如四舍五入、图层压缩、不同批次） |

免责声明必须逐字出现在产出末尾，且不得弱化：「本报告仅基于公开可见的稿件内容与本次实际执行的检测项，识别的是**异常信号**，不构成对数据真实性或作者行为的结论；信号可由排版、压缩、统计口径、数据处理流程等多种非不当原因造成；如需定性结论，应由期刊或机构按正式调查程序处理。」

「已执行/未执行」必须分表：未执行项写原因与补做方法（如缺图像比对工具 → 「未执行像素级比对；可提供原图后补做」）。这属 SKILL.md R2，不得含糊。

## ③ 分级意见与回复信

| 档 | 判据 | 写法 |
|---|---|---|
| 致命 | 影响结论成立（12 条致命项任一成立） | 「问题 + 位置 + 为什么致命 + 需要什么才能补救」 |
| 重要 | 影响可信度但不推翻结论 | 同上，加"建议的替代做法" |
| 次要 | 表述、格式、可读性 | 合并成清单，一条一行 |

- **禁改稿**：不输出改后段落。用户要改 → 显式转润色或撰写模块，并保留意见编号做对照。
- 返修/复审：只核"上轮每条意见是否逐条落实"，逐条给 已解决/部分解决/未解决 + 位置；不重新提全新意见（除非新引入问题）。
- 回复信：三条规则——逐条应答（编号对应）、不选边（审稿人意见互相冲突时分别回应并说明取舍依据，不评判谁对）、不承诺做不到的事（不能补的实验写"已在局限中说明"并在正文同步）。
- 证据层级：原文数据 > 系统评价 > 二手综述 > 观点评论。用低层级来源反驳高层级来源时，必须说明理由。

## 反例（什么样算不合格）

示例仅演示格式，规则本身领域无关。

| 反例 | 正确做法 |
|---|---|
| 「统计方法存在问题，建议修改」 | 「方法-4 用独立样本 t 检验分析配对数据（表2 为同一批受试者前后测），违反独立性假设；应改配对检验或线性混合模型」 |
| 「疑似造假，图片重复」 | 「图3A 与图5C 的条带背景噪点模式一致（位置：图3A-第2泳道 vs 图5C-第1泳道），强度中；可能解释：同一内参不同曝光、图像压缩」 |
| 「建议补充实验验证」 | 「若要支持因果表述，需补充 X；若不补充，讨论-2 的因果措辞应改为关联表述」 |
