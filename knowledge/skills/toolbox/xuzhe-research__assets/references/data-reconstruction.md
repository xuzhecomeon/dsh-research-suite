# 原始数据倒推（推断值）

> 定位：由已发表的统计量或图表**反解**出可能的底层数值，并如实标注不确定度。产出的是**推断值**，不是原始数据（SKILL.md §7 第 10 行）。不下推断统计结论：一致性异常移交 `manuscript-reading-review.md` 的异常信号块。

## 可反推字段与数学约束

| 反推目标 | 需要输入 | 方法与约束 | 置信度 |
|---|---|---|---|
| 整数均值反解 | n、均值、取值范围 | 总和＝均值×n 必须是整数；非整数即无可行解，不得四舍五入凑 | A |
| 均值一致性（GRIM） | n、均值、报告的小数位 | 均值×n 必须等于按该小数位舍入后的整数总和；不通过即"报告值互相矛盾" | A |
| 标准差一致性（GRIMMER） | n、均值、标准差（多位小数）、取值范围 | 穷举整数向量，其标准差不大于报告值且最接近者在末位舍入下与报告值相容；无可行解即判不一致 | A |
| 中位数与四分位距 → 标准差 | n、中位数、上下四分位 | 用三种等价换算取区间，不给点值 | B |
| 百分比 → 频数 | N、百分比 | 频数＝N×百分比舍入；同时给出满足该舍入的整数区间，并与均值一致性互检 | A（唯一）／C（多解） |
| 比值比或风险比＋区间 → 标准误 | 点估计、上下限 | 对数尺度：标准误＝(上限对数−下限对数)÷(2×1.96)；反解事件数需连续性校正并标注 | B |
| 四格表细胞数 | 比值比、边际和、总样本量 | 约束求解，输出全部可行解集，不挑一个当答案 | C |
| 生存曲线数字化 | 阶梯图、轴刻度、风险人数表 | 台阶高度按刻度换算，每个时间点的在险人数与曲线下降必须自洽 | B／C |
| 均值与标准差 → 整数向量 | n、均值、标准差 | 通常多解；只给可行解集与统计特征，不给"最可能的那一组" | C |

约束优先级：整数性 > 末位舍入一致性 > 取值范围 > 与风险表/边际和的自洽。任一层不通过即停，输出"无可行解"并列出冲突的约束名，**不返回近似值冒充可行解**。

## 置信度分级

| 级 | 含义 | 交付要求 |
|---|---|---|
| A | 约束给出唯一可行解且通过一致性检验 | 可给点值，附方法名 |
| B | 约束足以收窄到小区间或单点近似 | 必须给区间，不给单一小数 |
| C | 多解集，缺额外约束无法收紧 | 给解集与选择依据说明，明确"不唯一" |
| D | 缺关键输入（最常见是缺样本量）或本质上不可反推 | 只列字段名与"不可反推"，不填值 |

缺样本量一律降为 D 级，即使能算出一个数字也不用。

## 不可反推字段清单（必须写在产出首页）

| 字段 | 为什么不可反推 |
|---|---|
| 个体级配对关系 | 汇总统计量不含配对信息，"个体水平相关"无法由均值与标准差恢复 |
| 时序与事件顺序 | 边际分布与联合分布不是同一件事 |
| 协变量的联合分布 | 只给边际分布无法还原相关性结构 |
| 缺失机制 | 报告值通常基于非缺失子集，缺失原因不可见 |
| 重复测量的个体轨迹 | 组水平均值轨迹不含个体异质性 |
| 聚类与随机效应结构 | 中心/批次效应已被汇总量抹平 |
| 原始测量精度 | 表格舍入后信息已丢失 |
| 亚组内的分布 | 亚组样本量与统计量常未报告 |
| 由 P 值反推个体值 | P 值只约束检验统计量，不约束个体观测 |

## 表述与标注纪律

禁用词：「原始数据」「重建数据集」「还原数据」「恢复原始」。一律写「推断值（图表数字化＋模型反演）」。

每个输出单元格必须带四项元数据：类型为推断值、方法名、置信度、取值区间。文件结构：首页放不可反推清单，第二页放方法与约束表，之后是数据表；每个表标题下注"本表为推断值，不代表原始观测"。

## 反例（什么样算不合格）

示例仅演示格式，规则本身领域无关。

| 反例 | 正确做法 |
|---|---|
| n=20、均值=3.7（示例值）时硬给两个整数使总和成立 | 先报"总和非整数，无可行解" |
| 缺样本量仍算出标准差并标 A 级 | 降为 D 级，只列字段名 |
| 四格表多解里挑一个当"最可能"并不说明 | 给全部可行解并说明取舍依据 |
