# 论文撰写与参考文献标注

> 定位：输入是「用户稿件/数据 + 目标刊要求」，输出是**成稿与引文流水线**。只动语言与格式、不动结构 → 转 `language-polish.md`；要判断稿件好坏 → 转 `manuscript-reading-review.md`。

## 任务类型决策表

| 类型 | 触发 | 输入 | 产出 |
|---|---|---|---|
| A 撰写 | 写、起草、Methods、Introduction、讨论、综述 | 数据/结果 + 目标刊 + 引文 | 可投稿初稿（docx/md）+ 修改说明 |
| B 引文补充 | 补参考文献、加引用、文献不够 | 正文 + 缺口提示 | 正文角标 + 文末条目 |
| C 引文格式修正 | 规范参考文献、统一格式、换成目标刊格式 | 含文献表的稿件 | 重排后的文献表 + 角标对齐结果 |
| D 投稿包 | cover letter、投稿材料、期刊候选 | 成稿 + 目标刊 | cover letter + 期刊候选表 + 检查清单 |
| E 综述 | 综述、文献总结、研究进展 | N 篇文献 + 主题 | 综述稿（必含数据表）+ 三轴结构 |

## 中文线 10 条铁律

| # | 铁律 |
|---|---|
| 1 | 语言标杆锁定中华系列学术语体，优先于任何默认文风与翻译腔；润色时对标标杆、不对标原稿 |
| 2 | 参考文献一律 GB/T 7714-2015 顺序编码制，按正文出现顺序编号，不按字母排 |
| 3 | 正文引用编号必须上标（`[1]`、`[1-3]`、`[1,3-5]`）；文献表本身的编号不上标 |
| 4 | 术语首现写「中文（英文全称, 缩写）」，此后统一用缩写；英文全称小写、缩写大写 |
| 5 | 严禁 AI 痕迹：不用加粗/斜体/井号标记代替排版；不用"赋能、抓手、闭环、底层逻辑、重构"类造词；不写"本团队""详见某节"类元话语 |
| 6 | 医学名词英译必须用既有官方或既有文献译法，禁止自创拼音括注与生造英文 |
| 7 | 自称统一：论著/综述用「本研究」「本文」，指南用「本指南」「指南工作组」，禁用「我们」「笔者认为」 |
| 8 | 单句尽量 ≤40 字，一句一意；嵌套长句必拆；不用一逗到底 |
| 9 | 措辞克制：不用「根本性」「决定性」，改为「显著」「重要」「实质性」；推测只用「可能/提示/或有助于」 |
| 10 | 结果必带统计量：效应量＋区间＋P，禁止「效果显著」这类无数值判断 |

禁用套话（出现即改）：「值得注意的是」「综上所述」「近年来随着…的不断发展」「在当今…背景下」「扮演着重要角色」「提供了新思路」「众所周知」「具有重要理论意义和临床价值」「亟待进一步研究」「总体而言」「毋庸置疑」「不言而喻」。推荐短实衔接：因此/从而/进而/但/然而/尽管/此外/同时/鉴于。

## 英文线红线

| # | 红线 |
|---|---|
| 1 | 禁套话开头：「This study aims to investigate…」「In recent years, with the development of…」「It is well known that…」——直接写事实与缺口 |
| 2 | 禁编造引文：每条必须有可核验标识（DOI/PMID）；核验不到写「待核验」 |
| 3 | 近 5 年文献占比要能说清：方法学与经典机制可引旧文，但现状陈述以近 5 年为主；引不出比例就不得宣称"最新" |
| 4 | 时态纪律：方法与他人已发表结果用过去时，公认事实用现在时，本研究结论用过去时 |
| 5 | 不夸大：观察性研究不得用 cause/reduce the risk of；用 associated with |
| 6 | 缩写首现展开，之后统一；摘要与正文各自独立展开一次 |
| 7 | 数字与单位：句首不写阿拉伯数字；单位与数值之间留空格（% 除外按目标刊） |
| 8 | 不用第一人称复数堆叠；Methods 用被动或"we"须全篇统一 |

## 章节要素卡（写不出某栏即素材不足，不要用形容词填）

| 章节 | 必含要素 | 常见缺项 |
|---|---|---|
| Introduction | 领域现状（带证据锚点）→ 具体缺口 → 本研究问题与做法 → 一句结论预告 | 只堆背景不说缺口；缺口与本文问题不对应 |
| Methods | 设计、场景、人群与入排、变量定义与测量、样本量依据、统计方法（含软件与版本）、伦理 | 缺样本量依据；缺混杂清单；软件版本缺失 |
| Results | 按主要终点→次要终点→亚组→敏感性分析 顺序；每段一个结论性数字 | 用 P 值代替效应量；图表与文字重复整表 |
| Discussion | 主要发现（一句）→ 与既往研究比较 → 机制解释 → 临床意义 → 局限 → 结论 | 局限写成套话；结论强于数据支持 |

写作纪律：每个带证据的论断必须能落到一条引文或一个统计量（证据锚点行）；写完必过一遍自评再交付，不得自评即交付。

## 综述与病例报告

| 类型 | 结构 | 硬要求 |
|---|---|---|
| 综述 | 三轴择一并声明：时间轴（演进）/主题轴（分问题）/方法轴（分设计） | **必含数据表**（纳入文献的研究特征与主要结果），不得纯叙述；须写检索策略与纳入标准 |
| 病例报告 | 按 CARE：时间线 → 诊断依据 → 干预 → 结局 → 随访 → 讨论与文献对照 | 知情同意声明；时间线用表；不得从单例推普遍结论 |
| Meta 类写作 | 方法段须含检索、筛选、偏倚评估、效应量合并模型、异质性与发表偏倚 | 效应量模型选择与异质性阈值同时写明 |

## cover letter（三段，不超过一页）

① 投稿声明与题目、文章类型；② 创新点与为何契合该刊（3 条以内，每条一句，不重复摘要）；③ 常规声明（原创、未一稿多投、全体作者同意、利益冲突、伦理批件号、数据可得性）。推荐审稿人只在用户提供时列出，**不得编造姓名、单位与邮箱**。

## 参考文献格式

### GB/T 7714-2015 顺序编码制模板

| 类型 | 模板 |
|---|---|
| 期刊 | 作者. 题名[J]. 刊名, 年, 卷(期): 起-止页. DOI: 10.xxxx/xxxxx. |
| 专著 | 作者. 书名[M]. 版次. 出版地: 出版者, 年: 页码. |
| 学位论文 | 作者. 题名[D]. 城市: 单位, 年. |
| 电子资源 | 作者. 题名[EB/OL]. (更新日期)[引用日期]. 网址. |
| 预印本 | 作者. 题名[Preprint]. 平台, 年. DOI. |

作者规则：≤3 全列；>3 前列 3 位后加「, 等」或「, et al.」；西文作者姓前名缩写。类型标识 `[J]` 等紧随题名。英文刊名用标准缩写，中文刊名用全称。DOI 统一「DOI: 」前缀并以英文句点收尾。

### 格式切换（一次任务只用一种）

| 场景 | 格式 | 正文标注 |
|---|---|---|
| 中文期刊 | GB/T 7714-2015 顺序编码制 | 上标方括号编号，按出现顺序 |
| SCI 医学刊 | Vancouver | 上标或方括号编号，按出现顺序，作者 >6 取前 6 加 et al. |
| 社科/心理 | APA 7 | 作者-年份括注，文献表按字母序 |

用户指定优先；目标刊未明确时按上表默认并声明所选格式。Word 域与文献管理软件导出只作为可选交付说明，不作为主路径。

## 引文核验三态

| 态 | 含义 | 交付写法 |
|---|---|---|
| 命中 | 标识可解析且题名/作者/年份至少两项一致 | 记「命中」，附核验来源 |
| 待核验 | 无网络、接口失败、字段不全 | 记「待核验」，写原因；**不得补全** |
| 不匹配 | 标识可解析但题名/作者/年份冲突 | 记「不匹配」，并列冲突项与两个候选 |

缺字段处理三条（唯一顺序）：① 留空并标注缺哪一字段；② 标「待核验」并给出用户可自行验证的线索（题名+年份+刊名）；③ 问用户。**禁止**推断作者、补造卷期页码、把近似文献顶替。

## 术语与一致性

术语一致是脚本可自动发现的问题（同义词变体扫描）：同一概念全文只用一个译名与一个缩写；不出现"脓毒症/脓毒血症"混用、"随机对照试验/RCT"混用。数值与图表编号的一致性同样交给一致性核对：正文提到的表号必须在文中存在，图号不得跳号。

## 反例（什么样算不合格）

示例仅演示格式，规则本身领域无关。

| 反例 | 正确做法 |
|---|---|
| 「近年来随着…不断发展，X 已成为研究热点」 | 「X 在 Y 人群中的 90 天发生率为 12.0%（示例值），但危险因素尚未明确」 |
| 表 1 只有 P 值列 | 每行给统计量、自由度（适用时）、效应量与 95%CI、P |
| 引文 [7] 标题与所述内容无关 | 换为直接支持该论断的文献；无则删除该论断 |
