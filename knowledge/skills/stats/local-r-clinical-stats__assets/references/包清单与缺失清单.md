## 已知瞬时故障

`rms` 首次加载可能失败：

```
unable to load shared object '.../SparseM/libs/x64/SparseM.dll':
  LoadLibrary failure: 应用程序控制策略已阻止此文件
```

这是安全软件首次扫描 DLL 时的瞬时拦截。**重试即通过**（已复测 `library(rms)` => OK，且 `dyn.load()` 三个路径均 LOADED）。不需要任何处理。

## 排错对照表

| 症状 | 真实原因 | 处理 |
|---|---|---|
| `package 'compiler' does not have a namespace` | locale 变量未清除 | 清空 `LC_ALL`/`LANG`/`LANGUAGE` |
| `unable to translate '...' to native encoding` | 同上（中文安装路径） | 同上 |
| `installed.packages()` 返回 0 行 | 同上 | 同上 |
| `there is no package called 'X'` 但包确实存在 | 同上 | 同上 |
| `unexpected input in "锘"` | .R 脚本带 BOM | 用 Write 工具重写脚本 |
| 工具读不到 PowerShell 输出 | 本环境不捕获 PS stdout | 重定向到文件再 Read |
| 结果文件中文乱码 | 控制台回显编码混用 | 在 R 侧 `sink()` 写 UTF-8 文件 |
