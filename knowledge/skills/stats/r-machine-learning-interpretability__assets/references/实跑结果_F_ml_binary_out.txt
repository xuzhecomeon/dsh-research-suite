################ 2. 超参数选择方式对照（XGBoost）################

  网格大小： 36 组

  【方案 A】用【训练集】AUC 选参（课程原版做法）
     选中超参：max_depth=4, eta=0.20, nrounds=100
     训练集 AUC = 1.0000  →  验证集 AUC = 0.8971  （过拟合落差 训练−验证 = +0.1029）

  【方案 B】用【交叉验证】AUC 选参（修正做法）
     选中超参：max_depth=5, eta=0.10, nrounds=50  （CV-AUC = 0.8871）
     训练集 AUC = 0.9945  →  验证集 AUC = 0.9024  （过拟合落差 训练−验证 = +0.0921）

  ★ 关键判读指标是【训练集−验证集的落差】(optimism gap)：
     方案A 落差 +0.1029  vs  方案B 落差 +0.0921
     落差更小的方案，其超参选择更稳健（未过拟合训练集）。
