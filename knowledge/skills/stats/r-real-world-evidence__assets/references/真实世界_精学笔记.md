## 1. ★★★★ 克隆删失加权（`克隆删失加权new.R`）—— 本域技术金字塔尖

**要解决的问题**：**时依混杂（time-varying confounding）**
> 当某个协变量**既是后续治疗的预测因子、又是结局的中间变量**时（如"治疗过程中出现的器官功能恶化"），
> 传统的"调整基线协变量"和"把时依协变量放进模型"**都会引入偏倚**（前者残余混杂，后者阻断因果通路）。

**方法**：**Clone-Censor-Weight（CCW）** —— Hernán & Robins 提出的**序贯试验模拟（target trial emulation）**的核心实现。

**五步流程（课程实现）**
```r
## 步骤1：克隆（Cloning）
# 每个患者创建两个副本，分别分配到 A=0（对照）和 A=1（治疗）
data[, id := .I]
cloned_data <- data[rep(1:.N, each = 2)]
cloned_data[, A := rep(0:1, .N/2), by = id]

## 步骤2：定义"干预违背"的删失规则
# 治疗组（A=1）：实际未暴露，或暴露时间 > t → 违背"持续治疗"策略 → 删失
cloned_data[A == 1, censored := ifelse(exposure_status == 0 | exposure_time > 365, 1, 0)]
# 对照组（A=0）：实际发生暴露且暴露时间 ≤ t → 违背"从不治疗"策略 → 删失
cloned_data[A == 0, censored := ifelse(exposure_status == 1 & exposure_time <= 365, 1, 0)]

## 步骤3：定义结局
cloned_data[, Y := ifelse(time <= 400 & status == 1 & censored == 0, 1, 0)]

## 步骤4：删失模型 → IPCW 权重（★ 删失模型必须含处理变量 A 与基线协变量）
cens_model <- glm(censored ~ A + X1 + X2, data = cloned_data, family = binomial())
cloned_data[, p_uncens := 1 - predict(cens_model, type = "response")]
cloned_data[, weight := ifelse(censored == 0, 1 / p_uncens, 0)]
analysis_data <- cloned_data[censored == 0]

## 步骤5：用 survey 设计做分析（★★ 正确处理抽样权重）
design <- svydesign(ids = ~1, weights = ~weight, data = analysis_data)
model <- svyglm(Y ~ A + X1 + X2, design = design, family = quasibinomial())
cox_model <- svycoxph(Surv(time, Y) ~ A + X1 + X2, design = design)
```

**★★★ 为什么这是本域最值得学的脚本**
1. **克隆**把"一个含时依治疗的真实世界队列"转化为"**两组假设试验**"（每个人既可能"一直治疗"也可能"从不治疗"）
   → 从而**同时避免残余混杂与过度调整偏倚**
2. **正确使用了 `svydesign` + `svyglm` + `svycoxph`** —— 这正是第五域**缺失的正确方差处理方式**
3. **`family = quasibinomial()`** 而非 `binomial()` —— 加权后存在过离散，`quasibinomial` 给出更稳健的 SE。
   ★ 这是一个很细但很关键的技术点，**课程处理正确**
4. 步骤注释写得非常清楚（"按照治疗方案，规范治疗时间设置为 t"）

**问题**
| # | 问题 | 严重度 | 说明 |
|---|---|---|---|
| W1 | **`365` 与 `400` 硬编码**（治疗时间窗 / 随访窗） | 🟠 | 应参数化为 `grace_period` / `followup`，并做**多窗口敏感性分析**（CCW 的核心稳健性检验） |
| W2 | **`exposure_time` 的 NA 处理**：注释说"未暴露者设为 NA 或极大值"，但 `NA > 365` 返回 `NA` → `ifelse` 传播 NA | 🟠 | 会产生 `NA` 的 `censored`，进而污染后续逻辑。应用 `!is.na(exposure_time) & exposure_time > 365` 显式处理 |
| W3 | **`A := rep(0:1, .N/2), by = id`** 依赖行序 | 🟠 | 若 `.N` 为奇数或 `by` 重排序则错位。更稳健：`cloned_data[, A := rep(0:1, length.out = .N), by = id]` |
| W4 | **`Y` 被定义两次**（有 time / 无 time 两版本），后者覆盖前者 | 🟡 | 应注释掉一个或用 `if` 分支 |
| W5 | **缺 IPCW 权重的截断与诊断** | 🟠 | 与 IPTW 同理，需报告权重范围、ESS、并做截断敏感性分析 |
| W6 | 缺对"同一患者两个克隆不独立"的说明 | 🟡 | CCW 的标准做法是按 A 分组分别分析，故可接受；但应说明 |
| W7 | 缺**目标试验模拟的完整要素声明** | 🟠 | target trial emulation 应明确写出：资格标准 / 治疗策略 / 分配 / 随访起点 / 结局 / 因果对比 / 分析计划 |

## 2. ★★★ 重叠加权（`dataOW.R`）

```r
PSweight <- PSweight(ps.formula = drinking ~ age + lwt + race + ptl + ht + ui + ftv,
                     data = e1, weight = "overlap",    # ★ 重叠加权
                     yname = "low", family = "binomial",
                     ps.method = "glm", out.method = "glm")
summary(PSweight)

SumStat <- SumStat(ps.formula = formula.ps, data = e1, weight = "overlap", method = "glm")
summary(SumStat)              # 均衡性检验
SumStat[["ess"]]              # ★★ 有效样本量（ESS）
plot(SumStat)                 # 均衡性检验图
```

**★ 重叠加权的价值（Li, Thomas & Li 2018）**
- 权重 = `1 - e(X)`（治疗组）与 `e(X)`（对照组）→ 权重**永远在 [0, 1] 之间**
- → **天然规避了 IPTW 的极端权重问题**（IPTW 的 1/e(X) 在 e(X)→0 时可爆炸）
- → 估计的是 **ATO（平均治疗效应，重叠人群）**，即"**临床均势（clinical equipoise）**"人群中的效应
- → 当两组 PS 分布重叠差时，**ATO 比 ATE 更稳健、更可解释**

> ★★ **`SumStat[["ess"]]` 报告有效样本量（ESS = (Σw)²/Σw²）** ——
> **这正是第五域缺失的权重诊断项**！本域补上了，应作为标准做法。

## 3. ★★ 平衡性诊断的正确做法（`倾向得分R 代码.R`）—— 本域优于第五域

```r
library(cobalt)
## ① Love plot（SMD 图）★★ 明确以 0.1 为阈值
love.plot(m.out, drop.distance = TRUE, var.order = "unadjusted", abs = TRUE,
          line = FALSE, grid = FALSE, size = 3,
          thresholds = c(m = .1),        # ★★ 以 SMD = 0.1 为平衡标准
          limits = c(0, 1), position = "top",
          shapes = c("circle", "triangle"), colors = c("red", "blue"))

## ② PS 分布叠合图（重叠性检查）
ggdensity(e1, x = "pre", fill = "drinking", palette = "jco") + scale_x_continuous(limits = c(0,1))
bal.plot(m.out, var.name = "distance", which = "both", type = "density", mirror = F, grid = F, position = "top")
bal.plot(m.out, var.name = "distance", which = "both", type = "histogram", ...)

## ③ 匹配后基线表
summary(m.out)                 # 输出匹配前后 SMD 对照
plot(summary(m.out))
```

> ★★★ **本域用 `cobalt` 包做平衡性诊断，是比第五域（只用 tableone）更现代、更规范的做法**：
> - **`thresholds = c(m = .1)` 明确以 SMD < 0.1 为平衡标准** → 正是第五域所缺的方法学口径
> - `love.plot` 的 `var.order="unadjusted"` + `abs=TRUE` + `shapes/colors` 区分匹配前后 → 出版级图件
> - `bal.plot(type="density"/"histogram")` 检查 **PS 分布重叠性（positivity）**
> - `ggdensity` 画 PS 分布 → **重叠性检查的另一条路径**
>
> **★ 第五域与第七域是同一方法的两个版本，第七域明显更完整。两者应合并学习：以第七域的 cobalt 流程为准。**

## 4. ★★ E-value 敏感性分析（`E-Value.R`）—— 观察性研究的必备项

```r
library(EValue)
evalues.OR(est = 3.9, lo = 1.8, hi = 8.7, rare = TRUE)   # 二分类结局
evalues.RR(est = 10.73, lo = 8.02, hi = 14.36)            # 风险比
bias_plot(3.9, xmax = 20)                                  # 偏倚曲线
summary(evalues.RR(est = 2.5, true = 1.5))                 # 仅打印 E-value
```

**E-value 的含义**：**"未测量混杂需要与暴露和结局的关联强度至少达到多大（RR），才能把观察到的效应完全解释掉"**
- E-value 越大 → 结论越稳健（需要极强的未测量混杂才能推翻）
- 经验参考：E-value > 2 通常被认为较稳健
- ★★ **这是观察性研究（真实世界研究、PSM、IPTW）的推荐报告项**，第五域完全没有

**问题**
| # | 问题 | 严重度 |
|---|---|---|
| W13 | **数值全部硬编码**（3.9/1.8/8.7、10.73/8.02/14.36 均来自其他文献的示例） | 🟠 应改为从模型对象动态取（如 `exp(coef(m))` 与 `exp(confint(m))`） |
| W14 | 未说明 `rare = TRUE` 的含义 | 🟡 该参数表示"结局罕见"假设，影响 OR→RR 的转换方式；**当结局不罕见（>15%）时必须设 `rare=FALSE` 或直接报 RR** |
| W15 | 未说明 E-value 是**针对点估计还是 CI 下限** | 🟠 规范做法：**同时报"点估计的 E-value"与"CI 下限的 E-value"**，后者才是判断显著性的关键 |

## 5. 缺失数据方法对比（`缺失数据代码.R`）—— 九种方法的教学素材

**演示的方法**：均值填补、中位数填补、众数填补、KNN 填补（`VIM::kNN`）、随机森林填补（`missForest`）…（后续可能还有 MICE）

**★★ 关键方法学警告（课程未强调）**
| 方法 | 评价 |
|---|---|
| 均值 / 中位数 / 众数填补 | ❌ **会严重压缩方差、扭曲变量间关联、低估 SE** —— 仅在"缺失极少且仅用于描述"时勉强可用，**绝不推荐用于因果/关联分析** |
| KNN 填补 | ⚠️ 依赖距离度量；对高维/混合类型数据表现一般 |
| 随机森林填补（missForest） | ✓ 较好，能捕捉非线性与交互；但是**单次插补**，不反映插补不确定性 |
| **MICE（多重插补）** | ✅ **现代推荐**（见第一域 §16.3）；能正确合并插补间方差 |

## 6. 本域能力清单与跨域定位

**本域独有的三大方法（其他域没有）**
1. **克隆删失加权（CCW）** —— 处理时依混杂的序贯试验模拟
2. **重叠加权（Overlap Weighting）** —— ATO 估计 + 天然规避极端权重
3. **E-value** —— 未测量混杂的定量敏感性分析

**本域对第五域的补充（同一方法体系的两个版本）**

| 环节 | 第五域（倾向得分） | **第七域（真实世界，更完整）** |
|---|---|---|
| 平衡性诊断 | tableone + SMD | **cobalt：love.plot + bal.plot + thresholds=c(m=.1)** ✓ |
| 重叠性检查 | ❌ 缺 | ✓ ggdensity + bal.plot(type="density") |
| 权重诊断 | ❌ 缺 ESS | ✓ **`SumStat[["ess"]]`** |
| 加权方差 | 给了 svyglm 但未强调必要性 | ✓ **svyglm + svycoxph + quasibinomial** |
| 敏感性分析 | ❌ 缺 E-value | ✓ E-value |
| 时依混杂 | ❌ 未涉及 | ✓ **CCW** |

> ★★★ **结论：第五域与第七域是同一方法学的两个版本，应合并学习，以第七域为标准。**
> **推荐的标准 PS/IPTW 流程**：
> ① 明确估计量（ATT/ATE/ATO）→ ② 估计 PS → ③ **cobalt 做 love.plot（SMD<0.1）+ 分布重叠图** →
> ④ 加权/匹配 → ⑤ **报告 ESS + 权重范围** → ⑥ **svyglm/svycoxph 做分析** →
> ⑦ **E-value 敏感性分析** → ⑧（若有）**时依治疗则改用 CCW**
