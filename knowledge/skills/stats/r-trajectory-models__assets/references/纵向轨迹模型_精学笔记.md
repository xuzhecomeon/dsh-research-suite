## 1. 单变量轨迹模型（GBTM / LCGM）精读

### 1.1 ★★ 模型选择：四项指标缺一不可

```r
## ① 信息准则（越小越好）：AIC / BIC / CIC / SABIC
gbtm_ICs <- as.data.frame(rbind(gbtm1$ic, gbtm2$ic, gbtm3$ic, gbtm4$ic, gbtm5$ic))
# lcmm 包：
summarytable(lcgm1, lcgm2, lcgm3, lcgm4, lcgm5,
             which = c("G","loglik","AIC","BIC","SABIC","entropy","%class"))

## ② Avepp（平均后验概率，要求 > 0.7）
Avepp_results <- pad_vectors(list(gbtm1$appa, ..., gbtm5$appa))

## ③ OCC（正确分类概率，要求 > 5）
calculate_OCC <- function(appa, prior) { (appa/(1-appa)) / (prior/(1-prior)) }

## ④ 组占比（每组不应过小）
num_results <- pad_vectors(list(prop.table(table(gbtm1$assign)), ...))
```

| 指标 | 判读标准 | 含义 |
|---|---|---|
| **AIC / BIC / SABIC / CIC** | **越小越好** | 拟合优度 vs 复杂度的权衡 |
| **Avepp**（平均后验概率） | **> 0.7** | 每个轨迹组内，个体被正确归类的平均概率 → **分类质量** |
| **OCC**（正确分类概率/几率） | **> 5** | `(Avepp/(1−Avepp)) / (prior/(1−prior))` → 后验几率相对先验几率的倍数 → **分类精度** |
| **Entropy** | 越接近 1 越好 | 分类清晰度（lcmm 包提供） |
| **组占比** | 每组不应 < 5% | 过小的组稳定性差 |

> ★★★ **这四项是 GRoLTS Checklist 要求的核心报告集**。**轨迹模型论文若只报 BIC 不报 Avepp/OCC/组占比，会被审稿人质疑。**
> 常见错误：只看 BIC 选最小者 → 得到某个组只有 3 人的模型。**必须综合四项 + 临床可解释性**。

### 1.2 ★★ 处理局部最优：多随机起点（lcmm 包的关键技巧）

```r
## 粗筛：多随机起点 + 少量迭代
m2_gs <- gridsearch(
  rep     = 50,        # 初次可 50；最终建议 100~200 起
  maxiter = 10,        # 粗筛步数
  minit   = m1,        # 稳定种子（用 ng=1 的模型作起点）
  hlme(fixed = sit ~ 1 + time + I(time^2),
       mixture = ~ 1 + time + I(time^2),
       ng = 2, subject = "ID", data = long_data))

## 精跑：用粗筛最优起点，迭代到收敛
lcgm2a <- hlme(fixed = sit ~ 1 + time + I(time^2),
               mixture = ~ 1 + time + I(time^2),
               ng = 2, subject = "ID", data = long_data,
               B = m2_gs$best,      # ★ 用最优起点
               maxiter = 200)
lcgm2a$loglik; lcgm2$loglik    # ★ 对比：精跑的对数似然应 ≥ 直接建模
```

> ★★★ **这是 `lcmm` 建模最容易被忽略、却最关键的一步**：
> 潜类别模型的似然面有**大量局部最优**。若直接从单一起点拟合，很可能收敛到局部最优，
> 导致 **loglik 偏小、类别解不稳定、甚至因起点不同而得到完全不同的类别结构**。
> **正确做法：`gridsearch(rep=100~200)` 粗筛 → 取 `$best` 作为起点 → 精跑至收敛。**
> ★ 并应**报告 loglik 对比**以证明精跑确实优于直接拟合（课程代码里保留了 `lcgm2a$loglik; lcgm2$loglik` 的对比）。

### 1.4 轨迹分组后的后续分析

```r
## ① 提取分组并合并回宽数据
gbtm_group <- rownames_to_column(data.frame(group = gbtm3$assign), var = "ID")
gbtm_total <- merge(width_data, gbtm_group, by = "ID")

## ② ★ 按轨迹高低重新编号（便于结果解读）
gbtm_total <- gbtm_total %>% mutate(group = case_when(
  group == 1 ~ 2, group == 2 ~ 1, group == 3 ~ 3, TRUE ~ group))

## ③ 基线特征差异性分析（tableone，strata = "group"）
## ④ 多项 logistic 回归（轨迹组作结局）
library(nnet); library(broom)
log <- multinom(group ~ sit1 + age1 + gender1 + bmi1 + smoke1 + drink1, data = gbtm_total)

```

> ★ `rownames_to_column(..., var="ID")` 是把 `gbtm$assign`（命名向量）转成数据框的关键一步 —— 命名向量的

> ★ 轨迹分组后**按轨迹高低重新编号**是论文呈现的标准做法（否则"Class 1"的含义由算法随机决定）。

## 2. 多变量轨迹模型（GBMTM）

```r
## ★★ 与单变量版【唯一】的区别：x.names 传向量而非单变量
varNames <- c("sit", "sleep", "sport")
gbmtm1 <- gbmt(x.names = varNames, unit = "ID", time = "time", d = 2, ng = 1,
               data = long_data, scaling = 0)

plot(gbmtm3, bands = F, xlab = "年", ylab = "时间",
     titles = c("久坐时间(小时/天)", "睡眠时间(小时/天)", "身体活动时间(天/周)"))
```

> ★★ **GBMTM 的核心价值**：同时对**多个相关行为/指标**做轨迹建模，得到**联合轨迹组**
> —— 即"哪些人同时呈现'久坐高 + 睡眠差 + 运动少'的联合模式"。
> 这比单独做三个单变量轨迹更接近真实的健康行为共现结构。
> ★ 模型选择的四项指标与单变量版完全一致（AIC/BIC/CIC + Avepp + OCC + 组占比）。

## 3. 发现的问题清单

| # | 位置 | 问题 | 严重度 | 说明 |
|---|---|---|---|---|
| **L1** | `潜类别轨迹模型-R实操代码.R` | **`gbtm3` 用 `d=3`（三次多项式），而 gbtm1/gbtm2/gbtm4/gbtm5 用 `d=2`** | 🔴 | **多项式阶次不一致**！比较不同组数的模型时，**阶次必须统一**，否则 AIC/BIC **不可比**、模型选择结论无效。这是本域最严重的方法学错误 |
| **L2** | 同上 | `ggplot(long_data, aes(x=time, y=depression, group=ID)) + geom_line()` | 🟠 | 画**全部个体的轨迹线**（数千条）→ 图糊掉且无信息量。应画**分组平均轨迹 ± CI**，或随机抽样若干个体作"意大利面图（spaghetti plot）" |
| **L3** | 同上 | `plot(gbtm3, group=1/2/3)` 分三张图，**未合并对比** | 🟡 | 建议用 `patchwork` 合并，或直接用 `plot(gbtm3)` 的分组图 |
| **L4** | 同上 | `plot(gbtm3, n.ahead=3)` **预测未来轨迹但未讨论外推风险** | 🟠 | 三次多项式外推极不稳定；若用于预测应说明并做敏感性分析 |
| **L5** | 同上 | 未见 **GRoLTS Checklist 的逐项对照** | 🟠 | 本域有该 checklist 文件却未在脚本中体现 |
| **L6** | `GBMTM多变量轨迹R代码.R` | **只有 214 行，缺少后续分析**（轨迹组与结局的关联、基线表、回归） | 🟠 | 单变量版有而多变量版没有 → 多变量轨迹的"用途"未演示完整 |
| **L7** | 两脚本 | `gbmt()` 的模型拟合**未设随机种子** | 🟠 | 轨迹模型含随机初始化 → 不可复现。lcmm 版设了 `set.seed(123)` ✓，gbmt 版未设 |
| **L8** | 两脚本 | `pad_vectors()` 用 NA 填充不等长向量后 `rbind` | 🟡 | 可行；但当组数不同时列名为 Class1..max_len，**行=类别数、列=组**的语义需仔细核对，易混淆 |
| **L9** | `lcmm` 部分 | `lcgm2`（直接建模）与 `lcgm2a`（gridsearch 起点）**并存但未说明以哪个为准** | 🟡 | 应明确最终模型用 `lcgm2a` 并在正文报告 loglik 对比 |
| **L10** | 全篇 | `setwd()` / 路径未统一 | 🟡 | 建议 `here::here()` |
