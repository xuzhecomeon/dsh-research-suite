### 0.2 本域的研究主题（由案例文献反推）

**核心科学问题**：长期 PM2.5 暴露 → 心血管疾病（CVD），**TyG 相关指标（TyG、TyG-BMI）是否起中介作用？**

- 暴露 X：`PM25`（长期 PM2.5 暴露）
- 中介 M：`tygbmi`（甘油三酯-葡萄糖指数 × BMI）、`tyg`
- 结局 Y：`status`（CVD 事件）+ `time`（随访时间）
- 协变量：`age`、`gender`、`residence`（城乡）、`education`、`marriage`、`drink`、`smoke`、`hypertension`、`diabetes`

| 变量 | 缺失数 | 变量 | 缺失数 |

> 这决定了插补方法的选择：定量变量 `age` 用 `pmm`，二分变量用 `logreg`，多分类变量用 `rf`（随机森林）—— 课程的思路是对的（见 §3.4）。

### 1.3 ★★ 最重要的数据特征：`time` 是离散的随访波次

```
time 的取值：9, 4, ... 共 7 个唯一值（data.csv）/ 9 个（datana.csv）
```
- 这是 **CHARLS 的随访波次编号**（2011/2013/2015/2018/2020 等），**不是连续时间**（年或月）
- **后果**：用 Cox 模型处理时，**同一 `time` 取值上会有大量并列事件（ties）**
  - 若 `time` 是"存活波次数"，则每个波次有数百甚至上千例事件同时发生
  - Breslow / Efron 近似在大规模 ties 下精度下降，且**离散时间下的"风险集"定义本身与连续时间模型的前提不符**
- **两条正确路径**：
  1. **改用离散时间生存模型**：把数据展开为"人-波次"（person-period）格式，用 `glm(event ~ time + ..., family = binomial(link="cloglog"))`，即 **cloglog 离散时间模型**
  2. **若坚持用 Cox**：必须明确说明时间单位与 ties 的处理方法（`coxph(..., ties="efron")`），并在局限性中讨论
- ★ **课程的 8 个统计模块全部用 Cox，从未讨论这一点** —— 这是本域最重要的一处方法学缺口。

## 2. 标准分析流程精读（`统计方法实操代码.R`，8 个模块）

### 模块 1：数据导入与因子化
```r
tt <- read.csv("data.csv")
varsToFactor <- c("gender","residence","education","marriage","drink","smoke","hypertension","diabetes")
tt[varsToFactor] <- lapply(tt[varsToFactor], factor)   # 向量化因子化，写法标准
```
> ★ 注意：`education`、`drink`、`smoke` 是**有序分类**，用 `factor()` 会得到**无序因子**。
> 若要用到线性趋势，应收成有序因子（`ordered = TRUE`）或直接按数值处理（本脚本的趋势分析正是按数值处理的）。

### 模块 2：tableone 基线差异分析
```r
tab1 <- CreateTableOne(vars = myVars, strata = "status", factorVars = catVars,
                       data = tt, addOverall = TRUE)
table1 <- print(tab1, showAllLevels = TRUE)
```
> ★ `print()` 默认对连续变量用**正态检验自动选择 mean(SD) 或 median(IQR)**；脚本未显式指定 `nonnormal`，
> 因此**分布形态由软件自动判定** —— 论文中应显式声明哪些变量按非正态处理。

### 模块 3–4：单因素 / 多因素 Cox + **多模型策略**
```r
# 模型1：未调整       Surv(time,status) ~ PM25
# 模型2：部分调整     + age + gender + residence + education + marriage
# 模型3：完全调整     + drink + smoke + hypertension + diabetes
```
> ★★ **多模型策略（sequential adjustment）是环境流行病学的黄金标准**：
> 逐层加入协变量以展示效应估计的**稳健性**。这比"只报一个调整后模型"信息量大得多，
> 也是环境暴露类论文被顶刊接受的基本要求。
> **课程这一设计非常规范**，值得直接套用到其他研究（如职业暴露、气候因素与健康结局）。

### 模块 5：缺失数据多重插补 + 回归
```r
# 定义各变量的插补方法
meth <- make.method(datana)
meth["age"] <- "pmm"
meth[c("gender","residence","hypertension")] <- "logreg"
meth[c("smoke","drink","marriage","education")] <- "rf"

imputed <- mice(datana, m = 3, maxit = 20, seed = 314)     # ★★ 见下
fit <- with(imputed, coxph(Surv(time,status) ~ ...))
pooled <- pool.syn(fit)                                     # ★★ 见下
```

### 模块 6：趋势性分析 + **RCS 曲线**
```r
# ① 趋势性分析：按四分位分组 → 取各组中位数作为节点值 → 用该节点值做 Cox
tt$PM25_quartile <- cut(tt$PM25, breaks = c(-Inf, quart[2:4], Inf), labels = c("Q1","Q2","Q3","Q4"))
tt <- tt %>% group_by(PM25_quartile) %>% mutate(PM25_trend = median(PM25)) %>% ungroup()
trend_model <- coxph(Surv(time,status) ~ PM25_trend + ..., data = tt)

# ② RCS（限制立方样条）：4 个节点
rcs1 <- cph(Surv(time,status) ~ rcs(PM25,4) + ..., data = tt)
anova(rcs1)                              # ★ P Nonlinear < 0.05 为非线性
HR <- Predict(rcs1, PM25, fun = exp, ref.zero = TRUE)
# ggplot2 绘制：geom_line + geom_ribbon（95%CI）+ geom_hline(y=1) + geom_vline(参考值)
```
> ★★ **「趋势性分析 + RCS」是环境暴露研究的标配组合**：
> - **趋势性分析**（取组中位数作为节点值）给出**线性趋势的 P 值**（P for trend），避免"分组后只看各组的 HR"而丢失趋势信息
> - **RCS** 给出**剂量-反应曲线的具体形状**（线性/阈值/U 型/J 型），并由 `anova()` 的 **P for nonlinear** 判定非线性是否显著
> - ★ 关键细节：**组中位数作为节点值**是一个聪明的做法 —— 它保留了分组（便于呈现）又恢复了一个连续变量（便于趋势检验）

### 模块 7：中介分析
```r
med.fit <- lm(tygbmi ~ PM25, data = tt)                        # X → M
out.fit <- survreg(Surv(time,status) ~ tygbmi + PM25, data = tt)  # X + M → Y  ★★
med.out <- mediate(med.fit, out.fit, treat = "PM25", mediator = "tygbmi", sims = 1000)
```

### 模块 8：亚组分析 + 交互作用 + 森林图
```r
res <- TableSubgroupMultiCox(formula = Surv(time,status) ~ PM25,
                             var_subgroups = c("age","gender","residence","smoke",
                                               "drink","hypertension","diabetes"),
                             data = df)          # jstable 包，一次给出各亚组 HR 与 P for interaction
# 整理 → forestploter::forest() 绘制森林图
```

### 课程给出的实际结果（`subgroup_result.csv`）

| 亚组 | n | 占比 | HR |
|---|---|---|---|
| Overall | 5569 | 100% | **1.01** |
| age <60 | 3265 | 58.6% | 1.01 |
| age ≥60 | 2304 | 41.4% | 1.01 |
| gender Female | 2667 | 47.9% | 1.00 |
| gender Male | 2902 | 52.1% | 1.01 |

> ★ 注意：`PM25` 的 HR 约为 **1.01**（每 1 μg/m³ 的效应），且各亚组几乎一致 —— 说明在本数据上
> **PM2.5 对 CVD 的效应量很小、亚组间无实质异质性**。
> ★★ 这提示一个重要表述规范：**对"每单位"很小的连续暴露，应报告"每 IQR（或每 10 μg/m³）的 HR"**，
> 否则 HR = 1.01 会让读者误以为"无效应"。本数据 `PM25` 唯一值 124 个，应先算 IQR 再缩放效应量。
> 这是环境流行病学论文的常见做法，课程未体现。

## 3. 发现的问题清单

### 🔴 致命级（会导致结果错误）

| # | 位置 | 问题 | 后果 |
|---|---|---|---|
| **Q1** | 模块 5，`pool.syn(fit)` | **应为 `pool(fit)`** | `pool.syn()` 是 **mitools / 合成数据**的合并函数，**不适用于 `mice` 的 `mira` 对象**。会报错或给出无意义结果 → **多重插补分析无法完成** |
| **Q2** | 模块 5，`meth` 定义后未传给 `mice()` | 定义了 `meth`（`pmm`/`logreg`/`rf`）却调用 `mice(datana, m=3, maxit=20, seed=314)`，**没有 `method = meth` 参数** | **自定义插补方法完全未生效**！`mice` 用默认方法（`make.method` 的自动判定）→ 与作者意图不符，白定义 |
| **Q3** | 模块 7，使用 `survreg` 作为 `mediate()` 的结局模型 | `mediation::mediate()` 要求 `out.model` 为 **lm / glm 类**；`survreg` 返回 `survreg` 类（参数生存模型） | **很可能直接报错**；即便能跑，与主分析用 Cox 的口径也不一致。正确做法：① 把结局二分类化后用 `glm`；② 或用专门支持生存中介的包（`CMAverse` / `medflex` / `regmedint` / `survival` 的 AFT 框架） |
| **Q4** | 模块 6，RCS 图的 P 值**硬编码** | `label = expression(paste(italic("P"), " for nonlinear < 0.001"))` | P 值是**写死的文本**，不是从 `anova(rcs1)` 动态取。**换数据后图上的 P 值就是错的**，而代码不会报错 |
| **Q5** | 模块 6，RCS 参考线 | `geom_vline(xintercept = 54.124)`，注释写 `X=23.611 (查表HR=1对应的VD值)` | **注释与代码数值不一致**，且注释提到 **VD（维生素 D）** —— 明显是从另一个分析（维生素 D 与疾病）**复制粘贴残留**。必须核对「参考值」的真实来源与含义 |

### 🟠 严重级（方法学完整性）

| # | 问题 | 说明 |
|---|---|---|
| **Q6** | **`time` 是离散随访波次，却全程用 Cox** | 见 §1.3。应改 cloglog 离散时间模型，或明确说明 ties 处理与局限性 |
| **Q7** | **`mice(m=3, maxit=20)` 低于规范** | 课程注释自认「m 通常为 5，maxit 通常为 50，此处为节省时间进行缩减」。**照抄即得不可靠结果**；现代建议 **m ≥ 20**（甚至 m = 100×缺失率），maxit 至收敛 |
| **Q8** | **完全缺 PH 假设检验** | 8 个模块里的所有 Cox 模型都未做 `cox.zph`。环境暴露与年龄都可能违反 PH（见第一域 §16.1 的三条处理路径） |

| **Q11** | **因果中介的双向敏感性分析缺失** | 现代中介分析（如 `CMAverse`）要求检验"未测量混杂是否会颠覆中介结论"（E-value / 敏感性分析） |
| **Q12** | 亚组森林图列名**硬编码** | `names(plot_df) <- c("Variable","Count","Percent","PointEstimate","Lower","Upper","Pvalue","Pforinteraction")` → `jstable` 版本更新列名变化即静默错位 |

## 4. 本域的方法学亮点（值得直接复用）

1. **多模型策略（未调整 → 部分调整 → 完全调整）** —— 环境流行病学黄金标准，课程做得很规范
2. **趋势性分析（组中位数作节点值）** —— 兼顾"分组呈现"与"趋势检验"
3. **RCS + `anova()` 的 P for nonlinear** —— 剂量-反应形状的标准做法
4. **插补方法按变量类型分层指定**（`pmm` / `logreg` / `rf`）—— 思路正确（虽然代码没生效，见 Q2）
5. **`jstable::TableSubgroupMultiCox` 一次给出所有亚组 HR 与 P for interaction** —— 高效且规范
6. **`forestploter` 绘制可发表的森林图** —— 支持多列文本 + 图形混合
