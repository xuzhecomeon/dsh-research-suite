## 1. 方法学总纲（课件 1–3 + 12 的提炼）

### 1.1 什么是混杂偏倚

**混杂（confounding）**：当存在第三个变量 C，既与暴露 X 相关，又与结局 Y 相关（且不在 X→Y 的因果通路上）时，X 与 Y 的关联会被 C 扭曲。

**判断混杂的三条件**
1. 与暴露相关
2. 与结局相关（在未暴露人群中）
3. **不是暴露与结局之间的中间变量（不能是中介）**

> ★ 第 3 条最易被忽视：把**中介变量**当混杂调整，会**低估总效应**（过度调整偏倚，over-adjustment bias）。

### 1.2 混杂的应对方式（课件 1–3 的体系）

```
混杂偏倚的应对
├── 设计阶段
│   ├── 随机化（RCT，金标准）
│   ├── 限制（restriction）：只纳入某一层的人群
│   └── 匹配（matching）：按混杂因素配对
└── 分析阶段
    ├── 分层分析（stratification）
    ├── 多因素回归（regression adjustment）
    ├── ★ 倾向得分方法（propensity score）
    │   ├── 匹配 PSM
    │   ├── 分层 PS stratification
    │   ├── 加权 IPTW（Robins / Hernán 权重）
    │   └── 回归 PS as covariate
    └── 工具变量 / 孟德尔随机化（见第三域）
```

### 1.3 ★★ 反事实框架（课件 12 的核心）—— 理解一切 PS 方法的钥匙

**潜在结局（potential outcomes）**
- 每个个体有两个潜在结局：Y(1)（若接受治疗）、Y(0)（若未接受治疗）
- **个体因果效应** = Y(1) − Y(0)，**但永远只能观测到其中一个** → 这就是"因果推断的根本问题"
- **平均因果效应** ATE = E[Y(1) − Y(0)]

**倾向得分的定义（Rosenbaum & Rubin, 1983）**
```
e(X) = P(T = 1 | X)
```
即"在给定协变量 X 下，个体接受治疗的概率"。

**★ 倾向得分的两大定理（PSM 的数学基础）**
1. **平衡性（Balancing）**：若治疗分配在 X 上可忽略，则在 e(X) 的同一水平上，X 与 T 独立
   → **只需在 e(X) 一个维度上平衡，就能平衡所有 X**（降维）
2. **可忽略性下的无偏性**：若满足可忽略性（无未测量混杂）与重叠性（positivity），则在 e(X) 分层内的治疗效应估计无偏

**★ 三种效应量的区别（论文必须声明用哪个）**

| 效应量 | 含义 | 对应方法 |
|---|---|---|
| **ATE**（平均治疗效应） | 全人群接受 vs 全人群不接受 | IPTW（Robins 权重） |
| **ATT**（治疗组的平均治疗效应） | 治疗组接受 vs 治疗组不接受 | PSM 匹配、ATT 权重 |
| **ATO**（重叠人群的效应） | 只在"临床可均等选择"的人群 | 重叠权重（overlap weights） |

> ★★ **这是 IPTW 分析中最常被忽略的声明项**：**匹配默认估计 ATT，加权默认可估计 ATE（取决于权重公式）**。
> 论文中必须明确："本研究估计的是 ATT / ATE"，因为二者的**临床含义完全不同**：
> - ATT 回答"对已接受治疗的人，治疗有效吗"
> - ATE 回答"如果全人群都接受治疗，效果如何"
> ★ 且 **ATE 需要更强的重叠性假设** —— 当两组 PS 分布重叠差时，ATE 会被少数极端权重个体主导。

### 1.4 四种 PS 方法的对照（课件 5–10）

| 方法 | 原理 | 优点 | 缺点 |
|---|---|---|---|
| **PSM 匹配** | 为每个治疗者找 PS 相近的对照 | 直观、可看 Love plot；**样本量减少但有明确对应** | 只估计 **ATT**；丢弃未匹配个体；结果依赖匹配算法与 caliper |
| **PS 分层** | 按 PS 分 5–10 层，层内比较后合并 | 保留全部样本；简单 | **每层仍需平衡性**；层数选择主观 |
| **IPTW 加权** | 权重 = 1/e(X)（治疗组）或 1/(1−e(X))（对照组） | 保留全部样本；估计 **ATE**；直接给出"伪人群" | **权重极端 → 方差爆炸**；需权重诊断与截断 |
| **PS 作为协变量回归** | 模型中仅放入 PS | 简单；一步得到调整后效应 | **模型误设的双重风险**；SE 需特殊处理；不如前三种直观 |

> ★ **选择建议**：目标是**ATT** → PSM；目标是**ATE** → IPTW；**两者都报**是最稳健的做法（敏感性分析）。

### 2.2 匹配参数的含义（MatchIt）

| 参数 | 课程取值 | 含义 | 评价 |
|---|---|---|---|
| `method="nearest"` | 最近邻匹配 | 按 PS 距离找最近对照 | 最常用 ✓ |
| `distance="glm"` | 用 logistic 估计 PS | 自动拟合 PS 模型 | ✓ |
| `m.order="random"` | 随机匹配顺序 | 避免顺序偏倚 | ✓ 但**必须设种子**才可复现（课程未设） |
| `ratio=1` | 1:1 匹配 | 每个治疗者配 1 个对照 | ✓ |
| **`caliper=0.2`** | **PS 的 0.2 倍标准差** | Austin 推荐的卡钳宽度 | ✓ **符合规范**（`std.caliper=TRUE` 是默认，故单位是 SD） |
| `replace=FALSE` | 不重复使用对照 | 每个对照只用一次 | ✓ |

### 2.3 ★ 稳健方差：匹配后必须考虑配对结构

```r
# 课程代码（第 180 行）
fit <- coxph(Surv(Time,Status) ~ factor(Chemotherapy), cluster = subclass, data = psm_matchit_data)
```
> ★ **思路正确**：匹配后数据存在**配对/分层结构**，必须用**聚类稳健标准误**（`cluster` 或 `robust=TRUE`）才能得到正确的 CI。
> **但代码写错了**（见 §4-R 系列问题）：`cluster = subclass` 中的 `subclass` **未加引号也未用 `$`** → R 会去找全局对象 `subclass` → 报错。

## 3. 代码精读二：`IPTW R 代码.R`（倾向得分加权，含生存）

### 3.1 两种权重（Robins vs Hernán）

```r
# Robins 法（未稳定权重，unstable weights）
e1$w1 <- ifelse(e1$drinking == 1, 1/e1$pre, 1/(1 - e1$pre))

# Hernán 法（稳定权重，stabilized weights）
pt <- 73/189                                              # ★ 硬编码！见 §4
e1$w2 <- ifelse(e1$drinking == 1, pt/e1$pre, (1-pt)/(1-e1$pre))

# "或者"：用截距模型自动算 pt
tt <- glm(drinking ~ 1, data = e1, family = "binomial")
e1$pt <- predict(tt, type = 'response')
e1$w3 <- ifelse(e1$drinking == 1, pt/e1$pre, (1-pt)/(1-e1$pre))   # ★ 仍用硬编码 pt
```

**两种权重的数学含义**

| 方法 | 治疗组权重 | 对照组权重 | 效应量 |
|---|---|---|---|
| **Robins（IPTW）** | 1/e(X) | 1/(1−e(X)) | **ATE** |
| **Hernán（稳定 IPTW）** | P(T=1)/e(X) | P(T=0)/(1−e(X)) | **ATE** |
| ATT 权重 | 1 | e(X)/(1−e(X)) | **ATT** |

> ★ **稳定权重的意义**：乘上边际处理概率 P(T=1) 后，**权重的均值被拉回 1 附近，方差显著下降** → 估计更稳定。
> ★ **课程用注释明确标注「不稳定」vs「稳定」**，这是很好的教学处理。

### 3.2 传统方法 vs WeightIt 包

```r
W21 <- weightit(..., method = "ps", estimand = "ATE")                    # 不稳定权重
W22 <- weightit(..., method = "ps", estimand = "ATE", stabilize = TRUE)  # 稳定权重
```
> ★ `WeightIt::weightit()` 是**现代推荐**的加权实现，相比手工算权重更稳健（自动处理类别不平衡、支持多种估计量）。
> ★ 课程**同时演示手工法（Robins/Hernán）与包法（WeightIt）**，并对比二者结果 —— 设计很好。

### 3.3 加权后的分析（★ 本域最关键的方法学点）

```r
# ---- 方式 1：glm + weights（★ 有问题）----
glm.w1 <- glm(low ~ drinking, family = binomial(link="logit"), data = e1, weights = e1$w1)

# ---- 方式 2：survey 包（★ 正确）----
e1w1 <- svydesign(ids = e1$id, data = e1, weights = e1$w1)
svym1 <- svyglm(low ~ drinking, family = binomial(), design = e1w1)
```

**★★★ 加权分析中最重要的一个方法学要点**

| 做法 | 点估计 | **标准误** | 结论 |
|---|---|---|---|
| `glm(..., weights = w)` | ✓ 正确 | **✗ 错误** | `weights=` 被当作**精度权重**（precision weights），而 IPTW 权重是**抽样权重**（sampling weights）；R 不会自动给出稳健方差 |
| `coxph(..., weights = w)` | ✓ 正确 | **✗ 错误** | 同上（`coxph` 的 `weights` 也是精度权重） |
| `svyglm(..., design = svydesign(...))` | ✓ 正确 | **✓ 正确** | survey 设计对象自动处理抽样权重的方差 |
| `svycoxph(..., design = ...)` | ✓ 正确 | **✓ 正确** | 同上 |
| `coxph(..., weights = w, robust = TRUE, cluster = id)` | ✓ 正确 | ✓ 正确 | 三明治稳健方差 |

> ★★★ **课程同时给出了两种做法（`glm(weights=)` 与 `svyglm`），但从未说明前者得到的 SE 不可用。**
> 这是 IPTW 分析中**最常被审稿人质疑的错误**：用 `glm(weights=)` 报出的 CI 通常**过窄**（假阳性风险上升）。
> **正确路径有两条**：① `survey::svyglm` / `svycoxph`（课程已演示 ✓）；② `glm`/`coxph` + `robust=TRUE, cluster=id`。
>
> ★ **经验法则**：**只要用了 IPTW 权重，就必须用"能正确处理抽样权重的方差估计器"** ——
> 要么 `survey` 设计，要么三明治稳健方差。**绝不能用默认的 `weights=` 直接报 SE。**

### 3.4 生存资料的加权分析

library(RISCA)
ipw.log.rank(dat_inc$Time, dat_inc$Status, dat_inc$Chemotherapy, weights = dat_inc$w21)   # ★ 加权 log-rank
