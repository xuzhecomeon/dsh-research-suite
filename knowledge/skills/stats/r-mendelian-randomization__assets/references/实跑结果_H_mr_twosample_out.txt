################ 1. 五种 MR 估计方法（手写实现）################

【1】IVW（逆方差加权）
     b = +0.45164  SE = 0.04358  OR = 1.5709 (95%CI 1.4423–1.7110)  P = 3.64e-25

【2】MR-Egger（加权线性回归）
     斜率（因果效应）b = +0.44789  SE = 0.05945  P = 4.91e-14
     截距（方向性多效性）a = +0.00132  SE = 0.00165  P = 0.423  → 未检测到（注意：功效低，阴性≠无多效性）

【3】加权中位数（weighted median）
     b = +0.39991  （第 40 个 SNP，累计权重 0.524）
     Bootstrap SE = 0.09387  95%CI +0.36936 ~ +0.61300  P = 2.04e-05

【4】加权众数（weighted mode，核密度峰值）
     b = +0.39602

【5】简单中位数（simple median，参考）
     b = +0.39851  （中位比值）

  ★ 教材判读：IVW 为**主分析**（功效最高，但多效性敏感）；
     MR-Egger 提供多效性检验但功效低；加权中位数最稳健；众数最保守。
     若 IVW 与加权中位数方向一致且量级接近 → 结论稳健。

################ 2. 异质性检验（Cochran's Q）################

  Q = 141.72  df = 77  P = 1.006e-05   I² = 45.7%
  → ★ 存在显著异质性（提示多效性或效应异质）

################ 3. MR-PRESSO 全局检验（手写 + NbDistribution 敏感性）################

  RSSobs（观测）=  141.7229 
  NbDistribution = 1000  → 全局检验 P = 0.000999
  NbDistribution = 5000  → 全局检验 P = 0.0002
  ★★ 关键实证：同一数据、同一公式，仅因模拟次数不同（1000 vs 5000），
     P 值就会变化 —— 这就是课程注释里「NbDistribution 建议设 5000 以上」的原因。
     模拟次数不足时，P 值带有大 Monte-Carlo 误差，可能把 P=0.06 报成 P=0.03。

################ 7. ★★★ 等位基因方向反转实验 ################

  机理：GWAS-VCF 规范中 ES（效应量）对应 ALT 等位基因；
        若误把 REF 当 effect_allele，该 SNP 的 beta 符号整体反转，而【软件不报错】。

  [基准·正确方向] IVW b = +0.45164  SE = 0.04358  OR = 1.5709  P = 3.64e-25
                   Q = 141.72（异质性）, SNP 数 = 78

【实验A】全部 SNP 的效应等位基因写反：
          IVW b = -0.45164（基准的 -100.0%）  SE = 0.04358  OR = 0.6366  P = 3.64e-25
          比值 b_A / b_0 = -1.000000（理论 −1.000000）
          异质性 Q 是否变化：原 Q = 141.72 → 新 Q = 141.72（完全相同）

  ★★ 结论：效应方向【完全反转】，但 **OR 的绝对值、SE、P 值、Q 统计量、SNP 数一模一样**。
     即：所有「质量指标」都正常，只有【结论方向】是反的 —— 这是 MR 中最危险的错误。
     若不做方向核对，会把「BMI 降低 CAD 风险」的结论直接写进论文。

【实验B】随机部分 SNP 方向写反（模拟只有部分回文 SNP 判断错误）：
          翻转 10%（n=  8）：IVW b = +0.27348（基准的 +60.6%）  OR = 1.3145  P = 3.49e-10
          翻转 30%（n= 23）：IVW b = +0.21935（基准的 +48.6%）  OR = 1.2453  P = 4.82e-07
          翻转 50%（n= 39）：IVW b = +0.07776（基准的 +17.2%）  OR = 1.0809  P = 0.0744

  ★★ 实验B 的意义：真实场景中只有部分 SNP（如回文 SNP）方向错，
     结果不是干净的取反，而是【向零衰减 + 随机扰动】，甚至可能在某个错误比例下变号。
     这解释了为什么「效应方向与文献不一致」的第一步诊断必须是核对等位基因。

  ★★ 防御措施（已固化为技能铁律）：
     1) 回文 SNP（A/T、C/G）用 1000 Genomes 的 EAF 匹配判断方向；
     2) 显式检查 dat 的 palindromic / ambiguous 列并说明处理方式；
     3) 结果先与既往文献/临床常识核对方向（BMI↑ → CAD↑）；
     4) VCF 读取时确认 effect_allele = ALT（不是 REF）。
