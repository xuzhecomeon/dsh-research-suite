## 1. 标准两样本 MR 全流程精读（`MR-code.R`）

### 1.1 七步骨架

```
1. 读取暴露数据
   ├ 方式1（本地）：read_exposure_data(filename, sep, snp_col, beta_col, se_col,
   │                                   effect_allele_col, other_allele_col, eaf_col, pval_col, samplesize_col)
   └ 方式2（在线）：extract_instruments(outcomes = 'ieu-a-2')
2. 工具变量筛选：pval.exposure < 5e-8
3. 连锁不平衡剔除：clump_data(clump_kb = 10000, clump_r2 = 0.001)   ← 需 OpenGWAS token
4. 读取结局数据
   ├ 本地：read_outcome_data(snps = exp_dat$SNP, filename, ...)
   └ 在线：extract_outcome_data(snps, outcomes = 'ieu-a-7')
5. 等位基因协调：harmonise_data(exposure_dat, outcome_dat, action = 2)
6. MR 估计：mr(dat)  /  mr(dat, method_list = c("mr_ivw","mr_egger_regression","mr_weighted_median"))
   效应量转换：generate_odds_ratios(res)
7. 敏感性分析（★ 决定论文上限）
   ├ 异质性：mr_heterogeneity(dat)
   ├ 水平多效性：mr_pleiotropy_test(dat)
   ├ 离群值：run_mr_presso(dat, NbDistribution = ...)
   ├ 单 SNP 效应：mr_singlesnp(dat)
   └ 留一法：mr_leaveoneout(dat)
8. 可视化：散点图 / 森林图 / 留一法图 / 漏斗图
9. 工具变量强度：单 SNP F 值与总 F 值
```

### 1.2 MR 的方法学基石（文献 9 与课件 1–2 的核心）

**MR 成立的三条核心假设**
1. **相关性（Relevance）**：工具变量（SNP）与暴露强相关 —— 用 **F 统计量 / p<5e-8** 量化
2. **独立性（Independence）**：工具变量与暴露-结局的混杂因素无关 —— **不可直接检验**，靠研究设计（如限定同一人群、调整主成分）
3. **排他性（Exclusion restriction）**：工具变量只能通过暴露影响结局，无其他通路 —— **水平多效性检验**是其代理检验

**为什么 MR 被称为"自然随机对照试验"**
- 配子形成时等位基因**随机分配**（孟德尔第二定律）→ 相当于天然的随机化
- 因此 MR 对**未测量混杂**具有抗性 —— 这是它相对传统观察性研究的最大优势（文献 2 正是"传统病例对照 vs MR"的对照）
- **但 MR 依赖的假设不可全部检验**：这正是它被质疑的核心，也是 STROBE-MR 要求逐项声明的缘由

**常用估计方法（课程使用了前三种）**

| 方法 | 核心假设 | 特点 |
|---|---|---|
| **IVW**（逆方差加权） | 所有 SNP 均有效（无多效性） | 效率最高；**多效性存在时偏倚最大**；主分析 |
| **MR-Egger** | InSIDE 假设（多效性效应与 SNP-暴露效应无关） | 提供**截距项**作为多效性检验；但功效低、易受弱工具偏倚 |
| **Weighted median** | 至少 50% 的权重来自有效 SNP | 稳健；对离群 SNP 不敏感 |
| Weighted mode / Simple mode | 最大 SNP 子集有效 | 更稳健但功效最低 |
| **MR-PRESSO** | 可检测并校正离群 SNP | 三步：全局检验 → 离群检验 → 剔除后重估 |

> ★ 课程 `mr(dat)` 默认即输出 **5 种方法**（IVW / MR-Egger / Weighted median / Weighted mode / Simple mode），但 `res1` 只保留了前 3 种。**论文中通常主分析报 IVW，敏感性分析报其余**。

### 1.3 ★ 等位基因协调（harmonise_data）—— 本域技术含量最高的一步

```r
dat <- harmonise_data(exposure_dat = exp_dat3, outcome_dat = out_dat1, action = 2)
table(dat$mr_keep)     # ★ 必须检查：被剔除的 SNP 有多少、为什么
```

**`action` 参数的含义（极易踩坑）**
| action | 行为 |
|---|---|
| 1 | 假设所有 SNP 都是正链，**不做链推断**（若数据已验证链方向时可用） |
| **2**（默认） | **尝试从等位基因频率推断链方向**；无法推断时剔除 |
| 3 | 与 2 相同，但在无法推断时**保留并报警** |

> ★ **必做核查**：`harmonise_data` 会静默剔除"无法协调"的 SNP。若剔除过多（如从 50 个降到 10 个），**结论可能完全改变**。课程只打印了 `table(dat$mr_keep)`，未追踪被剔除的原因 —— 建议补做：
> ```r
> dat$reason <- dat$mr_keep  # 或直接查看 harmonise_data 产生的 mr_keep/mr_keep.exposure 等列
> print(dat[!dat$mr_keep, c("SNP","effect_allele.exposure","other_allele.exposure",
>                            "effect_allele.outcome","other_allele.outcome","palindromic","ambiguous")])
> ```

**回文 SNP（palindromic SNP）的处理**
- A/T 或 C/G 型 SNP 在双链上等价，**无法从等位基因判断方向** → 需要用 **EAF（效应等位基因频率）匹配**来解决
- 这正是 `方法/eaf匹配.R` + `mateaf` 包的作用：用 1000 Genomes 参考人群的 EAF 来判断方向
- **EAF 匹配是回文 SNP 的救命稻草，也是本域 `mateaf` 包存在的理由**

### 1.4 ★ 水平多效性检验（`水平多效性.R`）

**四层检验体系**
1. **MR-Egger 截距**：`mr_pleiotropy_test(dat)` → 截距显著偏离 0 提示方向性多效性
2. **MR-PRESSO 全局检验**：是否存在离群 SNP
3. **Cochran's Q（异质性检验）**：`mr_heterogeneity(dat)` → SNP 间效应异质提示多效性
4. **留一法（leave-one-out）**：逐个剔除 SNP，看结论是否被单个 SNP 驱动

**各检验的局限（文献 9 统计学共识强调）**
- MR-Egger 截距检验**功效低**，阴性不能证明无多效性
- MR-PRESSO 的 `NbDistribution` 需要 **≥5000** 才有稳定的 P 值（**课程用 1000，功效不足**）
- Cochran's Q 对异质性敏感但**不区分方向性/平衡性多效性**
- 现代补充：**径向 MR（radial MR）**可同时可视化并检验离群值与多效性

### 1.5 弱工具变量与 F 值（`弱工具变量F值计算公式.xlsx`）

**课程手写实现**
```r
r2 <- (2*eaf*(1-eaf)*beta^2) / (2*eaf*(1-eaf)*beta^2 + 2*eaf*(1-eaf)*N*se^2)
F  <- r2 * (N - 2) / (1 - r2)
```
- 这是标准的 **`get_r_from_bsen()`** 公式的展开形式（用 beta + se + N + EAF 反推 r²）
- **单 SNP F 值**经验界值：**F > 10 为强工具变量**；F < 10 提示弱工具偏倚
- **总 F 值**：课程写法 `Ft <- r3*(338903-2)/(1-r3)`，其中 `r3 = sum(r2)`
  - ★★ **这里硬编码了样本量 338903** —— 应改为 `dat$samplesize.exposure` 的实际值。若换数据集而忘记改这个数，总 F 值就是错的。**这是本域最容易跟着抄错的一处。**

> ★ 更稳妥的做法：直接用 `TwoSampleMR::add_rsq()` 或 `compute_f()` 系列函数，避免手写公式出错。

### 1.6 ★ 效应量方向与 OR 转换

```r
or1 <- generate_odds_ratios(res)
```
- **二分类结局** → 报 **OR（95%CI）**
- **连续型结局** → 报 **β（95%CI）**，即「暴露每升高 1 个标准差，结局变化多少」
- ★ **方向核对**：`generate_odds_ratios` 依赖 `dat$beta.outcome` 的符号，而符号由 `harmonise_data` 的等位基因方向决定。**任何等位基因方向错误都会导致效应方向整体反转**，且软件不会报错。

## 2. 多变量 MR（MVMR）精读

> 文件：`代码，数据，文献/1多变量MR/复现数据及代码/多变量复现.R`
> 文献 10 的首篇正是 MVMR 的经典应用：**用 MVMR 拆解各血脂分馏（HDL/LDL/TG）对结局的独立因果效应**

### 2.1 何时需要 MVMR

**单变量 MR 的致命局限**：若暴露 X₁ 与 X₂ 高度相关（如 HDL 与 TG），单变量 MR 估计的"X₁ → Y"效应**包含了通过 X₂ 传递的部分** → **总效应，不是直接效应**。
**MVMR 的价值**：把多个相关暴露同时纳入模型，估计**各暴露的独立（直接）因果效应**。

### 2.2 关键实现要点

```r
## ① 两个暴露的 SNP 合并后统一 clump（★ 注意 r2 放宽到 0.1）
mvmr.iv <- rbind(smoking, alcohol)
mvmr.iv <- unique(mvmr.iv["SNP"])
mvmr.iv <- clump_data(mvmr.iv, clump_r2 = 0.1)     # ← 单变量用 0.001，MVMR 用 0.1

## ② 把第二个暴露编码为 "outcome"（借用 harmonise_data 做等位基因对齐）
smoking.alcohol <- harmonise_data(exposure_dat = full.smoking1,
                                 outcome_dat  = full.alcohol1, action = 1)

## ③ 组装矩阵
object <- mr_mvinput(bx = bx, bxse = bxse, by = by, byse = byse)

## ④ 三种估计 + MVMR 专属敏感性分析
mr_mvivw(object); mr_mvegger(object); mr_mvmedian(object)
F  <- strength_mvmr(r_input = object, gencov = 0)      # 条件 F 值（弱工具诊断）
mv_hete <- pleiotropy_mvmr(r_input = object, gencov = 0)  # Q 统计量
```

> ★★ **MVMR 三条必须掌握的技术要点**
>
> **① clump 阈值必须放宽到 r2 = 0.1（甚至 0.2）**
> 单变量 MR 用 r2 < 0.001 是为了保证 SNP 独立；但 MVMR **恰恰需要保留那些"能区分两个暴露"的 SNP**。
> 若沿用 0.001 的严格阈值，会剔除掉大量与两个暴露都相关、但效应模式不同的 SNP，导致**条件 F 值过低**（弱工具）→ 结果不可靠。
>
> **② `gencov = 0` 是一个假设，不是事实**
> `gencov` 是两个暴露 GWAS 之间的**遗传协方差（样本重叠所致）**。
> 课程数据中吸烟（SmkInit）与饮酒（DrnkWk）**都来自 GSCAN 2022**，即**同源样本，存在重叠** → `gencov` 应为非零值。
> `MVMR` 包提供 `phenocov_mvmr()` 用表型相关系数估计 `gencov`；直接固定为 0 会**高估精度（低估 SE）**。
>
> **③ 条件 F 值（conditional F）而非单变量 F 值**
> `strength_mvmr()` 给出的是**条件 F**：在控制其他暴露后，该暴露的工具变量强度。
> MVMR 中的弱工具判断标准比单变量更严格（经验界值常取 **F > 10**，部分文献建议更严）。

### 2.3 MVMR 的模型选择层级

| 方法 | 假设 | 说明 |
|---|---|---|
| `mr_mvivw` | 所有 SNP 有效 | 主分析 |
| `mr_mvegger` | InSIDE | 提供多效性检验 |
| `mr_mvmedian` | ≥50% 权重有效 | 稳健 |
| `mr_mvlasso` / MVMR-cML | 稀疏假设 | 课程未涉及，现代前沿 |

### 3.2 中介效应的计算函数（课程自写，含重要方法学问题）

```r
med_cal <- function(beta1, se1, beta2, se2, beta_total, n = 1000) {
  mediate_effect <- beta1 * beta2
  mediate_se <- sqrt((beta1^2 * se2^2) + (beta2^2 * se1^2))   # ← ① Sobel 法
  m_low <- mediate_effect - 1.96 * mediate_se
  m_upper <- mediate_effect + 1.96 * mediate_se
  Z <- mediate_effect / mediate_se
  p <- 2 * pnorm(q = abs(Z), lower.tail = FALSE)
  ...
  mediate_percentage <- (mediate_effect / total_effect) * 100
  for (i in 1:n) {                                             # ← ② 参数化 Bootstrap
    beta1_boot <- rnorm(1, beta1, se1)
    beta2_boot <- rnorm(1, beta2, se2)
    mediate_percentages[i] <- (beta1_boot * beta2_boot / total_effect) * 100
  }
  pro <- (beta1*beta2 / total_effect) * 100
  se <- sd(mediate_percentages)
  pro_low <- pro - 1.96 * se                                   # ← ③ 又回到正态近似
  pro_upper <- pro + 1.96 * se
}
```

**⚠️ 四个方法学问题**

| # | 问题 | 正确做法 |
|---|---|---|
| ① | **中介效应的 CI 用 Sobel 法**（一阶 delta 法 + 正态近似） | Sobel 检验功效明显低于 Bootstrap；**现代规范（Hayes/MacKinnon）要求用 Bootstrap 分位数 CI 报中介效应本身** |
| ② | **Bootstrap 是参数化 Bootstrap**（`rnorm(1, beta, se)` 而非重抽样个体） | 参数化 Bootstrap 依赖正态假设；更严谨的是**非参数 Bootstrap**（重抽样 SNP）。若确实用参数化 Bootstrap，**必须在方法学中声明** |
| ③ | **算出的 Bootstrap 分布又用 `±1.96×sd` 转回正态近似** | 自相矛盾 —— Bootstrap 的初衷正是避免正态近似。**应直接用 `quantile(mediate_percentages, c(0.025, 0.975))` 取分位数** |
| ④ | **`mediate_se` 缺少协方差项** | 若 beta1 与 beta2 独立（不同 SNP 集）可接受；但**两步法中介中 X→M 与 M→Y 常共用同一批 SNP**，此时二者相关，缺少协方差项会**高估 SE** |

### 3.3 ★★ 中介 MR 的两条技术路线（课程只教了一条）

| 路线 | 做法 | 局限 |
|---|---|---|
| **两步法（课程使用）** | 分别估计 X→M 与 M→Y，乘积即中介效应 | 要求 X 与 M 的**工具变量集可以不同**；**无法控制 X 与 M 的共同上游**；中介比例在总效应接近 0 时不稳定 |
| **MVMR 框架（现代推荐）** | 把 X 与 M 同时放入 MVMR，**直接效应 = X 的系数，中介效应 = 总效应 − 直接效应** | 需要 X 与 M 的工具变量**同时可用**；但**能直接处理 X-M 相关性**，且提供条件 F 值做弱工具诊断 |

> ★★ **为什么 MVMR 框架更可靠**：两步法隐含假设「X→M 的 SNP 与 M→Y 的 SNP 相互独立且都有效」。当 X 与 M 存在共同上游混杂（如多效性 SNP 同时影响两者）时，乘积法会产生偏倚。文献 10 的首篇（血脂分馏）用的正是 MVMR 框架而非乘积法。
> **给用户的直接建议**：若要做中介 MR，**优先用 MVMR 框架报直接效应与中介效应**，把两步法作为敏感性分析。

### 3.4 中介 MR 还必须报告的内容（课程缺失）

1. **Steiger 方向性检验**（`directionality_test`）：验证 X→M、M→Y 的因果方向，防止反向因果
2. **每一步的异质性与多效性检验**（不是只做 X→Y 那一步）
3. **中介比例的 95%CI**（课程用 Bootstrap 算，但见 §3.2 的三个问题）
4. **中介比例 >100% 或为负的解释**（当直接效应与中介效应方向相反时会出现，需讨论）

## 4. 药靶 MR 与共定位（`4药靶MR/`）

**文件**：`药靶分析代码及数据/药靶1.R`、`共定位分析代码及数据/共定位.R`

**药靶 MR（Drug-target MR）的逻辑**
- 用**编码药物靶点蛋白的基因（如 PCSK9、HMGCR）的功能性变异**作为工具变量
- 估计「长期抑制该靶点」对结局的因果效应 → **为新药研发提供遗传学证据**
- 文献 10 的末篇（PCSK9 + CETP 联合抑制）是这一范式的顶刊示范
- ★ 关键差异：药靶 MR 的工具变量选择**通常放宽 p 阈值**（如 `p < 1e-5` 或用 eQTL/pQTL），因为功能性变异数量少

**共定位分析（Colocalization）**
- **解决的问题**：MR 只证明「该位点的变异与暴露、结局都相关」，但可能是**两个独立的因果变异处于连锁不平衡**（LD），而非同一因果变异
- **方法**：`coloc` 包的**后验概率 H4**（同一变异同时影响暴露与结局的概率）
- **判读**：H4 > 0.8 支持共定位（增强因果证据）；H4 < 0.5 需谨慎解释 MR 结果
- ★ **这是药靶 MR 的标配，单做 MR 不报共定位在顶刊会被质疑**

## 5. 肠道菌群 MR（`3肠道菌群MR/`）

**文件**：`本地数据多种菌群MR/多个肠道.R`
- **特点**：菌群 GWAS 通常**工具变量数量少、效应弱**（因菌群受环境/饮食影响大，遗传度低）
- → **弱工具偏倚风险高于常规 MR**；F 值核查尤为关键
- → 常需放宽 p 阈值（如 1e-5）并在局限性中说明
- → 多菌群分析需**多重比较校正**（如 FDR / Bonferroni）

## 10. 两样本 MR 实跑结果（Part H2，手写实现，BMI → CAD）

> 脚本：`assets/H2_mr_manual.R`；结果：`references/实跑结果_H_mr_twosample_out.txt`
> **说明**：`TwoSampleMR` / `MVMR` / `RadialMR` **已从 CRAN 归档**，对本机 R 4.5 不可用（Windows 源码安装需 Rtools）。
> 因此本脚本**不依赖任何 MR 专用包**，从公式出发手写实现全部方法 —— 这反而更完整地体现了方法学掌握程度。
> 数据：课程已协调好的 `dat.csv`（78 个 SNP，74 个非回文 + 4 个回文；无 ambiguous）。

### 10.1 五种估计方法（全部手写）

| 方法 | b | SE | **OR** | 95%CI | P |
|---|---|---|---|---|---|
| **IVW（主分析）** | **+0.4516** | 0.0436 | **1.5709** | **1.4423–1.7110** | **3.6e-25** |
| MR-Egger | +0.4479 | 0.0595 | 1.565 | 1.393–1.758 | 4.9e-14 |
| 加权中位数 | +0.3999 | 0.0939 | 1.492 | 1.241–1.793 | 2.0e-05 |
| 加权众数 | +0.3960 | — | 1.486 | — | — |
| 简单中位数 | +0.3985 | — | 1.490 | — | — |

> ★★ **五种方法方向完全一致、量级高度接近（b 在 0.396–0.452 之间）→ 结论极其稳健。**
> **主分析结论**：**BMI 每升高 1 个标准差，冠心病风险增加约 57%（OR = 1.571, 95%CI 1.442–1.711, P = 3.6e-25）**。
> **方向核对通过**：BMI↑ → CAD↑，与既往文献和临床常识一致 ✓

**手写实现的公式（可直接复核）**
```r
ratio   <- by / bx                       # 每个 SNP 的 Wald 比值估计
w       <- bx^2 / byse^2                 # = 1/ratio_se²，逆方差权重
b_ivw   <- sum(w * ratio) / sum(w)       # IVW 点估计
se_ivw  <- sqrt(1 / sum(w))              # IVW 标准误
# MR-Egger：加权线性回归 by ~ bx，权重 1/byse²；斜率=因果效应，截距=方向性多效性
beta_eg <- solve(t(X) %*% W %*% X) %*% t(X) %*% W %*% by
```

### 10.2 敏感性分析（四层，全部手写）

**（1）异质性 —— Cochran's Q**
```
Q = 141.72,  df = 77,  P = 1.006e-05,  I² = 45.7%   → ★ 存在显著异质性
```

**（2）水平多效性 —— MR-Egger 截距**
```
截距 a = +0.00132,  SE = 0.00165,  P = 0.423  → 未检测到方向性多效性
```
> 但需注意：MR-Egger 功效低，阴性不能证明无多效性。结合 Q 检验的显著异质性，更可能是**平衡性多效性**或**效应异质**。

**（3）★★ MR-PRESSO 全局检验 —— NbDistribution 敏感性的实证**
```
RSSobs（观测）= 141.7229
NbDistribution = 1000  →  P = 0.000999
NbDistribution = 5000  →  P = 0.0002
```
> ★★ **同一数据、同一公式，仅因模拟次数不同，P 值相差 5 倍。**

> 可能把 P = 0.06 报成 P = 0.03（或反之）——**直接决定"是否存在离群 SNP"的判断**。

| 差异 | +11.5（+0.2%） |

> ★ 本数据的 `N` 在 218359–339205 之间波动，中位数 338185.5 与硬编码的 338903 很接近，故差异只有 0.2%。
> **但换数据集若忘记改 338903，总 F 值会直接算错** —— 这正是 §7 的 M5 条之所以被列为"致命级"的原因（本例只是"运气好"）。

### 10.4 ★ Steiger 方向性检验（本次未完成，原因已定位）

```
暴露（BMI）R²_exp 合计 = 0.01571
结局（CAD）R²_out 合计 = NA   ← dat.csv 缺少 samplesize.outcome 列
```
> **失败原因（有价值的工程教训）**：`dat.csv` 是用 `read_outcome_data()` 从本地文件读的，
> 而该本地 CAD 文件（`cad.add.160614.website.txt`）**不含样本量列**（只有 `n_studies`，不是 N）。
> → Steiger 检验需要**结局的样本量**才能算 `R²_out`。
>
> **正确做法（三条路径）**：
> 1. 用 `extract_outcome_data()` 在线获取（会带 `samplesize.outcome`）
> 2. 从原文报告的表型方差与 MAF 手工推算
> 3. 用 `TwoSampleMR::directionality_test()` 前先补 `dat$samplesize.outcome`
>
> **这条经验很重要**：**本地 GWAS 文件往往缺少 Steiger 检验所需的样本量信息**。
> 若计划报 Steiger（STROBE-MR 推荐必备），**必须在数据准备阶段就确认结局数据的样本量可得**。

### 10.5 ★★★ 核心实验：等位基因方向写反的定量后果

**实验 A：全部 78 个 SNP 的效应等位基因写反**

| 指标 | 正确方向 | 全部写反 | 变化 |
|---|---|---|---|
| IVW b | **+0.45164** | **−0.45164** | **比值 = −1.000000（精确取反）** |
| SE | 0.04358 | 0.04358 | **完全相同** |
| P 值 | 3.64e-25 | 3.64e-25 | **完全相同** |
| **OR** | **1.5709** | **0.6366** | **从"增加 57% 风险"变成"降低 36% 风险"** |
| Cochran's Q | 141.72 | 141.72 | **完全相同** |
| SNP 数 | 78 | 78 | 完全相同 |

> ★★★ **这是本域最有价值的实证结论**：
> **一个"BMI 升高使冠心病风险增加 57%"的铁证（P = 3.6e-25），会变成"BMI 降低冠心病风险 36%"，
> 而所有"质量指标"——SE、P 值、异质性 Q、SNP 数、漏斗图、森林图——全都一模一样。**
>
> **没有任何统计量会报警。** 这是 MR（以及所有基于等位基因方向的遗传学分析）**独有的高危错误模式**：
> - 预测模型出错 → C-index 异常高或校准崩坏
> - 机器学习出错 → 训练集 AUC 异常高
> - **MR 方向出错 → 什么都不异常，只有结论是反的**
>
> **这也是为什么本技能把"效应方向与既往文献核对"列为第一条铁律。**

**实验 B：随机部分 SNP 方向写反（模拟只有回文 SNP 判断错误）**

| 错误比例 | 翻转 SNP 数 | IVW b | 相当于基准的 | OR | P | 结论状态 |
|---|---|---|---|---|---|---|
| 0% | 0 | +0.4516 | 100% | 1.571 | 3.6e-25 | 铁证 |
| **10%** | 8 | +0.2735 | **60.6%** | 1.315 | 3.5e-10 | 仍显著但效应缩水 40% |
| **30%** | 23 | +0.2194 | **48.6%** | 1.245 | 4.8e-07 | 效应腰斩 |
| **50%** | 39 | **+0.0778** | **17.2%** | 1.081 | **0.0744** | ★★ **失去统计学意义！** |

> ★★★ **实验 B 揭示了比"方向反转"更隐蔽的第三种错误模式**：
> 当**只有部分 SNP** 方向判断错误时，结果既不是干净的取反，也不是简单的衰减，而是
> **「向零衰减 + 最终失去显著性」** ——
> **50% 的 SNP 写反，就把一个 P = 3.6e-25 的因果关系变成了 P = 0.074 的"无统计学意义"。**
>
> **这解释了科研实践中一个常见困境**：「我认真跑了 MR，结果不显著，但文献说是有关联的」——
> 除了真正无因果的可能外，**等位基因方向的部分错误是必须优先排除的技术原因**。
> 而在真实场景中，方向错误的 SNP 往往集中于**回文 SNP（A/T、C/G）**，本数据就有 **4 个回文 SNP**。

**防御措施（已固化为技能铁律）**
1. **回文 SNP** 用 1000 Genomes 的 EAF 匹配判断方向（`mateaf` 包或 `eaf匹配.R`）
2. **显式检查** `dat` 的 `palindromic` / `ambiguous` 列，并在 Methods 中说明处理方式
3. **结果先核对方向**：与既往文献、临床常识对照（BMI↑ → CAD↑）
4. **VCF 读取时确认** `effect_allele = ALT`（GWAS-VCF 规范：ES 对应 ALT，**不是 REF**）
