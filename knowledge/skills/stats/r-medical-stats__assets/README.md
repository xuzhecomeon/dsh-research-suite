# r-medical-stats · 使用与导入说明

> R 语言医学统计与科研绘图通用引擎（双模式）。
> 可直接调用 R 完成统计分析与出图，也可在你没有 R 环境时**生成可直接运行的 R 脚本**。

---

## 一、在 ima（或其他支持 ZIP 导入 skill 的平台）

1. 打开 skill 导入入口 → 选择「导入 ZIP」
2. 上传本包（`r-medical-stats.zip`）
3. 导入后确认能看到 `SKILL.md`，即安装成功

**导入后怎么用**（直接说需求即可，不需要记命令）：

| 你可以这样说 | 技能会做什么 |
|---|---|
| 「帮我分析这份数据，看 XXX 对 YYY 的影响」 | 判断模式 → 生成脚本或直接执行 |
| 「给我一份能算 XXX 的 R 代码」 | 走**模式 B**，生成自包含脚本 + 运行说明 |
| 「帮我画一个 ROC 曲线 / 森林图 / KM 曲线」 | 给出图代码，并说明如何输出可编辑 SVG |
| 「这份数据的基线表怎么做」 | 给出 Table 1 代码 |
| 「我想投稿，图要能改」 | 说明 SVG 出图方案与三格式交付 |

## 二、双模式说明（技能会自动判断）

```
第 0 步：确认有没有 R 环境
├── 有 R（能跑 Rscript）  → 【模式 A 直接执行】
│     环境自检 → 数据质量六道闸门 → 分析 → 出图出表 → 交付文件
└── 无 R（如 ima 网页版） → 【模式 B 生成代码】
      生成六段式自包含脚本 + 运行说明，你在本地 R/RStudio 里跑
```

**★ 两种模式的交付价值是等价的。** 没有 R 不是"做不了"，而是换一种交付方式。

### 模式 A 交付什么

```
Fig1_ROC.svg  / .pdf / .png          ← SVG 可编辑（改字号/颜色/标注）｜PDF 投稿｜PNG 预览
Fig2_calibration.svg / .pdf / .png
Fig3_DCA.svg / .pdf / .png
Fig4_forest.svg / .pdf / .png
Table1_baseline.xlsx                 ← 可编辑表格
Table2_regression.xlsx
results.txt                          ← 全部数值结果
analysis_script.R                    ← 分析脚本（可复核、可修改）
```

### 模式 B 交付什么

一份**六段式脚本**（配置区 / 环境准备 / 读数据+质量检查 / 统计分析 / 出图 / 出表 / 落盘）
+ 一份《运行说明》（含 R 与 RStudio 下载地址、改哪两个路径、5 条常见报错对照）。

**你只需改两处**：数据文件路径、结果输出目录；再改一下变量名。

## 三、★ 关于 SVG（本技能的核心要求）

期刊返修常要求改图的字号、颜色、标注 —— **只有可编辑矢量图能改**。

| 格式 | 用途 |
|---|---|
| **SVG** | ★ **可编辑源文件**（Illustrator / Inkscape 打开，直接改文字与配色） |
| PDF | 投稿用矢量 |
| PNG（300 dpi） | 预览、PPT、备用位图 |
| ~~JPG~~ | ❌ 有损压缩，不要用于投稿 |

**本技能用 `svglite` 而非 R 内置 `svg()`** —— 后者可能把文字转成路径，变成改不了的"死图"。
用 `svglite` 输出的 SVG，文字是 `<text>` 元素，实测效果：

```xml
<text x='228.89' y='283.61' style='font-size: 9.96px; font-family: "Arial";'>
  AUC = 0.871 (95%CI 0.842-0.899)
</text>
```

★ **base 绘图也能出可编辑 SVG**：`rms::calibrate()` 的校准图、`rms::nomogram()` 的列线图、
`gbmt::plot()` 的轨迹图、`plot(survfit())` 的 KM 曲线 —— 用 `svglite()` 设备包起来同样得到可编辑 SVG。
这一点最常被忽略。

**表格不用 SVG**：表格用 DOCX / XLSX（在 Word 里编辑才方便）。

**自检**：`assets/svg_export_helpers.R` 提供 `svg_check()`，可检查 SVG 中 `<text>` 元素数量，
确认为可编辑状态。

## 五、关于数据安全

- **患者数据只在你的本地环境处理**（模式 A 在本地 R 中运行，模式 B 生成的脚本也在本地运行）
- 脚本中不包含任何上传或云同步逻辑
- 若数据含**可识别信息**（如身份证号、完整住院号），建议先脱敏再分析

## 六、常见问题

| 问题 | 解答 |
|---|---|
| 我完全不懂 R，能用吗？ | 能。模式 B 生成的脚本只需改 2 处路径 + 变量名，然后全选运行 |
| 生成的脚本跑报错怎么办？ | 附了 5 条常见报错对照表；仍不行可把报错贴回来 |
| 图能改成中文吗？ | 能。脚本里有 `font_sans` 配置项；中文图需注册中文字体（见 `references/02`） |
| 支持生存分析吗？ | 支持（KM / Cox / 时依 ROC / 校准 / DCA），见 `references/07` §一 |
| 支持 NHANES 这类加权数据吗？ | 支持，见 `references/07` §六（含加权 RCS 的实现） |
| 支持孟德尔随机化吗？ | 支持，见 `references/07` §四（含装不上 TwoSampleMR 时的手写实现） |

## 七、技能的能力边界（如实说明）

**能做的**：描述统计与基线表 · t 检验/方差分析/卡方/秩和 · 线性与 Logistic 回归 · Cox 生存分析 ·
ROC/AUC · 校准曲线 · DCA · 列线图 · RCS 剂量-反应 · 森林图 · 亚组与交互 · 倾向得分匹配与 IPTW ·
克隆删失加权 · E-value · 中介分析 · 重复测量与混合模型 · 缺失数据插补 · 机器学习与 SHAP ·
孟德尔随机化 · 网络药理学富集 · 单细胞分析 · 轨迹模型 · 加权复杂抽样（NHANES/CHARLS） ·
**样本量与效能估算 · 重复测量球对称校正 · 多重比较校正 · 判别分析与 Kappa/ICC/Bland-Altman 一致性 ·
期刊配色与色盲安全出图**（2026-09-29 第一轮，references 20-24 + lib_11，全部实测）·
**R 包选型 · tidyverse 数据整理 · mlr3 工作流 · 临床试验设计与统计 · 科研绘图代码骨架 ·
TRIPOD 报告规范**（2026-09-29 第二轮，references 25-37，152 张卡片全部代码实测）

**需要注意的**：
- 统计方法的选择仍需**专业判断**；技能会给出建议，但研究设计层面的决策（暴露/结局/混杂的界定）应以研究者判断为准
- 模式 A 需要能执行 R 的环境；在纯网页环境会自动转为模式 B
- 生成的代码若未能在本机实测验证，会**如实标注**（不会假装跑过）
- references 25-37 的每张卡片都标注了「库内依据」（来源文件），已用 6 个知识库的完整标题清单（75 837 条）逐条核验，
  **无编造**；库内确实没有的内容（如 NRI/IDI、色盲安全系统材料）已在 `37_IMA知识库主题地图.md` §五 列出缺口清单
- 其中 `35_临床试验设计与统计方法.md` 的 R 代码多为**等价补写**——该库底本以 SPSS/Stata/SAS 菜单操作为主，
  卡片内已逐条标注，非库内原文
- IMA 知识库中的统计学/R 语言订阅库（统计学、一起学统计工具、R语言包等 6 个）受平台权限限制，
  技能只能检索标题定位资料，**读不到正文**——正文需到 ima 客户端阅读（详见
  `~/.workbuddy/standards/06_IMA知识库清单.md` 能力边界表）
