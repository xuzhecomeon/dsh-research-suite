# 交集关系图 (upset)

> 交集关系图是一个用于可视化集合交集及其属性的 R 包，它通过矩阵布局展示集合的交集大小和其他属性

## 文件要求

上传文件：样本文件，首列为对象名称列（示例列名为Name），其余列为集合列，至少包含2个集合列。集合列使用0和1表示对象是否属于该集合，其中1表示属于、0表示不属于；集合列可以继续增加。

## 常规参数

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| data_col | string | 是 |  | 集合列，取值来源于上传文件第一行中除首列外的列名，至少选择2列； |
| color_panel | string | 是 | vik | 颜色面板，枚举：vik、vikO、broc、brocO、bam、bamO |
| decreasing | string | 是 | 降序 | 排序顺序，枚举：降序、升序 |
| width | number | 否 | 8 | 图像宽度(in)，范围：1 ~ 20 |
| height | number | 否 | 6 | 图像高度(in)，范围：1 ~ 20 |
