# 三元组图 (ternary)

> 三元组图通常是指以三元组形式表示的关系图

## 文件要求

上传文件：样本文件，必须包含以下四列——
x：第一组数据；
y：第二组数据；
z：第三组数据；
Group：数据所属的分组。
x、y、z列必须为数值列，Group列必须为分类变量列，每行代表一条观测记录。可以继续增加其他列。

## 常规参数

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| group_col | string | 是 | Group | 分组列，从上传的样本文件中选择分类变量列，用于区分数据所属的分组；默认选择Group列 |
| x_col | string | 是 | x | 第一组，从上传的样本文件中选择数值列，作为三元组图的第一维数据；默认选择x列 |
| y_col | string | 是 | y | 第二组，从上传的样本文件中选择数值列，作为三元组图的第二维数据；默认选择y列 |
| z_col | string | 是 | z | 第三组，从上传的样本文件中选择数值列，作为三元组图的第三维数据；默认选择z列 |
| color_panel | string | 是 | vik | 颜色面板，枚举：vik、vikO、broc、brocO、bam、bamO |
| width | number | 否 | 8 | 图像宽度(in)，范围：1 ~ 20 |
| height | number | 否 | 6 | 图像高度(in)，范围：1 ~ 20 |

## 高级参数

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| title | string | 否 | ternary plot | 标题，最多输入50个字符 |
