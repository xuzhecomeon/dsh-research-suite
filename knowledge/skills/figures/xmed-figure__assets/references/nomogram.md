# 诺莫图 (nomogram)

> 诺莫图（Nomogram），又称列线图，是一种将多因素回归分析结果可视化的工具。它通过将多个预测指标整合到同一平面上，以带有刻度的线段形式展示变量之间的关系。

## 文件要求

上传文件：样本数据：每行代表一条观测记录，至少包含以下三列——
status：结局变量，填写结局或事件状态的分类编码；
time：时间变量，填写随访时间或生存时间；
自变量列：填写用于模型预测的数据，至少包含1列，列名可以自定义，也可以继续增加其他自变量列。

## 常规参数

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| status | string | 是 | status | 结局变量，从上传的样本数据中选择分类变量列，用于表示结局或事件状态；默认选择status列 |
| time | string | 是 | time | 时间变量，从上传的样本数据中选择时间数据列，用于表示每条观测记录对应的随访时间或生存时间；默认选择time列 |
| predictors | string | 是 |  | 自变量，从上传的样本数据中选择用于模型预测的变量列，至少选择1列； |
| width | number | 否 | 8 | 图像宽度(in)，范围：1 ~ 20 |
| height | number | 否 | 6 | 图像高度(in)，范围：1 ~ 20 |
