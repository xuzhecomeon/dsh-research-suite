# 散点图 (scatter)

> 散点图是一种用于展示两个连续变量之间关系的图表类型。它通过在平面直角坐标系上绘制数据点的位置，直观反映变量之间的相关性、分布特征及异常值情况。

## 文件要求

上传文件：样本文件：每行代表一条观测记录，必须包含以下三列——
x：X轴数据，填写连续数值；
y：Y轴数据，填写连续数值；
group：分组数据，填写每条观测记录所属的分类分组。可以继续增加其他数据列。

## 常规参数

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| xcol | string | 是 | x | X轴列，从上传的样本文件中选择连续数值列，用于设置散点的横坐标；默认选择x列 |
| ycol | string | 是 | y | Y轴列，从上传的样本文件中选择连续数值列，用于设置散点的纵坐标；默认选择y列 |
| group | string | 是 | group | 分组列，从上传的样本文件中选择分类变量列，用于区分数据点所属的分组；默认选择group列 |
| point_size | number | 否 | 3 | 点大小，范围：1 ~ 10 |
| width | number | 否 | 5 | 图像宽度(in)，范围：1 ~ 20 |
| height | number | 否 | 4 | 图像高度(in)，范围：1 ~ 20 |

## 高级参数

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| x_title | string | 否 | X-axis | x轴标题，最多输入50个字符 |
| y_title | string | 否 | Y-axis | y轴标题，最多输入50个字符 |
| title | string | 否 | Scatter Plot | 图片标题，最多输入50个字符 |
