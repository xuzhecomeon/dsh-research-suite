# 交付前自检清单（Checklist）

每次交付 AI 绘图产物前，逐项核对；任一项不过，不得交付。

## A. 内容层
- [ ] **全英文**：图中零中文（含面板标题、步骤名、图例、注释）
- [ ] **无遗留问题**：无文字残影、无乱码符号、无元素越界/压框、无重叠遮挡
- [ ] **机制准确**：重绘版的关键分子/步骤/因果链与论文原文一致（位点、因子名、方向不能错）

## B. 结构层
- [ ] **文字活字**：AI 中双击任意标注可改字（非轮廓）
- [ ] **语义分组**：图层/图层面板中可见命名组（细胞、囊泡、箭头、文字、背景…）
- [ ] **符号矢量**：对勾/叉号/下标等为 path 图形，非 Unicode 字符

## C. 视觉层
- [ ] **临摹版**：与原图逐元素比对，形态/颜色/位置一致
- [ ] **重绘版**：插画级（多层渐变、投影、高光、细胞器细节齐全），不得简陋
- [ ] **排版**：面板边框对齐、间距均匀、标题不截断、图例完整

## D. 交付层
- [ ] **.ai 产出**：`ai_build.jsx` 可一键生成（列出 JOBS 清单）
- [ ] **预览导出**：AI 内渲染的 `*_aiview.png` 已核对
- [ ] **脚本位置**：脚本在工作目录，未污染 AI 脚本菜单
- [ ] **skill 回写**：本次新增的标准/坑/组件已更新到 `ai-figure-studio`

## E. 渲染验证命令
```bash
# 布局自查（浏览器渲染为唯一可靠标准）
"C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless --disable-gpu \
  --screenshot="check.png" --window-size=W,H --hide-scrollbars "file:///<绝对路径>.svg"
```
