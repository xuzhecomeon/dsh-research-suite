# 医学绘图科学准确性与视觉惯例

图形不仅要好看，更要科学正确。本文件列出常见结构的"画对要点"与视觉语义惯例。

## 细胞器画法要点（科学准确性）

| 结构 | 必须画出的特征 | 常见错误 |
|---|---|---|
| 细胞核 | 双层核膜、核孔、核仁 | 画成单层圆圈 |
| 线粒体 | 外膜光滑+内膜向内折叠成嵴 | 嵴画成横线而非折叠 |
| 高尔基体 | 3–7 层扁平弓形囊+出芽囊泡 | 画成实心圆饼 |
| 粗面内质网 | 膜表面附着核糖体颗粒 | 与滑面内质网混用 |
| 溶酶体 | 单层膜+内部点状水解酶 | 画成双层膜 |
| 细菌 | 无核膜（拟核）、细胞壁 | 画出具核膜的"原核细胞" |
| 病毒 | 核酸核心+衣壳（+包膜刺突） | 画成普通细胞 |
| 红细胞 | 双凹圆盘（中心色浅） | 画成实心红球 |
| 中性粒细胞 | 分叶核（2–5 叶） | 画成单个圆核 |
| 淋巴细胞 | 大圆核几乎占满细胞 | 核过小 |

## 视觉语义惯例

- **膜**：双排磷脂头+尾部（membrane_patch），或圆角粗线（membrane_boundary）。
- **受体**：跨膜蛋白，胞外段大、跨膜段细、胞内段中等；配体画成小圆点靠近胞外段。
- **离子通道**：开放=通道贯通并画离子穿过；关闭=通道口闭合。
- **抗体**：Y 形，两臂顶端为抗原结合位；结合抗原时在臂端画小圆（复合物）。
- **磷酸化**：在目标蛋白旁加黄色 "P" 圆点 + ATP→ADP 箭头。
- **泛素化**：目标蛋白串多个紫色 "Ub" 小圆 → proteasome → 降解。
- **复合物**：两形状靠近后用 binding（汇聚线）或直接重叠+虚线圈 group_box。

## 箭头语义（信号通路图核心）

| 箭头 | 含义 | 参数 |
|---|---|---|
| 实线+实心三角头 | 激活/促进/转化 | `kind="activation"` |
| 实线+末端短横杠(T) | 抑制/阻断 | `kind="inhibition"` |
| 虚线+箭头 | 易位/间接作用/释放 | `kind="translocation"` |
| 双向箭头 | 可逆反应/互作 | `kind="bidirectional"` |
| 弧形箭头 | 反馈、跨步骤 | `curve=±0.5`（正值弯向行进方向左侧） |

## 组织学（H&E 意象）配色惯例

用颜色模拟切片染色观感（本库为示意画风，非仿真染色）：

- 细胞质/间质：粉橙系（C["orange_l"], C["red_l"]）
- 细胞核：蓝紫系（C["purple_l"], C["purple"]）
- 胶原纤维：浅粉/浅橙波浪线
- 红细胞：鲜红小圆（C["red_l"]+C["red"] 描边）
- 腺体/黏液（杯细胞）：浅黄椭圆
- 上皮三层：单层扁平=squamous（极扁）、单层立方=cuboidal、单层柱状=columnar（加纹状缘 microvilli 或纤毛 cilia）

## 胚胎学系列图惯例

- 发育时序：受精→卵裂→桑椹胚→胚泡→植入，用 step_badge 编号 + 时间轴箭头串联。
- 卵裂球用小圆簇，胚泡=blastocyst（滋养层外圈+内细胞群），植入用 skin_section 作子宫内膜背景。
- 标注用 leader_label，避免文字压图形。
- 双胚层/三胚层分化用 group_box 分区 + 向下分支箭头。

## 中文标注排版

- 引线标注（leader_label）：线不穿过图形，文字带白色光晕（halo）保证可读。
- 标注统一放图形上方或右侧，同图内位置风格一致。
- 图题居中置顶（c.title），图例置底（legend_row）。
- 中文字体固定 SimHei；中英混排时库自动选择。
