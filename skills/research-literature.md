# 文献检索、筛选、精读与证据核验（research-literature）

本文件是 literature 域 11 张能力卡的融合 SOP。每张卡在 `data/capabilities/literature.json` 里有机器可读定义，本文件负责讲清「为什么这样排、做到什么程度算够」。

## 一、本域边界

- **找**：把研究问题拆成概念块，产出各库可粘贴的检索式与可复现的检索记录（库名、检索式、日期、命中数、去重后数）。
- **筛**：按预设标准做题摘与全文两级筛选，双人独立加第三人仲裁，产出 PRISMA 2020 数字自洽的纳入集与三份分组题录。
- **读**：单篇精读到「声称—证据」逐条对上，方法弱点点名到具体设计选择，材料不足就整节标不可评估。
- **评**：按设计选 RoB 2、ROBINS-I、Newcastle-Ottawa 或 AMSTAR 2 做偏倚风险评价，按 GRADE 给证据强度并写清升降级理由。
- **管**：文献库去重合并、题录补全、附件挂接、按下游格式导出；核验参考文献真伪与主张—原文一致性。
- **交界**：本域只交「要引什么」和「证据能不能站住」。参考文献表怎么排、正文编号怎么上标、图表题注、投稿包、期刊要求解析一律转 `research-format`。本域不做查重、不承诺查全率、不替用户编造或补全任何文献字段。

## 三、融合协议

下面每一节对应一张能力卡。步骤名后的括号是协作技能，箭头后是可机械判定的完成标志。

### 3.1 检索式构建（`pubmed-database` + `reference-retrieval-skill` + `qinyan-paper-search`）

1. **拆概念块** → 人群、干预或暴露、对照、结局四块，每块列中文原词、英文对应词、缩写与同义词。块数控制在二到四；超过四个说明问题还没收束，回到研究问题而不是堆 AND。先把概念块表给用户确认。
2. **建主题词表** → 每块查 MeSH 并记树状号与是否含下位词。`[mh]` 会自动带下位词，选了上位词就别重复列下位词。副主题宁少勿多：它是强限定，多一个常常把命中砍半。
3. **配自由词与截词** → 题名摘要自由词用 `[tiab]`；截词至少截到四个字母之后（`therap*` 会带出 therapist 与无关词）；英美拼写变体各写一遍。中文库没有截词，改穷举同义词与「症／病」「术／治疗」这类同义后缀。
4. **查全查准分两步** → 先跑查全版（块内 OR、块间 AND、零限定）记命中数；再逐条叠限定（`[pt]` 研究类型、`[dp]` 年份、`[la]` 语种、`[sb]` 免费全文、`[ti]` 标题限定），每叠一条记一次命中数变化。查全版几千到上万条属正常，叠完限定落到几百到两千便于人工筛。
5. **库间改写** → PubMed 用 `[tiab]`／`[mh]`；Embase 用 `:ti,ab` 与 `/exp`；Web of Science 用 `TS=` 与 `#1 AND #2`；CNKI 与万方用「主题＝」「题名＝」。每库检索式单独成行。把 PubMed 式原样粘到 WoS 会得到零结果。
6. **预试校准** → 每库跑一次登记命中数与检索日期；命中过少或过多按「去 AND 加 OR、补同义词、换上位或下位词」调三轮。三轮不到位就如实回报「可检索文献量可能确实很少」，不要继续加词硬凑。

### 3.2 检索可复现记录（`literature-review` + `ars-sr-screener` + `biomed-literature-pipeline`）

1. **冻结快照** → 检索式、检索日期、平台与界面（网页高级检索或 API）、字段与限定逐条抄成日志头部的快照。此后调参另起 v2 并保留 v1。快照要能被第三方原样粘贴执行。
2. **逐库登记** → 库名、检索日期、检索式编号、命中数、导出格式与文件名。原始导出另存 `search/` 目录，文件名含库名与日期。注意各库单次导出上限（PubMed 网页版单次最多一万条）。
3. **去重登记口径** → DOI 优先、题名加年份兜底；登记去重前、去重后与删除数；预印本与正式版算同一研究但保留正式版题录。必须满足「去重前＝去重后＋删除」。
4. **建数字链** → 各库命中与其它来源、去重、题摘筛除、全文获取失败、全文筛除（按原因分类）、最终纳入。全文获取失败是独立环节，不能并进排除数。
5. **出附录** → 每库一段检索附录、去重与筛选数字表、原始导出目录清单，以及可直接粘进方法学的文字。方法学段里的每个数字都要能在附表指到单元格。

### 3.3 双人筛选与 PRISMA（`ars-sr-screener` + `ars-deep-research` + `literature-review`）

1. **先定标准再筛** → 标准写成可判定条目，每条给出达标、不达标、信息不足三种判法；顺序把最客观最便宜的先判（类型、语种、年份、人群），主观的放后；用户确认后开筛。协议变更要写修订记录并重筛受影响记录。
2. **试筛校准** → 抽二十到三十条（含人工已判的种子文献）对账；漏判任一条应推进的记录就停下来改标准，不进全量。种子文献要含两三篇最终纳入的。
3. **题摘独立双筛** → 只判能否从题摘断定达标；达标与信息不足都推进，明确不达标才排除；只有全文才能判的标准禁止在题摘用；两人互不可见。
4. **全文复筛单码排除** → 每条排除只给一个排除码，取协议序第一条失败项，理由十五词以内；全文获取失败单列。
5. **仲裁与一致率** → 一方推进一方排除交第三人重读，平局倾向推进；双方都排除的抽样复核（默认一百条或全量）；报观察一致率、Cohen kappa 与 PABAK 三个数（极端纳入率下 kappa 会被压低）。
6. **数字自洽与交付** → 先去重后＝题摘筛除＋进入全文＋全文获取失败＋全文排除＋纳入这条等式自查，再出流程图与筛选日志，三份题录分别导出。

### 3.4 单篇精读（`nature-paper-card` + `literature-close-read` + `aris-alphaxiv`）

1. **定定位能力** → 抽得出可靠页索引为页级定位；只能靠章节图表为结构级（禁止页码）；只有摘要元数据为材料受限（禁止页码与未见内容推断）。判定结果写在笔记抬头。
2. **建证据清单** → 七项逐项抄：元数据、研究问题与声称贡献、方法与数据流、每个主图主表在论证中的角色、实验与基线指标消融、作者自陈局限、稳定指针。数字与超参逐字抄，文本没写就写「未指定」。先抄方法与结果再连背景与结论。
3. **建声称—证据矩阵** → 逐条列核心声称、对应到具体证据、标缺口（证据不足／只在某子集成立／只在作者自有数据上成立）。摘要里的强断言常常只对应有限子集。
4. **批判性评价** → 「样本量小」不算弱点，「样本量二十四且单中心，中心效应与处理效应无法分离」才算。每条标作者自陈还是读者推断；缺席主张要写清查过哪些章节。
5. **分节写作** → 材料不足的节整节标「现有材料无法评估」；作者陈述与评读者分析分小节；图表按原文编号引用，不重编号。
6. **交付前核对** → 逐条把断言回指到原文位置，指不到就删或降级；核对页码引用与定位级别一致。

### 3.5 偏倚风险与证据分级（`ars-deep-research` + `scientific-critical-thinking` + `literature-review`）

1. **按设计配工具** → 随机对照用 RoB 2 五域；非随机干预用 ROBINS-I 七域；观察性用 Newcastle-Ottawa；系统综述用 AMSTAR 2 十六项。同一篇只有一个主工具。「拿观察性量表评随机对照」会给不出分配隐藏与盲法，属错配。
2. **逐域判读留证** → 每域先判定再写依据（原文哪句、哪张表、哪个数字）。未报告不等于低风险：RoB 2 关键域未报告通常判「有一些担忧」。
3. **汇总与分歧** → 研究级评级取最严重的关键域，不是各域平均；分歧讨论到有依据为止，仍不一致就并列报告。
4. **GRADE 分级** → 随机对照起高、观察性起低；降级五项（偏倚风险、不一致性、间接性、不精确性、发表偏倚）与升级三项（效应量大、剂量反应、混杂反向）逐项记理由。不精确性看区间是否跨过决策阈值，不看样本量。
5. **交付与声明** → 分项评级表、证据概要表、方法学说明；声明评价者人数、独立性与 AI 参与；无法评价的单列并说明原因。

### 3.6 证据矩阵（`ars-deep-research` + `literature-review` + `xlsx`）

1. **定行列** → 研究标识、设计、样本量与人群、干预或暴露、对照、主要结局与效应量、随访、质量评级、与本综述的关系。列数十到十四，超出说明维度没收敛。行是研究不是论文，同研究多篇发表合并成一行。
2. **逐篇填表标空** → 原文没报填 NR 而不是留空；单位不同时原格留原值、另设换算列；效应量方向在表头统一约定。
3. **质量列对接评价** → 直接引偏倚风险结果并保留工具名；两种工具分列。只有高中低没有工具名的质量列无法解释。
4. **表下归纳** → 三到五条从矩阵读出的结论：结局方向是否一致、谁是唯一反例、哪个亚组证据稀薄；每条点名到具体行，不引入表外信息。
5. **交付** → `.xlsx`（冻结首行、按设计分组、NR 底纹）加 Markdown 摘要版，附列定义与 NR 统计。

### 3.7 综述骨架（`scholar-lit-review` + `ars-deep-research` + `deep-research`）

1. **冻结综述问题与理论视角** → 一句话写清问题、视角与综述类型（叙述性／范围综述／系统综述）。冻结后发现缺某类文献要回检索补，不是改问题迁就材料。
2. **建领域全景图** → 主要脉络、方法传统、被反复引用的奠基工作、近三年新方向；格子数六到九，标注代表文献与数量。
3. **归类到主题** → 按论证关系而非主题词字面归类；主题三到五个，每个必须有内在争点（两个以上研究给出不同结论或解释）；同一研究进多个主题要注明复用。
4. **写共识与争议** → 共识是什么、争议在哪、薄弱在哪；不一致双向披露并比较证据质量（一项大样本高质量研究不等于三项小样本研究的「多数意见」）。薄弱处具体到设计或人群，不写「尚需进一步研究」。
5. **排骨架与承接** → 主题顺序按「现象到机制／共识到分歧／方法到应用」选一种全篇一致；每节写过渡句；节末缺口要能接住后续研究。
6. **引文核对** → 骨架里每条断言挂引文位，交付前逐条核对「这篇是否真的说了这句」；核不过的改断言强度或换文献。

### 3.8 Meta 数据提取（`ars-deep-research` + `literature-review` + `scientific-critical-thinking`）

1. **定结局与效应量** → 二分类用 OR／RR／RD，连续用 MD／SMD，时间事件用 HR；同一结局全篇只用一种；方向在表头约定。OR 与 RR 不能直接合并，事后换算会引入误差。
2. **抽数值与样本** → 各组例数与事件数，或均值标准差与样本量；效应量与百分之九十五区间；调整变量；随访时长；分析集（意向性／符合方案）。能抄原始计数就不抄已算好的效应量。
3. **换算统一** → 缺标准误由区间反算（前提是百分之九十五区间），缺标准差按方案换算或由中位数四分位数推，单位统一。每条留公式与输入值，换算列与原始列并排。
4. **识别重复发表** → 同队列、同注册号、作者与中心重叠者只留信息最全或样本最大的一篇并记理由；设计或人群差异过大的标不可合并，留在表里不消失。重复计数会人为缩小可信区间。
5. **提取表可核** → 加原文定位列（表几或图几）；不要合并单元格、不要在数值列混单位文字；能直接导出 CSV 进统计软件。
6. **一致性核查** → 用提取表重算效应量与区间与原文比；双人独立提取分歧率应在百分之五以下；核查结果写进方法学段。

### 3.9 引文追踪与查全（`openalex-database` + `aris-semantic-scholar` + `scholar-monitor`）

1. **定种子与方向** → 二到五篇奠基加最新的关键文献；向后（参考文献找奠基）与向前（被引找发展）分开跑。
2. **向后追溯** → 抓种子参考文献与已有结果集比对，登记「由哪篇种子引出」；同一篇被多篇种子引出只登记一次，否则新增数虚高。
3. **向前追溯** → 按被引频次与年份分层，重点近三年高被引与怀疑漏检的期刊；命中过多按阈值或期刊白名单截断并写明规则。被引数只作导航不作质量证据。
4. **相关文献与灰色文献** → 相似文献推荐补一轮；灰色文献按类型查：预印本平台、会议论文、学位论文、试验注册库、机构报告；每类登记来源与检索日期。预印本要判断是否有正式版。
5. **增量判定与回写** → 去重算新增数与新增率；每条新增标注来源路径；新增率过高（如超原集两成）说明原检索式不合格，应回报重跑；最后回写检索式补词建议。

### 3.10 文献库管理（`pyzotero` + `citation-manager` + `scholar-rag`）

1. **先探明规模** → 库类型（个人／群组）、条目总数、集合结构、附件是否挂接。接口默认每页二十五条、条目列表默认一百条，不翻页会以为库里只有一百条。写操作必须走 Web API，本地接口只读。
2. **定去重规则** → DOI 主键；题名加年份加第一作者次键；缺 DOI 时题名归一化后比（去标点、去副标题、转小写）。合并时把标签、笔记、附件挂到保留条目上，并留合并记录可回滚。
3. **补全纠错** → 按 DOI 拉权威元数据逐字段比对写回，冲突以权威记录当前值为准并记差异。写回前先备份。中文文献在英文元数据源收录不全，另走中文库。
4. **附件与结构** → PDF 按条目挂接、文件名统一；标签体系在主题／方法／用途里选一种，不要混用；需要语义检索时再建索引。
5. **导出交付** → LaTeX 给 BibTeX，EndNote 与 Zotero 给 `.ris`，没有软件的用户给按样式排好的文本；导出后抽十条核对字段完整性。

### 3.11 引用真伪核查（`nature-ref-verifier` + `reference-verification` + `aris-citation-crosscheck`）

1. **先解析 DOI** → 最便宜的一步。解析失败＝编号错或不存在；解析成功但题名作者不符＝编号指向另一篇（实测里这类「张冠李戴」比完全虚构更常见）。分三堆：一致、不符、无法解析。
2. **多源补验** → 学术检索、语义索引、CrossRef、PubMed 顺序补验；中文文献转中文库，学位论文查机构库；命中即停并记录来源链接与访问日期。
3. **字段级比对** → 严重：作者姓名或顺序错、漏作者、页码差五页以上、文章号字母误读（T/7、l/1、O/0）、编号指向他文；中：卷年不符、电子预出版漂移、缺期号、页码小差；轻：大小写与缩写。文章号字母误读必须与原始记录逐字符比。
4. **主张与原文一致** → 第二层：这条文献是否真的支持这句话（不止主题相关）；结论是否越过原文限定（人群、剂量、因果强度）；把「相关」写成「导致」列严重。
5. **问题代码** → 每条给唯一代码（虚构／题名错／作者错／出处错／编号错／已撤稿／掠夺性期刊／无法核验／格式问题）；无法核验与虚构必须分列——前者是能力边界，后者是诚信问题。
6. **批量策略** → 十条以内全核；十一到三十条逐条精简；三十条以上重点核可疑条目加抽样并写明比例。可疑线索：作者组合不常见、刊名像真的但查不到、编号格式对但解析不到、年卷期数字特别整。

## 四、判据与红线

### 4.1 硬红线（违反即返工）

- **参考文献必须真实可查**：每条要有作者、题名、刊名、年、卷（期）、页码与 DOI 或 PMID。**严禁编造**，也不许把「无法核实」当灰色地带放行——确认不了存在就不进交付。
- **检索类交付必须附检索式与检索日期**，缺一即不合格。
- **候选筛选数字必须自洽**：去重后＝题摘筛除＋进入全文＋全文获取失败＋全文排除＋纳入。
- **不得把 AI 判定报成人工筛选**：方法学段必须披露 AI 参与与人工复核比例。
- **不得新增用户未提供的文献字段**（核验到的一致值除外）。
- **期刊选择不得给影响因子、审稿周期、录用率数字**——须现查。
- **不得假定用户装了任何文献管理软件或统计环境**：写成「若有则用其导出，否则给可直接粘贴的格式化文本／纯表」。

### 4.2 分场景判据（若…则…否则…）

- **若**用户要做系统综述或 Meta 分析，**则**走 `pubmed-database` 多库检索式加逐库命中数与日期；**否则**（只要开题清单）用五字段检索记录块即可，不加 PRISMA 全流程。
- **若**主题是中文社科、政策文本或地方研究，**则**走万方与中文原生库；**否则**直接套 PubMed 会因英文生物医学为主而得到零结果。
- **若**命中量过大且只要近三年，**则**叠年份与标题限定并保留查全版备份；**否则**（删同义词缩检索式）永久丢失文献且不可追溯。
- **若**团队有两个人，**则**双人独立加第三人仲裁；**否则**（单人）单筛加至少二十条抽样复核并如实披露，不许声称双人独立。
- **若**排除原因要进论文表格，**则**唯一排除码按协议序取第一条失败项；**否则**多原因会让排除分布重复计数、总和与排除数对不上。
- **若**手上只有摘要，**则**整段标材料受限、方法评价写不可评估；**否则**凭常识补评价一旦被引用就是编造。
- **若**研究全是随机对照，**则**RoB 2 加 GRADE 起始高；**否则**用观察性量表会漏掉分配隐藏与盲法，系统性低估偏倚。
- **若**纳入研究以观察性为主，**则**GRADE 起始低并重点评混杂；**否则**不能靠「本领域都这么做」上调等级。
- **若**某项关键指标多数研究未报告，**则**表下标 NR 比例并降级该结局；**否则**用间接推算填满表格＝数据造假。
- **若**怀疑同队列多篇发表，**则**按注册号查重只留一篇；**否则**重复计数会把不显著做成显著。
- **若**稿件经过 AI 补引或整篇生成，**则**全量逐条核且 DOI 优先；**否则**抽检几乎必然漏掉「真作者配假题名」这类元素混拼。
- **若**无法联网，**则**只做格式与内部一致性检查并把存在性核验列成待办；**否则**凭记忆判断会把真假都判错。

### 4.3 机械可查的交付门（写进 gate 的那些）

| 关卡 | 机械判定 |
|---|---|
| 检索式 | 每库命中数与检索日期齐备；查全版与查准版分列；概念块数二到四 |
| 检索记录 | 去重前＝去重后＋删除；各环节逐级可加总；原始导出按库名与日期落盘 |
| 筛选 | 三份题录条数之和＝去重后总数；排除码唯一；一致率三个数齐备 |
| 精读 | 回指失败数＝0；结构级与材料受限下页码引用数＝0；无出处数值数＝0 |
| 偏倚风险 | 工具与设计错配数＝0；每域有依据；无理由升降级数＝0 |
| 证据矩阵 | 空白单元格数＝0；方向混乱数＝0；行数＝独立研究数 |
| 综述骨架 | 主题数三到五；无引文断言数＝0（过渡句标注除外）；万能句数＝0 |
| Meta 提取 | 缺效应量或区间的研究数＝0；同队列计数＝1；表可导出 CSV |
| 引文追踪 | 每条新增有来源路径；两路不合并计数；灰色文献按类型分列 |
| 文献库 | 重复 DOI 数＝0；抽十条字段完整；未停在默认一百条 |
| 引用核查 | 无法核验与虚构分列；三段报告齐备；抽样比例已写 |

### 5.2 PubMed 检索式模板（含查全与查准两层）

```text
#1  "Diabetes Mellitus, Type 2"[Mesh] OR "type 2 diabetes"[tiab] OR "type II diabetes"[tiab]
    OR T2DM[tiab] OR NIDDM[tiab]
#2  "Exercise Therapy"[Mesh] OR exercise*[tiab] OR "aerobic training"[tiab]
    OR "physical activity"[tiab]
#3  "Glycated Hemoglobin A"[Mesh] OR HbA1c[tiab] OR "glycemic control"[tiab]
    OR "glycaemic control"[tiab]
#4  #1 AND #2 AND #3                      ← 查全版，先单独跑并记录命中数
#5  #4 AND ("2015/01/01"[dp] : "3000"[dp])
#6  #5 AND (randomized controlled trial[pt] OR controlled clinical trial[pt])
#7  #6 NOT (letter[pt] OR editorial[pt] OR comment[pt])
```

- 字段标签：`[mh]`（含下位词）、`[majr]`（主要主题）、`[tiab]`、`[pt]`、`[dp]`（可写区间）、`[la]`、`[au]`、`[1au]`、`[vi]`、`[pg]`、`[pmid]`、`[doi]`、`[pmc]`、`[sb]`（如 `free full text[sb]`）。
- 限速：无 API key 每秒三次、有 key 每秒十次。单次显示上限一万条；剪贴板五百条八小时过期，检索历史也八小时过期。
- 交付时把 `#4`、`#6` 与各步命中数一并登记，注明检索日期与平台。

### 5.3 CNKI 检索式模板（专业检索语法）

```text
(SU='2型糖尿病' + SU='Ⅱ型糖尿病' + SU='T2DM')
* (SU='运动疗法' + SU='有氧运动' + SU='运动干预')
* (SU='血糖控制' + SU='糖化血红蛋白' + SU='HbA1c')
```

- `SU=` 为主题，`TI=` 为篇名，`KY=` 为关键词，`AB=` 为摘要；`+` 为 OR，`*` 为 AND，`-` 为 NOT。
- 限定项（在高级检索面板里设置，不要写进检索式）：时间 2015-01-01 至今、来源类别（北大核心／CSSCI／CSCD）、文献类型（期刊／学位论文／会议）。
- 中文库没有截词与主题词自动扩检，必须穷举同义词与全半角变体；繁体与异体字（如「Ⅱ型」与「II 型」）各检一次。
- 万方用「主题:」与「题名:」字段，逻辑符用 `*`／`+`／`-`，与 CNKI 相近但不完全一致，需分别试跑。

### 5.4 PRISMA 2020 数字核对表

| 环节 | 定义 | 计数 | 关系校验 |
|---|---|---|---|
| 数据库命中 | 各库分别记 N₁…N_k | N₁…N_k | 每库附检索日期与检索式编号 |
| 其它来源 | 引文追溯、灰色文献、专家推荐 | N_other | 与数据库命中分开，不合并 |
| 去重删除 | DOI 优先、题名兜底 | d | — |
| 去重后 | 进入筛选的总量 | R | R ＝ ΣN_i ＋ N_other － d |
| 题摘排除 | 明确不达标（含排除码分布） | e_ta | — |
| 进入全文 | 题摘后推进的数量 | T | T ＝ R － e_ta |
| 全文获取失败 | 单列，不进排除 | e_na | — |
| 全文评估 | 实际读完的全文 | F | F ＝ T － e_na |
| 全文排除 | 按唯一排除码分类 | e_ft | Σ（各码计数）＝ e_ft |
| 最终纳入 | 进入综合与 Meta | k | k ＝ F － e_ft |

**总校验式**：ΣN_i ＋ N_other ＝ d ＋ e_ta ＋ e_na ＋ e_ft ＋ k。差一条就说明有记录落在环节之外。

### 5.5 精读笔记结构（页级／结构级／材料受限三态通用）

```text
定位级别：page-grounded | structure-grounded | source-limited
01 元数据（作者、年份、刊名、DOI、版本/预印本状态）
02 研究问题与作者声称的贡献（抄原文，加锚点）
03 方法组件与数据流（数据集、样本量、预处理、模型/统计方案）
04 各主图主表在论证中的角色（每张图支撑哪条声称）
05 实验设置（基线、指标、消融、超参；未写写 Not specified）
06 结果（数字逐字抄，含区间与单位）
07 作者自陈局限（引号＋锚点）
08 评读者推断的弱点（点名设计选择＋失效条件）
09 声称—证据矩阵（声称 / 证据 / 缺口）
10 不可评估项清单（为什么不可评估）
```

### 5.6 证据矩阵列定义（十到十四列）

| 列 | 填法 |
|---|---|
| 研究标识 | 第一作者＋年份；同研究多篇发表合并成一行并注明来源 |
| 设计 | 随机对照／队列／病例对照／横断面／系统综述／定性 |
| 样本与人群 | N 与关键纳排特征；跨研究用同一口径描述 |
| 干预或暴露 | 剂量、时长、实施方式 |
| 对照 | 常规照护／安慰剂／无对照 |
| 主要结局与效应量 | 原始值＋效应量＋百分之九十五区间 |
| 随访 | 时长与失访率 |
| 质量评级 | 工具名＋总体评级（两种工具分列） |
| 与本综述的关系 | 支持／反驳／方法参照／背景 |
| NR 备注 | 未报告项统计，避免空白被读成遗漏 |
