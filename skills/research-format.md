# 投稿格式、参考文献排版与交付（research-format）

本文件是 format 域 7 张能力卡的融合 SOP。机器可读定义在 `data/capabilities/format.json`，本文件讲清排序理由与判定标准。

## 一、本域边界

- **排文献**：把题录按 GB/T 7714-2015 或目标期刊样式排成参考文献表，缺字段显式标注而不猜；正文编号与文末表双向对齐，中文语境正文编号一律上标。
- **套格式**：按目标期刊或学校模板统一字体字号、页边距、行距、标题层级、三线表与图件规格，逐项对表打勾。
- **组投稿包**：正文、图表分文件、补充材料、伦理与利益冲突与数据可得性与 AI 使用声明、cover letter，按刊约命名与归档。
- **给建议而不是数字**：可给候选期刊清单、匹配理由、字数与结构差距、改投阶梯；**不给影响因子、审稿周期、录用率数字**，要用就去官网或权威索引现查。
- **软件中立**：不假定用户装了 Zotero、EndNote 或任何排版工具。有则用其原生路线（域代码、样式库），没有就给可直接粘贴的格式化文本或纯表格。
- **交界**：本域收 literature 域交来的「要引什么」，负责「怎么排」。文献是否真实存在、检索是否查全、证据是否成立，一律回 `research-literature`。

## 三、融合协议

### 3.1 参考文献表格式化（`paper-reference-formatter` + `qinyan-citation` + `chinese-medical-paper-writer`）

1. **先定样式与样式源** → 国标、温哥华、AMA、APA 或某刊自定义。有投稿指南就读指南里的参考文献示例；没有就让用户给两三条范例反推规则（标点、大小写、作者截断），写成样式卡。样式未定不排。
2. **解析字段判类型** → 作者、题名、载体、年、卷、期、页、DOI、类型。类型按载体保守推断：有连续卷期页为期刊，有出版地与出版社为专著，有学位与授予机构为学位论文，有会议名与会期为会议论文，只有链接与访问日为电子资源。
3. **排条目标缺字段** → 缺字段用占位或省略号，绝不估算。补一个看起来合理的卷号是最不可原谅的错：读者按这条查不到，等于制造假文献。缺失比例统计出来，超过两成说明题录来源有问题。
4. **作者与标点规范** → 三人以内全列，超过三人列前三加「等」或「et al」；中文作者用「等」、英文作者用「et al」，不混用；DOI 按样式写在页码之后或归一为链接形式；标点按语言分全角半角。
5. **一致性核对与交付** → 同类型格式一致、作者顺序未改、编号连续、未混两种样式；交付表加逐条待核清单。作者顺序绝对不能改，改了等于换署名。

### 3.2 正文引用与编号体系（`scholar-citation` + `chinese-medical-paper-writer` + `academic-reference-enhancer`）

1. **判体系与语言** → 顺序编码制还是著者出版年制；中文期刊正文编号一律上标，英文按样式决定。**同一篇文章不得混用两种体系**——同段里出现上标编号与括号作者年，会被判未按稿约准备。
2. **按首次出现定编号** → 顺序编码制按正文首现编号，同一文献全篇只用一个编号；多处合并按编号升序，连续三篇以上用连接号、不连续用逗号。
3. **处理上标** → 中文语境正文所有引用编号设为上标（含合并与区间），位于被引内容之后、句末标点之前；图表题注与脚注同样处理；**参考文献表的编号保持正常字号**（这两个位置规则相反，最容易搞错）。
4. **著者出版年制** → 正文写作者加年份（两位用「和」，三位以上用「等」或「et al」），同作者同年加 a b c 并在文末表同步；文末表按姓氏排序，中文按拼音或笔画并说明。
5. **双向核对** → 跑三件事：正文编号都在文末表、文末表每条都被引用、编号连续无跳号。修完再跑直到三类问题归零。这一关不能靠通读。
6. **交付与交接** → 另存新版本不覆盖原文件；附核对报告（三类问题前后数量）；把编号体系与样式来源交代给下游。

### 3.3 软件桥接与域代码（`format-references-zotero` + `format-references-endnote` + `citation-manager`）

1. **先问软件再动手** → 有没有安装、哪一款、哪个版本。装了走域代码路线；没装直接给格式化文本并说明手工增补方式。**把「你先装个 Zotero」当方案是把工具门槛转嫁给用户。**
2. **统一引用标记** → 编号、PMID、DOI 或作者年占位统一成一种可批量处理的标记；归一保留原对应关系，不按顺序重排，否则引文错位。
3. **生成域代码或占位符** → Zotero 生成原生域代码并把文末做成可刷新文献表域（首尾成对，只生成引文域刷新会报错）；EndNote 生成未格式化引文占位符加导入文件，占位符与源文件题名必须用同一归一化串（希腊字母转拉丁、智能引号转 ASCII、破折号转连字符、去方括号、去逗号、去尾句点）。
4. **源文件与缓存** → 同时导出 `.ris` 并缓存元数据；抓取失败的条目显式列出，**不许静默丢弃**——静默丢弃是最坏的失败方式：文档看起来生成成功，实际少了几条文献。
5. **交付与刷新说明** → 新 docx（不覆盖原件）、`.ris`、缓存、失败清单、刷新步骤与前提（软件须运行、样式须先装、联网才能拉元数据）。失败项给替代方案。

### 3.4 图表与题注核查（`venue-templates` + `chinese-medical-paper-writer` + `scientific-visualization`）

1. **取期刊图表要求** → 图数量上限、是否合并图表计数、分辨率与色彩模式、可接受格式、图注长度与要素、是否单独文件、双盲是否去标识。要求抄成清单逐项打勾；典型值会随改版变化，必须回稿约复核。
2. **核查表格** → 三线表（顶线、栏目线、底线，无竖线）；表题在上方含表序、表注在下方；表内小数点对齐；单位写在栏目头而非每格；缩写首现给全称；**表格必须是可编辑文本，截图表是硬伤**。
3. **核查图件与题注** → 分辨率（照片三百 dpi 起、线条图更高）、色彩模式（印刷 CMYK、在线 RGB）、格式（TIFF／EPS／PDF）、单栏或双栏尺寸、缩放后文字可读；题注含图序、一句话结论、方法或条件、缩写说明、统计信息与误差棒含义。误差棒不说清是标准差还是标准误等于没给。
4. **编号与引用一致** → 编号连续、正文引用一一对应、图表放首次提及段之后、补充材料单独编号（S1、S2）；删图后要重排后续编号。
5. **交付核查表与重做清单** → 逐项表（要求／现状／达标／修法），修法具体到操作（导出三百 dpi TIFF、单位移到栏目头、补误差棒含义）；重做图件按「会不会被初审退回」排序。

### 3.5 投稿包组装（`scholar-journal` + `chinese-medical-paper-writer` + `cover-letter`）

1. **建要求清单** → 字数上限、摘要结构与字数、图表数量、参考文献上限、必需声明、文件格式与命名、双盲匿名化、补充材料上限。不确定的条目标为待确认。清单在动笔前建，因为字数与图表上限会影响是否要删内容。
2. **正文与匿名化** → 查三处：正文文本、文档属性里的作者字段、图表文件属性。只看正文会漏掉元数据里的姓名。字数按刊约口径算（含不含摘要与参考文献各刊不同）。
3. **声明类材料** → 作者贡献（按贡献者角色分类）、利益冲突（**无也要写「无」**）、基金、伦理审批与知情同意（涉人研究必需，批号要能对应到机构与批件）、数据与代码可得性、AI 使用披露（说明用了什么、用在哪）。
4. **图表与补充材料分文件** → 图按刊约存独立文件、命名含图号；补充材料单独成册并按序编号，正文要有对应引用；每个补充文件都要有标题页。
5. **写 cover letter** → 五段：抬头与投稿声明、研究问题与贡献、与期刊的契合、声明类（原创、未一稿多投、利益冲突、AI 使用）、结尾。**信中每条主张要能回指稿件段落**，找不到就删或降级；编辑姓名抽不到写占位符，不许编。
6. **逐项过清单** → 每项标通过／不通过／不适用，不适用要写理由（留空与未检查无法区分）；敏感项（伦理、利益冲突、数据可得性）单独复核；给三条以内优先修复。

### 3.6 期刊要求解析与选刊（`scholar-journal` + `venue-templates` + `cover-letter`）

1. **抽稿件特征** → 字数（按刊约口径分正文与摘要）、图表数、参考文献数、研究设计、贡献类型、目标读者。字数口径必须按目标刊重算。
2. **建分档候选** → 五到十个候选，分冲刺／匹配／保底三档，每档标注领域范围、文章类型偏好、是否接收该设计。只列一个目标刊等于没有后备方案。
3. **逐项对表** → 九项硬要求（页数与字数、字号字体、页边距、行距、引用样式、图表要求、文件格式、双盲、补充材料上限）加四轴契合（范围、方法门槛、字数、读者面）。范围契合要看该刊近两年目录而不只是征稿范围。
4. **给理由与差距** → 每个候选三句：为什么匹配（对应到具体栏目或近期文章）、差在哪、改造成本（改格式是小时级、补分析是周级）。**影响因子、审稿周期、录用率一律不给数字。**
5. **改投阶梯** → 每步写明要改什么（格式、篇幅、侧重）与哪些改动可复用；至少给两级后备。

### 3.7 终稿交付格式（`docx` + `latex-output` + `typst-paper`）

1. **定交付格式与模板** → 投稿用 docx、打印送审用 pdf、有模板走模板。**模板优先是硬规则**：学校或期刊给了模板，任何自拟格式都是错的。没有模板再按通用规范设页面参数与行距。
2. **整篇格式统一** → 用样式而非手工逐段设：各级标题、正文、题注、参考文献条目各建样式；中文字体与西文字体分开设，英文数字用 Times New Roman。
3. **标点与语言层** → 中文语境一律全角（逗号、句号、括号、冒号、分号、引号），英文与数字内用半角；清 Markdown 残留符号与半角括号包裹的中文。核查要脚本化，一万字里找半角逗号靠肉眼必然漏。
4. **编译或导出并验证** → LaTeX 走 XeLaTeX 到出参考文献再两次 XeLaTeX（或 latexmk）；Typst 按「编译→格式→引用」顺序；docx 导出 pdf 后检查分页与图表是否错位。编译警告要看完，引用问号通常是要再编译一次。
5. **交付清单与归档** → 主文件、可选 pdf、源文件目录、交付说明（字体字号、页边距、模板来源、已知偏差）；命名含日期与版本，避免改动稿与定稿互相覆盖。

## 四、判据与红线

### 4.1 硬红线（违反即返工）

- **参考文献必须是真实可查的**：作者、题名、刊名、年、卷（期）、页码与 DOI 或 PMID 齐备。**严禁编造字段、严禁猜 DOI**。缺字段标出来；真实性存疑交 `research-literature` 核验，本域不下真假结论。
- **中文期刊正文引用编号一律上标**；参考文献表编号不上标。
- **参考文献表按 GB/T 7714-2015 全要素**：三人以内全列，超过三人列前三加「等／et al」；文献类型标识 `[J] [M] [D] [C] [EB/OL]` 齐备；DOI 保留。
- **文档属性也算正文**：双盲要求下文档属性里的作者字段必须清空。
- **禁止给影响因子、审稿周期、录用率数字**；可给候选清单与匹配理由。
- **不得假定用户装了任何文献管理软件或排版工具**；也不得把「换个软件」当解决方案。
- **修改必须另存新版本**，不覆盖用户原文件；批量写库前先备份。

### 4.2 分场景判据（若…则…否则…）

- **若**目标是中文期刊或学位论文，**则**用国标样式加国标全要素细则（含 DOI 与类型标识）；**否则**用文献管理软件自带样式直出会缺 DOI 与类型标识，投出去被判格式不全。
- **若**用户给了目标期刊两三条参考文献范例，**则**从范例反推样式卡再批量套；**否则**套最接近的通用样式，差别集中在标点大小写与作者截断，返修成本更高。
- **若**题录缺字段比例很高，**则**先回 literature 域补题录再排版；**否则**用占位符硬排的表不能投，等于白做。
- **若**目标期刊是中文核心或中华医学会系列，**则**顺序编码制加上标；**否则**用著者出版年制会被判未按稿约，初审即退。
- **若**用户从别的体系转过来，**则**全量重建按首现重编号；**否则**手工逐条改号必然留下跳号与错位。
- **若**用户已装 Zotero 且投英文刊，**则**走原生域代码路线；**否则**直接输出静态文本，每次改投都要人工重排。
- **若**用户没装任何文献管理软件，**则**给按样式排好的文本加增补说明；**否则**要求装软件是把工具门槛转嫁给用户。
- **若**引用标记含大量中文文献，**则**先补库内条目与导入文件再生成域代码；**否则**英文元数据源多半抓不到，会产生大量未找到条目。
- **若**目标是国际期刊，**则**按各刊图件规格核对分辨率与色彩模式；**否则**按国内习惯准备图会过不了技术审查。
- **若**图本身不达标，**则**重画图件再按刊约导出；**否则**插值放大或改标称 dpi 印刷后仍然模糊，编辑部抽查原图就露。
- **若**期刊只收 docx，**则**用 docx 样式驱动排版；**否则**用 LaTeX 排完再转 docx 会丢样式与公式，编辑部反而更难改。
- **若**学校或期刊提供了模板，**则**套模板走完整编译链；**否则**手写格式凑版面必然有偏差。
- **若**稿件是中文且要送审打印，**则**导出 pdf 并核查全角标点与页码；**否则**不同机器打开 docx 会因缺字体变版。
- **若**用户问影响因子或录用率，**则**说明本插件不给这些数字并指导去官网或权威索引现查；**否则**凭记忆给数字会直接误导投稿决策。
- **若**没有对照模板只能给通用文档类，**则**在交付说明里写明「未套模板、按通用规范排」；**否则**用户会以为已符合校方或刊方要求。

### 4.3 机械可查的交付门

| 关卡 | 机械判定 |
|---|---|
| 参考文献表 | 每条含作者／题名／刊名／年／卷期／页／DOI 或 PMID；国标每条带类型标识；作者截断规则一致；未混两种样式 |
| 正文编号 | 正文编号与文末表双向缺失数＝0；跳号数＝0；中文语境上标数＝正文引用总数；文末表编号非上标 |
| 域代码 | 未找到条目数显式列出；文末可刷新区域与引文域首尾成对；不覆盖原文件 |
| 图表 | 三线表且可编辑；表题在上图题在下；分辨率与格式合规；图表编号连续且一一对应 |
| 投稿包 | 就绪报告无空白项；双盲三处无作者信息；五项声明齐备（无则写「无」）；cover letter 无依据主张数＝0 |
| 选刊 | 候选≥5 且分三档；九项硬要求逐项打勾；影响因子与录用率数字出现次数＝0 |
| 终稿 | 中文语境半角逗号句号括号直引号数＝0；标题字体字号混用数＝0；编译错误数＝0（有源工程时） |

## 五、模板与校验

### 5.1 GB/T 7714-2015 各类型条目模板

**期刊论文 [J]**

```text
[1] Moore E E, Moore H B, Kornblith L Z, et al. Trauma-induced coagulopathy[J].
    Nature Reviews Disease Primers, 2021, 7(1): 30. DOI: 10.1038/s41572-021-00264-3.
```

**专著 [M]**

```text
[2] 王建华, 李明. 临床流行病学[M]. 3 版. 北京: 人民卫生出版社, 2020: 145-160.
```

**学位论文 [D]**

```text
[3] 张晨曦. 社区老年人多重用药与跌倒风险的队列研究[D]. 上海: 复旦大学, 2022: 28-41.
```

**会议论文 [C]**

```text
[4] Smith J R, Lee K. Early warning scores in sepsis: a prospective cohort study[C]//
    Proceedings of the 42nd Annual Meeting of the Society of Critical Care Medicine.
    Chicago: SCCM, 2023: 112-119.
```

**电子资源 [EB/OL]**

```text
[5] World Health Organization. Global report on hypertension 2023[EB/OL].
    (2023-09-19)[2024-11-04]. https://www.who.int/publications/i/item/9789240079149.
```

**预印本（按期刊要求，通常标 [J/OL] 或 [EB/OL]）**

```text
[6] Chen L, Zhao Y. Machine learning for triage prediction: a multicenter study[J/OL].
    medRxiv, 2024[2024-11-04]. https://doi.org/10.1101/2024.05.12.24307123.
```

排版细则（逐条检查）：

- 三人以内全列；超过三人列前三加「, 等」或「, et al.」；两位作者之间用逗号，不用「and」。
- 类型标识紧跟题名，`[J]` 最常漏；电子资源写 `[EB/OL]` 并带（发表日期）[引用日期]。
- 英文著者姓全大写或首字母大写按刊约；名缩写不加点（GB/T 习惯）。
- 英文刊名用 NLM 标准缩写，中文刊名用全称。
- DOI 写在页码之后，形如 `DOI: 10.xxxx/xxxx`（大写 DOI 加冒号空格加小写编号），不写成「DOI：」全角。
- 卷（期）用半角括号，页码用「起页-止页」连接号，不用波浪线。

### 5.2 正文引用写法对照

| 体系 | 单篇 | 连续多篇 | 不连续多篇 | 上标要求 |
|---|---|---|---|---|
| 顺序编码制（中文刊） | 上标 `1` | 上标 `1-3` | 上标 `1,3` | 正文一律上标，文末表不上标 |
| 顺序编码制（英文刊，如温哥华） | `[1]` | `[1-3]` | `[1,3]` | 按刊约，多数方括号不上标 |
| 著者出版年制（APA 7） | `(Wang, 2021)` | `(Wang, 2021; Li & Zhao, 2020)` | 同左，按字母序排 | 不上标 |
| 著者出版年制（中文刊） | `（王建华，2021）` | `（王建华，2021；李明，2020）` | 同左 | 不上标 |

### 5.3 图表核查表

| 项 | 要求 | 判定 |

| 表注 | 表下方，符号与说明对应 | 通过／不通过 |

| 编号 | 连续，正文引用一一对应 | 空号数 |
