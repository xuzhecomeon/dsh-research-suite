# 科研幻灯（融合 SOP）

本域只做一件事：把研究材料变成**能讲、能看、能过评审的可编辑 .pptx**。幻灯的失败只有两类——**讲不清**（页序不成链，每页都是资料切片）与**看不清**（字号、图分辨率、配色任一塌方）。两类失败都能在前台算出来，所以本 SOP 的起点不是排版，而是五组数值：页数由时长算，字号由观看距离定，图由版心反算 DPI，备注由配速算字数，颜色由强调数量限。

数值算不出来就停，不许开始画页面。任何一项靠「感觉差不多」的，最后都会在评审现场暴露。

## 一、本域任务判定树

### 1.1 入口三问（缺一项就停）

1. **交付格式**：必须可编辑 .pptx／只要放映／网页演示？格式问错，后面全部返工。
2. **场合与时长**：组会、会议 oral、答辩、公开演讲，各几分钟？时长决定页数区间，没时长不排页。
3. **素材状态**：只有一篇论文／已有成稿 PPT／有 JSON 与数据表？素材状态决定走骨架卡还是统一卡。

补充可选输入：学校或实验室母版 .pptx、统计数字表、预判问题清单。

### 1.2 诉求到能力卡

| 诉求信号 | 能力卡 | 先做的一步 | 交付物 |
| --- | --- | --- | --- |
| 组会讲一篇论文、文献汇报 | C1 `slides.journal-club` | 锁时长与听众 | 17～20 页 .pptx ＋ 对账表 |
| 会议 oral／spotlight／答辩 | C2 `slides.conference-defense` | 定 talk 类型与页数 | .pptx ＋ 时间轴讲稿 |
| 版式乱、字号不统一、要套母版 | C3 `slides.deck-system` | 问齐七槽位与母版 | 统一后 .pptx ＋ 版式说明 |
| 论文图放进去看不清、多面板 | C4 `slides.figure-refit` | 判图能不能用 | 重出图 ＋ 表页 ＋ 图注清单 |
| 要备注台词、算每页讲多久 | C5 `slides.speaker-notes` | 算字数预算 | 注好备注的 .pptx ＋ 讲稿 |
| 每月重出、批量、JSON 转 PPT | C6 `slides.auto-build` | 写设计单与 JSON | .pptx ＋ 脚本 ＋ qa_report |
| 网页放映、图像页 deck | C7 `slides.web-deck` | 先问交付格式 | HTML 或 .pptx ＋ 边界说明 |
| 幻灯、讲稿、摘要对不上 | C8 `slides.consistency` | 定权威源 | 对账表 ＋ 改后文件 |

### 1.3 组合纪律

- 一次任务最多走三张卡，按固定顺序：**骨架（C1／C2）→ 图（C4）→ 版式（C3）→ 备注（C5）→ 对账（C8）**。顺序颠倒会把已排好的版面推倒重来。
- 只改三页且内容已定：只走 C3 的最小改动路径，不重跑整套确认门。
- 交付格式未定：先走 C7 第 1 步问格式，不许先把 HTML 做出来再解释。
- 同一诉求命中两张卡时，选**交付物更小**的那张。

### 1.4 不适用（转域，不要在本 SOP 里硬做）

- 只要 .md 大纲或思路清单：转写作域，本域交付物一律是可编辑 .pptx。
- 学术海报、单页展板：转图件域；海报是单页视觉优先，与幻灯的时间叙事不同。
- 数据重新分析、统计重跑：转统计域；本 SOP 只重排版面，不改数字。
- 改论文正文措辞：转写作／润色域。
- 动画视频、动态网页产品：不在范围内，硬做会得到无法投影的文件。

## 二、每张卡的融合 SOP

### 2.0 三处取长补短的账（写清楚为什么这样拼）

**其一，备注。** `slidep-pptx-notes` 证明了「备注只写进替代文本等于假交付」——`notes={}` 只落 `<p:cNvPr descr>`，notesSlides 部件数是 0，PowerPoint 备注区空白；它给了四件套注入法，但**不管台词写多少字**。`aris-paper-slides` 给了三行备注格式与逐页时间轴，但**没有配速阈值**。本 SOP 取前者的四件套注入，取后者的三行格式，再自己补 200～210 字/分钟的字数算式，三者拼成 C5。

**其二，母版与间距。** `workbuddy-pptx` 给了 60px 内边距、24／32px 两档间距、85% 填充率，但画布口径是 px（1280×720）。`论文汇报PPT制作` 给了 pt 五档字号，但没有栅格与间距规则。两套单位不能混着用，本 SOP 用 1pt≈1.333px 建双单位对照表，把 1280×720px 折成 13.333×7.5 英寸，再让每条规则都写清用哪个单位量。

**其三，出图。** `scientific-slides` 给了「图内字号 ≥18pt、单页 panel ≤2、直标替图例」的验收判据，但没给出图参数。`paper-slide-deck` 给了按 bbox 检测图区与 clip 渲染的取图法，但它的成品走 AI 生成、不可编辑。本 SOP 把 DPI 反算公式与 bbox clip 拼成一条链路：先算所需像素，再按 bbox 高分辨率渲染，最后用 18pt 判据验收。

### 2.1 C1 组会与文献汇报（slides.journal-club）

**结构铁律：主文献引入 → 背景知识 → 前沿扩展**，不是论文目录照搬。三段各占约三分之一时长；组会 17～20 页，15 分钟档 10～12 页。

| 页序 | 页型 | 只许一层主信息 | 字数上限 |
| --- | --- | --- | --- |
| 1 | 封面 | 题目（中译）＋期刊＋汇报人＋日期 | 40 |
| 2 | 文献信息 | 期刊、影响因子、DOI、发表年、研究类型 | 50 |
| 3 | 导航 | 三段式目录，当前段高亮 | 30 |
| 4～7 | 背景四卡 | 现象／研究缺口／语境／本文贡献，一卡一论点 | 120 |
| 8～9 | 理论框架 | 概念卡＋原文框架图（重出图） | 100 |
| 10 | 研究问题 | RQ 或假设 ≤3 条，色框突出 | 60 |
| 11～13 | 方法 | 抽样、测量、分析策略各一页，含操作化与编码信度 | 120 |
| 14～16 | 结果 | 一页一结论，每页一图或一表 | 120 |
| 17 | 讨论 | 与既有研究对话（支持／修正／冲突三类） | 120 |
| 18 | 批判反思 | 理论、方法、编码者三个角度各一条 | 120 |
| 19 | 启示与中国语境 | 3～4 张策略卡＋本土化三条约束 | 120 |
| 20 | 局限与结尾 | 局限一页；结尾用母版原页，不许重绘 | 80 |

执行步骤：

1. **锁听众与时长**：先问时长、听众构成、是否有母版；三项缺一项就停。时长决定页数区间（15 分钟 10～12 页、30～40 分钟 17～20 页），听众决定详略与术语密度。
2. **判论文类型**：discovery／methods／resource／clinical／materials／review 六类之一，判定结果一句话报给用户，便于廉价纠正。
3. **建术语账本**：术语、基因名、数据集名、指标口径逐项登记，后面每页按账本用词，跨页不许换说法。
4. **补背景**：按 Foundation／Context／Evidence／Application／Trends 五层各取 1～2 条权威来源；检索来的二手结论只补背景与前沿，结果段一律回原文取数。
5. **写标题与压字数**：每页标题写成完整结论句；正文压到 120 字以内，超限拆页而不是缩字号。
6. **对账后出片**：术语、数字、页脚日期三列对完再导出；母版封面与结尾页原样保留。

组会与论文宣讲的分水岭是「批判反思」与「中国语境」两页：缺这两页听众会问「你自己的判断在哪里」。

### 2.2 C2 会议与学位答辩（slides.conference-defense）

**先定类型，页数由类型与分钟数反推。**

| talk 类型 | 时长 | 页数 | 每页配速 |
| --- | --- | --- | --- |
| poster-talk | 3～5 分钟 | 5～8 | 30～60 秒 |
| spotlight | 5～8 分钟 | 8～12 | 30～45 秒 |
| oral | 15～20 分钟 | 15～22 | 45～90 秒 |
| invited／seminar | 30～45 分钟 | 25～40 | 60～120 秒 |
| 学位答辩 | 40 分钟 | 20～26 | 90～120 秒 |

经验律：oral 约 1 页／分钟，spotlight 约 1.5 页／分钟。另一条独立复核口径来自按帧数的技能：12 分钟 8～10 帧、20 分钟 13～16 帧、45 分钟以上 25～35 帧；两条口径都超配就砍页，不许改配速。

oral 的 22 页逻辑链一行写完：**标题 → 目录 → 问题背景 → 问题陈述 → 动机 → 关键洞察 → 方法总览 → 设计 1／2／3 → 备选方案 → 实现 → 评估设置 → 端到端结果 → 结果深挖 → 消融 → 扩展性 → Demo → 相关工作 → 总结 → 展望 → 致谢**。

- 关键洞察单独占一页，且必须放在方法总览之前；相关工作放在结果之后，不许放开头。
- 最强 2～3 张图进正片，其余进备份页；备份页编号 A1、A2…，页码独立，不计入正片页数。
- 段落时长预算：结果 40～50%、方法 15～20%、背景 15～20%、讨论 15～20%、结论 5%。
- 答辩加两条：每章前插目录页并高亮当前章；每章首给一句「本章在全文中的位置」。方法细节与数字溯源必须留在正片，评委按这两项核独立完成度。
- 排练检查点（15 分钟档）：3～4 分钟应讲完动机与洞察，7～8 分钟应进入结果，12～13 分钟应开始总结；任一检查点落后 1 分钟就当场砍页，砍页顺序预先写进设计单。

### 2.3 C3 母版、版式与视觉统一（slides.deck-system）

**先对齐母版七个槽位**：主色、辅色、强调色、正文色、底色、Logo、字体。拿不到组织规范再走兜底学术宝蓝：

| 槽位 | 兜底值 | 用量 |
| --- | --- | --- |
| 主色 | `#1E4FA8` | 15～25% 视觉重量 |
| 辅色 | `#3D7BD9` ／ `#E8EFF8` | 5～15% |
| 强调红 | `#D9534F` | ≤3% |
| 数据黄 | `#FFC107` | ≤3% |
| 正文三级 | `#1A2230` ／ `#4A5568` ／ `#8B97A8` | 正文与次要文字 |
| 底色 | `#FFFFFF` | ≥60% |
| 辅底／分隔线 | `#F7F9FC` ／ `#D6DCE5` | 分区与细线 |

纪律：蓝族合计 20～40%，红加黄 ≤5%，金色＝0；禁紫、粉、玫红、橙绿大块、彩虹渐变、纯黑大底。

**画布与栅格（双单位对照，别混用）：**

| 项 | px（1280×720 画布） | 英寸（16:9 幻灯片） |
| --- | --- | --- |
| 画布 | 1280×720 | 13.333×7.5 in |
| 四边内边距 | 60px（硬下限） | 0.625 in（不小于 0.5 in） |
| 内容区 | 1160×600 | ≈12.08×6.25 in |
| 页脚顶边 | y＝670 | ≈6.98 in |

页脚 14～16px（≈10～12pt）灰色，左论文题目与版本号、右页码；封面、目录、章节扉页、封底、感谢页不加页脚。

**五档字号（本域硬口径，不许出现第六档）：**

| 层级 | pt | px（1280 画布） |
| --- | --- | --- |
| 页面标题 | 28pt 加粗 | 37～40px |
| 正文 | 16pt | 20～24px |
| 卡片／表格 | 12pt | 16～18px |
| 图注 | 11pt 灰 `#666666` | 14～15px |
| 来源注 | 10pt 灰 `#666666` | 13～14px |

换算按 1pt≈1.333px；同页「字体＋字号＋字重」组合不超过 4 种，出现第六种字号说明层级没收敛。

**四组卡片色（浅底深字，一卡一论点）：**

| 组 | 浅底 | 深字／强调 |
| --- | --- | --- |
| 蓝 | `#EBF3FA` | `#5A97D0` |
| 橙 | `#FEF3E8` | `#E87A00` |
| 绿 | `#E8F5E9` | `#4A904A` |
| 红 | `#FFEBEE` | `#E53935` |

**强调与密度：**

- 关键数据用纯红 `#FF0000` 加粗，**全篇不超过 5 处**；超过就降级为深灰加粗。一页红色或高亮 ≤2～3 处。
- 红绿对比对禁用（约 8% 男性不可辨），改蓝橙或蓝红；文字与底色对比度 ≥4.5:1，投影环境争取 7:1。
- 块间距只用两档：24px 紧、32px 松；兄弟卡片的标题块、正文块、尾部元素三段 y 轴等高，任一卡尾部 y 差 >16px 返工。
- 卡片填充率 ≥85%（高 ≥380px 的卡正文 ≥100 字、高 ≥480px 的 ≥130 字）；常规页留白 ≤35%，焦点留白 ≥40px。
- 一页 ≤4 个区、只有一个总结块；一页 ≤2～3 个浅色底容器，每个都要有语义理由。
- 分区手段优先级：细线／留白／对齐 > 浅色底块。令 T＝区内标题到正文间距、L＝正文行距、G＝分区间距，G≥2T 且 G>L 才用 1px 细线，否则只用留白加对齐。
- **三禁**：标题下横线、居中大段正文、默认 Office 蓝。另禁「标题下只有标题 1/8 宽的短装饰线」——这是 AI 生成幻灯最稳的指纹。
- 母题：全篇一个贯穿结构元素（标题下贯通细线、固定章节眉标、统一编号块），每页复用。
- 母版是底板：用户给了母版就继承，封面与结尾页原样保留，只替换内容。

**落版后双门审图**：第一门看「像不像可以直接交付」，第二门查硬缺陷（溢出、重叠、裁切、占位符残留、边距 <0.5 英寸、对比度不足）。两门都过才算完成；`soffice --headless --convert-to pdf` 转 PDF 后 `pdftoppm -jpeg -r 150` 逐页出图目检，转换要核对退出码与产物时间戳。

### 2.4 C4 论文图与表改成幻灯图（slides.figure-refit）

论文图服务于「经得起细看」，幻灯图服务于「三秒内看懂一个结论」。因此不是缩放，而是重出。

**DPI 反算（目标版面宽 × 300）：**

| 目标版面宽 | 所需像素 |
| --- | --- |
| 5 in | 1500 px |
| 6.67 in | 2000 px |
| 8 in | 2400 px |
| 10 in | 3000 px |
| 12 in | 3600 px |

从 PDF 重渲染时先取 3 倍（216 DPI 起步），要 300 DPI 时按目标像素反算到约 4.2 倍。低于 300 DPI 一律重出图，**不许用幻灯片里的缩放把 800px 硬拉到全宽**——那是 80 DPI。

**图内字号 ≥18pt 是「在幻灯片上呈现时的实际字号」，不是图像内部像素值。** 判断方法：把图插到目标版面尺寸，看轴标签高度是否低于正文 16pt 的 1.2 倍；不达标注定重出。

**取图三步**：位图按 bbox 直接 clip 渲染；forest、flow 这类矢量图没有 image bbox，用图注文本块的 y 坐标反推区域再 clip；抠出的图文件名带源图号与 DPI，便于回溯。

**改造规则**：

- 一页 ≤2 个 panel；6 panel 组合图拆成 2～3 页，每页 1～2 个 panel 各配一句结论。拆页比缩图信息量高。
- 删图例改线端直标；删网格线、删多余误差条说明。
- 表格不许截图：重排成表页，只留 3～5 行关键行，字号 12pt，表头加粗，数字右对齐，单位写进表头；三线表，禁整行底色。
- 图注 11pt 灰，三要素齐：横轴含义与单位、纵轴含义与单位、样本量与统计方法。
- 来源注 10pt 灰，写成「重绘自原文 Figure 3，300 DPI」，能指回原刊页；不许只写「来自原文」。
- 渐进披露：复杂机制图拆连续两页（全貌页＋局部放大页），圈注只用纯红，受 5 处上限约束。
- 同变量在全文所有图里同色；色盲检查看灰度打印能否分辨两条线。
- 拿不到原始数据只许高分辨率重取原图或做对象级重建，**禁止按肉眼估读的数值重画**，那是造假数据。
- 内容超载的处置顺序固定：删文字 → 拆页 → 换版式 → 缩图宽，最后才允许缩字号。

### 2.5 C5 演讲备注与讲稿（slides.speaker-notes）

**先算字数，再写台词。**

| 时长 | 台词总字数（200～210 字／分钟） |
| --- | --- |
| 10 分钟 | 2000～2100 |
| 15 分钟 | 3000～3150 |
| 20 分钟 | 4000～4200 |
| 30 分钟 | 6000～6300 |
| 40 分钟 | 8000～8400 |

页数一变就重算：15 分钟 18 页即每页 165～175 字；留 5% 余量给停顿与翻页。反过来校验：18 页每页写 300 字＝5400 字，按 205 字／分钟要讲 26 分钟，这类超时在写稿阶段就该算出来。

**每页备注固定三行**：

1. 第一行：时长（`1.5 分钟` 或 `90 秒`）。
2. 第二行：本页要点（第一句说什么、中间报哪个数、手指到哪里）。
3. 第三行：过渡句（点出下一页要解决的问题）。现场卡壳时这一行是救命句。

**台词写法**：每句 15～25 字、每页 3～5 句，写成能直接开口的完整句子；备注写讲者动作与判断，不是复述页面文字。禁「此处讲解要点」「略」「见正文」「根据内容讲解」。英文段落按 130～150 词／分钟另算，中英混讲要分段计时。

**注入真备注部件（四件套缺一不生效）**：

1. `notesSlideN.xml`——备注正文部件；
2. `notesSlideN.xml.rels`——指向 notesMaster 与 slide；
3. `[Content_Types].xml` 增加对应 Override；
4. `slideN.xml.rels` 追加 notesSlide 关系。

两个必须记住的坑：字符串模板漏插值会造成悬空 Target，工具会静默新建约 576 字节的空部件；描述文本被双重转义要 `html.unescape` 一次，否则备注里出现 `&quot;`。另外 `upsert-dsl` 单页更新会把备注还原成 descr 形态，需重跑注入。

**读回验收**：python-pptx 读回每页 `has_notes_slide` 与文本，打印字数与前 20 字；四项全中才算完成——覆盖率 100%、无 `&quot;`/`&amp;`/`&lt;` 残留、部件数＝内容类型条目数＝页数、每页字数落在预算区间。脚本退出码 0 不算验收，要看到数字。

**双轨**：备注放提示版台词，另出逐页时间轴讲稿（`[0:15-1:30]`）只用于彩排与答辩备份；讲稿末页附 5 问预判（对比最强基线、局限、成本、泛化、最意外的发现），每问一句结论加两条证据。

### 2.6 C6 脚本化批量出片（slides.auto-build）

**设计单先行**：一页写清页数与时长、每页页型序列、配色与母版来源、页脚三件套。页型只许用固定清单，不许每次临时发明：`cover`／`section`／`agenda`／`content`／`two_column`／`table`／`chart`／`timeline`／`quote`／`image`／`summary`。

**JSON 驱动口径**：顶层五键 `{style, footer, page_numbers, output, slides}`；配色可选 business_blue／academic_white／creative_purple／tech_dark／minimal_gray 五套；只依赖 python-pptx，坏页记录后跳过并逐页报告。

**选引擎三问**：页数是否 ≤30 且数据稳定（是→JSON 驱动生成器）？是否需要网页模板（是→HTML 模板导出原生形状）？是否需要渐变视觉定制（是→Python Builder 预渲染背景）？混用两套引擎会长出两套页脚与页码规则，返工成本高于一开始选定。

**出片与复跑**：开页码与页脚（`04 / 18` 形式，页脚含版本号），封面结尾页不加页脚；失败只重跑失败页，保住已人工调过的页；同数据跑第二次，差异应只有时间戳，出现内容差异说明脚本里混入了随机或手工修改。

**审计落盘**：`qa_report.md` 记录页数、字号五档抽检、备注覆盖率、失败页与原因。交付时附复跑说明四样：命令、依赖版本、输入文件清单、已知限制。

### 2.7 C7 网页型演示与图像页 deck（slides.web-deck）

**第一个问题就问交付格式**：必须可编辑 .pptx 就导出或转 C6；只要放映才允许纯 HTML；接受图像页才允许整页生成。格式问错，后面全部返工。

- 纯 HTML 分支：36 套主题（选 academic-paper 一类克制主题）、36 种版式、一页一个 `.slide`，颜色只用 token 禁字面 hex；presenter mode 备注 150～300 字／页，正好用作 C5 的字数交叉校验。
- 本地预览端口用 5200～5999，禁 `python -m http.server` 之类静态服务器；预览要逐页看字体回退，网页里缺字体比 pptx 更隐蔽。
- 导出可编辑 pptx 两条路：页面接口 `/api/export-editable-pptx`，或命令行 `npm run export:pptx -- <deck>/ppt <out.pptx>`；导出后必须用 python-pptx 读回页数与备注，确认不是空壳。
- 纯放映分支用渲染脚本出 PNG 存档，公开演讲必须准备 PNG 备份防现场网络故障。
- 图像页 deck：整页生成的美术一致性强，但文字不可逐字改，改一个字要重生成整页；这条必须写进交付说明，否则收件人拿到才发现改不动，等于交付事故。

### 2.8 C8 幻灯、讲稿与摘要三方对账（slides.consistency）

**先定权威源**：论文原文 > 数据表 > 幻灯 > 讲稿。没有优先级就会来回改：讲稿写错跟着改幻灯，最后两边都错。

**抽五类要素**：版本号、统计数字（含样本量、P 值、效应量）、引用、关键术语、日期；逐类列出现位置，术语按账本同一写法比对。

**流程**：冲突处标 `STALE` 并给出权威值与出处，一次给全清单请用户确认；确认后就地更新，只改冲突处，保住原字体、版式与页码；幻灯本就比正文短，不许把论文长句搬进幻灯；改完检查页脚版本号、日期、封面与致谢页。

**重新导出的双闸**：第一闸看退出码（管道会吞掉退出码，要单独取 `${PIPESTATUS[0]}` 或用 `-halt-on-error`）；第二闸看产物 mtime 新于源文件，PDF 页数可解释。转换失败不许伪装成功。

**对账表五列**：要素、原值、权威值、所在页、状态（`STALE`／已修正）。表与 `qa_report.md` 同目录交付，下一版迭代直接在这张表上改。

## 三、常见错误清单

1. **照搬论文目录排页**：Introduction、Related Work、Method 是写给审稿人的顺序，听众第二页就掉队。改成「引入→背景→前沿」或六句逻辑链。
2. **标题写名词短语**：写「研究结果」等于让听众自己总结。改写成完整结论句，一页只证一句话。
3. **整段论文文字贴进幻灯**：为塞内容把字号压到 10pt 以下，后排全是灰块。拆成「结论句＋两条证据」，单页 ≤120 字。
4. **用缩字号解决内容超载**：字号一降离场就开始。处置顺序固定为删文字→拆页→换版式→缩图宽。
5. **6 panel 大图整张塞一页**：轴标签缩到不可读，等于贴装饰图。拆 2～3 页，每页 1～2 panel 配结论。
6. **位图硬拉全宽**：800px 拉到 10 英寸＝80 DPI，投影全是马赛克。按目标版面反算像素，低于 300 DPI 重出。
7. **标题下横线、标题下 1/8 短装饰线**：AI 生成幻灯最稳的指纹。删掉，改用字重与留白分层。
8. **红标满页**：全篇 20 处红字等于没有重点。压到 ≤5 处，其余深灰加粗。
9. **红绿对比图**：约 8% 男性读者看不出差别，结论对他们不存在。改蓝橙或蓝红，并保持同色同义。
10. **备注写「此处讲解要点」**：上台后没有任何可念的字。改成能开口的完整句子，按每页 165～175 字给。
11. **备注只写进替代文本**：PowerPoint 备注区其实是空的，翻到演讲者视图才发现。按四件套注入 `notesSlides` 并读回验收。
12. **备注与页数不匹配**：18 页写 5400 字，按 205 字／分钟要讲 26 分钟。写完先除一遍时长，超 10% 就砍字。
13. **px 与 pt 混算**：按 1280px 画布调好的字号直接搬到 13.333 英寸幻灯片会整体偏小。两个单位都要写清，按 1pt≈1.333px 换算。
14. **超时靠临场砍**：现场砍掉的通常是过渡句与结论，逻辑链当场断裂。预标可删段与备份页，砍的顺序写进设计单。
15. **表格截图贴页**：字号必然不足 12pt，且无法改数。重排成表页，只留 3～5 行关键行。
16. **交付 .md 大纲或图片版 PDF**：收件人要改一个字就得重做。交付物一律可编辑 .pptx；只能出 PDF 时必须在交付说明写明不可逐元素编辑。
17. **网页版交差但要求是可编辑**：HTML 交付在 PowerPoint 里改不动，等于没交。先问格式，必须可编辑就走导出或脚本链路。
18. **批量出片后手工补页**：下次重跑手工页会消失，可复现性被静默破坏。补页要改脚本，改完重跑全量。
19. **母版结尾页被挪位后重绘**：重绘的结尾页与学校模板不一致，答辩现场会被要求重做。用收尾操作把母版原页移回末尾。
20. **备份页混进正片**：页数超配、时间不够。备份页编号 A1、A2…，页码独立、不计入正片页数。

## 四、交付前自检

### A 内容

- [ ] 页数落在对应区间（oral 15～22、spotlight 8～12、组会 17～20／15 分钟 10～12、答辩 20～26）。
- [ ] 每页标题是完整结论句；名词短语与疑问句标题命中数＝0。
- [ ] 单页正文 ≤120 字；整段论文原文贴入的页数＝0。
- [ ] 三段式或六句逻辑链齐备；组会档的批判反思、中国语境两页不缺。
- [ ] 数字、样本量、P 值、图号能指回原文；术语账本覆盖率 100%。
- [ ] 引用编号一律上标 `[1]` 并与文末表一一对应；禁编造文献。

### B 视觉

- [ ] 五档字号抽 3 页全中；第六种字号命中数＝0。
- [ ] 中文微软雅黑、英文 Arial；其他字体命中数＝0。
- [ ] 纯红 `#FF0000` 加粗 ≤5 处；红绿对比＝0；对比度 ≥4.5:1。
- [ ] 四边距 ≥0.5 英寸；越界元素 0；重叠 0；并列卡顶底差 ≤8px。
- [ ] 三禁项（标题下横线、居中正文、默认蓝）命中数＝0。
- [ ] 每页至少一个视觉元素；页脚页码与来源注在位；同页文字样式组合 ≤4 种。

### C 图与表

- [ ] 每张嵌入图按目标版面反算 ≥300 DPI。
- [ ] 图内最小字号 ≥18pt；单页 panel ≤2；同变量跨页同色。
- [ ] 每图有 11pt 灰图注（三要素）与 10pt 灰来源注。
- [ ] 表格 12pt、≤5 行关键行、三线表；无截图贴表。

### D 备注与讲稿

- [ ] 台词总字数 ÷ 时长 ∈ 200～210 字／分钟，偏差 ≤10%。
- [ ] 每页备注含时长与过渡句；占位句式命中数＝0。
- [ ] `has_notes_slide` 为真占 100% 页；转义残留命中数＝0。
- [ ] 逐页时间轴讲稿存在，末页附 5 问预答。

### E 机械核对（三条命令必跑）

```bash
# 占位符与残留
grep -nE 'lorem|ipsum|xxxx|待填|此处讲解要点|TODO' slides.md
# 转图目检
soffice --headless --convert-to pdf talk.pptx && pdftoppm -jpeg -r 150 talk.pdf review/page
# 结构读出：页数、备注覆盖率、字数
python - <<'PY'
from pptx import Presentation
p = Presentation('talk.pptx')
print('pages', len(p.slides))
for i, s in enumerate(p.slides, 1):
    txt = s.notes_slide.notes_text_frame.text if s.has_notes_slide else ''
    print(i, 'notes_chars', len(txt), txt[:20])
PY
```

硬规则：转图目检必须完成一轮「修—验」循环；编译或转换失败要查退出码与产物时间戳，不许用「大概没问题」代替目检。
