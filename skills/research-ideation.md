# 选题、假说、标书、伦理：从「想做什么」到「能不能立项」

本域只有两种失败模式。**第一是把不存在的理由说成理由**——「该方向具有重要意义」「尚未见报道」「首次提出」，这三句在评审眼里等于什么都没说，且第三句一旦被查证就是硬伤。**第二是在不可行的想法上继续堆砌**——用户已在写标书第三章，而核心主张还撑不住一条最基础的反对意见。

本域就在这两处下刀：先把候选压到能一句话说清「为何重要、为何现在能做、凭什么做得到」，再把「我觉得新」变成「我能点名对比谁、差在哪一轴」。**不做文献精读**（literature 域）、**不做统计执行**（样本量计算与检验选择交 stats 域，本域只保证设计说清了要算什么）、**不做成稿写作**（writing 域）。

| 场景 | 调用 | 说明 |
|---|---|---|
| 不知道走哪张卡 | `research_capability(id='ideation.grant')` | 七张卡：topic / novelty / question / feasibility / design / grant / ethics |
| 按顺序做完一段 | `research_playbook(task='写标书')` | 返回任务的能力序列与判据 |
| 读技能原文 | `research_kb_read(name='aris-grant-proposal')` | 一次最多 2 个，只在本协议点名某节时读 |

## 一、本域边界

1. **做**：从模糊方向或一堆材料发散候选并收敛；查新与差异化定位；把选题写成 FINER/PICO 成立的问题与可被一次实验杀死的竞争假说；研究设计与技术路线（含流程图、里程碑、预算量级）；标书撰写与评审视角自检；判伦理审查类型、写知情同意与脱敏方案、决定是否预注册。
2. **不做**：不做系统性综述与逐篇精读（转 literature）；不跑样本量计算与统计建模（转 stats）；不扩写成论文正文（转 writing）；不做语言润色（转 polish）；不画成品图（转 figures，本域只出图清单与要表达什么）。
3. **不做但要说清**：不做「能不能被接收」的判断（转 review），不做经费金额精算（只给量级与科目，金额占位）。
4. **边界争议**：用户说「把想法写成论文」时，停在问题卡或标书骨架，并讲清：正文写作需要既有方法、结果与文献。用户坚持成稿则按 writing 处理，但把问题卡与 claim 链带过去当输入。
5. **必须停下问人**：涉及具体资助方当年指南、限项、预算上限、伦理批号与注册号时，不凭记忆回答，改为列「需用户核对的三项」并给占位。

## 二、融合对比表

| 能力 | 主用技能 | 关键长处 | 明确短板 | 融合取舍 |
|---|---|---|---|---|
| 选题发现与创新点提炼 | airs-brainstorming-research-ideas | 十个 lens 各带自检问题，收敛阶段每道 filter 有 kill criterion，不会失控发散 | 不检索文献，新颖性只到「感觉」层 | 当骨架；缺口检索与淘汰留痕交 aris-idea-creator，材料型提问交 scholar-brainstorm |
| 查新与差异化定位 | aris-novelty-check | 裁决边界最硬：没点名论文不许判放弃，拥挤但有 delta 仍算可做 | 只做早期闸门，不做影响力判断 | 三档裁决与「可核查的 delta」原样保留；趋势与年份分布借 qinyan-topic-analysis，但检索结果须逐条验明 |
| 研究问题与假说构建 | hypothesis-generation | 竞争假说须彼此可区分，每条落到定量预测与证伪条件 | 不判选题价值，不给论文级文献定位 | 问题合法性交 scholar-idea 的质询清单，已知/未知分区借 scholar-lit-review-hypothesis 的综述阶段，但不许它代写综述 |
| 立项前的可行性与致命缺陷审计 | idea-evaluator | 先查致命缺陷再打分，且规定「无证据只能给 5 分」，挡住自嗨式高分 | 偏个人决策，不写标书文字 | 当独立审计位；路线与预算现实性由 aris-experiment-plan 的里程碑口径回补 |
| 研究设计与技术路线 | aris-experiment-plan | 从 claim 反推实验块，每块必须写「失败怎么解释」，挡住凑数消融 | 假定实验已能跑，不管伦理与场地 | 主干；结果表骨架借 experiment-results-planning，临床与基础医学的申报式拆解借两个 extractor，但它们只抽取不代设计 |
| 标书撰写与评审视角自检 | aris-grant-proposal | 八类基金模板加评审准则，写作顺序也规定：先定 aims 再写背景 | 无当年指南与限项，金额只能占位 | 骨架与叙事弧全用它；机构评审表与拒稿点补 research-grants；对抗式评审用 arf-review-grant；证据账本与降承诺用 researchwrite |
| 伦理审查、知情同意与预注册 | scholar-ethics | 审查类型判定表、知情同意八要素、稿件声明模板都可直接抄结构 | 只覆盖常见情形，不替代本机构伦理委员会 | 主用；预注册平台与分析计划用 scholar-open；脱敏与数据最小化用 scholar-safety；三者都不许编造批号与通过日期 |

三处真实冲突，按下面规则取舍，不要平均用力：

- **发散要不要限量**：brainstorming 要 10～20 个，idea-creator 要 8～12 个。取舍是**下限取 10**——少于 10 个时「没得选」会让用户直接爱上第一个想法；上限不设，但第 10 个之后只写一行摘要。
- **新颖性谁裁**：qinyan 倾向用热度说话，novelty-check 明令热度不等于被占。取舍是**热度只进描述不进裁决**，裁决全按三档边界。
- **评分能否给高分**：idea-evaluator 只认实测与可辩护机制；评审自检给的是主观印象分。取舍是**自检分只用来排序待改项**，对外材料只出现「已核查/未核查」与「有/无证据」。

## 三、融合协议

### 3.1 选题发现与创新点提炼（ideation.topic）

1. **定题位与约束**。先分清是三张局面：白纸（有方向没想法）、材料（有数据/笔记/预实验没选题）、已有想法要论证。再记三条硬约束：可支配时间、算力/场地/样本通道、必须交代的产出（论文/学位/基金）。白纸走 lens 组合，材料走材料驱动提问，已有想法直接从第 4 步进。
2. **发散出量**。从十个 lens 挑 3～5 个（全用只会得到十个平庸答案）：问题先行、抽象阶梯、张力搜索、跨域移植、什么变了、失败分析、简洁性检验、相关方轮换、组合分解、讲得清测试，各出一批候选，合计至少 10 个，每个压到一句话。写不出一句话的候选是还没成形，不留占位。
3. **结构化收敛**。五道 filter 逐条过，每道给「留/杀 + 理由」：讲得清（两句模板填不满即杀）、问题优先（说不出谁受益即杀）、简洁性（复杂度换来的提升在噪声内即杀）、相关方（挑不出一个会反对的人即杀）、可行性（两周内做不出可判定的 pilot 即杀）。收敛到 1～5 个。
4. **结构缺口补位**。给留下的候选做缺口体检：方法能否从邻近领域移植、两篇文献是否互相矛盾、有没有被当公理却未经检验的假设、结论是否只在某规模区间成立、缺的是不是诊断性工作。输出是缺口类型，用于后面选检索词。
5. **淘汰留痕**。被杀的候选进一张表：候选 / 杀在哪道 filter / 什么条件下值得复活。被淘汰的想法是下次立项的库存，用户也会回头问「那个为什么不行」。
6. **交付三件套**。每个入选选题给两句 pitch（领域卡在哪、我们用什么机制解、为什么这机制成立）、最强反对意见（评审第一句会问什么）、两周 pilot 的一句话设计，附第 5 步淘汰表。

### 3.2 查新与差异化定位（ideation.novelty）

1. **抽技术 claim**。拆成 3～5 条可检索的技术主张，每条写清：用了什么方法、解决什么问题、机制是什么、与最显然的做法差在哪。检索不出关键词组合的 claim 说明抽象过度，继续拆。
2. **多式检索**。每条 claim 至少三组查询式（方法名+问题、机制名+领域、结论式表述），覆盖预印本与期刊库，且必查近六个月——最容易被抢的正是这一段。检索不到写「未检出」，不写「尚未见报道」。
3. **逐条比对**。每条 claim 点名最接近的一篇（标题/年份/发表处），回答它做到什么、仍没做到什么、我们的差异在哪个轴：研究对象、机制、输入粒度、问题设定，四轴至少命中一轴才算有 delta。**标题相似不算重复**，要看它实际做了什么。
4. **三档裁决**。按时序判三条边界：能点名一篇已发表论文把你这件事做完了（才可判放弃）→ 有邻居但 delta 站得住（推进）→ 拥挤但 delta 薄（谨慎推进并写明补什么才立住）。**谨慎不是安全中间态**：说不出薄在哪就判推进。
5. **定位句**。写成一句可核查的话：「与 A（年）相比，我们把 X 从 Y 换成 Z，因此在 W 条件下能做到此前做不到的事」。这句话后面要能原样进标书立项依据与论文引言。
6. **专利情形分流**。用户目标含专利时，先说明两套口径不同（专利新颖性含宽限期与公开时序，论文查新只管学术先例），分流到专利口径并提醒「公开时点」是硬约束。**不得用学术查新结论代替专利判断**。

### 3.3 研究问题与假说构建（ideation.question）

1. **界定问题边界**。用 FINER 五问过一遍（可行/有趣/新颖/合伦理/相关），再用 PICO/PECO 结构化：人群、暴露或干预、对照、结局。若一个术语在四栏里出现两次，说明概念没切干净。
2. **已知与未知分区**。每个候选标成「已知-共识」「已知-有争议」「未知-有线索」「未知-无数据」。只有后两类值得立项；有争议的值得做裁决型研究。写法是「争议在 X，两派证据分别是 Y 与 Z」，不写「研究较少」。
3. **建竞争假说**。每个问题造 2～4 个机制上不同的假说（不是同机制的不同强度）。若两个假说对同一实验给出相同预测，它们其实是一个，合并。
4. **判质量标准**。按可检验、可证伪、节俭、解释力、范围、与既有证据一致、新颖七条逐条打分，标出最弱一维。节俭被牺牲时必须写明为什么不得不加。
5. **写定量预测**。每个假说一行：方向（增/减/无差异）、幅度（量级或区间）、成立条件、区分它与竞争假说的关键观测、被证伪时看到什么。幅度拿不准就写「量级待 pilot 定，判据为方向 + 超过最小可检测效应」，不编数值。
6. **出问题卡**。一页纸：问题、PICO、竞争假设、预测与证伪条件、需要的数据、最强反对。这张卡是设计、标书、伦理三张卡的共同输入。

### 3.4 立项前的可行性与致命缺陷审计（ideation.feasibility）

1. **一句话故事与类型定位**。写一句话（做什么、给谁、凭什么成立），再定类型：新问题/新方法/新设定/新发现。类型决定尺子——新设定不要求方法新颖，新方法必须与方法基线比。
2. **致命缺陷审计**。按经典缺陷清单查，最多列两条最致命的，每条写「缺陷/怎么检出/怎么辩护」。最常命中四条：核心机制已被数据驳倒（检出即判致命）、新颖性只是标题相似（须落真实检索）、结论依赖未披露的有利设置（需消融）、能力与生命周期不匹配。
3. **生命周期与能力匹配**。判属于应用型、基础理论型、交叉型、前沿探索型、数据密集型、新技术型哪一类，再核对有效投入时间、技能深度、偏理论还是偏应用。不匹配就标出来并给两条路：换生命周期选题，或换承担方式（合作者、缩范围）。
4. **五维打分**。更高/更快/更强/更省/更广各 1～10 分。纪律：每维从 5 起，只有「用户提供的实测结果」或「站得住的机制论证」能把分数推离 5；后者标「机制推断、未经数据确认」并指名验证它的那个实验。两样都没有就留 5 分写「无依据」。
5. **风险与闸门**。对算力、数据、工程、时间四类风险各给一条缓解与一个止损点，止损点必须可判定（如「主表第一行与最强基线差距小于 2 倍标准差则放弃该主张，改写为诊断性工作」）。
6. **三档裁决**。给「强推/改后可行/放弃并转向」之一，列接下来三件事。强推的条件是四条同时成立：零致命缺陷、至少两维 8 分以上（带证据）、能力匹配、生命周期合适；缺一即降为「改后可行」。

### 3.5 研究设计与技术路线（ideation.design）

1. **冻结 claim 三层**。写死一条主 claim、一条支撑 claim、一条反 claim（要主动排除的解释，如「提升只来自更多参数」「新组件只是装饰」）。主 claim 上限两条，因为再多就没有做完关键消融的资源。
2. **主表与证据先行**。先定论文主表长什么样（行是系统或组别，列是数据集与指标），再定每块实验填哪一格。填不进任何一格、也不能改变审稿人对某条 claim 信念的实验，砍掉。
3. **排五段里程碑**。按「连通性验证→基线复现→主方法→关键消融/决策点→打磨」排序，每段写目标、跑什么、通过闸门、成本量级与风险。决策点必须写「两种结果各导向哪条路线」，否则那不是决策点是盲跑。
4. **生物医学分支**。临床或人群研究走 PICO→研究类型（随机对照/前瞻队列/回顾队列/病例对照/横断面/诊断/预后模型等）→主要终点、次要终点、关键混杂、亚组、敏感性分析、数据质量控制；基础实验走「主实验 4～7 个、每个 2～5 个子实验」的申报式编排，不同检测手段必须拆成独立条目。缺操作细节写「待定」，不填默认值。
5. **预算与外部依赖**。给算力量级、样本量级、场地设备、数据许可、人员分工。金额一律占位并提示用户补，不给「三年三百万」这类凭空数字。
6. **交付双产物**。技术路线（claim 表、实验块表、里程碑表、风险表）与执行跟踪表（每次运行一行：编号、里程碑、目的、系统、数据划分、指标、优先级、状态），都落成 Markdown 表便于贴进标书。

### 3.6 标书撰写与评审视角自检（ideation.grant）

1. **读评审表定标准**。先定资助方与项目类型，取其评审准则当写作纲（基础研究看科学价值与创新，人才项目看潜力与基础，应用类看转化与匹配）。**当年指南、限项、页数、预算上限须由用户核对**，本协议只按公开一贯口径给结构。
2. **搭链条骨架**。按「科学问题→假说→总目标与具体目标→研究内容→方法→预期结果→创新点→可行性→风险与备选→工作基础→经费与进度」搭一版只有标题加一句话的骨架。具体目标 2～4 条，每条须独立有价值（一条失败其余仍成立）、彼此有逻辑推进、有明确交付物。
3. **反推创新点**。写成「相对谁、在哪一轴、带来什么可检验好处」，逐条与某条目标、某个方法模块对上。禁止「首次/填补空白/重大意义」这类无法核查的表述；确需用「首次」必须附检索证据与时间窗。
4. **证据与承诺对齐**。为每条主张建一行账本：主张/现有证据/证据等级/允许措辞/禁止措辞。证据只到相关性就不许写因果，只到预实验就不许写「已证明」。降承诺优于加解释：缩范围，不在正文找补。
5. **经费进度与可行性**。经费按科目给理由（为什么这个人、这笔材料、这次出差），进度按年度给交付物与里程碑；可行性分三块写：团队（谁做过什么）、条件（设备与通道）、前期基础（初步数据）。金额周期与批号占位。
6. **评审视角自检**。用评审表逐项打勾，再跑一次对抗式预审：模拟不友好评审问六问——问题重要吗、创新站得住吗、方法与目标对得上吗、可行吗、钱和时间合理吗、我会给什么等级。每条要么被材料回答，要么进「必改清单」。

### 3.7 伦理审查、知情同意与预注册（ideation.ethics）

1. **判审查类型**。按对象与风险定档：公开二手数据、成人无标识问卷、敏感主题访谈、民族志田野、弱势群体、欺骗设计、公开数据抓取、私域社媒数据各对应不同档位（豁免/简易/全体/先咨询）。判档依据写进材料，不写「应该属于豁免」。
2. **写知情同意**。按八要素写：研究目的、时长与流程、可预见风险与不适、潜在收益、保密范围与数据使用、补偿、联系人（研究者与伦理委员会）、自愿参与与随时无罚退出。在线问卷用「同意前言 + 勾选」，附「不勾选即退出且不留数据」。
3. **定脱敏方案**。结构化数据走「删直接标识→泛化准标识→顺序编号替换→核查无原始标识列残留→另存匿名副本（绝不覆盖原始）」；文本走占位替换（人名、地名、机构、日期、罕见病种）。脱敏后做残留检查，把「查了什么、剩什么风险」写进方案。
4. **决预注册**。原创数据收集/实验/田野→应当预注册；纯归纳质性或档案史学→不适用但须显式声明；二手数据按「只看过描述统计/已分析过」区分能否确证，分析过的一律标探索性。写分析计划：每个假设的模型、主次分析、排除与停止规则、多重比较处理、阳性判据、零结果解释。
5. **出材料包**。伦理申请表主体（背景、方案、风险受益、保密、同意、数据管理）+ 知情同意书 + 脱敏方案 + 预注册草稿 + 稿件声明段（批号占位、同意方式、数据可得性、利益冲突、AI 使用披露）。动物实验另加批号占位、3R 说明、麻醉与安乐死方式、饲养与痛苦分级。
6. **标注待补项**。所有硬事实（批号、注册号、指南版本、金额、周期）集中成一张表：缺什么、去哪拿、填进哪一段。**任何一项都不许留空后被默认填写**。

## 四、判据与红线

### 4.1 决策判据（若…则…否则…）

- **发散不足不收敛**：若候选少于 10 个，则回到发散补齐；不许拿 3 个候选硬排优先级。
- **新颖性不用热度**：若你能点名一篇已完成同事的论文，则按那篇判；否则按「有无点名论文」走三档，热度只进描述。
- **谨慎档不是默认档**：若说不出 delta 薄在哪，则判推进；只有能写清「补什么才能立住」时才用谨慎档。
- **假说互为竞争才算数**：若两个假说对同一实验给出相同预测，则合并为一个；否则保留并写上区分它们的那个观测。
- **分数只认证据**：若某维没有实测也没有机制论证，则留 5 分注明无依据；否则按证据强度上调，机制类标未验证并指名验证实验。
- **致命缺陷短路**：若核心机制已被数据驳倒，则直接判放弃转向，不再评五维；否则继续。
- **实验必须辩护 claim**：若一个实验填不进主表任何一格、也不能改变审稿人对某条 claim 的信念，则砍掉；否则排进 must-run 或 nice-to-have。
- **目标不许悬空**：若某条具体目标没有对应方法模块，则补方法或删目标；否则通过。
- **创新点必须可核查**：若含「首次/填补空白/重大意义」且无检索证据，则改写为「相对 X 的差异」；否则保留。
- **伦理先行**：若涉及人且未定审查类型与同意方式，则不得进入数据收集设计；涉及动物时须先有批号占位与 3R 说明。
- **预注册三档不混**：若数据已分析过，则只能标探索性并如实声明；否则按计划内与计划外区分报告。

### 4.2 可机械检查的 gates

写作与交付前逐条过，每条都能被脚本或人工快速判定：

1. 每个入选选题都有两句 pitch，且含「为何重要」与「为何现在能做」。
2. 每条「放弃」结论都点名了具体论文（标题＋年份）；无点名的放弃视为越权。
3. 每个假说都有一行「被证伪时观察到什么」。
4. 每个致命缺陷都写了检出规则与辩护路径。
5. 每个实验块都写了检验哪个 claim 与失败时怎么解释。
6. 具体目标与方法逐条编号对应，无悬空目标。
7. 伦理章节四要素齐全：审查类型、批号占位、知情同意方式、数据脱敏。
8. 全文无编造的具体数字：基金名、批号、影响因子、审稿周期、经费金额、未定样本量一律占位或写「待定」。
9. 每条创新点都能指到一条具体目标与一个方法模块。

### 4.3 红线（命中即退回，不解释）

- 编造文献、批号、金额、周期、影响因子、期刊分区、评审周期。
- 用「具有重要意义」「尚未见报道」「填补空白」充当论证。
- 把「我觉得新」写成「首次提出」。
- 把探索性分析包装成验证性结论；把相关性写成因果。
- 未经用户确认就替其决定：目标资助方、是否预注册、是否报专利、是否缩范围。
- 在材料里留下未标注的空白字段（空白会被下游当成「无需填」）。

## 五、模板与校验

### 5.1 FINER / PICO 判定表

| 维度 | 问法 | 通过判据 | 不通过处置 |
|---|---|---|---|
| F 可行 | 三个月内能拿到第一批可分析数据吗 | 是，或能给出缩减版 | 缩范围或换设计 |
| I 有趣 | 同行会想知道答案吗 | 能举出两个具体的人或组 | 回到选题发散 |
| N 新颖 | 与最近三篇的差异落在哪一轴 | 至少命中一轴 | 转查新流程 |
| E 伦理 | 涉及人与动物吗 | 有审查档位与同意方式 | 转伦理流程 |
| R 相关 | 回答它改变什么决策或做法 | 能写出一句 | 重写问题 |

PICO 四栏：人群 / 暴露或干预 / 对照 / 结局；实验研究换成：对象与体系 / 干预或操作 / 对照条件 / 读出指标。四栏各一句，术语不重复。

```
假说 H1/H2/H3（互为竞争，机制不同）：
  H1：<机制一句话>
    预测：方向 <↑/↓/无差异>｜幅度 <效应量级或「待 pilot 定」>｜成立条件 <…>
    区分观测：<只有 H1 预测、H2 不预测的那一个观测>
    被证伪时看到：<…>
    最弱一维（七条质量标准）：<…>
需要的数据：<…>
最强反对：<…>
```

### 5.4 致命缺陷审计表

| # | 缺陷 | 检出规则 | 严重级 | 辩护路径 |
|---|---|---|---|---|
| 1 | 核心机制已被数据驳倒 | 有直接反例指向该机制 | 致命 | 无（转方向） |
| 2 | 新颖性只是标题相似 | 三组查询式内出现同题论文 | 致命 | 落差异轴并给 delta 句 |
| 3 | 依赖未披露的有利设置 | 增益可被更强基座或更宽数据解释 | 重大 | 补消融或降主张范围 |
| 4 | 能力与生命周期不匹配 | 有效投入时间短于该类研究常规周期 | 重大 | 缩范围或换承担方式 |

五维打分表：维度（更高/更快/更强/更省/更广）× 分数（1～10）× 证据（实测引用 / 机制推断未验证 / 无依据），**无依据一律 5 分**。

### 5.6 标书章节骨架与机构差异

| 章节 | 必含内容 | 常见失分点 |
|---|---|---|
| 立项依据 / 研究现状 | 领域进展 → 具体缺口 → 为何现在能解 | 只综述不设缺口；缺口语焉不详 |
| 科学问题与假说 | 一句问题 + 2～3 条可检验假说 | 问题过大；假说写成目标 |
| 总目标与具体目标 | 总目标一句，具体目标 2～4 条各有交付物 | 目标并列而非递进；无交付物 |
| 研究内容与方法 | 每个目标配方法模块，写设计与分析思路 | 目标—方法错位；方法缺判据 |
| 预期结果 | 每条目标对应可观测结果与判断标准 | 写成「将取得成功」 |
| 创新点 | 相对谁、在哪一轴、带来什么可检验好处 | 「首次」「填补空白」 |
| 可行性 | 团队 / 条件 / 前期基础分三块 | 混成一段泛泛而谈 |
| 风险与备选 | 每类风险一条缓解与一条替代路线 | 罗列风险不给替代 |
| 工作基础 | 前期数据与已发表工作，逐条对应本申请 | 与申请内容脱节 |
| 经费与进度 | 按科目给理由，按年度给里程碑与交付物 | 金额无理由；进度无交付物 |

机构口径差异（结构层面，不含当年政策）：

| 体系 | 关键章节 | 评审侧重 |
|---|---|---|
| NSF | 摘要一页、项目描述十五页、数据管理计划、预算说明 | 学术价值与广泛影响等权，前期数据受期待 |
| NIH | 具体目标一页、研究策略十二页（意义/创新/方法） | 三条打分；方法须含样本量、分析计划、替代策略 |
| 国家自然科学基金 | 立项依据、研究内容与目标、方案、可行性、创新性、预期成果、研究基础 | 科学意义、创新性、可行性、队伍；研究基础权重高 |
| ERC / KAKENHI 等 | 扩展摘要加主体、工作包与年度里程碑、人权保护 | 高风险高回报；学术重要性、独创性、计划妥当性 |

### 5.7 评审自检表（十行链条）

`科学问题 ← 假说 ← 总目标 ← 具体目标 ← 内容 ← 方法 ← 预期结果 ← 创新点 ← 可行性 ← 风险与备选`

三问（每条落到页码或章节）：①每一环能否指到上下相邻两环？②有没有哪一环只有形容词没有对象？③若某个具体目标失败，其余目标是否仍能交付价值？

### 5.8 伦理材料包清单与预注册判定

| 材料 | 必含 | 待补占位 |
|---|---|---|
| 伦理申请表主体 | 背景、方案、风险受益、保密、同意、数据管理 | 批号、审查档位、提交日期 |
| 知情同意书 | 八要素齐全 | 研究者与伦理委员会联系人 |
| 脱敏方案 | 直接标识删除、准标识泛化、编号替换、残留核查 | 数据存放与访问权限 |
| 预注册草稿 | 假设编号、分析计划、排除与停止规则、阳性判据 | 平台与注册号 |
| 稿件声明段 | 审查类型与批号、同意方式、数据可得性、利益冲突、AI 使用 | 机构名与批号 |
| 动物实验补充 | 3R、麻醉、安乐死方式、痛苦分级、饲养条件 | 伦理批号、许可证 |

| 情形 | 结论 | 要写的话 |
|---|---|---|
| 原创数据收集/实验/田野 | 应当预注册 | 按平台模板写全量分析计划 |
| 纯归纳质性/档案史学 | 不适用 | 显式声明「探索性设计，未预注册」 |
| 二手数据：只下载未看 | 可全量预注册 | 写全部分析计划 |
| 二手数据：看过描述统计 | 部分预注册 | 注明已看内容与探索范围 |
| 二手数据：已分析过 | 不能确证 | 全部标探索性并如实披露 |

### 5.9 校验

- 包内结构自检：`node scripts/verify-capabilities.mjs ideation`，须 0 错误。
- 文档自检：七节标题齐全且顺序不变；gates 九条逐条可判；无「可参考某某技能」式空话；未把某个具体数字写成既定事实。
- 占位规范：未定硬事实统一写成【机构名】【伦理批号】【申报年度指南】这类全角方括号占位，并在交付物末尾附「待用户补全」表。
